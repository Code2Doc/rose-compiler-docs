Adds a FailSafe attribute to a specified SgNode.

This function attaches a FailSafe::Attribute object to an attribute list associated with the provided SgNode. If the node does not already possess an attribute list under the name "FailSafeAttributeList", a new AttributeList is instantiated, attached to the node, and then the specified attribute is appended to this list.

Parameters
attributeA pointer to the FailSafe::Attribute to be added to the list.
nodeA pointer to the SgNode to which the attribute will be attached.
Precondition
attribute must not be NULL.
node must not be NULL.
node must be an instance of SgLocatedNode (or a subclass thereof) to allow location-based processing.
Postcondition
The attribute is appended to the AttributeList associated with the node.
If no "FailSafeAttributeList" existed on the node, a new AttributeList is created and stored on the node.
Note
This function uses ROSE_ASSERT to validate that both the attribute and the node (as a located node) are valid.

void FailSafe::parse_directives_to_attributes ( SgSourceFile * sageFilePtr)

Parse failsafe directives and generate/attach attributes.

Parses pragma directives within a source file to extract and attach FailSafe attributes.

This function iterates through the AST of a given source file to identify pragma declarations that use the "failsafe" keyword. For C/C++ source files, it queries the subtree for all nodes of type V_SgPragmaDeclaration. For each identified pragma, it expands macro calls within the pragma string to ensure the directive is correctly parsed. If the pragma starts with the "failsafe" key, the function parses the directive's specific parameters and attaches the resulting FailSafe attributes to the pragma declaration node.

Parameters
sageFilePtrA pointer to the SgSourceFile representing the source file to be parsed. The pointer must not be NULL.
Precondition
sageFilePtr must not be NULL.
Postcondition
If "failsafe" pragmas are found, they are added to the FailSafe::pragma_list and their associated attributes are attached to the corresponding SgPracmaDeclaration nodes.
Note
Currently, the implementation contains placeholders for handling Fortran-specific language extensions (F77, F90, F95, F2003), which are not yet implemented.
The function relies on SageInterface::replaceMacroCallsWithExpandedStrings to handle preprocessor expansions within pragma strings.

void FailSafe::process_fail_safe_directives ( SgSourceFile * sageFilePtr)

Processes fail-safe directives within a given source file.

This function handles the lifecycle of fail-safe directive processing. It performs three primary stages: first, it parses the directives found in the provided source file and generates corresponding attribute information; second, it constructs dedicated Abstract Syntax Tree (AST) nodes to represent these directives; and third, it performs the translation of these fail-safe AST nodes into their final representation. The function also provides logging capabilities if the global SgProject verbosity level is set higher than 1.

Parameters
sageFilePtrA pointer to the SgSourceFile object representing the source file to be processed.
Precondition
sageFilePtr must not be NULL.
Postcondition
The attributes for the directives in sageFilePtr are updated, and dedicated AST nodes are built and translated.
Note
This function relies on the internal implementation of parse_directives_to_attributes to populate the initial attribute data.
