Recursively filters out nodes from an access set based on member function criteria.

This function performs a depth-first traversal of a set of access set records. It evaluates each node in the provided set and its children. A node is removed from the set if its associated child set becomes empty after the recursive call and the node meets specific criteria (being a member function, a pointer arrow access, or a field access). During the removal of a member function node, the function's declaration is extracted and its compiled internal name is added to the called functions list within the provided record.

Parameters
thisSetA reference to a set of AccessSetRecord objects to be filtered. The function modifies this set in-place by erasing nodes.
recordA reference to a FunctionReadWriteRecord object used to track the called functions discovered during the filtering process.
Precondition
The thisSet parameter must contain valid AccessSetRecord elements.
Postcondition
The thisSet parameter will be modified such that nodes meeting the deletion criteria (empty child set and specific access/type properties) are removed. The record.calledFunctions set will be updated with function names if a MEMBER_FUNCTIONS node is deleted.
Note
This function uses a post-order traversal logic, meaning it deletes items as it recurses back out of the tree structure.

void filterPlainFunctions ( std::set< ReadWriteSets::AccessSetRecord > & thisSet)

Removes empty function access records from the provided set.

This function iterates through a set of AccessSetRecord objects and identifies records where the variable type is specifically set to FUNCTIONS and the associated fields collection is empty. Such records are considered "plain" functions with no specific field access and are removed from the set to clean up the data structure.

Parameters
thisSetA reference to a set of ReadWriteSets::AccessSetRecord objects to be filtered.
Precondition
thisSet should be a valid, initialized std::set of ReadWriteSets::AccessSetRecord.
Postcondition
The input set will no longer contain any AccessSetRecord elements that have a varType of FUNCTIONS and an empty fields collection.
Note
The function uses the iterator-based erase pattern to safely remove elements while traversing the container.

bool isJustALocalStructDecl ( SgInitializedName * initName)

Determines if an initialized name represents a local structure declaration.

This function checks the structural hierarchy of the provided SgInitializedName node. It verifies if the parent of the initialized name is a variable declaration, and if that declaration's parent is a class definition. Furthermore, it validates that the class definition is contained within an SgBasicBlock, which characterizes the declaration as a local structure within a block scope.

Parameters
initNameA pointer to the SgInitializedName node to be inspected.
Returns
True if the initialized name is part of a variable declaration within a class definition that is enclosed in an SgBasicBlock; false otherwise.
Precondition
initName must not be a null pointer.
Postcondition
The state of the SgInitializedName and its parent nodes remains unchanged.
Note
This function relies on the structural integrity of the Sg tree and the correctness of the parent-child relationships established during parsing.

This is an attempt to get around a bug in the RWSets that come back from Qing's code. If a struct is declared inside a function, that comes back as a write to just an SgInitializedName. Which gets labeled as a local variable, sans the surrounding struct.

Overloads the stream insertion operator to serialize a LocalRWSetGenerator object.

This function provides a way to output the contents of a LocalRWSetGenerator to an output stream, typically for logging or file serialization. The implementation checks if the internal rwSetCache is empty. If the cache is empty, it outputs an empty JSON object "{}" to ensure compatibility with JSON parsers (like nlohmann/json) that may encounter issues with empty files. If the cache contains data, it utilizes the ReadWriteSets::convertCacheToJson method to format the cache as a JSON string with an indentation of 4 spaces.
