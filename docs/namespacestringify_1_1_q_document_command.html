This function provides access to a constant, static vector of 64-bit integers. The vector is initialized with a fixed set of values ranging from 0 to 4. Because the vector is declared as static, it is initialized only once during the first call to the function and persists for the lifetime of the program.

Converts a command identifier integer into its corresponding string representation.

Convert QDocumentCommand::Command enum constant to a string.

This function maps specific 64-bit integer values to their human-readable string equivalents used within the QDocumentCommand context. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the command ID to be stringified.
Returns
A pointer to a constant character string representing the command name. Returns "None" for 0, "Insert" for 1, "Erase" for 2, "Replace" for 3, and "Custom" for 4. Returns an empty string "" if the input does not match any of the predefined cases.
Precondition
The input parameter i should ideally be one of the defined command constants.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function does not handle values outside the range 0-4 with specific labels, returning an empty string instead.

Generates a formatted command string with an optional prefix removal.

Convert QDocumentCommand::Command enum constant to a string.

This function retrieves a command string associated with a specific 64-bit integer ID. It first attempts to call an overloaded version of Command(int64_t). If the resulting string is empty, it constructs a fallback string in the format "(QDocumentCommand::Command)" followed by the string representation of the ID using boost::lexical_cast. Finally, if the generated string starts with the provided strip string, that prefix is removed.

Parameters
iThe 64-bit integer identifier used to look up or construct the command string.
stripA string representing the prefix to be removed from the start of the generated command string if it exists.
Returns
A string containing the formatted command, potentially with the specified prefix stripped away.
Precondition
The parameter strip should be a valid string.
Postcondition
The returned string will not start with the contents of strip if strip was a prefix of the original command.
Note
This function relies on the existence of an overloaded Command(int64_t) function and the boost::lexical_cast and boost::starts_with utilities.
