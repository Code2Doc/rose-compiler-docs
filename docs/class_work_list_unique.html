Detailed Description

template<typename T, class Compare = std::less<T>>
class WorkListUnique< T, Compare >

A version of WorkList that checks for uniqueness by default. The insertion methods check for item uniqueness and do not insert the item if it currently exists in the list. The uniqueness checking can be disabled per insert operation by specifying a false value for the check_uniqueness argument. Insertions and existence are O(log N) regardless of whether uniqueness checks are performed. Such a worklist internally stores two copies of every element.
