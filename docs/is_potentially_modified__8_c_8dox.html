Checks if a node or its components refer to the same non-constant variable as the provided expression.

This function performs a recursive traversal of the provided SgNode to determine if it contains a reference to the same underlying symbol as the given SgExpression. The function handles assignment initializers by unwrapping them to their operands. It specifically checks for identity between nodes and compares the declarations of variable references. If the node is a dot expression, the function recursively checks the left-hand side operand of the dot expression.

Parameters
nA pointer to the SgNode to be inspected for non-constant references.
lhsA pointer to the SgExpression to compare against the node n.
Returns
True if the node n or its constituent parts refer to the same declaration as lhs, or if n and lhs are identical; false otherwise.
Precondition
n and lhs should not be null pointers.
Postcondition
The function does not modify the state of the provided SgNode or SgExpression.
Note
The function uses recursion to traverse dot expressions (isSgDotExp).

Checks if the address of a specific expression has been taken within a given node tree.

Does expression expr potentially have its address taken somewhere in the tree pointed to by root?

This function determines whether the expression provided by expr is subject to an address-of operation or is part of a pointer-related expression (such as a pointer array reference or pointer dereference) within the scope of the root node. It first performs a local check on the expression itself to see if it is inherently an address-taking expression. If not, it utilizes a HasAddressTakenVisitor to traverse the root tree in preorder to search for any occurrences where the address of expr is taken.

Parameters
exprThe expression whose address is being checked for being taken.
rootThe root node of the tree to be traversed during the search.
Returns
True if the address of expr is found to be taken within the root tree or if expr is a pointer array reference or pointer dereference expression; false otherwise.
Precondition
expr and root should be valid, non-null pointers to SgExpression and SgNode objects respectively.
Postcondition
The state of the root tree remains unchanged.
Note
The traversal uses a preorder strategy via the HasAddressTakenVisitor.

Determines if an assignment initializer is being used to initialize a non-const reference variable.

This function checks whether the provided initializer n is initializing a reference variable that is non-const and whether the expression expr contains a non-const use of the variable. The implementation extracts the string representation of the expression (or the symbol name if it is a variable reference) and traverses the parent hierarchy of the initializer to identify the underlying initialized name and its type.

Parameters
nA pointer to the SgAssignInitializer representing the assignment/initialization node.
exprA pointer to the SgExpression that serves as the initializer.
Returns
True if the initializer refers to a non-const reference variable and the expression contains a non-const use; false otherwise.
Precondition
The parent of n must be an instance of SgInitializedName.
The identified SgInitializedName must have a valid type.
Postcondition
The function does not modify the state of the provided SgAssignInitializer or SgExpression.
Note

This function performs a traversal of the provided SgNode tree starting from the root to detect if the target SgExpression is subject to modifications. It utilizes the IsPotentiallyModifiedVisitor pattern to perform a preorder traversal of the AST. The visitor checks for any operations or assignments that could alter the state or value of the expression in question.

Parameters

rootA pointer to the SgNode that serves as the root of the tree to be traversed.
Returns
True if the expression is found to be potentially modified during the traversal; otherwise, false.
Precondition
The pointers expr and root should be valid, though the function handles a null root by returning false.
Postcondition
The state of the root node tree remains unchanged after the traversal.
Note
If root is NULL, the function immediately returns false without performing any traversal.
