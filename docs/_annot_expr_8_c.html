SymbolicVal ReadSymbolicExpr ( int level,
istream & in )

Parses and constructs a symbolic expression from an input stream based on operator precedence.

This function implements a recursive descent parsing strategy to reconstruct symbolic mathematical expressions. It reads a symbolic term and then iteratively checks for subsequent binary operators. If an operator is found with a precedence level higher than the current level, the function recursively calls itself to parse the next operand and applies the corresponding arithmetic or functional operation (multiplication, addition, subtraction, division, or custom symbolic functions) to the accumulated result.

Parameters
levelThe current precedence level threshold. Only operators with a precedence level strictly greater than this value will be processed in the current loop.
inThe input stream from which the symbolic expression is being read.
Returns
A SymbolicVal object representing the parsed and constructed symbolic expression.
Precondition
The input stream in must be in a valid state and positioned at the start of a valid symbolic expression or term.
Postcondition
The input stream in will have advanced past the parsed symbolic expression.
Note
This function relies on helper functions ReadSymbolicTerm, peek_ch, is_operator, and read_operator to handle the underlying stream parsing and operator identification.

SymbolicVal ReadSymbolicTerm ( istream & in)

Parses a single symbolic term from an input stream.

This function implements a recursive descent parser to interpret symbolic expressions from a character stream. It identifies various symbolic constructs including parenthesized expressions, numeric constants (integers and floats), identifiers (variables, functions, and special operators like min/max), unary operators, member access via dot notation, function pointer calls, and array indexing.

The parser handles:

  • Parenthesized expressions via recursive calls to ReadSymbolicExpr.
  • Numeric literals, distinguishing between 'int' and 'float' based on the presence of a decimal point.
  • Identifiers, including special handling for 'min' and 'max' functions, and general function calls or variable declarations.
  • Unary operators such as the negation operator.
  • Member access (fields or member functions) using the '.' operator.
  • Array access using the '[]' syntax.
Parameters
inThe input stream from which the symbolic term is to be parsed.
Returns
A SymbolicVal object representing the parsed symbolic term (e.g., SymbolicConst, SymbolicVar, SymbolicFunction, etc.).
Precondition
The input stream in must be in a valid state and positioned at the start of a valid symbolic term.
Postcondition
The input stream in will have advanced past the parsed symbolic term.
Note
The function relies on helper functions such as peek_ch, read_ch, is_num, read_num, is_id, read_id, is_operator, and read_operator to perform low-level stream processing.
