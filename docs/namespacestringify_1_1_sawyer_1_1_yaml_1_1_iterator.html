Convert Sawyer::Yaml::Iterator::eType enum constant to a string.

This function retrieves the string representation of an enum value using the overloaded eType(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a specific class path and the integer value. Additionally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer value representing the enum type to be converted.
stripA string representing the prefix to be removed from the start of the generated type string if it exists.
Returns
A string containing the formatted enum type name, potentially with the strip prefix removed.
Precondition
The input i should correspond to a valid enum value recognized by the underlying eType(int64_t) implementation for optimal results.
Postcondition
The returned string will not start with the strip substring if the original string contained it.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
