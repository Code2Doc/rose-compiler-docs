timeval getCPUTime ( )

Retrieves the user CPU time consumed by the current process.

This function utilizes the getrusage system call with the RUSAGE_SELF flag to extract resource usage statistics for the calling process. It specifically extracts the user time component (ru_utime) from the rusage structure.

Returns
A timeval structure representing the amount of time spent executing in user mode.
Precondition
The system must support the getrusage function call.
Postcondition
Returns a valid timeval structure containing the user CPU time.
Note
This function only tracks user-mode CPU time and does not include system-mode CPU time or I/O wait time.

Checks if two sets of SgGraphNode pointers have no elements in common.

This function determines whether the intersection of two sets of SgGraphNode pointers is empty. The implementation uses a two-pointer approach (iterators) to traverse both sets simultaneously. Since std::set is inherently ordered, the algorithm compares elements at the current iterators and advances the iterator pointing to the smaller element. An optimization is included to check the boundaries of the sets (comparing the smallest element of one to the largest of the other) to potentially return true early.

Parameters
set1The first set of SgGraphNode pointers to compare.
set2The second set of SgGraphNode pointers to compare.
Returns
True if the two sets are disjoint (contain no common elements), false otherwise.
Precondition
The elements within the sets must be comparable via the standard operators used by std::set.
Postcondition
The state of the input sets remains unchanged.
Note
The time complexity is O(n + m), where n and m are the sizes of the respective sets.

Calculates the elapsed time between two timeval structures in seconds.

This function computes the difference in time between a given end timestamp and a beginning timestamp. The calculation converts the microsecond component of each structure into seconds by dividing by 1,000,000 and adds it to the seconds component before performing the subtraction. This provides a high-precision floating-point representation of the duration.

Parameters
endThe end timestamp structure containing seconds and microseconds.
beginThe start timestamp structure containing seconds and microseconds.
Returns
The difference between the end and begin timestamps expressed in seconds.
Precondition
The end timestamp should represent a point in time equal to or later than the begin timestamp to ensure a non-negative result.
Postcondition
The returned value represents the duration in seconds with microsecond precision.
Note
The precision of the result is limited by the precision of the tv_usec field in the timeval structures.
