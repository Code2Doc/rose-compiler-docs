ROSE_DLL_API bool SgTreeTraversal_inFileToTraverse ( SgNode * node,
bool traversalConstraint,
SgFile * fileToVisit )

Determines whether a specific AST node should be traversed based on file constraints.

This function implements a heuristic-based decision process to decide if the traversal should proceed into a given node. The logic considers whether a traversal constraint is active, whether the node belongs to a specific file, and whether the node represents "code" versus "header" content. It specifically handles edge cases involving compiler-generated code, transformation-generated code, and nodes lacking file information (such as SgProject or certain Java/Asm nodes).

The heuristic for identifying "code" (as opposed to headers) is based on the node's parent: if the node is not in the global scope and not within a namespace definition, it is treated as code and traversed.

Parameters
nodeThe current AST node being evaluated for traversal.
traversalConstraintA boolean flag indicating if a specific file traversal constraint is active.
fileToVisitThe SgFile object representing the target file that the traversal is constrained to.
Returns
True if the node should be traversed; false otherwise.
Precondition
node must not be NULL.
Postcondition
The return value indicates the decision for the traversal engine.
Note
The function uses ifdef ROSE_ENABLE_BINARY_ANALYSIS to include additional checks for SgAsmNode when binary analysis is enabled.
Nodes with NULL file information are permitted to pass if they are identified as SgProject, SgJavaImportStatementList, or SgJavaClassDeclarationList.

The function uses a heuristic where nodes included from global scope or namespace definitions are treated as "headers" and may be skipped, unless they are explicitly part of the target file or are compiler-generated.
