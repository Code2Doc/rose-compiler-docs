Generates a human-readable string representation of an attribute's full name and type.

This function constructs a descriptive string that identifies an attribute by its name (derived from its ID) and its associated class type. It handles cases where the attribute pointer is null or the ID is invalid. If the attribute pointer is valid, it attempts to retrieve the class name via the attribute_class_name() method. If the class name is not overridden from the base "AstAttribute", it flags the type as unknown.

Parameters
valueA pointer to an AstAttribute object. If NULL, the function returns a null attribute message.
idThe unique identifier for the Sawyer attribute.
Returns
A string containing the formatted name and type information of the attribute.
Precondition
value may be NULL.
Postcondition
The returned string is a valid, non-empty std::string.
Note
The function uses StringUtility::cEscape to ensure that special characters in the attribute name or class name are properly escaped for display.

Deletes an attribute value based on its ownership policy.

This function manages the memory deallocation of an AstAttribute object. It inspects the ownership policy of the provided attribute to determine whether the memory should be explicitly deleted, or if a warning should be issued regarding potential memory leaks or unknown ownership.

The function handles the following ownership policies:

  • CONTAINER_OWNERSHIP: The memory is explicitly deleted using the delete operator.
  • NO_OWNERSHIP: The memory is not deleted, and a warning is logged if a memory leak is detected.
  • CUSTOM_OWNERSHIP: The function assumes the subclass handles its own memory management.
  • UNKNOWN_OWNERSHIP: A warning is logged indicating that ownership is unknown, which may lead to a leak. The function also provides a one-time instructional message on how to properly implement the ownership policy.
Parameters
valueA pointer to the AstAttribute to be deleted. If the pointer is NULL, no action is taken.
idThe unique identifier for the attribute, used for logging and identification.
Warning
If the ownership policy is set to NO_OWNERSHIP and a leak is detected, a warning is emitted to the mlog.
If the ownership policy is UNKNOWN_OWNOWNSHIP, a warning is emitted regarding potential leaks and instructions for fixing the policy.
Precondition
The value pointer should be a valid pointer to an AstAttribute or NULL.
Postcondition
If the ownership policy is CONTAINER_OWNERSHIP, the memory pointed to by value is deallocated.
Note
The instructional message for UNKNOWN_OWNERSHIP is displayed only once per program execution via a static boolean flag.

Determines whether a specific warning should be emitted for a given attribute ID.

This function checks if a specific warning type has already been recorded for the provided attribute ID within the global tracking container wasEmitted_. It utilizes a two-step insertion process into a nested container structure (a Map of Sets). The function effectively tracks unique pairs of Attribute IDs and WarningTypes.

Parameters
idThe unique identifier of the attribute being checked.
warningThe type of warning to be evaluated for emission.
Returns
True if the specific warning for the given attribute ID has not been recorded previously; false if this specific warning/ID pair already exists in the tracker.
Precondition
The global container wasEmitted_ must be properly initialized and accessible.
Postcondition
If the function returns true, the pair (id, warning) is guaranteed to be present in the wasEmitted_ container.
Note
This function relies on the insertMaybeDefault and insert operations of the Sawyer::Container classes to manage the state of emitted warnings.
