Aggregates multiple MetricAttr objects into a single sum.

This function iterates through a list of synthesized attributes and computes their cumulative sum. It initializes a new MetricAttr object with the provided attribute name and a zeroed value, then uses the overloaded += operator to accumulate the values from each element in the provided attribute list.

Parameters
attr_nameThe name of the attribute to be assigned to the resulting MetricAttr object.
attr_listA list of synthesized MetricAttr objects to be summed together.
Returns
A single MetricAttr object representing the sum of all attributes in the list.
Precondition
The attr_list must contain valid MetricAttr objects that support the += operator.
Postcondition
A new MetricAttr object is returned containing the aggregated value of the input list.
Note
The summation process relies on the implementation of the addition operator for the MetricAttr class.
