void Backstroke::writeCFGEdge ( std::ostream & out,
const CFGEdgeType & e )

This function helps to write the DOT file for edges.

Writes a formatted Graphviz-style edge label to an output stream.

This function formats a Control Flow Graph (CFG) edge as a Graphviz attribute string. It extracts the string representation of the edge using the edge's toString() method, escapes any special characters to ensure valid Graphviz syntax, and wraps the result in a label attribute with a solid line style.

Parameters
outThe output stream where the formatted edge string will be written.
eThe CFG edge object containing the data to be represented. The object must implement a toString() method and be compatible with escapeString().
Precondition
The edge object e must have a valid toString() method available.
Postcondition
The output stream out will contain a string in the format: [label="<escaped_string>", style="solid"]
Note
This function relies on an external escapeString function to handle special characters within the edge's string representation.

template<class CFGNodeType>
void Backstroke::writeCFGNode ( std::ostream & out,
const CFGNodeType & cfgNode )

This function helps to write the DOT file for vertices.

Writes a formatted DOT-style representation of a Control Flow Graph (CFG) node to an output stream.

This function generates a string suitable for Graphviz DOT format, representing a single node in a CFG. It determines the node's color based on the underlying SgNode type (e.g., blue for statements, green for expressions, red for initialized names). It also handles the generation of labels by unparsing the node content, with special handling for function definitions to label entry and exit points. The node style (solid or dotted) is determined by whether the CFG node is marked as "interesting".

Parameters
outThe output stream where the formatted node string will be written.
cfgNodeThe CFG node object containing the underlying SgNode and metadata such as index and interest status.
Precondition
The underlying SgNode retrieved from cfgNode must not be null, as the function performs a ROSE_ASSERT on it.
Postcondition
The specified output stream out will contain a string representing a DOT node attribute list, including label, color, and style.
Note
The function performs string replacements on the unparsed node content to escape double quotes and backslashes to ensure valid DOT syntax.
For certain node types like SgScopeStatement, SgCaseOptionStmt, or SgDefaultOptionStmt, the label will instead show the class name in angle brackets.
