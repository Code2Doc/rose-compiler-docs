Parses and transforms pragma RHS conditions into a C++-compatible class reference format.

This function processes a string representing the right-hand side (RHS) of a pragma, specifically looking for parenthesized conditions. It identifies equality (==) or inequality (!=) operators within these parentheses and verifies that the variable being checked exists within the provided class fields. The function transforms simple variable names into a format that uses a classReference-> prefix, effectively preparing the string for use in a conditional statement. It also handles logical conjunctions such as '&' and '|' if they appear between subsequent conditions.

Parameters
unionFieldsA list of SgNode pointers representing the fields within a union.
classFieldsA list of SgNode pointers representing the fields within the class scope, used to validate the existence of control variables.
pragmaRHSA string containing the right-hand side of the pragma to be parsed.
Returns
A string formatted as an "if" statement containing the transformed conditions, e.g., "if( (classReference->var==val) & (classReference->var2!=val2) )".
Precondition
The variables referenced within the parentheses in pragmaRHS must be present in classFields as variable declarations.
Postcondition
The returned string is a valid C++ conditional expression string wrapped in an "if" block.
Warning
The function calls exit(1) and terminates the program if it encounters unsupported operators (other than == or !=) or if a variable name found in the pragma cannot be located in classFields.
The function uses ROSE_ASSERT to validate that variable declarations are found; if the assertion fails, the program will abort.
Note
The implementation relies on string searching for '(' and ')' to delimit sub-conditions.
The function specifically looks for the presence of '&' or '|' to handle chained logical conditions.

This function scans the beginning of the input string to identify any leading whitespace characters, specifically spaces, tabs, newlines, and carriage returns. It iterates through the string from the first character until it encounters a non-whitespace character, then returns a substring starting from that position to the end of the original string.

Parameters

Returns
A new string that is a copy of the input string with all leading whitespace characters removed.
Precondition

Postcondition
The returned string contains no leading characters found in the set " \t\n\r".
Note
The function uses std::string::find to check for whitespace and std::string::substr to perform the trimming operation.
