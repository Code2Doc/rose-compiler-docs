std::string Sawyer::Language::Clexer::toString ( TokenType tt)

Converts a TokenType enumeration value into its corresponding string representation.

This function performs a mapping from the TokenType enum to a human-readable string. It utilizes a switch statement to evaluate the provided TokenType and returns the appropriate string literal. If an unrecognized TokenType is encountered, the function triggers an assertion failure.

Parameters
ttThe TokenType value to be converted to a string.
Returns
A string containing the name of the token type (e.g., "eof", "left", "char").
Precondition
The input tt must be a valid member of the TokenType enumeration.
Postcondition
The returned string is a valid, null-terminated C-style string encapsulated in a std::string.
Warning
If the input tt does not match any of the defined cases in the switch statement, the function will call ASSERT_not_reachable, which typically terminates the program.
Note
This function is primarily used for debugging, logging, and error reporting where the textual representation of a token is required.
