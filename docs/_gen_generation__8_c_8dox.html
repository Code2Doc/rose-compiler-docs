NodeQuerySynthesizedAttributeType querySolverClassFields2 ( SgNode * astNode)

Retrieves a list of variable declarations within a class definition.

This function inspects a given AST node to determine if it represents a class definition. If the node is an instance of SgClassDefinition, the function iterates through all members of the class. It identifies and collects all members that are specifically variable declarations, aggregating them into a NodeQuerySynthesizedAttributeType container.

Parameters
astNodeA pointer to the SgNode to be queried. This node is expected to be a class definition for the function to perform its search.
Returns
A NodeQuerySynthesizedAttributeType containing a list of SgNode pointers, where each pointer refers to a variable declaration found within the provided class definition. If the node is not a class definition or contains no variable declarations, an empty list is returned.
Precondition
astNode must not be NULL.
Postcondition
The returned list contains only nodes that satisfy isSgVariableDeclaration.
Note
The function relies on the validity of the SgClassDefinition and its internal member list. It uses ROSE_ASSERT to ensure the input node is not null.

Searches for a specific variable name within a given AST node's variable declarations.

Queries a variable declaration node by matching a specific name.

This function inspects a provided AST node to determine if it contains a variable declaration matching the name provided in variableNameNode. It specifically checks if the astNode is of type V_SgVariableDeclaration. If it is, the function iterates through the list of initialized names within that declaration and compares each name to the target name. If a match is found, the astNode is added to the returned list.

Parameters
astNodeThe AST node to be inspected for variable declarations.
variableNameNodeAn SgNode representing the name of the variable to search for. This node must be an SgName object.
Returns
A NodeQuerySynthesizedAttributeType (a list of SgNodes) containing the astNode if a matching variable name is found within the declaration, otherwise an empty list.
Precondition
astNode must not be NULL.
variableNameNode must be a valid SgName object.
The string representation of variableNameNode must not be empty.
Postcondition
Returns a list containing astNode if the name matches, or an empty list if no match is found.
Note
The function uses ROSE_ASSERT to validate that variableNameNode is an SgName, that the extracted name is not empty, and that astNode is not NULL.

It iterates through the list of initialized names within the variable declaration and collects the astNode into a list if a name match is found.
