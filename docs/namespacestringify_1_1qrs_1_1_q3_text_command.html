const char * stringify::qrs::Q3TextCommand::Commands ( int64_t )

Converts a command identifier into its corresponding string representation.

Convert qrs::Q3TextCommand::Commands enum constant to a string.

This function maps a 64-bit integer ID to a human-readable string constant representing specific Q3 text commands. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer identifier representing the command.
Returns
A pointer to a constant character string representing the command name. Returns "Invalid" for 0, "Insert" for 1, "Delete" for 2, "Format" for 3, "Style" for 4, and an empty string "" for any other value.
Precondition
The input parameter i should ideally correspond to one of the defined command integer constants.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function does not handle any values outside the specified range with specific labels, returning an empty string for unknown IDs.

Generates a command string for a given ID and optionally removes a prefix.

Convert qrs::Q3TextCommand::Commands enum constant to a string.

This function retrieves a command string associated with the provided 64-bit integer ID by calling the overloaded Commands(int64_t) function. If the resulting string is empty, a default fallback string is constructed using the format "(qrs::Q3TextCommand::Commands)" followed by the string representation of the ID. Additionally, if the generated string starts with the specified strip string, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier used to look up or generate the command string.
stripA string representing the prefix to be removed from the start of the generated command string if it exists.
Returns
A string containing the command information, potentially with the strip prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present in the original command string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
