bool N::eq ( List< float > & f1,
List< float > & f2 )

Compares two lists of floats for equality.

This function iterates through both lists simultaneously, comparing the values of the current nodes. The comparison continues as long as the values at the current positions in both lists are identical. The function determines equality based on whether both list traversals reached the end of their respective lists (null pointers) at the same time.

Parameters
f1A reference to the first list of floats to be compared.
f2A reference to the second list of floats to be compared.
Returns
True if both lists contain the same sequence of values and have the same length; false otherwise.
Precondition
The lists f1 and f2 must be valid, initialized List objects.
Postcondition
The state of the lists f1 and f2 remains unchanged.
Warning
This function assumes that the lists are not null and that the traversal will eventually reach a null pointer. If the lists contain circular references, this function will enter an infinite loop.
Note
The comparison is performed element-wise using the equality operator for float values.

float N::head ( List< float > & fl)

Retrieves the value of the first element in a list of floats.

This function accesses the head node of the provided list and extracts the floating-point value stored within it. It assumes the list is not empty and that the head pointer is valid.

Parameters
flA reference to a List of floats from which the head value is retrieved.
Precondition
The list fl must not be empty. The head of the list must be a valid pointer to a node containing a value member.
Postcondition
The state of the list fl remains unchanged.
Warning
Accessing this function with an empty list will result in undefined behavior, such as a null pointer dereference.
