SgNode * SageUtils::walkupDots ( SgNode * current)

Recursively traverses up the AST to find the base object of a chain of dot or arrow expressions.

walkupDots

There's a bug in Qing's R/W sets in that it handles dot and arrow expressions weirdly. If you have a reference like a.b.c.d R/W sets returns just a.b. This makes it hard to get all the info we need. So This recursive function walks up the dot expressions to get the outtermost dot expression so we can interpret the whole reference.

This function performs a recursive upward traversal starting from the provided node. It checks the parent of the current node to determine if the parent is a member access expression (either a dot expression or an arrow expression). If the parent is such an expression, the function continues the traversal from that parent node. The recursion terminates when it reaches a node whose parent is not a dot or arrow expression, effectively finding the root object of the access chain.

Parameters
currentThe starting node from which the upward traversal begins.
Precondition
current must not be a null pointer.
Postcondition
Returns a pointer to the SgNode that represents the base of the member access chain.
Note
This function relies on the existence of a valid parent-child relationship in the AST and the availability of isSgDotExp and isSgArrowExp utility functions.
