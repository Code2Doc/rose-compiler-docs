Convert AstAttributeDOT::DOTStyles enum constant to a string.

Parameters

Generates a DOT-formatted style string for a given identifier with an optional prefix removal.

Convert AstAttributeDOT::DOTStyles enum constant to a string.

This function retrieves a DOT-formatted string representation for the provided 64-bit integer ID by calling an overloaded version of DOTStyles(int64_t). If the resulting string is empty, it constructs a fallback string in the format "(AstAttributeDOT::DOTStyles)ID". Additionally, if the generated string starts with the specified 'strip' prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier used to generate the base DOT style string.
stripA string representing the prefix to be removed from the start of the generated style string if it exists.
Returns
A string containing the processed DOT style representation.
Precondition
The 'strip' parameter should be a valid string.
Postcondition
The returned string will not start with the 'strip' prefix if the prefix was present.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
