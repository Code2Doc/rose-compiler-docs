Replaces all occurrences of a specified pattern within a string with a replacement string.

This function performs a global search-and-replace operation on the provided input string. It iteratively searches for the first occurrence of patternInInput using the string::find method. When a match is found, the substring is replaced by replacePattern using the string::replace method. The process continues until no more occurrences of the pattern are found in the modified string.

Parameters
patternInInputThe substring to be searched for within the input string.
replacePatternThe string that will replace each occurrence of the pattern.
inputThe original string that is to be processed.
Returns
A new string where all instances of patternInInput have been replaced by replacePattern.
Warning
If replacePattern contains patternInInput, this function will enter an infinite loop because the pattern will be found repeatedly in the newly replaced segments.
Precondition
The input string and patterns should be valid std::string objects.
Postcondition
The returned string contains no instances of patternIn substring that were present in the original input, provided the replacement does not re-introduce the pattern.
Note
The complexity of this function depends on the number of occurrences found and the length of the strings involved, as each replacement may require shifting subsequent characters in the string.
