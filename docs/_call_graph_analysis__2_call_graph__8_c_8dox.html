◆ get_type_vector()

std::vector< SgType * > get_type_vector ( SgType * currentType)

Retrieves a sequence of types representing the hierarchy of the given type.

This function traverses the underlying type hierarchy of a provided SgType. It iteratively inspects the type to determine if it is a modifier, reference, pointer, array, or typedef type. For each layer of the type hierarchy discovered (such as pointers or references), the underlying type is extracted and added to the resulting vector.

The implementation specifically handles the unwinding of SgModifierType, SgReferenceType, SgRvalueReferenceType, SgPointerType, and SgArrayType. For SgTypedefType, the function traverses to the underlying type but removes the typedef itself from the vector to ensure typedefs are used for comparisons rather than being part of the structural hierarchy in the returned list.

Parameters
currentTypeA pointer to the starting SgType to begin the traversal.
Returns
A vector of SgType pointers containing the sequence of types encountered during the traversal, from the initial type down to the base type.
Precondition
currentType must not be null.
Postcondition
The returned vector contains a non-empty sequence of types if currentType is valid.
Note
The traversal continues until a type is encountered that does not have an underlying type (a base type) or is not one of the specifically handled derivatives.
There is a known todo regarding the handling of templated types and aliases.

It handles various C++ calling constructs, including direct function calls, member function calls (via dot or arrow operators), function pointers, and member function pointers. The implementation accounts for complex scenarios such as pointer dereferencing, comma operators, and constructor initializers. For polymorphic calls, it utilizes the provided class hierarchy to resolve potential overrides.
