Finds the nearest ancestor declaration statement that resides within a global scope.

This function traverses the parent hierarchy of a given declaration statement upwards. It searches for the most recent ancestor that is an SgDeclarationStatement and continues climbing the tree until it reaches a node that is identified as a global scope (via isSgGlobal). The algorithm effectively identifies the deepest declaration statement that is still part of the global scope hierarchy.

Parameters
fA pointer to the starting SgDeclarationStatement from which the upward traversal begins.
Returns
A pointer to the closest SgDeclarationStatement found within the global scope. Returns 0 (nullptr) if no global scope is encountered during the traversal or if the traversal reaches the root without finding a global node.
Precondition
f must not be null. The function uses ROSE_ASSERT to validate this.
Postcondition
The returned pointer, if not null, points to an SgDeclarationStatement that is an ancestor of f (or f itself) and is contained within a global scope.
Note
The function relies on the validity of the parent pointers within the SgNode hierarchy.
