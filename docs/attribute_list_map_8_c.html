NodeQuerySynthesizedAttributeType queryFloatDoubleValExp ( SgNode * astNode)

Retrieves a list of nodes representing floating-point or double-precision expression values.

Retrieves a list of nodes representing floating-point or double-precision constant expressions.

This function inspects a given AST node to determine if it represents a floating-point constant (float, double, or long double). It checks the variant type of the provided node and, if it matches one of the specified floating-point variants, adds the node to a returned list of synthesized attributes.

Parameters
astNodeA pointer to the SgNode to be queried.
Returns
A NodeQuerySynthesizedAttributeType containing a list of nodes that match the floating-point variants. If the node is not a floating-point variant, an empty list is returned.
Precondition
astNode must not be null.
Postcondition
The returned list contains the input astNode if its variant is V_SgDoubleVal, V_SgLongDoubleVal, or V_SgFloatVal; otherwise, the list is empty.
Note
This function uses ROSE_ASSERT to validate that the input pointer is non-null.
