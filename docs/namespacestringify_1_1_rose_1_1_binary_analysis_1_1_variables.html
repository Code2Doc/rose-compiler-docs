Retrieves a string representation of a variable access and optionally strips a prefix.

Convert Rose::BinaryAnalysis::Variables::Access enum constant to a string.

This function retrieves the string representation of a variable access using the single-parameter Access(int64_t) overload. If the resulting string is empty, it constructs a fallback string containing a specific namespace identifier and the integer ID. Additionally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe unique identifier for the variable access.
stripA string prefix that, if found at the start of the access string, should be removed.
Returns
A string representing the variable access, potentially modified by stripping the prefix.
Precondition
The parameter i should be a valid identifier for an existing access.
Postcondition
The returned string will not contain the strip prefix if it was present at the start.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
