void FixFileInfo ( SgNode * n)

Recursively updates and corrects file information for SgNodes.

This function traverses the Abstract Syntax Tree (AST) starting from the provided node n to ensure that the end-of-construction file information (filename, line, and column) is correctly propagated and populated.

The implementation performs the following steps:

  1. If the node is a function declaration with a valid definition, it updates the declaration's end-of-construction info based on the end of the function body.
  2. It recursively calls itself on all children of the current node.
  3. If the current node lacks end-of-construction information, it attempts to derive this information from the last non-null child node in its successor container.

This is particularly useful for ensuring that nodes representing scopes or blocks have accurate metadata for debugging or source-to-source translation.

Parameters
nA pointer to the SgNode to be processed. If the pointer is null, the function returns immediately.
Precondition
The input node n should be a valid pointer to an SgNode or null.
Postcondition
The end-of-construction file information for the node n and its descendants is updated or propagated where possible.
Note
This function performs a deep traversal of the node hierarchy.
