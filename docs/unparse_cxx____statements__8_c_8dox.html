Escapes a string specifically for use in assembly language unparsing.

This function provides a specialized version of string escaping designed for assembly strings. Unlike standard utility escape functions that might expand backslashes globally, this implementation ensures that escape sequences like "\n" and "\t" are preserved as literal substrings rather than being escaped into double-backslashes. The function iterates through the input string and maps specific control characters (such as double quotes, bell, form feed, newline, carriage return, tab, and vertical tab) to their escaped string representations. For non-printable characters not explicitly handled in the switch statement, the function converts them into an octal escape sequence format (\ooo).

Parameters

Returns
A new string containing the escaped version of the input string, suitable for assembly unparsing.
Precondition
The input string s should be a valid std::string.
Postcondition
The returned string contains the escaped characters, and the length of the returned string is greater than or equal to the length of the input string.
Note

Calculates the number of 'else' statements required to prevent dangling 'if' problems.

This function traverses the structure of a given SgStatement to determine how many 'else' clauses must be added to ensure that 'if' statements are properly closed and do not become dangling. The algorithm recursively inspects the bodies of various statement types. For statements that have a fixed end marker (like switch statements or blocks that cannot end with an unmatched if), it returns 0. For statements that contain nested structures (like for loops, while loops, or catch sequences), it recurses into the relevant body. Specifically, for an 'if' statement, if there is no 'else' body present, it increments the count and continues checking the 'true' body.

Parameters
sA pointer to the SgStatement to be analyzed.
Returns
The total number of 'else' statements needed to prevent dangling 'if' statements within the provided statement structure.
Precondition
s must not be NULL.
Postcondition
The returned value represents the count of required 'else' keywords to maintain structural integrity of if-else chains.
Note
The function uses a switch statement based on the variant type of the SgStatement. It relies on ROSE-specific casting functions like isSgIfStmt and isSgForStatement.

Adjusts the current scope within the unparse information object to ensure correct name qualification.

This function resets the current scope stored in the SgUnpan_Info object. This is necessary to ensure that name qualification during the unparsing process works correctly. The function examines the structural parent of the provided declaration statement to determine the appropriate scope. It handles various structural parent types such as SgTemplateInstantiationDirectiveStatement, SgVariableDeclaration, SgForInitStatement, SgTypedefDeclaration, and SgLambdaExp.

The implementation relies on the structural parent of the declaration statement rather than its semantic scope to compute name qualification. If the unparse information is configured to force qualified names, the scope reset is bypassed.

Parameters
ninfoA reference to the SgUnparse_Info object that holds the current unparsing state and scope.
declarationStatementA pointer to the SgDeclarationStatement whose parent's scope needs to be evaluated and potentially applied to the ninfo object.
Precondition
declarationStatement must not be NULL.
The parent of declarationStatement must not be NULL.
Postcondition
If forceQualifiedNames() is false in ninfo, the current scope in ninfo is updated to the scope derived from the structural parent of declarationStatement.
Note
This function uses ASSERT_not_null to validate the integrity of the AST nodes during traversal.
If the parent of the declarationStatement is a SgLambdaExp, the function attempts to find the scope of the enclosing statement.
Warning
If the parent of the declarationStatement does not match any of the handled variants (e.g., V_SgTemplateInstantiationDirectiveStatement, V_SgVariableDeclaration, V_SgForInitStatement, V_SgTypedefDeclaration, or V_SgLambdaExp), the function will trigger a ROSE_ABORT().

bool isOutputAsmOperand ( SgAsmOp * asmOp)

Determines whether a given assembly operand is an output operand.

This function evaluates if an SgAsmOp represents an output operand using one of two different mechanisms. The first mechanism is used when the operand descriptions record specific register details, allowing for a precise check via get_isOutputOperand(). The second mechanism is a more general, instruction-set-independent approach that relies on checking for the presence of the e_output modifier bit within the operand's modifiers. The string-based mechanism is less precise as it lacks detailed register information but remains portable across different architectures.

Parameters
asmOpA pointer to the SgAsmOp object to be inspected.
Returns
True if the operand is identified as an output operand; false otherwise.
Precondition
asmOp must not be a null pointer.
Postcondition
The state of the asmOp object remains unchanged.
Note
The precision of the check depends on whether the operand descriptions are recorded using raw register details or as strings.

Replaces all occurrences of a substring within a string with a new substring.

This function performs a global search-and-replace operation on the provided subject string. It iterates through the subject string, locating every instance of the search string and substituting it with the replacement string. The algorithm uses a while loop combined with std::string::find to identify positions and std::string::replace to perform the substitution. The search position is advanced by the length of the replacement string to prevent infinite loops in cases where the replacement string contains the search string.
