Overloads the stream insertion operator for the Hasher class.

Prints a hash to a stream. See Hasher::print.

This function provides a way to output the internal state or representation of a Rose::Combinatorics::Hasher object directly to an output stream. It delegates the actual formatting and printing logic to the Hasher::print method.

Parameters
outThe output stream where the hasher information will be written.
hasherThe Hasher instance to be streamed to the output.
Returns
A reference to the same std::ostream object, allowing for chained stream operations.
Precondition
The out stream must be in a valid state and writable.
Postcondition
The contents of the hasher, as defined by its print implementation, are written to the stream.
