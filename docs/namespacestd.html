Swaps the contents of two nlohmann::json objects.

This is a template specialization of the standard swap algorithm specifically for nlohmann::json objects. It provides an efficient way to exchange the internal state of two JSON objects by invoking the member swap function of the nlohmann::json class. This typically involves swapping pointers to the underlying data structures rather than performing a deep copy of the JSON tree.

Parameters
j1The first JSON object to be swapped.
j2The second JSON object to be swapped.
Precondition
The objects j1 and j2 must be valid, initialized nlohmann::json instances.
Postcondition
The contents of j1 and j2 are interchanged.
Note
The noexcept specification of this function is conditionally determined based on whether nlohmann::json is nothrow move constructible and nothrow move assignable.
