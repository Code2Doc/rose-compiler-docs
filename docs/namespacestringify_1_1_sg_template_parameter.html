Retrieves a constant vector containing the predefined template parameter enumeration values.

Return all SgTemplateParameter::template_parameter_enum member values as a vector.

This function provides access to a static collection of 64-bit integer values that represent the standard enumeration for template parameters. The values are hardcoded within the function scope and are stored in a static vector to ensure they persist for the lifetime of the program and are only initialized once.

Returns

Precondition

Postcondition

Note

Converts an integer identifier into its corresponding template parameter type string.

Convert SgTemplateParameter::template_parameter_enum enum constant to a string.

This function maps specific 64-bit integer values to string representations of template parameter categories. It uses a switch-case mechanism to perform the lookup based on the provided integer ID.

Parameters
iThe 64-bit integer representing the template parameter type.
Returns
A pointer to a constant character string representing the enum name. Returns "parameter_undefined" for 0, "type_parameter" for 1, "nontype_parameter" for 2, and "template_parameter" for 3. Returns an empty string "" for any other value.
Precondition
The input parameter i should be a valid identifier within the defined range.
Postcondition
The returned string is a static constant string literal.

Generates a formatted string representation of a template parameter enum.

Convert SgTemplateParameter::template_parameter_enum enum constant to a string.

This function retrieves the string representation of a template parameter index and optionally removes a specified prefix. It first calls the single-argument template_parameter_enum(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(SgTemplateParameter::template_parameter_enum)i". Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer representing the template parameter index.
stripA string representing the prefix to be removed from the start of the generated string if it exists.
Returns
A string containing the formatted template parameter name, potentially with the strip prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present at the start of the original generated string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix checking.
