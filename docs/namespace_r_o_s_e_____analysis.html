Constructs a Control Flow Graph (CFG) from a list of AST statements.

This function iterates through a provided list of AST nodes (statements) and applies a traversal operation to build the Control Flow Graph within the context of the provided AST interface. It utilizes the BuildCFGTraverse mechanism to process each node sequentially, updating the graph structure based on the configuration and the logic defined in the traversal operator.

Precondition

Postcondition

Constructs a Control Flow Graph (CFG) for a given AST node.

This function initiates the process of building a Control Flow Graph by utilizing a traversal operator. It encapsulates the logic of the CFG construction within the BuildCFGTraverse class, which performs a depth-first or structured traversal of the provided AST node to identify basic blocks and edges.

Parameters
faA reference to the AstInterface object used to manage and store the resulting CFG structure and associated metadata.
headA pointer to the root AstNode from which the CFG construction begins.
gA configuration object of type BuildCFGConfig<Node> that contains the settings, parameters, and algorithmic instructions for the construction process.
Precondition
The AstInterface object fa must be properly initialized and capable of receiving new graph nodes and edges.
The head node must be a valid, non-null pointer to an AST node.
Postcondition
The fa object will be updated with a newly constructed CFG representing the control flow of the subtree rooted at head.
Note
This function acts as a high-level wrapper around the BuildCFGTraverse functor to simplify the interface for CFG generation.
