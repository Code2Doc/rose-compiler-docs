const char * stringify::DependencyInfo::State ( int64_t )

Converts an integer status code into its corresponding string representation.

Convert DependencyInfo::State enum constant to a string.

This function maps specific 64-bit integer values to human-readable string literals representing the state of a dependency. It uses a switch-case mechanism to evaluate the input integer and return the appropriate constant character pointer.

Parameters
iThe 64-bit integer representing the state code to be stringified.
Returns
A pointer to a constant character string representing the state: "VALID" for 0, "INVALID" for 1, "ERROR" for 2, or an empty string "" for any other value.
Precondition
The input parameter i should ideally be one of the defined state constants (0, 1, or 2).
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function does not handle values outside the defined range with specific labels, returning an empty string instead.

Generates a formatted state string for a given identifier, optionally removing a prefix.

Convert DependencyInfo::State enum constant to a string.

This function retrieves a string representation of the state associated with the integer identifier i by calling the overloaded State(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(DependencyInfo::State)" followed by the string representation of i. Additionally, if the resulting string starts with the provided strip string, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier used to determine the state.
stripA string representing the prefix to be removed from the start of the generated state string if it exists.
Returns
A string representing the processed state, potentially with a prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present at the start of the original state string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
