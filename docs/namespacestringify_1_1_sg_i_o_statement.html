Converts an integer representation of an IO statement enum to its string name.

Convert SgIOStatement::io_statement_enum enum constant to a string.

This function performs a mapping from a 64-bit integer value to a corresponding string literal representing the IO statement type. It uses a switch-case implementation to compare the input value against predefined integer constants representing various IO operations such as read, write, open, and close.

Parameters
iThe 64-bit integer value representing the IO statement enum.
Returns
A pointer to a constant character string containing the name of the IO statement. Returns "e_unknown" for 0, specific names for values 1 through 10, and an empty string "" for any value not explicitly handled in the switch statement.
Precondition
None.
Postcondition
The returned string is a static string literal and does not require manual memory management.
Note
The mapping is limited to the specific integer values defined within the function's switch block.
