void generateModFile ( SgFile * sfile)

Generates Fortran 90 specific module files (*.rmod) for a given source file.

This function iterates through all module declarations found within the provided SgFile AST. For each module statement identified, it constructs an output filename (typically using a predefined suffix) and writes a specialized module file. The generated file contains variable definitions and function declarations necessary for separate compilation. The process utilizes an unparser with specific configuration flags, such as outputFortranModFile, to ensure the output is formatted correctly for Fortran 90 module compatibility. The function also handles directory path construction and ensures the output filename is converted to lower case.

Parameters
sfileA pointer to the SgFile object representing the source file being processed. This object must not be null.
Precondition
sfile must not be null.
Postcondition
For every SgModuleStatement found in sfile, a corresponding .rmod file is created on the filesystem containing the module's interface.
Warning
If the output file cannot be opened for writing, the function will trigger a ROSE_ABORT(), terminating the program.
Note
The function relies on the global SgProject::get_verbose() setting to determine whether to print progress messages to the standard output.
The output filename is constructed using the module name and a constant MOD_FILE_SUFFIX.
