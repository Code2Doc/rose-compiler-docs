Processes command-line arguments specifically for Fortran-related configurations.

Process all Fortran commandline options.

This function iterates through the provided command-line arguments to identify and apply settings relevant to Fortran processing within the Rose framework. It performs two primary tasks: first, it invokes ProcessFortranOnly to handle language-specific flags, and subsequently calls the Ofp::Process routine to handle OpenMP-related Fortran options. If the project's verbosity level is set higher than 1, an informational message is printed to the standard output.

Precondition
project must not be a null pointer.
Postcondition
The project state is updated based on the relevant flags found in argv.
Note
This function relies on the global verbosity setting of the SgProject to determine whether to log processing information.

Configures the project to Fortran-only mode based on command-line arguments.

This function inspects the provided command-line arguments for the presence of the "-rose:fortran" flag. If this flag is detected, the function updates the state of the provided SgProject object to enable Fortran-only processing. If the project's verbosity level is greater than 1, an informational message is printed to the standard output.

Parameters
projectA pointer to the SgProject instance that will be modified if the Fortran-only flag is found.
argvA vector of strings containing the command-line arguments to be parsed.
Precondition
project must not be a null pointer.
Postcondition
If the "-rose:fortran" option is present in argv, project->set_Fortran_only(true) will be called, effectively setting the Fortran-only flag to true in the project.
Note
This function relies on CommandlineProcessing::isOption to parse the arguments.

void Rose::Cmdline::Fortran::StripRoseOptions ( std::vector< std::string > & argv)

Removes ROSE-specific Fortran command-line options from the argument vector.

This function processes the command-line argument vector to identify and extract options that are prefixed with the ROSE-Fortran specific prefix. It utilizes CommandlineProcessing::generateOptionWithNameParameterList to parse the vector, stripping the ROSE-specific prefix from the identified options and re-inserting them into the original vector with a standard prefix. This effectively separates ROSE-specific configuration from standard Fortran compiler-style options.

Parameters
argvA reference to a vector of strings representing the command-line arguments. The vector is modified in-place by removing the prefixed ROSE options and appending the stripped versions.
Precondition
The argv vector should contain the raw command-line arguments as passed to the application.
Postcondition
The argv vector will no longer contain options starting with the Cmdline::Fortran::option_prefix, and those options will instead appear with a stripped prefix (e.g., "-").
Note
This function relies on the implementation of CommandlineProcessing::generateOptionWithNameParameterList to handle the actual parsing and prefix stripping logic.
This function also calls Cmdline::Fortran::Ofp::StripRoseOptions to perform additional downstream stripping of OFP-specific options.
