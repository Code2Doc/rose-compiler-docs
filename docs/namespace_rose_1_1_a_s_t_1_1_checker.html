Detailed Description

Auto-generated documentation for the Rose::AST::Checker namespace.

Checking function that apply to the whole AST.

Two categories of checker: integrity and consistency If integrity checker reports defects then the consistency checker might fail. Similarly, if the edges integrity checker reports defects then the other integrity checkers might fail.

Run all integrity checkers starting by the edge integrity checker then the other integrity checkers if the edges have no defect.

This function executes a series of validation passes to ensure the structural and semantic consistency of the SgProject. It sequentially verifies the integrity of edges, declarations, symbols, and types. The process follows a short-circuit logic where if any individual integrity check fails, the function immediately returns false to prevent unnecessary subsequent computations.

bool Rose::AST::Checker::integrity_edges ( SgProject * project)

for all valid node in the AST's graph check that the target of all edges are valid.

Verifies the integrity of edges within the project structure.

Parameters
project
Returns
true if no defect was found

Check the edges out of all allocated nodes in the memory pool. For each (non-null) edge, it looks for the pointer in all memory pools. If not found, an IntegrityEdgeDefect is produced with Reason::invalid. If found in an unexpected memory pool, an IntegrityEdgeDefect is produced with Reason::incompatible. If found but not marked as allocated, an IntegrityEdgeDefect is produced with Reason::unallocated. A single edge can yield two defects one with Reason::incompatible and the other with Reason::unallocated.

Any defect found is saved in Rose::AST::Defect::all (aka Rose::AST::Defects::defect_t<Defects::Kind::any>::all).

This function checks whether any defects were introduced during an edge integrity traversal process. It captures the initial count of all known defects, performs a traversal of the memory pool using the EdgeIntegrityTraversal mechanism, and then compares the final defect count to the initial count.

Parameters
projectA pointer to the SgProject instance to be checked.
Returns
True if the number of defects remains unchanged after the traversal, indicating no new integrity issues were detected; false otherwise.
Precondition
The SgProject pointer must be valid, and the Defect::all container must be initialized.
Postcondition
The state of the memory pool may be traversed, but the defect count is checked for consistency.
Note
This function relies on the EdgeIntegrityTraversal class to perform the actual memory pool inspection.
