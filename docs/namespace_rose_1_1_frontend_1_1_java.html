int Rose::Frontend::Java::Run ( SgProject * project)

Executes the Java frontend process for a given Rose project.

This function serves as the entry point for running the Java-specific frontend. It determines the execution mode based on the global configuration of the Rose compiler. If the ECJ (Eclipse Compiler for Java) batch mode is enabled via the define or configuration settings, it invokes the specialized batch mode runner. Otherwise, it falls back to the standard serial frontend execution. The function ensures that the resulting status code is recorded within the project object.

Parameters
projectA pointer to the SgProject instance to be processed. The project must not be null.
Returns
An integer status code representing the result of the execution. A value of 0 typically indicates success, while non-zero values indicate various error states encountered during the frontend run.
Precondition
The project parameter must not be null.
Postcondition
The project's frontend error code is updated with the status returned by the execution process.
Note
This function relies on the global state of Rose::Cmdline::Java::Ecj::batch_mode to decide between batch and serial execution paths.
