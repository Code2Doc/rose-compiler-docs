void resetNamesInAST ( )

Resets and synchronizes names within the Abstract Syntax Tree (AST).

This function performs a multi-pass cleanup of the AST to ensure name consistency. It first addresses the issue of empty names in declarations that contain multiple variables or typedef types using the ResetEmptyNames visitor. Subsequently, it addresses inconsistencies between defining and non-defining declarations for SgClassDeclaration and SgFunctionDeclaration using the ResetInconsistantNames visitor. The function utilizes assertions to verify that the global mangled name map remains empty throughout the process, ensuring no stale or incorrectly mapped names persist.

Precondition
The AST must be in a state where the global mangled name map is empty before and after the name reset operations.
Postcondition
The AST names are synchronized, and any empty or inconsistent names in declarations are corrected.
Note
This function must be called after any operations that might have introduced empty names.
