Detailed Description

Displays Source and Binary side-by-side.

  • Relies on AsmToSourceMapper annotations
  • has own (hacky) mechanism to map from a SourceCode location (cursor-location) to the according SgNode, and from there with AsmToSourceMapper annotation to the binary TODO use mechanism here which is used in QRSourceBox
