void detectMacroOrIncludeFileExpansions ( SgSourceFile * sourceFile)

Identifies and maps macro expansions and include file expansions within a source file.

This function performs a traversal of the provided SgSourceFile to detect instances where macros or include files have been expanded. It utilizes a specialized traversal mechanism (DetectMacroOrIncludeFileExpansions) and an inherited attribute to navigate the token stream sequence map. The function identifies macro expansion objects and associates them with their corresponding statements in the source file's macro expansion map.

The implementation iterates through a stack of macro expansions collected during the traversal. For each expansion, it iterates through all associated statements and updates the source file's macro expansion map, ensuring that each statement is uniquely mapped to exactly one macro expansion.

Parameters
sourceFileA pointer to the SgSourceFile object to be analyzed for macro and include expansions.
Precondition
sourceFile must not be NULL.
Postcondition
The macro expansion map within the sourceFile is updated to include mappings from SgStatement nodes to their respective MacroExpansion objects.
Note
The function relies on the existence of a token stream sequence map within the sourceFile.
If the macro expansion map is not empty prior to execution, a warning is printed to the standard output.
The function uses ROSE_ASSERT to validate that the traversal results in a non-null top attribute and that no statement is mapped to multiple expansions.

int get_distanceFromSourceDirectory ( Sg_File_Info * X)

Calculates the directory depth distance between a file and its source directory.

This function determines how many levels deep the file represented by the Sg_File_Info object is located relative to its corresponding source directory. It retrieves the parent file information, extracts the source directory path, and uses a FileNameClassification algorithm to compute the hierarchical distance.

Parameters
XA pointer to the Sg_File_Info object representing the file being analyzed.
Returns
An integer representing the number of directory levels between the file's location and the source directory.
Precondition
X must not be null.
The parent of X must correspond to a valid SgFile that can be retrieved via TransformationSupport::getFile.
Postcondition
The returned value is a non-negative integer representing the path depth.
Note
This function relies on TransformationSupport::getFile and StringUtility for path manipulation and file classification.
The calculation is dependent on the operating system type retrieved via StringUtility::getOSType().

void preventConstructionOnStack ( SgNode * n)

Verifies that a given SgNode is not allocated on the function stack.

This function performs a runtime check (in non-debug builds) to ensure that the memory address of the provided SgNode is not within the current stack frame. It calculates the distance between the pointer address of the node and the address of a local variable (the stack frame reference). If the distance falls within a specific threshold (between -10000 and 10000 bytes), it indicates that the object is likely residing on the stack, which is prohibited for this specific node type.

The implementation uses compiler-specific intrinsics or workarounds to determine the frame address:

  • For MSVC (Visual Studio), it uses the address of a local variable to approximate the frame address, with specific handling for versions >= 1600 to avoid 'auto' keyword conflicts.
  • For GNU compilers, it utilizes builtin_frame_address(0).
  • For specific older versions of GNU (4.0.x), the check is downgraded to a silent warning to avoid known false positives in certain environments.
Parameters
nA pointer to the SgNode to be checked for stack allocation.
Precondition
The pointer n should be a valid pointer to an SgNode.
Postcondition
If the function completes without an assertion failure, the node is verified to be outside the immediate stack frame range.
Warning
This function triggers an assertion failure or a compiler pragma message if the node is detected to be on the stack, unless running in a debug build (ifndef NDEBUG) or using specific older GNU compiler versions.
Note
The check is only active when ifndef NDEBUG is true.

Prints pragma associated with a grammatical element.

Iterates through a list of attributes and prints unique pragma directives to an output stream.

This function traverses a list of SgAttribute pointers, specifically looking for attributes that represent pragma directives. For each pragma found, it checks if the directive has already been printed to prevent duplicate output. If a pragma is encountered that has not been printed, it writes the formatted "#pragma [name]" string to the provided output stream and marks the pragma as printed. The function skips the first element of the list during its initial check.

Parameters
pattrA reference to a list of SgAttributePtr containing the attributes to be inspected.
osThe output stream where the formatted pragma directives will be written.
Precondition
The input stream os must be in a valid, writable state.
Postcondition
Any pragma attributes found in pattr that were not previously marked as printed will be written to os and their internal "printed" state will be set to 1.
Note
The function uses a manual iterator traversal and explicitly skips the first element of the pattr list by incrementing the iterator before entering the primary loop.
