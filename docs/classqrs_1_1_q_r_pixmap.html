QPixmap * qrs::QRPixmap::getPixmap ( const char ** pixdef)
static

Returns a /qpixmap.html>QPixmap object from an XPM data-structure.

QRose and Qt use the /qpixmap.html>QPixmap class to deal with images and icons in widgets, such as buttons. All QRose icons are stored in xpm format in the include/icons directory. You can use QPixmap::getPixmap to convert an xpm file into QPixmap object the first time it is accessed, and stored for subsequent accesses. All instances of QPixmap stored are automatically destroyed at the end of the program cycle.

Example:
int main(int argc, char *argv[]) {
QRGUI::init(argc, argv);
QRDialog *d = QRGUI::getDialog(0);
QRTestWidget *w = new QRTestWidget(d);
w->setCaption(QRPixmap::getPixmap(RoseIcons::no), "quit");
QRGUI::exec();
return 0;
}
