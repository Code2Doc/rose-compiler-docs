Checks if the debug copy split option is enabled in the command options.

This function determines whether the "-debugcopysplit" flag has been passed via the global command options instance. It uses a static integer to cache the result of the check after the first invocation, ensuring that the lookup in CmdOptions::GetInstance() only occurs once during the program's lifetime.

Returns
