Iterates through the project files to identify and collect matching statement handles.

This function traverses the list of files within a given SgProject. For each source file, it constructs an abstract node and attempts to match string-based handles stored in Outliner::handles against the IR nodes. If a match is found and the resulting node is identified as an SgStatement, it is added to the provided targets list.

Parameters
projA pointer to the SgProject containing the file list to be processed. Must not be NULL.
targetsA reference to a TargetList_t container where identified SgStatement nodes will be stored.
Returns
The number of handles collected (currently returns 0).
Precondition
proj must not be NULL.
Postcondition
The targets list will contain all SgStatement nodes that matched the strings in Outliner::handles found within the project's source files.
Note
The function uses ifdef _MSC_VER to handle specific compiler compatibility issues regarding node type casting.
There is a potential memory leak noted in the implementation regarding the lifecycle of the fhandle object.
Warning
This function relies on the global state of Outliner::handles and Outliner::enable_debug.

Identifies and collects Fortran target statements from a project.

This function traverses the subtree of a given SgProject to find all nodes of type V_SgStatement. It iterates through the retrieved list in reverse order and evaluates each statement using processFortranComment. If a statement is identified as a Fortran target, it is appended to the provided targets list.

Parameters
projA pointer to the SgProject containing the AST to be searched.
targetsA reference to a TargetList_t container where identified Fortran target statements will be stored.
Returns
The total number of Fortran target statements successfully collected and added to the targets list.
Precondition
The proj pointer must not be null and must point to a valid SgProject instance.
Postcondition
The targets list will contain all statements identified as Fortran targets found during the traversal, and the returned count will match the number of new elements added to the list.
Note
The function uses a reverse iterator to process the nodes, which may affect the order in which targets are added to the list relative to their appearance in the original AST.

If a pragma declaration is successfully processed, it is added to the provided pragmas list.

SgStatement * processFortranComment ( SgLocatedNode * node)

Processes and removes specific Fortran-style directive comments attached to a node.

This function iterates through the attached preprocessing information of a given SgLocatedNode to identify Fortran-style comments that match specific pragma patterns (e.g., using PRAGMA_OUTLINE). If a matching comment is found, the function attempts to identify the node as an SgStatement, marks the comment for removal, and subsequently deletes the identified preprocessing information objects from the node's metadata.

Parameters
nodeA pointer to the SgLocatedNode whose attached preprocessing information is to be inspected and potentially modified.
Returns
A pointer to the SgStatement associated with the node if a matching Fortran-style directive is found; otherwise, returns NULL (0).
Precondition
node must not be NULL.
Postcondition
If a matching Fortran-style directive is found, the corresponding PreprocessingInfo object is removed from the node's attached preprocessing information and its memory is deleted.
Warning
If a matching Fortran-style comment is found but the provided node cannot be cast to an SgStatement, an error message is printed to stderr and a ROSE_ASSERT failure is triggered.
Note
The function specifically checks for comment strings starting with "!$", "c$", or "*$" followed by the PRAGMA_OUTLINE macro value.

SgStatement * processPragma ( SgPragmaDeclaration * decl)

Processes a pragma declaration to identify statements for outlining.

This function inspects a given pragma declaration to determine if it contains an outlining directive. It specifically checks if the pragma string matches the predefined PRAGMA_OUTLINE constant. If a valid outlining pragma is identified, the function retrieves the subsequent statement in the abstract syntax tree (AST) that is intended to be outlined.

Parameters
declA pointer to the SgPragmaDeclaration object to be processed.
Returns
A pointer to the SgStatement that follows the pragma declaration if the pragma is a valid outlining pragma; otherwise, returns 0 (nullptr).
Precondition
decl must be a valid pointer to an SgPragmaDeclaration object.
Postcondition
If a valid pragma is found, the returned statement is the next statement in the sequence following the declaration.
Note
The function uses const_cast to return a non-const SgStatement pointer.
The implementation relies on the SageInterface::getNextStatement utility to traverse the AST.
