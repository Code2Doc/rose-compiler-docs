Iterates through project files to identify and collect matching statement handles.

This function traverses the file list within a given Rose project to find source files. For each valid source file, it constructs an abstract node and an associated file handle. It then iterates through a global list of predefined handles (Outliner::handles) to attempt to match string-based identifiers against the current file context. If a matching handle is found and it points to a valid Rose statement node, that node is appended to the provided target list.

Parameters
projA pointer to the SgProject instance containing the file list to be processed. Must not be NULL.
targetsA reference to a TargetList_t container where identified SgStatement nodes will be stored.
Returns
Returns 0 upon successful completion of the traversal.
Warning
The function performs manual memory management by deleting the file handle (fhandle) at the end of each file iteration, but it may not address potential memory leaks related to other allocated objects.
Precondition
proj must not be NULL.
Postcondition
The targets list will contain all SgStatement nodes that successfully matched the handles defined in Outliner::handles during the traversal.
Note
This function relies on the global state of Outliner::handles and Outliner::enable_debug.
The implementation contains platform-specific logic for MSVC (Microsoft Visual C++) to handle differences in member access and return type requirements.

Scans an SgProject for Fortran-style pragma statements and collects them into a target list.

This function performs a reverse traversal of all SgStatement nodes within the provided SgProject. It utilizes a subtree query to identify all nodes of type V_SgStatement. For each statement found, the function invokes processFortranComment to check for specific Fortran-style pragma comments. If a valid target is identified via the comment processing, the statement is appended to the provided targets list.

Parameters
projA pointer to the SgProject representing the AST root to be searched. Must not be NULL.
targetsA reference to a TargetList_t (container of SgStatement pointers) where the identified Fortran target statements will be stored.
Returns
The total number of Fortran target statements successfully identified and added to the targets list.
Precondition
The proj parameter must be a valid, non-null pointer to an SgProject.
Postcondition
The targets list is populated with all SgStatement nodes that contain matching Fortran pragma comments. The original state of the SgProject nodes is preserved, though associated preprocessing information may be modified by the underlying comment processing.
Warning
The function relies on the validity of the SgProject structure. If the project contains malformed nodes that cannot be safely cast to SgStatement, unexpected behavior may occur during the iteration process.
Note
The traversal is performed in reverse order (using reverse iterators) of the raw list of statements retrieved from the subtree query.

SgStatement * processFortranComment ( SgLocatedNode * node)

Identifies and removes specific Fortran-style pragma comments attached to a node.

This function iterates through the preprocessing information attached to a given SgLocatedNode to find Fortran-style comments that match specific pragma patterns (e.g., !$PRAGMA_OUTLINE, c$PRAGMA_OUTLINE, or *$PRAGMA_OUTLINE). If such a comment is found, the function attempts to identify the associated SgStatement, marks the comment for removal, and subsequently deletes the comment objects from the node's preprocessing information.

Parameters
nodeA pointer to the SgLocatedNode being inspected for attached preprocessing information. Must not be NULL.
Returns
A pointer to the SgStatement associated with the identified pragma comment. Returns NULL if no matching Fortran-style pragma comment is found or if no preprocessing information is attached to the node.
Warning
This function performs memory management by deleting the PreprocessingInfo objects found in the removeList. It also triggers a ROSE_ASSERT failure and prints an error to stderr if a matching comment is attached to a node that cannot be cast to an SgStatement.
Precondition
The input node must be a valid, non-null pointer to an SgLocatedNode.
Postcondition
If a matching pragma comment is found, it is removed from the node's attached preprocessing information and its memory is deallocated.
Note
The function specifically looks for trimmed strings matching the prefixes !$ , c$ , or *$ followed by the PRAGMA_OUTLINE macro value.

SgStatement * processPragma ( SgPragmaDeclaration * decl)

Identifies and retrieves the statement associated with an outlining pragma.

This function inspects a given pragma declaration to determine if it contains an "outline" directive. If the pragma is identified as a PRAGMA_OUTLINE, the function traverses the Abstract Syntax Tree (AST) to locate and return the immediate next statement following the pragma declaration. This is typically used during refactoring or code transformation passes to identify the block of code targeted for extraction into a new function.

Parameters
declA pointer to the SgPragmaDeclaration object to be processed. This object contains the pragma metadata and the underlying pragma string.
Returns
A pointer to the SgStatement that follows the pragma declaration if the pragma is a valid PRAGMA_OUTLINE. Returns 0 (nullptr) if the declaration is null, the pragma content is empty, or the pragma type does not match PRAGMA_OUTLINE.
Warning
The function uses const_cast to return a non-const pointer to an SgStatement. The caller must ensure that the underlying AST structure is handled safely regarding const-correctness.
Precondition
The input parameter decl must be a valid pointer to an SgPragmaDeclaration instance, or null.
Postcondition
If a valid PRAGMA_OUTLINE is found, the function returns the next statement in the sequence, effectively advancing the focus of the transformation tool to the target code block.
Note
This implementation relies on SageInterface::getNextStatement to perform the AST traversal.
