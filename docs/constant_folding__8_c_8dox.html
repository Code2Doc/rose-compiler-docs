int cf_get_int_value ( SgValueExp * sg_value_exp)

Extracts an integer value from a given SgValueExp object.

This function attempts to retrieve an integer representation from various types of SgValueExp subclasses. It performs type checking using specific predicates (e.g., isSgBoolValExp, isSgIntVal) to determine the underlying value type. The function supports boolean, character, enumeration, integer, short, UPC mythread, and UPC threads expression types.

Parameters
sg_value_expA pointer to the SgValueExp object from which the integer value is to be extracted.
Returns
The integer value extracted from the expression.
Warning
If the provided sg_value_exp does not match any of the supported types, an error message is printed to stderr and the program is terminated via ROSE_ABORT().
Precondition
sg_value_exp must not be null and must be an instance of a supported SgValueExp subclass (bool, char, enum, int, short, upcMythread, or upcThreads).
Postcondition
The function returns the integer value of the expression, or aborts execution if the type is unsupported.
Note
This function relies on the ROSE framework's type-checking predicates and value-retrieval methods.

SgValueExp * evaluateBinaryOp ( SgBinaryOp * binaryOperator)

Evaluates a binary expression and performs constant folding.

This function attempts to perform constant folding on a given binary operator. If both the left-hand side (LHS) and right-hand side (RHS) operands of the binary operator are constant value expressions (SgValueExp) and share the same type variant, the function computes the result of the operation at compile-time and returns a new expression representing that constant value.

The implementation uses a switch statement to dispatch the evaluation logic based on the type variant of the operands. It handles various primitive types including integers (short, int, long, long long, unsigned variants), floating-point types (float, double, long double), characters, booleans, enums, and strings.

Parameters
binaryOperatorA pointer to the SgBinaryOp node representing the binary operation to be evaluated.
Returns
A pointer to a new SgValueExp containing the folded constant value if both operands are constants of the same type. Returns NULL if the operands are not both constants, if they have different type variants, if either operand is NULL, or if the type variant is not explicitly handled.
Precondition
binaryOperator must not be NULL.
Postcondition
If a result is returned, it is a new SgValueExp object representing the computed constant.
Note
The function currently ignores cases where operands have different types.
For SgFloatVal, the implementation may promote the result to a double to preserve accuracy, as noted in the source code.
For SgEnumVal, the value is simplified to an integer equivalent.
The implementation contains if 1 and if 0 blocks which may affect the logic for integer evaluation depending on the compilation environment.

SgValueExp * evaluateConditionalExp ( SgConditionalExp * cond_exp)

Evaluates a conditional expression of the form a?b:c.

This function performs a constant folding evaluation of a conditional expression. It inspects the condition expression to determine if it evaluates to a constant boolean value. If the condition is a constant integer-like type (such as char, short, bool, enum, int, or thread counts) and is non-zero, the function attempts to return the true branch. If the condition is zero, it attempts to return the false branch. The evaluation is only performed if the condition itself is an instance of SgValueExp.

Parameters
cond_expA pointer to the SgConditionalExp node representing the conditional expression to be evaluated.
Returns
A pointer to an SgValueExp representing the result of the evaluated conditional expression. Returns NULL if the condition is not a constant value expression, if the type is unhandled, or if the selected branch is not a valid SgValueExp.
Precondition
cond_exp must not be a null pointer.
Postcondition
The returned pointer points to either the true branch, the false branch, or NULL, depending on the evaluation of the condition.
Note
The implementation currently handles integer-compatible variants including V_SgCharVal, V_SgShortVal, V_SgBoolValExp, V_SgEnumVal, V_SgIntVal, V_SgUpcMythread, and V_SgUpcThreads.
There is a known TODO regarding the handling of scalar types such as floating point and pointers.

SgValueExp * evaluateUnaryOp ( SgUnaryOp * unaryOperator)

Evaluates a unary expression and returns a value expression if the operand is a constant.

This function performs constant folding for unary operators. It inspects the operand of the provided unary operator to determine if it is a constant value expression (SgValueExp). If the operand is a constant, the function applies the unary operation to the underlying value using type-specific logic (e.g., handling boolean, integer, floating-point, and various sized integer types). The result is then wrapped in a new SgValueExp.

Parameters
unaryOperatorA pointer to the SgUnaryOp node to be evaluated.
Returns
A pointer to a new SgValueExp containing the folded result if the operand is a constant and the operation is supported; otherwise, returns NULL.
Precondition
unaryOperator must not be NULL.
Postcondition
If the operand is a constant, a new SgValueExp is returned representing the result of the unary operation.
Note
For SgSgBoolValExp, special handling is implemented to extract the integer representation and rebuild it using SageBuilder::buildIntVal.
For SgSgFloatVal, the function promotes the value to a double during the folding process to prevent loss of accuracy.
If an unhandled SgValueExp variant is encountered, an error message is printed to the standard output.
