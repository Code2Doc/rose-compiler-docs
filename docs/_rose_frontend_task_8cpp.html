void annotateFiles ( SgProject * project,
SgFile * file )

Performs various annotation tasks on a specific SgFile within an SgProject.

This function iterates through different types of SgFile objects to apply specific annotation processors. It handles two primary logic paths:

  1. If the file is an SgSourceFile, it performs flop counting via FlopCounterProcessor and uses an AsmToSourceMapper to map information from all SgBinaryComposite files within the project back to this source file.
  2. If the file is an SgBinaryComposite, it performs instruction count annotation using InstructionCountAnnotator (creating a .pin sidecar file) and uses AsmToSourceMapper to map information from this binary file to all SgSourceFile objects within the project.
Parameters
projectA pointer to the SgProject containing the collection of files to be processed.
fileA pointer to the SgFile that is the target of the annotation process.
Precondition
project must not be NULL and must contain a valid collection of SgFile objects.
file must not be NULL.
Postcondition
The target file (and potentially other files in the project) will have updated metadata or annotations based on the applied processors.
Note
The function relies on type-checking functions like isSgSourceFile and isSgBinaryComposite to determine the appropriate annotation logic.
