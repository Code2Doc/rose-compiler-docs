typedef double Rose::Color::Component

Type for color components.

Darkens an HSV color by a specified factor.

Darken a color.

Makes a color darker according to amount, which should be in the range [0..1]. If amount is zero then the value is not changed, if amount is one then the color becomes black, others are interpolated linearly. This method does not affect the hue, saturation, or alpha.

This function reduces the value (brightness) component of an HSV color representation based on a provided amount. The calculation subtracts a percentage of the current value from itself, effectively scaling the brightness downwards. The resulting value is passed through a clipping function to ensure it remains within valid bounds.

Parameters
hsvThe original HSV color structure to be darkened.
amountA double representing the fraction of the value to remove. For example, an amount of 0.2 reduces the value by 20%.
Returns
A new HSV object with the same hue, saturation, and alpha components, but with a modified, darker value component.
Precondition
The input hsv object must be a valid HSV instance.
Postcondition
The returned HSV object will have a value component less than or equal to the original hsv.v(), assuming amount is positive.
Note
The function relies on a clip function to prevent the value from falling below the valid range.

This function takes an input HSV color and produces a new HSV color where the value (brightness) component is inverted. The inversion is performed by calculating (1.0 - v), where v is the original value. The hue, saturation, and alpha components remain unchanged.

Component Rose::Color::rgb_from_hue ( Component p,

Component t )

Computes a color component value based on the hue position within a specific sector.

This function implements a piece-wise linear interpolation algorithm used in converting Hue-Saturation-Lightness (HSL) or Hue-Saturation-Blue (HSB) color models to RGB. It calculates the intermediate color value for a given sector of the color wheel by interpolating between two reference components, p and q, based on the normalized position t. The function handles wrap-around for values of t outside the [0, 1] range and applies specific linear transformations for the different segments of the hue rotation.

Parameters
pThe primary color component value for the current sector.
qThe secondary color component value for the current sector.
tThe normalized position within the hue cycle, typically in the range [0, 1].
Returns
The calculated color component value as a Component type.
Precondition
The input components p, q, and t should ideally be within a valid range defined by the Component type (typically [0, 1]).
Postcondition
The returned value is normalized such that the effective t is within [0, 1].
Note
The function performs an implicit wrap-around for t if t < 0 or t > 1 by adding or subtracting 1.0.

std::string Rose::Color::toAnsi ( const RGB & rgb,
Layer layer )

Converts an RGB color to an ANSI escape sequence string.

Create an ANSI color escape.

These characters can be emitted to an ANSI terminal after the appropriate escape sequence in order to change the foreground or background color. The escape sequence is usually "\033[38;2;" for the foreground and "\033[48;2;" for the background. The foreground and background colors can be canceled by emitting "\033[0m". If a layer is specified, then the escape sequence is part of the return value. ANSI doesn't support alphas, so if the alpha is less than 0.5 the return value is an empty string.

This function generates a string containing the ANSI escape code for TrueColor (24-bit) formatting. It maps the red, green, and blue components of the provided RGB object to the 0-255 integer range. The function handles both foreground and background layer types. Since the ANSI standard does not support an alpha channel, the transparency is handled by checking if the alpha component is at least 0.5; if the color is considered transparent, an empty string is returned.

Parameters
rgbThe RGB color object containing red, green, blue, and alpha components.
layerThe target layer (e.g., FOREGROUND or BACKGROUND) for which the ANSI sequence is being generated.
Returns
A string containing the ANSI escape sequence (e.g., "\033[38;2;R;G;Bm") if the color is opaque (alpha >= 0.5), or an empty string if the color is transparent.
Precondition
The rgb object must contain valid color components.
Postcondition
Returns a valid ANSI escape sequence string or an empty string.
Note
The implementation uses boost::numeric::converter to handle the conversion from double to unsigned to ensure consistent rounding behavior, as standard C++ rounding might vary across platforms.
The color components are clipped before being scaled to the 0-255 range.
