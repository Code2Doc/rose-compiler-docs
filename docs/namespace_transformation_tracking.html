void TransformationTracking::addInputNode ( SgNode * affected_node,
SgNode * input_node )

Establishes a relationship between an affected node and an input node by mapping their IDs.

This function updates the internal tracking structure (inputIDs) to record that the specified input_node serves as an input to the affected_node. It retrieves the unique AST node IDs for both nodes and inserts the input node's ID into the set associated with the affected node's ID.

Parameters
affected_nodeA pointer to the SgNode that is being modified or affected by the input.
input_nodeA pointer to the SgNode that acts as the input to the affected node.
Precondition
The affected_node and input_node must not be NULL.
Both affected_node and input_node must have been assigned a valid, non-zero AST_NODE_ID.
This function should be called after the transformation is completed and all IDs are assigned.
Postcondition
The input_id of input_node is added to the collection of input IDs associated with affected_id in the inputIDs map.
Warning
If the nodes have not been properly initialized with IDs via the getId function, the ROSE_ASSERT macros will trigger a program termination.
Note
The implementation uses if 0 blocks for debugging purposes which are excluded from production builds.

std::pair< Sg_File_Info *, Sg_File_Info * > TransformationTracking::copyBeginAndEndFileInfo ( SgNode * n)

Creates deep copies of the start and end file information for a given SgNode.

This internal helper function retrieves the beginning and ending file information associated with a specific SgNode. If the node is identified as a pragma or a located node, the function performs a deep copy of the start and end construction information using SageInterface::deepCopy to ensure that the returned file information objects are independent of the original node's lifecycle.

Parameters
nA pointer to the SgNode whose file information is to be copied.
Returns
A pair of Sg_File_Info pointers, where the first element is the deep copy of the start of construction information and the second element is the deep copy of the end of construction information. If the node is not a pragma or a located node, the pair contains null pointers.
Precondition
n must not be NULL.
Postcondition
The returned Sg_File_Info objects are deep copies, meaning they are distinct from the original objects held by the node n.
Note
This function relies on the isSgPragma and isSgLocatedNode predicates to determine if file information extraction is appropriate.

◆ getId()

AST_NODE_ID TransformationTracking::getId ( SgNode * n)

Retrieves the unique AST node ID associated with a given SgNode.

This function performs a lookup in the AstToIdTable to map a pointer to an SgNode to its corresponding AST_NODE_ID. This mapping is used to provide a stable identifier for nodes within the AST structure.

Parameters
nA pointer to the SgNode for which the ID is being retrieved.
Warning
The current implementation relies on a table lookup that may be susceptible to issues if memory addresses are reused. As noted in the implementation, ROSE may reuse memory space from released nodes for new AST nodes, meaning the memory address of a pointer is not a guaranteed unique identifier for the lifetime of the logical AST node.
Precondition
n must be a valid pointer to an SgNode that has been registered within the AstToIdTable.
Postcondition
The function returns the AST_NODE_ID associated with the provided node.
Note
This function is currently subject to a TODO regarding the reliability of using memory addresses as keys in environments where memory reallocation occurs.

void TransformationTracking::registerAstSubtreeIds ( SgNode * root)

Assign Ids and save current File Info.

Registers unique identifiers for all nodes within an AST subtree.

This function performs a complete traversal of the Abstract Syntax Tree (AST) starting from the provided root node. It utilizes a visitor pattern implementation via the visitorTraversal class to visit every node in the tree using a preorder traversal strategy. The primary purpose is to ensure that every node in the subtree is assigned a unique ID during the traversal process.

Parameters
rootA pointer to the root SgNode of the AST subtree to be traversed.
Precondition
The root pointer must not be null.
Postcondition
All nodes reachable from the root node will have been visited and processed by the traversal mechanism.
Note
The traversal follows a preorder pattern, meaning the parent node is processed before its children.

void TransformationTracking::setId ( SgNode * n)

Assigns a unique identifier to an SgNode if one is not already present.

This function checks if the provided SgNode already possesses an AST node ID. If the current ID is zero (indicating no ID is assigned), the function searches for the next available unused ID by incrementing a global counter until an empty slot is found in the IdToAstTable. Once an unused ID is identified, the function updates the bidirectional mapping between the node and the ID, and associates the ID with the corresponding file information using copyBeginAndEndFileInfo.

Parameters
nA pointer to the SgNode that requires an ID assignment.
Precondition
n must not be NULL.
Postcondition
If n had no ID, it will be assigned a new unique ID, and the global lookup tables (AstToIdTable, IdToAstTable, and IdToFileInfoTable) will be updated to reflect this assignment.
Note
This function relies on the existence of global or externally defined tables such as IdToAstTable, AstToIdTable, and IdToFileInfoTable, as well as the global variable nextId.
Warning
The function uses ROSE_ASSERT to validate that the input pointer is not NULL; if n is NULL, the program will abort.
