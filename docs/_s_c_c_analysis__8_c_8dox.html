Performs a recursive depth-first search to identify Strongly Connected Components (SCCs).

This function implements a single step of Tarjan's strongly connected components algorithm. It traverses the graph using depth-first search (DFS), maintaining discovery numbers (DFNUMBER) and low-link values (LOWLINK) for each node. The low-link value represents the smallest discovery number reachable from the node in the DFS tree, including itself and nodes reachable via back-edges to nodes currently on the recursion stack. When a node's low-link value equals its discovery number, it signifies the root of an SCC, and all nodes belonging to this SCC are popped from the stack and processed by the operator.

Parameters
dgA pointer to the GraphAccessInterface used to traverse the graph structure.
vThe current node being visited in the depth-first search traversal.
stateA reference to a LowLinkState object that tracks discovery numbers, low-link values, visitation status, and the recursion stack.
opA reference to an SCCAnalOperator used to handle the creation and population of identified strongly connected components.
Precondition
The graph dg must be valid and the node v must be a member of the graph.
The state object must be properly initialized to handle new discovery numbers.
Postcondition
The node v and all nodes in its SCC will be marked as visited.
If v is the root of an SCC, the op object will have a new SCC created containing v and all its descendants in the current SCC.
Note
This is a recursive function; for very deep graphs, stack overflow may occur.
