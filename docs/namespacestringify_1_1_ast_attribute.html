Retrieves a constant reference to the predefined ownership policy values.

Return all AstAttribute::OwnershipPolicy member values as a vector.

This function provides access to a static, immutable collection of 64-bit integer values that represent the standard ownership policies used within the system. The values are stored in a static vector to ensure they are initialized only once and persist for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the ownership policy values {0, 1, 2, 3}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing the predefined policy constants.
Note
The returned vector is static and thread-safe for concurrent reads after its initial construction.

Converts an integer ownership policy ID into its corresponding string representation.

Convert AstAttribute::OwnershipPolicy enum constant to a string.

This function maps specific 64-bit integer values to their human-readable string constants representing different ownership policies within the AstAttribute namespace. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the ownership policy ID.
Returns
A pointer to a constant character string representing the policy name. Returns "CONTAINER_OWNERSHIP" for 0, "NO_OWNERSHIP" for 1, "CUSTOM_OWNERSHIP" for 2, "UNKNOWN_OWNERSHIP" for 3, and an empty string "" for any other value.
Precondition
The input parameter i should correspond to one of the defined policy constants.
Postcondition
The returned string is a static literal and does not require manual memory management.
Note
The function handles only the specific cases 0 through 3.

Generates a formatted ownership policy string with an optional prefix removal.

Convert AstAttribute::OwnershipPolicy enum constant to a string.

This function retrieves the ownership policy string associated with a given 64-bit integer identifier. It first calls the overloaded OwnershipPolicy(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(AstAttribute::OwnershipPolicy)" followed by the string representation of the identifier. Finally, if the resulting string starts with the provided strip prefix, that prefix is removed from the string.

Parameters
iThe 64-bit integer identifier used to look up or construct the ownership policy.
stripA string representing a prefix to be removed from the start of the generated policy string if it exists.
Returns
A string representing the processed ownership policy.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present at the beginning of the original policy string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
