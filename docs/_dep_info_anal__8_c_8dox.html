Analyzes the read and write references within a given statement node.

This function traverses the AST node n to identify and collect all nodes involved in modification (writes) and reading (reads) operations. It utilizes a StmtSideEffectCollect operator to perform the traversal. The function tracks whether any unknown AST nodes are encountered during the process.

Parameters

Returns
True if all encountered nodes are known and the analysis completed without encountering AST_UNKNOWN; false if any node encountered was AST_UNKNOWN.
Precondition

Postcondition
The wRefs and rRefs collections will be populated with the identified read and write references from the node n.

Computes the global dependency information for a given statement reference dependency.

This function calculates the dependency information (DepInfo) by analyzing the loop domains of the two statements involved in a dependency reference. It utilizes the dependency type and the communication level to determine the relationship between the references. The function specifically handles the construction of dependency relations for communication levels, adjusting the dependency direction based on the provided position.

Parameters
analA reference to the DepInfoAnal object containing the analysis state and statement information.
refA constant reference to a StmtRefDep structure representing the dependency between two statement references.
tThe type of dependency being analyzed.
posAn integer representing the position or offset used to determine the dependency relation in cases involving communication levels.
Returns
A DepInfo object containing the computed dependency information. Returns an empty DepInfo if the reference has no communication level and the position is less than or equal to 0.
Precondition
The anal object must contain valid loop information for the statements referenced in ref.r1.stmt and ref.r2.stmt.
Postcondition
Returns a populated DepInfo object containing the calculated dependency relations.
Note
If ref.commLevel is greater than 0, the function explicitly sets a dependency relation at the entry (ref.commLevel, ref.commLevel) with a direction of DEPDIR_LE, where the distance is 0 if pos >= 0, and -1 if pos < 0.

Computes the dependency information for private dependencies within a loop structure.

This function calculates the dependency relation (DepInfo) between two statements based on their reference information and a specified dependency type. It determines the dimensionality of the dependency by inspecting the loop domains of the involved statements. The function initializes the dependency matrix by generating a base dependency using DepInfoGenerator and then refines the diagonal entries based on the communication level and the provided position index. Finally, it applies restrictions to the dependency information based on the source and sink properties of the statement domains.

Parameters
analA reference to the DepInfoAnal object used to retrieve loop dependency information for the statements involved in the reference.
refA constant reference to a StmtRefDep structure containing the details of the dependency, including the two statements (r1 and r2), their references, and the communication level.
tThe type of dependency being analyzed (DepType).
posAn integer representing the position or offset used to determine the direction of the dependency relation (e.g., equality or less-than-or-equal) when communication levels are involved.
Returns
A DepInfo object representing the computed dependency relations between the two statements.
Precondition
The statements referenced in ref.r1.stmt and ref.r2.stmt must be valid and retrievable via anal.GetStmtInfo.
Postcondition
The returned DepInfo object will have its entries restricted according to the source and sink constraints of the statement domains.
Note
If ref.commLevel is false and pos is less than or equal to 0, the function returns an empty DepInfo object immediately.

Computes dependency information between two sets of reference nodes.

This function iterates through two lists of AST nodes (rs1 and rs2) to identify and compute dependencies (array, global scalar, or private scalar) based on whether the nodes represent array accesses or scalar references and whether they alias. It handles self-comparison cases when rs1 and rs2 point to the same list. The function utilizes the provided dependency analysis context to determine the specific type of dependency and populates the provided dependency collections.

Parameters
analThe dependency analysis context containing the AST interface and analysis methods.
refA structure used to store the current pair of references being analyzed.
rs1A pointer to a doubly linked list of AST nodes representing the first set of references.
rs2A pointer to a doubly-linked list of AST nodes representing the second set of references.
tThe type of dependency being analyzed.
outDepsA collection object used to store the computed outgoing dependencies.
inDepsA collection object used to store the computed incoming dependencies.
Precondition
The pointers rs1 and rs2 must point to valid, initialized DoublyLinkedListWrap objects.
The anal object must contain a valid AST interface.
Postcondition
The outDeps and inDeps collections are updated with any newly discovered dependencies found during the traversal of the reference sets.
Note
