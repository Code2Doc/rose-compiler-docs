llvm::PassPluginLibraryInfo getROSEPassPluginInfo ( )

Retrieves the plugin information for the ROSEPass LLVM plugin.

This function serves as the entry point for the LLVM plugin loading mechanism. It returns a llvm::PassPluginLibraryInfo structure containing metadata such as the plugin name, LLVM API version, and LLVM version string.

The implementation defines a registration callback that performs two primary tasks:

  1. Registers the "ROSEPass" pass within the pipeline parsing callback, allowing it to be invoked via the -passes=ROSEPass command-line argument.
  2. Registers the "ROSEPass" as a module pass that is automatically inserted into the optimization pipeline at the OptimizerLastEPCallback stage.

The registration process involves setting up FunctionAnalysisManager and ModuleAnalysisManager to ensure the pass has access to necessary analyses.

Returns
An llvm::PassPluginLibraryInfo object containing the plugin's identity and the registration logic for the LLVM PassBuilder.
Precondition
The LLVM environment must be compatible with the LLVM_PLUGIN_API_VERSION defined in the plugin.
Postcondition
The "ROSEPass" is registered within the LLVM PassBuilder, making it available for both explicit pipeline specification and automatic pipeline insertion.
Note
This function relies on the LLVM_PLUGIN_API_VERSION and LLVM_VERSION_STRING macros.

This function provides the necessary metadata and registration logic required for LLVM to recognize and load the ROSEPass plugin. It returns a PassPluginLibraryInfo structure containing the plugin API version, the plugin name ("ROSEPass"), and the LLVM version string.

  1. It registers a pipeline parsing callback, allowing the pass to be invoked via the -passes=ROSEPass command-line argument. This involves setting up FunctionAnalysisManager and ModuleAnalysisManager.
  2. It registers the pass as an optimizer last EP (Extension Point) callback, ensuring that ROSEPass is automatically added to the module pipeline during the optimization phase.
