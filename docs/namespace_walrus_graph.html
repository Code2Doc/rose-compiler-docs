void WalrusGraph::generateWalrusGraph ( SgNode * node,
string outputFilename )

Generates a graph representation in the Walrus format and writes it to a file.

This function traverses the provided SgNode hierarchy to extract structural information and writes the resulting node and edge lists into a file specified by outputFilename. The function identifies if the node belongs to an SgProject and handles binary analysis configurations if ifdef ROSE_ENABLE_BINARY_ANALYSIS is active. It utilizes a preorder traversal to map the graph components and subsequently calls generateEdges and generateNodes to populate the output stream.

Parameters
nodeA pointer to the root SgNode from which the graph generation begins.
outputFilenameThe filesystem path where the generated Walrus graph file will be saved.
Warning
The generated Walrus format file typically requires manual post-processing. For large files, the trailing comma at the end of the edge and node lists must be manually removed. For binary files, the initial self-looping edge (source=0, destination=0) and the final entry in the node list must be manually deleted to ensure compatibility.
Precondition
The output file path must be writable by the application.
Postcondition
A file is created or overwritten at outputFilename containing the graph data.
Note
If the input node is an SgProject and binary analysis is enabled via ifdef ROSE_ENABLE_BINARY_ANALYSIS, the function may modify the project's binary-only status.
