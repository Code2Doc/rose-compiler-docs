FinderBase & finder )

Traverses the AST upwards from a given node to find the first node matching a predicate.

This function performs a reverse traversal of the Abstract Syntax Tree (AST) starting from the provided node and moving towards the root. It utilizes a predicate-based approach via the FinderBase object to check each node in the upward path. The traversal stops immediately upon finding the first node that satisfies the finder's condition.

Parameters
astA pointer to the starting SgNode in the AST from which the upward traversal begins.
finderA reference to a FinderBase object used to evaluate nodes and store the result. The finder must implement an operator() that returns true if the node is a match.
Precondition
The ast pointer must be valid, though it may be nullptr (in which case the function returns immediately).
Postcondition
If a matching node is found, finder.found is updated to point to that node.
Note
The traversal relies on the node->get_parent() method to navigate the tree hierarchy.

Executes a traversal of an AST node using a wrapped visitor.

This function serves as a helper utility to initiate a forward traversal on a specific SgNode. It utilizes the WrapVisitorBase mechanism to adapt the provided visitorBase into a compatible format for the traverse method, then applies that visitor to the provided AST node.

Parameters
astA pointer to the SgNode to be traversed.
visitorBaseThe base visitor object containing the logic for the traversal.
Precondition
The visitorBase must be a valid, initialized instance of VisitorBase.
Postcondition
If ast is not null, the node and its children are processed by the visitor.
Note
If the ast parameter is null, the function performs no operation and returns immediately without attempting traversal.

void Rose::AST::Traversal::detail::reverseHelper ( SgNode * ast,
const VisitorBase & visitorBase )

Performs a bottom-up traversal of an AST path by reversing a top-down traversal.

This function traverses the path from a given AST node up to the root of the tree. It first performs a pre-order traversal by visiting each node in the upward path (from child to parent) and storing them in a vector. After reaching the root, it iterates through the stored nodes in reverse order (from parent to child) to perform a post-order traversal. This effectively simulates a depth-first traversal logic specifically for the lineage of the provided node.

Parameters
astA pointer to the starting SgNode from which the upward traversal begins.
visitorBaseA reference to the VisitorBase object used to apply visitation logic to each node in the path.
Precondition
The ast pointer should be valid and not null to ensure the traversal starts correctly, although the loop condition handles null pointers.
Postcondition
The visitorBase is applied to every node in the path from ast to the root, first with Order::PRE and then with Order::POST.
Note
This implementation uses a std::vector to store the path, resulting in O(d) space complexity, where d is the depth of the node in the tree.
