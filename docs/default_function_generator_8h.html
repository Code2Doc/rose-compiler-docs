ROSE_DLL_API void defaultFunctionGenerator ( SgProject * prj)

Executes a multi-pass generation and testing sequence on an SgProject.

This function orchestrates a standardized workflow for generating default functions within a project. The process involves two distinct traversal passes using a DefaultFunctionGenerator instance in preorder mode. After the generation passes, the function performs post-processing on the AST via AstPostProcessing and concludes by executing the full suite of available tests through AstTests::runAllTests.

Parameters
prjA pointer to the SgProject instance that will undergo the generation and testing process.
Precondition
The prj parameter must not be null and must point to a valid, initialized SgProject object.
Postcondition
The SgProject prj will have been modified by the two-pass generation process and the post-processing step. All associated tests will have been executed.
Note
The generation process uses a fixed two-pass approach where the generator's pass member is explicitly set to 1 and then 2.
