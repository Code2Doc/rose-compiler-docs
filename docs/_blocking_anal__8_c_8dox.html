const CompSliceDepGraphNode::NestInfo * DoNonPerfectBlocking ( const CompSliceDepGraphNode::FullNestInfo & nestInfo)

Identifies a single non-perfectly blocked nest within a given nest hierarchy.

This function traverses the hierarchy of nested information starting from the inner nest of the provided FullNestInfo. It searches for a level in the hierarchy that contains a valid CompSliceNest. The algorithm is designed to identify exactly one such level. If it encounters exactly one level with a non-null nest, it returns that level's NestInfo. If it finds zero or more than one level with a non-null nest, it returns a null pointer.

Parameters
nestInfoThe FullNestInfo structure containing the hierarchy of nests to be inspected.
Returns
A pointer to the NestInfo of the single identified non-perfectly blocked nest, or a null pointer if no such nest is found or if multiple such nests are detected.
Precondition
nestInfo must be a valid reference to a CompSliceDepGraphNode::FullNestInfo object.
Postcondition
The returned pointer points to a valid NestInfo within the hierarchy if a single non-perfectly blocked nest was found; otherwise, the return value is 0.
Note
The implementation explicitly restricts the result to only one valid nest level. If the loop encounters a second level containing a non-null CompSliceNest, the search terminates and returns 0.

SymbolicVal GetDefaultBlockSize ( const CompSlice * slice)
static

Retrieves the default block size for a given computation slice.

This function determines the block size to be used during loop transformations. If dynamic tuning is disabled in the global loop transformation options, it returns a static default block size. If dynamic tuning is enabled, the function constructs an AST expression that calls a tuning function "getTuningValue". This expression is calculated based on the current dynamic tuning index and the total number of iterations in the loop associated with the provided CompSlice (calculated as upper bound minus lower bound plus one).

Parameters
sliceA pointer to the CompSlice representing the current computation context, used to extract loop bounds for dynamic tuning calculations.
Returns
A SymbolicVal representing the block size. This may be a constant value from the options or a SymbolicVar representing a function call for dynamic tuning.
Precondition
The slice parameter must not be null if dynamic tuning is enabled, as the function accesses the loop iterator and loop information.
Postcondition
The returned SymbolicVal is a valid AST node or variable that can be used in subsequent code generation steps.
Note
The function relies on the global state of LoopTransformOptions and the AstInterface provided by LoopTransformInterface.

Determines the number of entries in a slice nest that exhibit reuse characteristics.

This function iterates through the entries of a given slice nest to identify the first index where no temporal or spatial reuse is detected by the provided locality registry. It effectively measures the depth of the nest that can be considered "reusable" based on the criteria defined in the CompSliceLocalityRegistry.

Parameters
analA pointer to a CompSliceLocalityRegistry instance used to query temporal and spatial reuse information for each slice entry.
nA constant reference to a CompSliceNest object containing the sequence of slice entries to be analyzed.
Returns
An integer representing the count of consecutive entries in the slice nest (starting from index 0) that exhibit either temporal or spatial reuse. If no entries exhibit reuse, returns 0.
Precondition
The pointer anal must be valid and not null.
Postcondition
The function does not modify the state of the n slice nest.
Note
The function stops searching as soon as it encounters an entry where both TemporaryReuses and SpatialReuses return 0.
