void markTemplateSpecializationsForOutput ( SgNode * node)

Fixups template specializations generated by ROSE from template instantiations.

All specializations that are located in the source file shoud be output in the code generation.

Fixups template specializations generated by ROSE from template instantiations.

This function identifies and marks template specializations that should be included in the output. The implementation handles different types of AST structures:

  1. If the provided node is a root node (no parent), it checks if the node is an SgProject. If it is, the function iterates through all files in the project and calls markTemplateInstantiationsForOutput for each file.
  2. If the node has a parent, the function attempts to retrieve the associated SgFile using TransformationSupport::getSourceFile. If a valid file is found, a MarkTemplateSpecializationsForOutput traversal is initiated using a MarkTemplateSpecializationsForOutputInheritedAttribute to traverse the node.

The function utilizes a TimingPerformance timer to track the execution time of the marking process.

Parameters
nodeA pointer to the SgNode to be processed. This can be a specific AST node, a file, or an SgProject.
Precondition
node must not be NULL.
Postcondition
Template specializations within the scope of the provided node (or project) are marked for output via a traversal process.
Note
If the node is an AST fragment unattached to the primary AST, any template specializations within that fragment will not be marked during this call. Such cases are expected to be handled during later post-processing once the fragment is attached to the primary AST.

This function traverses the provided AST node (or an entire project if the node is a root-level SgProject) to identify and mark template specializations that should be included in the output. If the node is part of a valid source file, it utilizes a specialized traversal mechanism (MarkTemplateSpecializationsForOutput) to perform the marking. If the node is an SgProject, the function iterates through all files in the project and calls markTemplateInstantiationsForOutput on each.
