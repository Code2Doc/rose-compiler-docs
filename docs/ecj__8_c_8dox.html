Retrieves the cached Java class reference for "JavaTraversal".

This function implements a singleton-style pattern to retrieve and cache the JNI class reference for the "JavaTraversal" class. It checks if a static reference ofp_class has already been initialized. If not, it attempts to find the class using jserver_FindClass. If the class lookup fails, it invokes jserver_handleException to manage the resulting Java exception.

Returns
The jclass reference for the "JavaTraversal" class. Returns NULL if the class could not be found and an exception was handled.
Precondition
The JNI environment must be properly initialized and the jserver_FindClass function must be available in the current execution context.
Postcondition
If the class is found, a valid jclass is cached in a static variable for subsequent calls.
Note
This function relies on a static variable ofp_class to persist the class reference across multiple calls, reducing the overhead of repeatedly searching for the class.

Invokes a Java-based Fortran parser traversal using JNI.

This function serves as a bridge between C++ and the Java Virtual Machine to execute a specific Java traversal class (JavaTraversal). It converts C-style command-line arguments into a Java String array, initializes the Java environment with necessary method IDs for file and directory manipulation, and invokes the static main method of the specified Java class. It also handles error checking for both JNI exceptions and application-level errors reported by the Java side.

Parameters
argcThe number of command-line arguments passed to the function.
argvAn array of C-style strings representing the command-line arguments. The last argument in this array is expected to be the filename of the Fortran source to be parsed.
Returns
An integer representing the return status. Returns 0 if the execution is successful, or a non-zero value if an error occurred during the Java method execution or if the Java-side error method returns true.
Precondition
The JNI environment must be properly initialized before calling this function.
The argument argv[argc-1] must point to a valid, null-terminated string representing a filename.
Postcondition
The Java static method main of the JavaTraversal class is executed.
The global state of Rose::Frontend::Java::Ecj (such as currentJavaTraversalClass and currentEnvironment) may be updated with new class and method references.
Warning
If a JNI exception occurs during the execution of the Java method, this function will print an error to stderr and throw a std::runtime_error.
If the fileName, args, or type objects are NULL, the function calls jserver_handleException().
Note
This implementation relies on several helper functions from the jserver and jofp libraries, such as jserver_getJavaStringArray, jserver_getJavaString, and jofp_get_method.
