const std::vector< int64_t > & stringify::CFG::EdgeType ( )

Retrieves a static collection of predefined edge type identifiers.

Return all CFG::EdgeType member values as a vector.

This function provides access to a constant, static vector containing a fixed set of 64-bit integer values representing various edge types. The values are hardcoded within the function scope and are stored in a static std::vector to ensure they are initialized only once and persist for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the predefined edge type values (0 through 7).
Precondition
None.
Postcondition
The returned reference points to a valid, immutable vector of int64_t values.
Note
The implementation uses a static local variable to avoid the overhead of re-allocating and re-initializing the vector on subsequent calls.

const char * stringify::CFG::EdgeType ( int64_t )

Converts an integer edge type identifier into its corresponding string representation.

Convert CFG::EdgeType enum constant to a string.

This function maps specific 64-bit integer values to human-readable string constants representing different types of edges within a Control Flow Graph (CFG). The implementation uses a switch statement to perform a direct lookup of the provided identifier.

Parameters
iThe 64-bit integer representing the edge type to be stringified.
Returns
A pointer to a null-terminated string containing the name of the edge type. Returns an empty string ("") if the provided integer does not match any of the predefined edge type constants.
Precondition
The input parameter i should ideally correspond to one of the defined edge type constants (0 through 7) for a meaningful return value.
Postcondition
The returned string is a static string literal and should not be modified.
Note
The mapping is as follows: 0: TRUE_EDGE 1: FALLTHROUGH_EDGE 2: FALSE_EDGE 3: BACK_EDGE 4: MULTIWAY_EDGE 5: BREAK_EDGE 6: CONTINUE_EDGE 7: RETURN_EDGE

std::string stringify::CFG::EdgeType ( int64_t ,

Retrieves and formats an edge type string with an optional prefix removal.

Convert CFG::EdgeType enum constant to a string.

This function retrieves the base edge type string for a given identifier using the overloaded EdgeType(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(CFG::EdgeType)" followed by the string representation of the identifier. Additionally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the edge type.
stripA string representing a prefix to be removed from the start of the resulting edge type string if it exists.
Returns
A string representing the formatted edge type, potentially with the strip prefix removed.
Precondition
The identifier i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the strip content if the original string contained it.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
