bool isFromAnotherFile ( SgLocatedNode * lnode)

Determines if a given node originates from a different physical file than its enclosing statement.

This function checks the file metadata associated with a provided SgLocatedNode. It first attempts to traverse through assignment initializers and cast expressions to find the underlying operand/leaf node. Once the base node is identified, the function retrieves the enclosing statement and its corresponding file. If the node is not part of a transformation or compiler-generated code, and its physical filename differs from the filename of the enclosing statement, the function returns true.

Parameters
lnodeA pointer to the SgLocatedNode to be inspected.
Returns
True if the node's physical filename is different from the enclosing file's physical filename, and the node is neither a transformation nor compiler-generated. Returns false otherwise.
Precondition
lnode must not be NULL.
Postcondition
The state of the provided lnode is not modified.
Note
The function uses ifdef DEBUG__isFromAnotherFile to perform additional logging for debugging purposes.
The function relies on the existence of an enclosing statement and file via SageInterface.
