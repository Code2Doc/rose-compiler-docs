void fortran_error_handler ( int signum)

Handles fatal errors during the Fortran parsing process.

This function serves as a signal handler or error callback to manage fatal execution errors. It attempts to identify the source of the error by retrieving the current filename via getCurrentFilename(). It then inspects the top of the astScopeStack to locate the most recent SgScopeStatement. By traversing the statement list of the current scope, the function identifies the last processed statement to extract its line number. The error message is then printed to stderr or std::cerr with specific file and line information if available. Finally, it flushes all standard I/O streams, calls fortran_error_handler_end(), and terminates the program with an exit code of -1.

Parameters
signumThe signal number that triggered the error handler.
Precondition
The astScopeStack should be initialized and contain valid SgScopeStatement pointers if the parser is in a valid state.
Postcondition
The program is terminated with an exit status of -1. All standard I/O streams are flushed.
Note
This function relies on global or externally accessible objects such as astScopeStack and functions like getCurrentFilename().
Warning
This function calls exit(-1), which will immediately terminate the entire process.

Initializes the signal handlers for Fortran error management.

This function sets up custom signal handlers for SIGABRT and SIGSEGV using the sigaction API. It ensures that the fortran_error_handler function is registered to intercept these specific signals, allowing for controlled error reporting or cleanup when a program aborts or encounters a segmentation fault.

The implementation uses the sigaction structure to define the handler, clears the signal mask using sigemptyset, and sets the sa_flags to 0. If the registration of SIGABRT fails, an error message is printed to stderr. If SIGABRT is successfully registered, it proceeds to attempt registration of SIGSEGV.

Precondition
The system must support the sigaction API and the signals SIGABRT and SIGSEGV must be available.
Postcondition
The signal handlers for SIGABRT and SIGSEGV are configured to point to fortran_error_handler, provided the registration was successful.
Note
If the define FEH_DEBUG macro is active, a debug message is printed to stdout upon successful execution.
Warning
If the sigaction call fails for either signal, an error message is printed to stderr, and the handler for that specific signal will not be updated.
