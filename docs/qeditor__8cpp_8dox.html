Inserts a string of text at the beginning of the specified document cursor position.

This function creates a mutable copy of the provided QDocumentCursor and performs a text insertion at the start of the line (column 0). The operation is performed silently, meaning it does not trigger side effects like undo/redo stack updates or view refreshes that would typically occur during a standard insertion.

Parameters
curThe original, constant document cursor representing the current position.
txtThe string of text to be inserted into the document.
Precondition
The provided QDocumentCursor must be a valid, initialized cursor.
Postcondition
The document at the position corresponding to the original cursor's line will contain the new text at the start of that line.
Note
The function uses setSilent(true) to suppress notifications during the insertion process.

This function iterates through a list of QDocumentCursor objects and tracks the highest line number encountered. It performs a linear scan of the provided QList, comparing the value returned by each cursor's lineNumber() method against a running maximum.

Parameters

Precondition

Postcondition
The returned integer represents the maximum line number found, and the input list remains unmodified.
Note
The complexity of this function is O(n), where n is the number of elements in the list.

This function iterates through a list of QDocumentCursor objects to determine the smallest line number present in the collection. It initializes the minimum value to the maximum possible 32-bit signed integer (0x7fffffff) and updates it whenever a smaller line number is encountered or if the current minimum is negative.

Parameters
lA constant reference to a QList of QDocumentCursor objects to be evaluated.
Returns
The minimum line number found in the list. If the list is empty, the function returns 0x7fffffff.
Warning
The implementation contains logic to handle negative line numbers, but users should be aware of the behavior regarding the sign bit as noted in the implementation comments.
Precondition
The input list l should contain valid QDocumentCursor objects.
Postcondition
The returned integer represents the lowest line number found in the provided list.
Note
The function uses a foreach loop to traverse the list.

Determines if a document cursor is positioned within a protected or non-editable line.

This function checks whether the line associated with the provided cursor is considered "protected." A line is deemed protected if it contains specific flags such as being hidden, or being the start or end of a collapsed block. If the cursor has an active selection, the function also evaluates the line containing the anchor of that selection to ensure the entire selection range is checked for protection.

Parameters
cA constant reference to the QDocumentCursor being inspected.
Returns
True if the cursor's current line (or the anchor line if a selection exists) is marked as Hidden, CollapsedBlockStart, or CollapsedBlockEnd; false otherwise.
Precondition
The provided QDocumentCursor c must be a valid, initialized cursor object.
Postcondition
The function does not modify the state of the input cursor or the document.
Note
The protection logic relies on the flags defined in QDocumentLine.

bool unindent ( const QDocumentCursor & cur)
static

Removes leading whitespace from the current line to perform an unindent operation.

This function identifies the leading whitespace (tabs and spaces) at the beginning of the line pointed to by the provided QDocumentCursor. It calculates how many characters constitute the current indentation level based on the global tab stop setting. The function then moves the cursor to the start of the block and removes the identified amount of leading whitespace. The algorithm iterates backwards from the first character of the line, accounting for tab expansion where a single '\t' character increments the logical indentation count by the remaining distance to the next tab stop.

Parameters
curA reference to the QDocumentCursor representing the current position in the document where the unindentation should be applied.
Returns
True if whitespace was successfully identified and removed; false if no leading whitespace was found to unindent.
Precondition
The QDocumentCursor cur must point to a valid position within a QDocument.
Postcondition
If the function returns true, the leading whitespace of the current line is reduced by one indentation level (one tab stop). If it returns false, the document remains unchanged.
Note
The function uses a silent cursor mode during the removal process to prevent unnecessary side effects or UI updates during the operation.
The calculation of indentation width is dependent on the value returned by QDocument::tabStop().
