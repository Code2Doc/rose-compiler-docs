Transforms jump statements into goto-style basic blocks within an AST.

This function iterates through a mapping of jump statements and their associated IDs, replacing each original jump statement with a newly created basic block that implements a goto-like behavior. The transformation relies on a replacement mechanism where the parent statement of the original jump is updated to point to the new block.

Parameters
jump_varA pointer to the SgVariableSymbol representing the variable used to manage or track the jump state.
jumpsA reference to a JumpMap_t containing the mapping from SgStatement pointers (the original jumps) to their respective jump identifiers.
local_targetA pointer to the SgLabelStatement that serves as the destination target for the newly created goto blocks.
Precondition
jump_var must not be null.
The jumps map must contain valid SgStatement pointers as keys.
The parent of each jump statement in the jumps map must be a valid SgStatement.
Postcondition
The original jump statements in the jumps map are replaced in the AST by new basic blocks created via createJumpReplacementGoto.
Note
This function uses const_cast to modify the statement pointer, implying that the underlying AST nodes are mutable.
The function relies on ROSE_ASSERT to validate the integrity of the AST nodes and the newly created blocks during the transformation process.

Creates a basic block that assigns a jump ID to a variable and then jumps to a target label.

This function constructs a new basic block containing two sequential statements. The first statement is an assignment operation where the value of jump_id is assigned to the variable represented by jump_var. The second statement is a goto statement that directs control flow to the specified target label. This is typically used in transformations where a standard goto is replaced by a mechanism that tracks jump identifiers via a variable.

Parameters
jump_varA pointer to the SgVariableSymbol representing the variable that will hold the jump ID.
jump_idThe numeric identifier to be assigned to the jump variable.
targetA pointer to the SgLabelStatement representing the destination of the goto statement.
Returns
A pointer to the newly created SgBasicBlock containing the assignment and the goto statement.
Precondition
jump_var must not be null.
target must not be null.
Postcondition
The returned SgBasicBlock contains an assignment statement and a goto statement.
The assignment statement and the goto statement have the returned basic block set as their parent.
Note

Recursively constructs a nested if-else structure to implement a jump table.

This function iterates through a mapping of jump values to statements, building a chain of conditional statements. For each entry in the iterator range, it creates an equality comparison between a provided variable and the jump value. If the comparison is true, the original jump statement is executed. If false, the function recurses to check the next entry in the jump map.

Parameters
jump_varA pointer to the SgVariableSymbol representing the variable used in the equality comparison for the jump table.
iThe current iterator in the ASTtools::JumpMap_t range being processed.
endThe end iterator of the ASTtools::JumpMap_t range, marking the termination of the recursion.
Returns
A pointer to the constructed SgIfStmt representing the jump table logic. Returns 0 (nullptr) if the iterator i has reached the end iterator.
Precondition
The range [i, end) must be valid and traversable.
Postcondition
The returned SgIfStmt (if not null) contains a nested structure of conditional branches covering the elements in the range [i, end).
Note
This function uses deep copying for the jump statements to ensure the original AST nodes are not mutated during the construction of the new control flow structure.

void renumberJumps ( ASTtools::JumpMap_t & J)

Reassigns sequential identifiers to all entries in a jump map.

This function iterates through the provided jump map and updates the value associated with each key to a new, monotonically increasing sequence of identifiers starting from 1. This is useful for normalizing jump targets after structural changes to the AST have occurred.

Parameters
JA reference to an ASTtools::JumpMap_t object containing the jump mappings to be renumbered.
Precondition
The jump map J must be a valid, initialized instance of ASTtools::JumpMap_t.
Postcondition
All values in the jump map J will be updated to a contiguous range of integers from 1 to the original size of the map.
Note
The order of renumbering depends on the iteration order of the underlying container in ASTtools::JumpMap_t.
