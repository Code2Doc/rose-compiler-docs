DepInfoSet Closure ( DepInfoSet t)

Computes the transitive closure of a set of dependency information.

This function calculates the complete set of dependencies by finding the transitive closure of the input dependency set. The implementation uses a recursive approach to expand the initial set and then applies a fixed-point iteration algorithm (similar to the Floyd-Warshall concept) to ensure all indirect dependencies (the product of existing dependencies) are captured. The process continues until no new dependencies can be added to the set.

Parameters
tThe initial set of dependency information to be expanded.
Returns
A new DepInfoSet representing the transitive closure of the input set t.
Precondition
The input DepInfoSet t should be a valid, well-formed dependency set.
Postcondition
The returned DepInfoSet contains all direct and indirect dependencies derived from the input set t.
Note
The complexity of this function is high due to the nested loops and the fixed-point iteration, which may lead to significant computation time for large dependency sets.

Computes the Cartesian product of two DepInfoSet objects.

This operator performs a cross-product operation between two dependency information sets. It iterates through every element in the first set (t1) and every element in the second set (t2), applying the multiplication operator of the underlying DepInfo objects. The resulting DepInfoSet contains all possible products generated from the pairs of elements from the input sets.

Parameters

t2The second dependency information set.
Returns
A new DepInfoSet containing the union of all products of elements from t1 and t2.
Precondition

Postcondition

Note
