void detectTransformations ( SgNode * node)

Detects and reports invalid transformation flags within the AST and memory pool.

This function performs a dual-layer validation check to ensure that no Sg_File_Info nodes are incorrectly marked with a transformation flag. It utilizes two distinct traversal mechanisms: first, it performs a preorder traversal of the provided AST node using the DetectTransformations traversal; second, it performs a comprehensive traversal of the entire ROSE memory pool using a custom DetectTransformationsOnMemoryPool visitor. The primary goal is to identify any instances where isTransformation() returns true, which indicates an inconsistent state in the IR metadata.

Parameters
nodeThe root node of the AST from which the initial traversal begins.
Precondition
The provided node must be a valid, non-null pointer to an SgNode or a valid subtree within the ROSE IR.
Postcondition
The function will print an error message to stdout if an invalid transformation state is detected during the memory pool traversal.
Note
This function includes performance tracking via the TimingPerformance class to monitor the overhead of the detection process.
The memory pool traversal is more exhaustive than the AST traversal as it checks every possible IR node existing in the memory pool, not just those reachable from the provided node.

void detectTransformations_local ( SgNode * node)

Performs a local transformation detection traversal on a given SgNode.

This function initiates a traversal process to identify and detect specific transformations within the provided SgNode hierarchy. It utilizes the DetectTransformations class to perform the actual traversal logic. The traversal is executed using a preorder strategy to ensure that transformations are identified from the top-down, maintaining consistency with other interface traversal patterns.

Parameters
nodeA pointer to the SgNode that serves as the root of the traversal.
Precondition
node must not be a null pointer.
Postcondition
The transformation detection process is completed for the subtree rooted at the provided node.
Note
The traversal uses a preorder approach to ensure uniform interface behavior across different traversal types.
