Performs template instantiation for non-real reference expressions by replacing template parameters with their corresponding arguments.

This function recursively traverses an expression tree to perform template instantiation. It specifically targets variable references (SgVarRefExp) that correspond to template parameters. When a match is found between a template parameter and a variable reference, the function attempts to replace the reference with the provided template argument expression. If an argument is not provided for a parameter, it attempts to use the default expression associated with that parameter. The function also handles recursive instantiation for complex expression types such as conditional expressions, size-of operators, casts, unary operations, and binary operations.

Parameters
exprThe root expression to be instantiated.
tpl_paramsA vector of template parameters used for matching against variable references.
tpl_argsA vector of template arguments that will replace the identified template parameters.
Returns
A pointer to the instantiated SgExpression. Returns nullptr if the input expression is null. Returns the original expression if it is a value expression or if no replacements are applicable.
Warning
The function calls ROSE_ABORT() if it encounters an SgNonrealRefExp or if it encounters an expression type that is not explicitly handled in the implementation.
Precondition
The input expression expr should be a valid SgExpression pointer or nullptr.
The tpl_params and tpl_args vectors should be properly initialized.
Postcondition
The returned expression tree will have template parameters replaced by their corresponding template arguments where applicable, effectively performing a single level of template instantiation for references.
Note
The implementation uses if DEBUG_Rose_Builder_Templates_instantiateNonrealRefExps to provide detailed logging of the instantiation process, including pointer addresses and class names.

Recursively instantiates non-real template types and their arguments.

This function performs the heavy lifting of template instantiation for non-real types (types that depend on template parameters). It traverses the type hierarchy, and when it encounters an SgNonrealType, it attempts to resolve the template parameters by looking up the corresponding arguments provided in the tpl_args vector. The function handles the recursive instantiation of template arguments that are themselves types or expressions. If a template parameter is encountered, it maps the parameter position to the provided argument list.

Parameters
typeThe SgType to be instantiated. This can be a standard type, a typedef, or a non-real type.
tpl_paramsA vector of SgTemplateParameter pointers representing the available template parameters.
tpl_argsA vector of SgTemplateArgument pointers representing the arguments provided for the template instantiation.
Returns
A pointer to the instantiated SgType. Returns nullptr if the type is null, if a template parameter cannot be resolved, or if an instantiation step fails.
Precondition
The input type must be a valid SgType pointer.
Postcondition
If a non-real type is successfully instantiated, a new SgTemplateInstantiationDecl is added to the scope of the original template declaration.
Note
The function uses if DEBUG_Rose_Builder_Templates_instantiateNonrealTypes to provide detailed logging of the instantiation process, including hex addresses and class names.
The function relies on ROSE_ASSERT to validate that non-real declarations are valid and that instantiation declarations are correctly formed.
Warning
The function calls ROSE_ABORT() if it encounters unsupported template argument types (such as template template parameters) or unhandled type categories (such as certain pointer/reference/const types).
