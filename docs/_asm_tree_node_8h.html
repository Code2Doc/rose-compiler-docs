Build up the ItemTree which is used in AsmView.

This function initiates the construction of an assembly tree (ItemTreeNode) by traversing the provided SgNode hierarchy. It serves as the entry point for the tree building process, initializing a root node of type AsmTreeRootNode and delegating the recursive traversal and node creation to the buildAsmTreeVisit function.

Parameters
nodeA pointer to the starting SgNode from which the assembly tree is to be built.
filterA pointer to an AstFilterInterface used to filter or determine which nodes should be included in the resulting tree.
Returns
A pointer to the root of the newly constructed ItemTreeNode tree, or NULL if the input node is NULL or has no traversal successors.
Precondition
The node parameter should not be NULL and should contain valid traversal successors to produce a non-empty tree.
Postcondition
A new AsmTreeRootNode is allocated on the heap if the function returns a non-NULL pointer. The caller is responsible for managing the memory of the returned tree.
Note
The function relies on the implementation of buildAsmTreeVisit to populate the tree structure.

Build up the ItemTree which is used in AsmView, diff-view of two binaries.

Build up the ItemTree which is used in AsmView, diff-view of two binaries.

This function performs a structural comparison between two assembly-level SgNode trees. It identifies differences at both the function level and the instruction level. The algorithm first extracts filtered assembly functions from both input nodes using the provided filters. It then utilizes a Longest Common Subsequence (LCS) based difference algorithm to find matching and differing function nodes. For each pair of functions identified, the function recursively performs a similar comparison on the underlying assembly instructions. The resulting structure is encapsulated in an ItemTreeNode hierarchy, where each node represents a point of divergence or correspondence between the two input trees.

Parameters
node1The primary SgNode representing the first assembly tree to be compared.
node2The secondary SgNode representing the second assembly tree to be compared.
filter1An AstFilterInterface used to filter the sub-tree nodes of node1 during queries.
filter2An AstFilterInterface used to filter the sub-tree nodes of node2 during queries.
Returns
A pointer to the root of the newly created ItemTreeNode tree representing the computed difference.
Precondition
node1 and node2 must be valid, non-null SgNode pointers.
filter1 and filter2 must be valid, non-null AstFilterInterface pointers.
Postcondition
A new ItemTreeNode hierarchy is allocated on the heap. The caller is responsible for managing the memory of the returned tree.
Note
The function relies on the LCS::getDiff implementation to compute the sequence of differences.
The function assumes that the nodes provided can be safely cast to SgAsmFunction and SgAsmInstruction during the traversal process.
