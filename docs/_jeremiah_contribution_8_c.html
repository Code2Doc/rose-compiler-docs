vector< SgBreakStmt * > findBreakStmts ( SgStatement * code)

Searches for all break statements within a given statement block.

This function traverses the provided statement tree starting from the given code block to identify and collect all instances of break statements. It utilizes a helper function to perform a deep traversal of the statement hierarchy.

Parameters
codeA pointer to the root SgStatement from which the search begins.
Returns
A vector containing pointers to all discovered SgBreakStmt objects within the scope of the provided code.
Precondition
The code parameter should point to a valid SgStatement object, typically representing the body of a loop or a switch statement.
Postcondition
Returns a non-empty vector if break statements are found, or an empty vector if no break statements are present in the provided scope.
Note
This function should be executed on a scope that does not define a new sub-scope that would otherwise intercept or isolate break statements, as the search is bounded by the structure of the provided statement tree.

vector< SgContinueStmt * > findContinueStmts ( SgStatement * code)

Searches for all continue statements within a given statement block.

This function traverses the provided statement block to identify and collect all instances of continue statements. It utilizes an internal helper function, findContinueStmtsHelper, to perform a deep traversal of the AST. The search is bounded by constructs that introduce new scopes, ensuring that only continue statements applicable to the current loop context are captured.

Parameters
codeA pointer to the SgStatement representing the block of code to be searched.
Returns
A vector of pointers to SgContinueStmt objects found within the provided code block.
Precondition
The parameter code should be a valid, non-null pointer to an SgStatement.
Postcondition
Returns a vector containing all discovered continue statements; the vector may be empty if no continue statements are found.
Note
This function should typically be called on the body of a loop. It is designed to stop traversing at any construct that defines a new scope, which prevents the collection of continue statements that are not legally reachable within the target loop's scope.

vector< SgInitializedName * > findVariablesDirectlyInScope ( SgStatement * sc)

Retrieves all variables initialized within the immediate scope of a given statement.

Find the variables directly in a scope, excluding those in nested scopes. This is done by searching the scope directly, so it should only be used inside a function. It might be worth fixing this up to work in all contexts.

This function performs a shallow inspection of the successors of the provided SgStatement. Unlike a standard tree traversal, this implementation is designed to avoid entering nested inner scope statements, focusing only on declarations and initializations that occur directly within the current scope level. It iterates through the traversal successor container in reverse order to collect variables from SgVariableDeclaration nodes and recursively processes SgForInitStatement nodes.

Parameters
scA pointer to the SgStatement whose immediate scope is being inspected.
Returns
A vector of SgInitializedName pointers representing the variables found directly within the scope of the provided statement.
Precondition
sc must not be a null pointer.
Postcondition
The returned vector contains all variables declared in the immediate successors of sc, including those from for-loop initialization statements.
Note
This function uses a reverse iteration over the successor container, which affects the order in which variables are inserted into the result vector.
