Extracts the portion of a string that follows a specific substring.

This function searches for the first occurrence of the provided tag within the string s. If the tag is found, the function returns a new string containing all characters appearing after the end of the tag. If the tag is not found within s, an empty string is returned.

Parameters
sThe source string to be searched.
tagThe substring to search for within the source string.
Returns
A string containing the characters from s that follow the first occurrence of tag. Returns an empty string if tag is not found.
Precondition
The input strings s and tag should be valid std::string objects.
Postcondition
The returned string is a new string object; the original string s remains unmodified.
Note
The function uses std::string::find to locate the substring and std::string::substr to perform the extraction.

string trim ( const string & s)

Removes leading and trailing whitespace from a string.

This function creates a copy of the input string and removes all whitespace characters (space, tab, newline, carriage return) from both the beginning and the end of the string. The implementation uses the find_first_not_of and find_last_not_of member functions of the std::string class to identify the boundaries of the non-whitespace content.

Parameters
sThe input string from which leading and trailing whitespace should be removed.
Returns
A new string that is a copy of the input string with all leading and trailing whitespace characters removed. If the string consists entirely of whitespace, an empty string is returned.
Precondition
The input parameter s must be a valid std::string object.
Postcondition
The returned string contains no characters from the set {' ', '\t', '
', '\r'} at its start or end.
Note
The whitespace characters handled are specifically space, horizontal tab, newline, and carriage return.

Extracts the prefix of a string up to the end of a specified tag.

This function searches for the first occurrence of the provided tag within the string s. If the tag is found, the function returns a substring of s starting from the beginning and ending exactly at the end of the found tag. If the tag is not found, an empty string is returned.

Parameters
sThe source string to be searched.
tagThe substring to search for within the source string.
Returns
A substring of s containing everything from the start up to and including the end of the tag. Returns an empty string if the tag is not found in s.
Precondition
The input strings s and tag should be valid std::string objects.
Postcondition
The returned string is a new string object containing the prefix of s.
Note
The function uses std::string::find to locate the tag and std::string::substr to extract the result.
