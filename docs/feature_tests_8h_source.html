1// This file defines various C preprocessor macros that describe what ROSE features are enabled in this configuration. The
2// advantage of doing this in a C header instead of calculating it in the configuration system and storing a result is that
3// this same logic can then be used across all configuration and build systems.
4//
5// All ROSE feature macros start with the letters "ROSE_ENABLED_" followed by the name of the feature. These macros are defined
6// if the feature is enabled, and not defined (but also not #undef) if the feature is not automatically enabled. By not
7// explicitly undefining the macro, we make it possible for developers to enabled features from the C++ compiler command-line
8// that would not normally be enabled.
