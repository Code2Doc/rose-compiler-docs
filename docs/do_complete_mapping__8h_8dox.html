separator * mapSeparatorsAST ( std::vector< SgNode * > & linearizedAST)

Maps scope boundaries within a linearized AST to a hierarchical separator structure.

This function traverses a linearized Abstract Syntax Tree (AST) to identify scope statements and construct a tree of separator objects. It tracks nested scopes using a stack-based approach, effectively mapping the start and end indices of code blocks. The algorithm specifically filters out certain types of scope statements (such as function definitions, switch statements, and if statements) to avoid processing basic blocks that are already attached to their parent scopes. It maintains a hierarchy of separators where each separator can contain sub-separators representing nested scopes.

Parameters
linearizedASTA vector of SgNode pointers representing the linearized AST to be processed.
Returns
A pointer to a separator object representing the global scope, which contains the hierarchical structure of all identified scopes within the AST.
Precondition
The linearizedAST must be a valid, non-empty vector of SgNode pointers.
Postcondition
Returns a pointer to a newly allocated separator object. The caller is responsible for managing the memory of the returned separator and its hierarchy.
Note
The implementation uses ifndef _GLIBCXX_CONCEPT_CHECKS to conditionally handle the assignment of sub_separators, ensuring compatibility with different standard library configuration levels.
The function relies on ROSE_ASSERT and ROSE_ABORT for error handling during structural inconsistencies in the AST or stack depth.

separator * mapSeparatorsTokenStream ( token_container & tokenStream)

Maps brace-delimited scopes within a token stream to a hierarchical structure of separators.

Maps curly brace scopes within a token stream to a hierarchical structure of separators.

This function iterates through a stream of tokens to identify matching left and right curly braces. It constructs a tree-like structure of separator objects, where each separator represents a scope defined by braces. The function tracks nesting levels using a stack-based approach, creating a new scope level whenever a T_LEFTBRACE is encountered and closing/finalizing a scope when a T_RIGHTBRACE is encountered. The resulting structure is encapsulated within a root separator object representing the global scope.

Parameters
tokenStreamA reference to a token_container containing the sequence of tokens to be parsed.
Returns
A pointer to a separator object representing the top-level (global) scope, containing all identified nested scopes.
Precondition
The tokenStream should contain valid tokens, and the brace nesting within the stream must be balanced.
Postcondition
A new separator object is allocated on the heap. The caller is responsible for managing the memory of the returned pointer and its nested structure.
Warning

Note
