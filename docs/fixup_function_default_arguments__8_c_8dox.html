Checks if a given expression node contains any lambda expressions within its subtree.

This function performs a deep traversal of the provided AST subtree starting at the given node. It is specifically utilized to identify the presence of lambda expressions to ensure that complex cleanup operations, such as deleting lambda expressions and their associated generated classes and member functions, are handled correctly. This is necessary because the standard SageInterface::deleteAST mechanism may not be robust enough for these specific complex cases involving lambdas.

The implementation uses an internal class, LambdaTestTraversal, which inherits from AstSimpleProcessing. This traversal class implements a visitor pattern that flags a boolean value if any node encountered during the preorder traversal is identified as an SgLambdaExp.

Determines the best function declaration to associate default arguments.

This function identifies the most appropriate function declaration within the AST to hold default arguments, ensuring that redundant default argument entries across multiple declarations are eliminated. It handles both SgProject nodes (by recursively processing all files in the project) and SgFile nodes.
