void testAstForUniqueNodes ( SgNode * node)

Verifies that all nodes within an Abstract Syntax Tree (AST) are unique.

This function performs a structural validation on the provided AST starting from the given node. It utilizes the TestAstForUniqueNodesInAST utility to traverse the tree and ensure that no two pointers within the tree structure refer to the same memory address, thereby detecting potential issues with node duplication or incorrect tree cloning.

Parameters
nodeA pointer to the root SgNode of the AST to be tested.
Precondition
node must not be a null pointer.
Postcondition
The function completes the uniqueness check, potentially triggering a test failure if duplicate nodes are detected.
Note
This function is primarily used for regression testing and structural integrity verification during AST manipulation.
