Detailed Description

Auto-generated documentation for the IntegerOps namespace.

Bit-wise operations on integers.

Many of these are function templates for the best optimization, but we also provide non-template versions for those cases when the arguments are not known at compile time. The non-template versions typically have "2" appended to their names to indicate that they should be the second choice–used only when the template version cannot be used.

Checks if the bitmask m2 is a subset of the bitmask m1.

This function determines whether all bits set in the second bitmask (m2) are also set in the first bitmask (m1). The implementation uses a bitwise NOT operation on m1 followed by a bitwise AND with m2. If the result is zero, it implies that no bits exist in m2 that are not present in m1.

Performs a logical right shift on a value with a safety check against the bit width.

Shifts bits of value right by count bits without sign extension.

This function implements a logical right shift operation on a value of type T. It includes a bounds check to ensure that the shift count does not exceed or equal the predefined bit width NBits. If the shift count is greater than or equal to NBits, the function returns a zero-initialized value of type T, preventing undefined behavior associated with shifting by a value greater than or equal to the width of the type.

Parameters
valueThe value to be shifted.
countThe number of positions to shift the value to the right.
Returns
The result of the logical right shift if count < NBits; otherwise, 0 of type T.
Precondition
The template parameter NBits should represent the bit width of the type T to ensure logical consistency.
Postcondition
The returned value is either the shifted value or zero, depending on the relationship between count and NBits.
Note
This function is useful for bit manipulation in fixed-width integer arithmetic where preventing undefined behavior from large shift counts is critical.

Performs sign extension on a value from a specified bit width to a new bit width.

Sign extend value. If the bit FromBits-1 is set set for value, then the result will have bits FromBits through ToBits-1 also set (other bits are unchanged). If ToBits is less than or equal to FromBits then nothing happens.

This function extends the sign bit of a value from a source bit width (FromBits) to a target bit width (ToBits). It works by checking the state of the bit at position FromBits-1. If that bit is set, the function applies a mask to fill all bits from FromBits up to ToBits-1 with ones. Otherwise, it ensures the upper bits are zeroed. The implementation relies on the signBit and GenMask utilities to manipulate the bitmask.

Parameters
valueThe input value of type T that needs to be sign-extended.
Template Parameters
FromBitsThe bit width of the input value's significant bits.
ToBitsThe target bit width to which the value should be extended.
Precondition
The type T must be an integral type capable of representing the bit widths.
FromBits and ToBits must be valid sizes for the type T.
Postcondition
The returned value has the same numerical value as the input, but represented within the context of the ToBits width.
Note
This function uses template metaprogramming via GenMask to compute bitmasks at compile time.

Performs sign extension on a value from a specified bit width to a larger bit width.

This function extends the sign bit of a value from a source bit width (from_width) to a target bit width (to_width). It works by checking the bit at the from_width - 1 position. If that bit is set (indicating a negative value in two's complement), the function applies a mask to fill the bits from from_width up to to_width - 1 with ones. Otherwise, it leaves the upper bits as zeros.

Parameters
valueThe input value to be sign-extended.
from_widthThe bit width of the original value's significant bits.
to_widthThe target bit width to which the value should be extended.
Precondition
The from_width and to_width must be less than or equal to the total bit width of the type T (8 * sizeof(T)).
Postcondition
The returned value has the bits from from_width to to_width - 1 set to the value of the sign bit of the original from_width-bit value.
Note
This function relies on the existence of signBit2 and genMask functions.
Warning
If from_width is greater than to_width, the behavior depends on the implementation of the bitwise XOR and masking logic, which may not produce a standard sign extension.
