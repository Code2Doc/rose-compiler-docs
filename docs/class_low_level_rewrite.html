◆ isRemovableStatement()

bool LowLevelRewrite::isRemovableStatement ( SgStatement * s)
static

This function qualifies a statement as to if it can be removed from the AST or not. Not all statements can be removed, e.g. the SgBasicBlock in a SgForStatement or similar statement containing a SgBasicBlock to represent a body. Only a statement in an AST node representing a list can be removed (I don't know of any exceptions). By definition, the statement is removeable if it's parent is a container.
