SgVariableSymbol * getVarSym ( SgNode * n)

Retrieves the variable symbol associated with a given SgNode.

This function attempts to extract a variable symbol from the provided SgNode. It internally calls the constant version of the function, getVarSym_const, and then performs a const_cast to strip the const-qualification from the returned pointer, allowing the caller to receive a non-const pointer to the SgVariableSymbol.

Parameters
nA pointer to the SgNode from which the variable symbol is to be retrieved.
Returns
A pointer to the SgVariableSymbol associated with the node. The returned pointer is non-const.
Precondition
n should be a valid pointer to an SgNode.
Postcondition
The returned pointer points to an SgVariableSymbol that may be modified by the caller, as the const-qualification has been removed.
Note
This function relies on the implementation of getVarSym_const.

SgVariableSymbol * getVarSymFromName ( SgInitializedName * name)

Retrieves the variable symbol associated with a given initialized name.

This function attempts to find and return the SgVariableSymbol that corresponds to the provided SgInitializedName. It internally calls the constant version of the function, getVarSymFromName_const, to perform the lookup. If the lookup fails, the function currently does not perform any explicit error handling, though the underlying implementation may have been subject to assertions or logging in previous iterations. The result is cast from a const pointer to a non-const pointer to allow for modification of the returned symbol.

Parameters
nameA pointer to the SgInitializedName object whose associated variable symbol is to be retrieved.
Returns
A pointer to the SgVariableSymbol associated with the input name. Returns NULL if no symbol is found for the provided name.
Precondition
name must not be NULL.
Postcondition
The returned pointer points to a non-const SgVariableSymbol if a match is found, or NULL if no match exists.
Note
The function uses const_cast to strip the const-qualification from the pointer returned by the const version of the lookup function.

void getVarSyms ( SgNode * n,
ASTtools::VarSymSet_t * p_syms )

Extracts variable symbols from an AST node and populates a provided symbol set.

This function traverses the provided SgNode and identifies variable symbols within it. It handles different node variants including SgVariableSymbol, SgVariableDeclaration, and SgInitializedName. For variable declarations, it iterates through the list of initialized names and attempts to resolve them to symbols. The function also performs filtering to exclude compiler-specific built-in function names like PRETTY_FUNCTION, FUNCTION, and func depending on the platform.

Parameters
nA pointer to the SgNode to be inspected for variable symbols.
p_symsA pointer to an ASTtools::VarSymSet_t where discovered symbols will be inserted.
Precondition
n must not be NULL and p_syms must not be NULL for the function to perform any work.
Postcondition
If valid nodes are found, p_syms will contain the discovered SgVariableSymbol pointers.
Note
The function uses ifdef linux to handle platform-specific filtering of compiler-generated function name strings.
If a symbol cannot be resolved during a variable declaration traversal, a warning is printed to stderr.
