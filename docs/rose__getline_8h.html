ROSE_UTIL_API ssize_t rose_getline ( char ** lineptr,
size_t * n,
FILE * stream )

Reads a line from the specified stream and stores it in the buffer.

Reads a line of text from a stream.

This function reads an entire line from stream, storing the text (including the newline and a terminating null character) in a buffer and storing the buffer address in lineptr. This documentation is copied from the GNU source code with a few formatting modifications and name changes. The original GNU getline() function is reportedly not available on Mac OSX v10.6 (Snow Leopard) for licensing reasons, so we provide our own implementation.

Before calling rose_getline(), you should place in lineptr the address of a buffer n bytes long, allocated with malloc(). If this buffer is long enough to hold the line, rose_getline() stores the line in this buffer. Otherwise, rose_getline() makes the buffer bigger using realloc(), storing the new buffer address back in lineptr and the increased size back in n.

If you set lineptr to a null pointer, and n to zero, before the call, then rose_getline() allocates the initial buffer for you by calling malloc().

In either case, when rose_getline() returns, lineptr points to the text of the line.

When rose_getline() is successful, it returns the number of characters read (including the newline, but not including the terminating null). This value enables you to distinguish NUL characters that are part of the line from the NUL character inserted as a terminator.

This is the recommended way to read lines from a stream. The alternative standard functions are unreliable.

If an error occurs or end of file is reached without any bytes read, getline() returns -1.

This function acts as a wrapper for the underlying implementation of the getline functionality. It reads characters from the provided file stream until a newline character or end-of-file is encountered. The function manages the buffer pointed to by lineptr, potentially reallocating memory to accommodate the length of the line read.

Parameters
lineptrA pointer to a pointer to a buffer. On success, the buffer points to the allocated string. If *lineptr is NULL, the function allocates a new buffer.
nA pointer to a size_t variable that stores the size of the buffer pointed to by *lineptr.
streamA pointer to a FILE object representing the input stream.
Returns
The number of characters read, including the newline character, on success. Returns -1 on error, and sets errno appropriately.
Precondition
The stream parameter must be a valid, open FILE pointer.
Postcondition
The buffer pointed to by *lineptr is updated to contain the read line, and *n is updated to reflect the new buffer size.
Note
This function relies on the implementation provided by rose_getline_impl.

Reads a line of text from a stream.

This function reads an entire line from stream and returns the line along with any line termination characters that were present. Returns an empty string when the end of the stream is reached. NUL characters that appear as part of the input are preserved in the return value.

This function serves as a wrapper around the rose_getline function that manages memory for the buffer internally. It utilizes a local RAII structure named Resources to handle the allocation and deallocation of the character buffer. The function reads characters from the provided stream until a newline character or end-of-file is encountered.

Parameters

Returns
A std::string containing the line read from the stream. If no characters were read (e.g., due to an error or EOF), an empty string is returned.
Precondition
The stream parameter must be a valid, open FILE pointer.
Postcondition
The memory allocated for the internal buffer is automatically freed via the Resources destructor.

ROSE_UTIL_API std::string rose_getline ( std::istream & stream)

Reads a single line from an input stream and returns it as a string.

This function serves as a wrapper around the lower-level rose_getline function. It manages the lifecycle of a temporary buffer using a local RAII structure named Resources. The function allocates memory via the underlying rose_getline call and ensures that the allocated buffer is freed when the Resources object goes out of scope. The content of the buffer is then converted into a std::string.

Parameters
streamThe input stream from which the line is to be read.
Returns
A std::string containing the characters read from the stream up to the newline character. Returns an empty string if no characters were read or if an error occurred during reading.
Precondition
The input stream stream must be in a valid state and ready for reading.
Postcondition
The memory allocated by the internal rose_getline call is guaranteed to be released.
Note
This function relies on the existence of a compatible rose_getline function that accepts a pointer to a char pointer and a pointer to a size_t for buffer management.
