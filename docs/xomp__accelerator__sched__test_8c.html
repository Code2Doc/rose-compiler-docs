Initializes parameters for a static loop scheduling strategy.

This function calculates the necessary scheduling parameters for a static distribution of loop iterations across multiple threads. It determines the chunk size, the starting index for a specific thread, and the stride between chunks. The implementation handles both single-threaded and multi-threaded execution contexts. In a single-threaded context, the scheduling index is simply set to the lower bound. In a multi-threaded context, the chunk size is scaled by a step factor, and the starting index and stride are computed based on the thread ID and the total number of threads.

Parameters

upThe upper bound of the loop.
stepThe step factor used to scale the original chunk size.
orig_chunk_sizeThe base size of the loop chunk before scaling.
_p_num_threadsThe total number of threads participating in the parallel execution.
_p_thread_idThe unique identifier of the current thread.
loop_chunk_sizePointer to an integer where the calculated chunk size will be stored.
loop_sched_indexPointer to an integer where the calculated starting index for the current thread will be stored.
loop_stridePointer to an integer where the calculated stride between thread chunks will be stored.
Precondition

Postcondition

If _p_num_threads is greater than 1, loop_chunk_size, loop_sched_index, and loop_stride are updated with calculated values.

Determines the next iteration range for static loop scheduling.

This function calculates the lower and upper bounds for the next chunk of iterations to be processed by a specific thread. It handles both single-threaded and multi-threaded execution contexts. In a single-threaded context, it iterates through the loop sequentially. In a multi-threaded context, it advances the global loop scheduler index by the specified stride and calculates a chunk of work based on the provided chunk size.

Parameters
loop_sched_indexA pointer to the current global iteration index. This value is updated by the function to track progress through the loop.
loop_endThe total number of iterations or the end boundary of the loop.
loop_strideThe increment value applied to the loop_sched_index in multi-threaded execution.
loop_chunk_sizeThe size of the block of iterations to be processed in the current step.
_p_num_threadsThe total number of threads participating in the parallel execution.
_p_thread_idThe unique identifier of the current thread.
lbA pointer to an integer where the calculated lower bound of the current iteration chunk will be stored.
ubA pointer to an integer where the calculated upper bound of the current iteration chunk will be stored.
Returns
Returns 1 if a valid iteration range was calculated and there is work to be done; returns 0 if the loop has reached its end or no further iterations are available.
Precondition
loop_sched_index, lb, and ub must point to valid, writable integer memory locations.
Postcondition
loop_sched_index is updated by loop_stride in multi-threaded mode, or set to loop_end in single-threaded mode.
The values pointed to by lb and ub are updated with the bounds of the current iteration chunk.
Note
If loop_chunk_size is greater than 0, the function ensures the upper bound does not exceed loop_end. If loop_chunk_size is 0 or negative, the function follows a different termination logic based on the comparison of the current index and loop_end.
