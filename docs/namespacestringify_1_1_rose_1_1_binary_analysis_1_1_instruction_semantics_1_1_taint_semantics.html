Converts a numerical taint state into its corresponding string representation.

Convert Rose::BinaryAnalysis::InstructionSemantics::TaintSemantics::Taintedness enum constant to a string.

This function maps specific 64-bit integer values to their human-readable string labels representing the level of taintedness in the analysis. The mapping follows a lattice-based approach where 0 represents the least element (BOTTOM) and 3 represents the greatest element (TOP).

Parameters
iThe 64-bit integer representing the taint state to be converted.
Returns
A pointer to a constant character string representing the taint state. Returns "BOTTOM" for 0, "UNTAINTED" for 1, "TAINTED" for 2, "TOP" for 3, and an empty string "" for any other value.
Precondition
The input parameter i should ideally be within the range [0, 3] to receive a valid semantic label.
Postcondition
The returned string is a static string literal and does not require memory deallocation by the caller.
Note
This function uses a simple switch-case implementation for constant-time lookup of the string labels.
