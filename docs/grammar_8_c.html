bool generate_override_keyword ( AstNodeClass & node,
GrammarString & data )

Determines whether an override keyword should be generated based on the node type and variable name.

This function evaluates a specific set of criteria involving an AST node's base name and a variable name string from the grammar data. It checks for specific combinations of node types (such as XXXPragma, IfStmt, ClassDeclaration, etc.) and associated property strings (such as startOfConstruct, end_numeric_label, type, or name). If the current node and variable name match any of the predefined blacklisted patterns, the function indicates that an override keyword should not be generated.

Parameters
nodeA reference to an AstNodeClass object representing the current AST node being evaluated.
dataA reference to a GrammarString object containing the grammar metadata, specifically the variableNameString to be checked.
Returns
True if the node and variable name combination does not match any of the restricted patterns, implying an override keyword can be generated; false otherwise.
Precondition
The node and data references must be valid and initialized.
Postcondition
The return value indicates the validity of generating an override keyword without modifying the input parameters.
Note
The implementation contains various hardcoded checks for different language constructs including Ada, C++, Java, and Assembly (Asm).
Historical notes indicate that untyped Sage nodes were removed to streamline the construction of regular IR nodes from the Jovial parser.

bool generate_override_keyword_for_set_functions ( AstNodeClass & node,
GrammarString & data )

Determines whether the override keyword should be generated for setter functions based on node type and variable name.

This function evaluates a specific set of AST node classes and their associated variable name strings to decide if the override keyword should be suppressed. It checks the base name of the provided AstNodeClass against a predefined list of node types (such as Pragma, File, TemplateParameter, etc.) and specific property strings (such as "type", "name", "scope", or "startOfConstruct"). If a match is found between the node's base name and the variable name string, the function indicates that the override keyword should not be generated.

Parameters
nodeThe AST node class instance being evaluated.
dataA GrammarString containing the variable name string to be checked against the node's properties.
Returns
True if the override keyword should be generated; false if the current node and variable name combination matches a known case where the keyword should be suppressed.
Precondition
The node parameter must be a valid, initialized instance of AstNodeClass.
Postcondition
The return value indicates the eligibility for the override keyword generation.
Note
The implementation contains specific logic to exclude certain untyped nodes, as noted in the source comments regarding the transition from the Jovial parser to regular IR nodes.
