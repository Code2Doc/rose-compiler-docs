Compares two keyword strings for lexicographical order.

This function serves as a comparator callback, typically used with standard C library functions like qsort. It performs a deep comparison by casting the void pointers to pointers of character pointers (const char **) and then dereferencing them to access the underlying strings. The comparison is performed using the strcmp function.

Parameters
aA pointer to a pointer to a constant character string.
bA pointer to a pointer to a constant character string.
Returns
An integer less than, equal to, or greater than zero if a, b, or a is not equal to b, respectively, based on the lexicographical order of the strings being pointed to.
Precondition
The pointers a and b must not be NULL, and the memory they point to must contain valid pointers to null-terminated character strings.
Postcondition
The state of the strings being compared remains unchanged.
Note
This function assumes that the input pointers are of type const char**. Incorrectly passing pointers to types other than char* will result in undefined behavior.

void style_init ( Fl_Text_Buffer * buf)

Initializes the global text buffer and applies syntax styling.

This function sets the global text buffer pointer to the provided buffer and performs an initial pass to generate a style buffer. It allocates a temporary character array to hold style information, initializes it with a default style character 'A', and then invokes style_parse to analyze the text content and apply specific formatting rules. The resulting style string is then applied to the global style buffer.

Parameters
bufA pointer to the Fl_Text_Buffer containing the text to be styled.
Precondition
The parameter buf must not be a null pointer.
Postcondition
The global variable glob_textbuf is updated to point to buf. The global variable glob_stylebuf is initialized if it was null. The contents of glob_stylebuf are updated based on the parsed style.
Note
This function relies on the existence of global variables glob_textbuf, glob_stylebuf, and the function style_parse. It performs dynamic memory allocation for the style array and assumes the text buffer is valid.
Warning
This function calls free() on the pointer returned by glob_textbuf->text(), which may lead to undefined behavior if the buffer's internal text pointer is managed by the Fl_Text_Buffer object and should not be manually freed by the caller.

Parses a text buffer to assign syntax highlighting styles to each character.

This function iterates through a provided character buffer and determines the appropriate syntax style for each character based on its context (e.g., directives, comments, strings, or keywords). It uses a state-machine approach to track the current parsing state, such as being inside a block comment, a line comment, or a string literal. The function identifies keywords by performing a binary search against predefined arrays code_types and code_keywords.

Parameters
textA pointer to the input null-terminated string or buffer to be parsed.
styleA pointer to a character buffer where the calculated style identifiers will be written for each character in the input.
lengthThe number of characters in the text buffer to be processed.
Precondition
The style buffer must be large enough to hold at least length characters.
Postcondition
The style buffer will contain a sequence of style identifiers corresponding to the characters in text.
Note
The function relies on the existence of global or externally defined code_types and code_keywords arrays, and a compare_keywords comparison function for the bsearch calls.
The parsing logic handles escaped quotes (e.g., %" ) within strings to prevent premature termination of string state.

Updates the text style buffer based on recent text insertions or deletions.

This function synchronizes the style buffer with the text buffer following an edit operation. It handles character insertion, deletion, and replacement within the style buffer, then triggers a re-parsing of the affected text range using style_parse to ensure syntax highlighting remains consistent. If the style change at the end of the modified line affects the styling of subsequent lines (e.g., due to multi-line comment delimiters), the function performs a recursive-style re-parse from the start of the modified line to the end of the entire buffer.

Parameters
posThe starting position of the update in the text buffer.
nInsertedThe number of characters that were inserted into the text buffer.
nDeletedThe number of characters that were deleted from the text buffer.
nRestyledThe number of characters that were restyled (unused in implementation).
deletedTextThe string containing the text that was removed (unused in implementation).
cbArgA pointer to the callback argument, which must be a pointer to an Fl_Text_Editor instance used for triggering redisplay.
Precondition
The global buffers glob_textbuf and glob_stylebuf must be initialized and valid.
cbArg must be a valid pointer to an Fl_Text_Editor object.
Postcondition
The glob_stylebuf is updated to reflect the new text content.
The Fl_Text_Editor specified by cbArg is notified to redisplay the affected ranges.
Note
The function uses dynamic memory allocation via new[] and malloc/free (via text_range/style_range) and is responsible for cleaning up the allocated text and style buffers.
If nInserted and nDeleted are both zero, the function simply unselects the style buffer and returns early.
