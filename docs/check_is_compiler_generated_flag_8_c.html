size_t checkIsCompilerGeneratedFlag ( SgNode * ast)

Checks and marks AST nodes as compiler-generated if they are frontend-specific.

This function performs a preorder traversal of the provided Abstract Syntax Tree (AST) using a custom visitor pattern (AstSimpleProcessing). It inspects all nodes that implement the SgLocatedNode interface. For each located node, it examines the associated file information. If the file information is identified as being frontend-specific but is not currently marked as compiler-generated, the function updates the file information to set the compiler-generated flag and increments a violation counter.

Parameters
astA pointer to the root SgNode of the AST to be traversed and inspected.
Returns
The total number of violations found, where a violation is defined as a frontend-specific file info object that was not previously marked as compiler-generated.
Precondition
The parameter ast should be a valid, non-null pointer to an SgNode representing the root of a valid AST.
Postcondition
Any SgLocatedNode within the AST that possesses frontend-specific file information will have its compiler-generated flag set to true.
Note
The implementation uses an internal helper struct T1 derived from AstSimpleProcessing to manage the traversal state and violation count.
The function uses if and ifdef preprocessor directives to manage debug logging, which is currently disabled via if 0.
