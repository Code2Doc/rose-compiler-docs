Node Rose::Yaml::toYaml ( const json & j)
static

Converts a JSON object into its corresponding YAML Node representation.

This function performs a deep conversion of a JSON structure into a YAML structure. It recursively traverses the input JSON object, mapping JSON types (null, object, array, boolean, string, and various numeric types) to their equivalent YAML node types. For objects and arrays, the function calls itself recursively to ensure the entire nested hierarchy is converted.

Parameters
jThe input JSON object to be converted.
Returns
A YAML Node containing the converted data structure.
Precondition
The input JSON object j should contain valid, serializable data.
Postcondition
The returned YAML Node will have a structure that mirrors the input JSON hierarchy, with primitive types mapped to YAML scalars.
Note
The function relies on the json library's type-checking methods such as is_object(), is_array(), etc. It uses an assertion to ensure that if a value is not one of the explicitly handled types, it must be a numeric type.
