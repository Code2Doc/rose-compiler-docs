bool Rose::Cmdline::Unparser::OptionRequiresArgument ( const std::string & option)

Determines if a specific command-line option requires an accompanying argument.

Returns
true if the Unparser option requires a user-specified argument.

This function checks the provided command-line option string against a hardcoded list of options that are known to require an argument. Currently, it specifically checks if the input string matches the "-rose:unparser:some_option_taking_argument" flag. This is used during the parsing phase of the unparser command-line interface to decide whether the parser should look for a subsequent value in the argument list.

Parameters
optionA string representing the command-line option to be checked.
Returns
True if the specified option requires an argument, false otherwise.
Precondition
The option string should be a valid command-line flag (e.g., starting with a hyphen).
Postcondition
The return value indicates the requirement status of the input option.
Note
This implementation is currently limited to a single hardcoded option.

Processes command-line arguments for the Unparser component.

Process all Unparser-specific commandline options, i.e. -rose:unparser.

This function iterates through the provided command-line arguments to configure the Unparser behavior. It specifically handles the identification and processing of input files that should be treated as clobber targets. If the global verbose level of the SgProject is set higher than 1, an informational message is printed to the standard output.

Parameters
projectA pointer to the SgProject instance which holds the global configuration and verbosity settings.
argvA vector of strings containing the command-line arguments to be parsed.
Precondition
project must not be a null pointer.
Postcondition
The command-line arguments are processed, potentially modifying the state of the project or identifying files for clobbering via ProcessClobberInputFile.
Note
This function relies on the global verbosity state of the SgProject to determine whether to log processing information.

void Rose::Cmdline::Unparser::ProcessClobberInputFile ( SgProject * project,
std::vector< std::string > & argv )

Processes the clobber input file option from the command line arguments.

This function scans the provided command line argument vector for the "clobber_input_file" option using the Unparser's specific option prefix. If the option is found, it modifies the provided SgProject instance to enable the destructive clobber mode and removes the option from the argv vector. If the option is not present, it ensures the clobber mode is disabled in the project.

Parameters
projectA pointer to the SgProject instance that will be updated with the clobber setting.
argvA vector of strings representing the command line arguments to be parsed.
Warning
Enabling clobber mode is a destructive operation that may overwrite input files.
Precondition
project must not be a null pointer.
Postcondition
The state of the clobber input file setting in the project is synchronized with the presence of the "clobber_input_file" flag in argv.
Note
If the project's verbose level is greater than 1, an informational warning is printed to standard output when clobber mode is activated.

Removes Rose-specific unparser options from the command line argument vector.

This function processes the provided command line argument vector to identify and strip out options that are prefixed with the unparser-specific Rose prefix. It specifically handles options without arguments by utilizing the sla utility. The function is designed to clean the argv vector so that only general command line arguments remain, while the extracted unparser options are processed or handled separately.

Parameters
argvA reference to a vector of strings representing the command line arguments to be modified in place.
Precondition
The argv vector must be a valid, initialized vector of strings.
Postcondition
The argv vector will have all elements matching the "-rose:unparser:" prefix (and their associated arguments where applicable) removed.
Note
This function currently relies on the sla utility for handling options without arguments.
