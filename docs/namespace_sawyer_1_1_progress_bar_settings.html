SAWYER_EXPORT double Sawyer::ProgressBarSettings::initialDelay ( )

Retrieves the initial delay value for the progress bar.

Delay before first message is emitted. A relatively large delay produces fewer messages by avoiding messages when the entire task can be completed quickly. The default is 5 seconds, although some libraries that use Sawyer change the default. This value is global, applying to all progress bars.

This function provides access to the configured initial delay period, which represents the amount of time the progress bar waits before it begins to appear or start updating. The value is retrieved from the underlying implementation class.

Returns
The initial delay value as a double.
Precondition
None.
Postcondition
The state of the object remains unchanged.

Retrieves the minimum interval allowed between progress bar updates.

Minimum time between updates. Measured in seconds.

This function provides access to the internal minimum update interval setting used by the progress bar implementation. This value is used to throttle the frequency of UI or console updates to prevent excessive resource consumption during high-frequency progress changes.

Postcondition
The state of the object remains unchanged.
Note

◆ minimumUpdateInterval() [2/2]

SAWYER_EXPORT void Sawyer::ProgressBarSettings::minimumUpdateInterval ( double s)

Sets the minimum interval between progress bar updates.

This function updates the internal configuration for the progress bar to establish a threshold for how frequently the progress bar is allowed to refresh its visual state. This is typically used to prevent excessive UI redraws and reduce CPU overhead during high-frequency updates.

Parameters
sThe new minimum time interval (in seconds) between updates.
Precondition
The value of s should be non-negative.
Postcondition
The internal minimum update interval is updated to the value provided by s.
Note
A very small value for s may lead to increased CPU usage due to frequent UI updates.
