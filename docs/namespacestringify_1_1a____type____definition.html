Retrieves a constant reference to a vector containing type definition kind values.

This function provides access to a predefined, static collection of 64-bit integer constants representing various type definition kinds. The values are stored in a static vector to ensure they are initialized only once and persist for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the sequence of integers from 0 to 7.
Precondition

Postcondition

Note

Converts a type definition kind integer ID into its corresponding string representation.

This function performs a mapping from a 64-bit integer identifier to a human-readable string constant representing the specific type of a type definition. It uses a switch-case mechanism to evaluate the input value against known type definition kinds.

Parameters
iThe 64-bit integer representing the type definition kind.
Returns
A pointer to a null-terminated string containing the name of the type definition kind. Returns "tdk_unknown" for 0, specific strings for values 1 through 7, and an empty string "" for any other value.
Precondition
The input parameter i should ideally correspond to one of the defined integer constants for type definition kinds.
Postcondition
The returned string is a constant character array that does not require manual memory management.
Note
The mapping is as follows: 0: tdk_unknown 1: tdk_ref_class 2: tdk_interface_class 3: tdk_value_class 4: tdk_enum_class 5: tdk_delegate 6: tdk_native_class 7: tdk_native_enum
