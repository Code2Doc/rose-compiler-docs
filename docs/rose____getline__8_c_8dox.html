int get_next_char ( FILE * stream)

Reads the next character from the specified file stream.

This function serves as a wrapper around the standard C library function fgetc. It retrieves the next character available from the input stream pointed to by the stream argument.

Parameters
streamA pointer to a FILE object that defines the input stream.
Returns
The next character on the specified stream, returned as an int. If the end-of-file is reached or a read error occurs, EOF is returned.
Precondition
The stream parameter must not be NULL.
Postcondition
The file position indicator for the stream is advanced by one character.
Note
This function is a simple abstraction for fgetc and behaves identically to the underlying standard library implementation.
