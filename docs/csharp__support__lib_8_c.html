Processes a source file by invoking a Mono-based execution pipeline.

This function constructs a path to a specific C# DLL (csharp_main.dll) located within the ROSE build directory and then executes a processing routine through Mono. It serves as a bridge to trigger C# logic from the C++ environment. The function explicitly avoids using define macros like ROSE_AUTOMAKE_TOP_BUILDDIR directly to prevent symbol duplication between the main ROSE process and the loaded DLL.

Precondition

Postcondition
The function executes processThroughMono with the constructed DLL path and the provided source file path, printing progress logs to standard output.
Note

Stores an integer value into a container identified by a 64-bit handle.

This function takes a 64-bit unsigned integer representing a raw pointer or handle to a Container object, casts it to a Container pointer, and invokes the storeValue method of that container with the provided integer value.

Parameters
containerA 64-bit unsigned integer that must represent a valid, reinterpretable address of a Container object.
valueThe integer value to be stored within the container.
Precondition
The container parameter must contain a valid memory address that can be safely cast to a Container* and points to an initialized Container object.
Postcondition
The value specified by the value parameter is stored in the container referenced by the container parameter.
Warning
Using an invalid or incorrect address for the container parameter will result in undefined behavior, such as segmentation faults or memory corruption.
