void addPrototypesForTemplateInstantiations ( SgNode * node)

Adds prototype declarations for template instantiations marked for output.

This function identifies template instantiations that are marked as output and ensures they have corresponding prototype declarations. The process involves two main stages: first, a traversal using CollectTemplateInstantiationsMarkedForOutput to find the first location of the template instantiation call; second, an iterative traversal using AddPrototypesForTemplateInstantiations to insert the necessary prototype declarations. This is specifically required for instantiations that do not already possess a prototype declaration. The function operates on an SgFile or SgProject level to allow for the necessary scope to locate and insert declarations.

Parameters
nodeThe root node (typically an SgFile or SgProject) to be traversed for template instantiations.
Precondition
The node parameter must not be null and should represent an SgFile or SgProject to ensure the traversal can correctly locate template instantiation calls and insert prototypes.
Postcondition
The provided node and its descendants may be modified to include new prototype declarations for template instantiations that were previously missing them.
Note
This function utilizes a fixed-point iteration approach via the AddPrototypesForTemplateInstantiationsInheritedAttribute to ensure all necessary declarations are processed.
Performance tracking is implemented via the TimingPerformance timer.
