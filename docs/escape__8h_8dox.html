std::string escapeString ( const std::string & s)

Escapes special characters within a string for safe representation.

This function iterates through the input string and replaces specific control characters and symbols with their escaped string equivalents (e.g., '
' becomes "\\n"). For characters that are not printable, the function converts them into an octal escape sequence format (\xxx).

Parameters
sThe input string to be escaped.
Returns
A new string containing the escaped version of the input string.
Warning
This function should not be used on assembly strings for the unparser. The presence of "\n" and "\t" substrings causes transformations to "\\n" and "\\t", which causes bugs when used with the asmembler. A specialized version of this function that avoids processing "\n" to "\\n" is required for unparser assembly strings.
Precondition
None.
Postcondition
The returned string contains no unescaped backslashes, quotes, or non-printable characters.
Note
See also, Rose::StringUtility::cEscape.

std::string unescapeString ( const std::string & s)

Converts a string containing escape sequences into its literal character representation.

This function iterates through the input string and processes backslash-escaped characters. It handles standard escape sequences such as newline, carriage return, and tab, as well as octal-encoded characters. The process terminates early if an unescaped double quote character is encountered.

Parameters
sThe input string containing potential escape sequences to be processed.
Returns
A new string where escape sequences have been replaced by their corresponding actual characters.
Precondition
The input string s must be well-formed such that any backslash character is followed by a valid escape character or a valid octal sequence to avoid assertion failures.
Postcondition
The returned string contains the unescaped characters and is terminated by the end of the string or an unescaped double quote.
Note
This function uses assertions to validate the structure of escape sequences. If an octal sequence is encountered, it expects a specific format of digits. The function is related to the logic found in Rose::StringUtility::cUnescape.
