Finds the lowest common ancestor loop between two statements based on their nesting depths.

This function traverses up the loop hierarchy from two given statements, b1 and b2, to find a common enclosing loop. It uses the provided nesting dimensions (dim1 and dim2) to align the traversal levels. The algorithm first brings both statements to the same nesting depth by moving up the hierarchy of the deeper statement. Then, it moves both statements up simultaneously until a common ancestor is found or the top level is reached.

Parameters
ast_interfaceAn interface object providing access to the Abstract Syntax Tree (AST) and methods to navigate the hierarchy, such as GetEnclosingLoop and IsLoop.
b1The first statement from which to begin the upward traversal.
dim1The nesting depth/dimension of statement b1.
b2The second statement from which to begin the upward traversal.
dim2The nesting depth/dimension of statement b2.
levelA pointer to an integer where the resulting common dimension (dim1) will be stored, if the pointer is not null.
Returns
The common enclosing loop statement found. Returns the interface's NULL representation if no common loop is found.
Precondition
The parameters b1 and b2 should be valid statements within the AST managed by ast_interface.
Postcondition
If level is not null, it will contain the dimension of the common loop found.
Note
The function relies on the accuracy of the provided dim1 and dim2 values to correctly align the traversal.

Finds the common loop structure between two statements.

This function identifies the shared loop hierarchy between two given statements (b1 and b2) by iteratively reducing the loop depth of each statement until a common ancestor or common loop level is reached. It utilizes the loop levels of both statements to traverse the loop nesting structure via the provided AST interface.

Parameters
ast_interfaceA reference to the AST interface used to query loop levels and traverse the structure.
b1The first statement to compare.
b2The second statement to compare.
levelA pointer to an integer used to track or store the current loop level depth. Defaults to 0.
Returns
The statement representing the common loop found between b1 and b2.
Precondition
The provided ast_interface must be a valid, initialized interface capable of performing loop level queries and structural traversals.
Postcondition
The returned statement represents the highest common loop ancestor of b1 and b2.
Note
This function relies on the implementation of GetLoopLevel and an overloaded version of GetCommonLoop that handles the actual structural comparison.

Interface & ast_interface )

Retrieves the nearest ancestor node that represents a loop statement.

This function performs an upward traversal of the Abstract Syntax Tree (AST) starting from the provided node n. It iteratively moves to the parent of the current node using the provided AST interface until it either encounters a node identified as a loop or reaches the root of the tree (represented by the interface's NULL value).

Parameters
nThe starting statement node from which the upward traversal begins.
ast_interfaceA reference to the interface object used to navigate the AST, providing methods to retrieve parents, check for loop types, and identify the NULL node.
Returns
The first ancestor node of n that is a loop statement. If no loop ancestor is found before reaching the root, the function returns the NULL node as defined by ast_interface.getNULL().
Precondition
The ast_interface must be a valid, initialized object that implements GetParent(Stmt), IsLoop(Stmt), and getNULL().
Postcondition
The returned node is either a loop statement or the NULL node.
Note
The traversal relies on the ast_interface correctly implementing the parent-child relationships within the AST.

Calculates the nesting depth of a loop containing a given statement.

This function determines the loop level of a specific statement by traversing upwards through its enclosing loop structures. It iteratively calls GetEnclosingLoop to move from the current statement to its parent loop, continuing this process until the end of the AST hierarchy (represented by a null pointer from the interface) is reached.

Parameters
sThe statement whose loop nesting level is to be determined.
ast_interfaceA reference to the AST interface used to navigate the abstract syntax tree and identify loop boundaries.
Returns
The integer representing the nesting depth of the statement. A value of 0 indicates the statement is not contained within any loop.
Precondition
The ast_interface must be a valid, initialized interface capable of providing a null terminator via getNULL() and navigating the AST.
Postcondition
The function returns a non-negative integer representing the count of enclosing loops.
