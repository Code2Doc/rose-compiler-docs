void GetLoopTreeSize ( LoopTreeNode * root,
int & stmtnum,
int & stmtlevel )

Calculates the total number of statements and the maximum loop nesting level within a loop tree.

This function traverses the loop tree starting from the provided root node. It iterates through all reachable statements using a LoopTreeTraverseSelectStmt iterator. For every statement encountered, it increments a counter for the total number of statements and updates the maximum loop level if the current statement's loop level exceeds the previously recorded maximum.

Parameters
rootA pointer to the root node of the loop tree to be traversed.
stmtnumA reference to an integer where the total count of statements found during traversal will be stored.
stmtlevelA reference to an integer where the maximum loop nesting level encountered during traversal will be stored.
Precondition
root must not be a null pointer.
Postcondition
stmtnum and stmtlevel are initialized to 0 and then updated with the results of the traversal.
Note
The function uses an iterator-based approach to visit all nodes in the tree structure.
