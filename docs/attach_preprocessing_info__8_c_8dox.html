Attaches preprocessor directives and comments to a source file AST node.

Empty function or ill-formed function detected. /.

This function is responsible for extracting C/C++ preprocessor directives and comments from the source code and attaching them to the corresponding SgSourceFile node in the Abstract Syntax Tree (AST). It utilizes the AttachPreprocessingInfoTreeTrav traversal to build a list of attributes (comments and directives) and then updates the preprocessorDirectivesAndCommentsList of the provided sageFilePtr. The function also handles the cleanup of redundant include files for initializers via fixupInitializersUsingIncludeFiles.

Parameters
sageFilePtrA pointer to the SgSourceFile node representing the source file to which the preprocessing information will be attached.
new_filenameA string representing the new filename to be used during the processing of comments and CPP directives.
Precondition
sageFilePtr must not be NULL.
The flag returned by sageFilePtr->get_processedToIncludeCppDirectivesAndComments() must be false (the file must not have been processed for directives/comments yet).
The project associated with sageFilePtr must be valid and not NULL.
Postcondition
The sageFilePtr node will have its preprocessorDirectivesAndCommentsList updated with the newly extracted information.
The flag returned by sageFilePtr->get_processedToIncludeCppDirectivesAndComments() will be set to true.
Warning
This function should not be called for binary files; it is intended for C/C++ source code.
If the include ROSE_SKIP_COMPILATION_OF_WAVE macro is defined and the file requires Wave processing, the function will call ROSE_ABORT().
Note
The function uses TimingPerformance for performance tracking within the ROSE framework.
The implementation uses ifdef and ifndef logic to handle different compilation configurations, such as CXX_IS_ROSE_CODE_GENERATION.

Generates a DOT graph representing the hierarchy of included header files.

This function constructs a directed graph in DOT format that visualizes the relationship between a source file and its included header files. It effectively builds a tree-like structure (though it may contain multiple edges if headers are included multiple times) by traversing the include dependencies starting from the provided source file. The function writes the resulting graph to a file on disk.

Parameters
sourceFileA pointer to the SgSourceFile object representing the root source file from which the include traversal begins.
filenameThe base name for the output DOT file. If this string is empty, the function defaults to "include_file_graph.dot".
Precondition
sourceFile must not be NULL.
Postcondition
A DOT file with the extension ".dot" is created or overwritten on disk.
The IncludeFileGraph::graphNodeSet is cleared after the graph is generated.
Note
The function utilizes the IncludeFileGraph namespace to manage the output file stream and the graph construction process.
If define DEBUG_HEADER_GRAPH_SUPPORT is active, the function prints debugging information to the standard output.
