Postcondition
The returned string is a substring of the input full_pathname and does not contain any leading forward slash characters.

string GenUtil::getDirname ( const string & full_pathname)

Extracts the directory component from a given full file path.

This function parses the provided string to identify the directory portion of a path. It searches for the last occurrence of the forward slash ('/') character within the string. If a slash is found, the function returns the substring preceding that slash. If no slash is found, it indicates the path refers to a file in the current directory, and the function returns ".".

Parameters
full_pathnameThe complete path string from which the directory name is to be extracted.
Returns
A string containing the directory path. Returns "." if no directory separator is found.
Precondition
The input string full_pathname should be a valid path string.
Postcondition
The returned string is a substring of the input or is ".".
Note
This implementation specifically looks for the forward slash ('/') character and may not correctly handle Windows-style backslash ('\') separators unless they are explicitly handled elsewhere in the application logic.
