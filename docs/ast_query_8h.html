This operator implements the addition of two VariantVector instances by creating a new vector that contains all elements from the left-hand side (lhs) followed by all elements from the right-hand side (rhs). The implementation utilizes the copy constructor to initialize the return vector with the contents of the lhs, and then uses the insert method to append the range of elements from the rhs.

Parameters

rhsThe second VariantVector, whose elements are appended to the end of the lhs elements.
Returns
A new VariantVector containing the concatenated elements of lhs and rhs.
Precondition
The lhs and rhs operands must be valid, initialized VariantVector objects.
Postcondition
A new VariantVector is returned containing the elements of lhs followed by rhs, leaving the original lhs and rhs objects unmodified.
Note
