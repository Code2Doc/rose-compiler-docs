std::string commentAndCppInformation ( SgNode * node)

Extracts and formats information regarding attached comments and C/C++ preprocessor directives for a given node.

This function inspects an SgNode to determine if it is an SgLocatedNode. If the node contains attached preprocessing information, the function retrieves the counts of comments and directives categorized by their relative position (before, inside, or after the node). The resulting information is formatted into a string suitable for DOT output or debugging.

Parameters
nodeA pointer to the SgNode to be inspected for attached preprocessing information.
Returns
A string containing the formatted counts of comments and directives at different positions relative to the node. If no information is found, an empty string is returned.
Precondition
node should be a valid pointer to an SgNode.
Postcondition
The returned string contains a newline-delimited summary of preprocessing information if the node is an SgLocatedNode with attached info.
Note
The implementation specifically checks for SgLocatedNode to access AttachedPreprocessingInfoType.

std::string generateFileLineColumnString ( Sg_File_Info * fileInfo)

Generates a formatted string containing file, line, and column information.

This function constructs a single string representing the source location of a given file info object. The string includes the stripped filename, the line and column numbers, the physical line number, and the raw line and column numbers. The format is designed for DOT output and includes explicit string conversions for integers to ensure compatibility with optimized builds where integer-to-string stream operations might be optimized away.

Parameters
fileInfoA pointer to an Sg_File_Info object containing the source location metadata.
Returns
A string containing the formatted file path, line, column, physical line, and raw line/column information, ending with a newline character.
Precondition
fileInfo must not be NULL.
Postcondition
Returns a non-empty string containing the formatted location data.
Note
The filename is processed using Rose::utility_stripPathFromFileName to remove directory paths.
The function uses StringUtility::numberToString for explicit integer-to-string conversion to prevent optimization issues in certain compiler versions.
The raw line and column information is included based on the if 1 preprocessor directive.

Counts the number of preprocessing elements at a specific relative position.

This function iterates through a collection of attached preprocessing information, such as comments and C/C++ directives, and counts how many of these elements match the specified relative position type. It performs a linear scan through the provided container.

Parameters
commentsAndCppDirectivesA pointer to a container of PreprocessingInfo pointers representing attached comments and C/C++ directives.
posThe specific relative position type to match against.
Returns
The total count of elements found that match the given relative position.
Precondition
commentsAndCppDirectives must not be a null pointer.
Postcondition
The returned value is a non-negative integer representing the count of matches.
Note
The complexity of this function is O(n), where n is the number of elements in the commentsAndCppDirectives container.

◆ sourcePositionInformation()

std::string sourcePositionInformation ( SgNode * node)

Generates a string containing detailed source position and metadata information for a given SgNode.

This function extracts and formats various pieces of source location information associated with an IR node. It checks if the node is an SgLocatedNode and, if so, retrieves file information including whether the code is compiler-generated, front-end specific, or part of a transformation. It also identifies if the code is part of the output in code generation. For nodes with valid file info, it appends line and column strings for the start and end of the construction, along with the stripped physical filename. If the node is an SgFile, it attempts to retrieve information from the file's file info. The resulting string is intended for use in DOT output and debugging token-stream unparsing.

Parameters
nodeA pointer to the SgNode whose source position information is to be retrieved.
Returns
A std::string containing the formatted source position information, including file details, line/column numbers, and metadata flags, or a message indicating no source position is available.
Precondition
node should be a valid pointer to an SgNode.
Postcondition
The returned string contains a newline-delimited summary of the node's location and metadata.
Note
The function relies on the node being castable to SgLocatedNode or SgFile via internal helper functions like isSgLocatedNode and isSgFile.
