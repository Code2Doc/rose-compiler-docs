Dumps the contents of a collection of conditional blocks.

This function serves as a wrapper to initiate the dumping process for a given collection of conditional blocks (represented by Ifs_t). It identifies the beginning and end of the provided iterator range and delegates the actual printing or logging task to an overloaded dump function that accepts iterators.

Parameters
ifsA constant reference to a collection of conditional blocks (Ifs_t) to be processed and dumped.
Precondition
The provided ifs container must be a valid, initialized Ifs_t object.
Postcondition
The contents of the provided ifs container are output via the internal iterator-based dump mechanism.
Note
This function relies on the existence of an overloaded dump function with the signature compatible with CPreproc::Ifs_t::const_iterator.

void CPreproc::extractIfDirectives ( SgNode * root,
Ifs_t & ifs )

Extracts the 'if' directive structure from a project.

Extracts all if, ifdef, ifndef, and elif directives from a given AST node.

This function performs a traversal of the provided SgNode tree to identify and collect all preprocessor conditional directives. It utilizes an internal IfDirectiveExtractor visitor pattern to traverse the node hierarchy and populate the provided collection of conditional statements.

Parameters
rootA pointer to the root SgNode from which the extraction process begins.
ifsA reference to a collection of Ifs_t used to store the discovered directives.
Precondition
root must not be a null pointer.
Postcondition
The ifs container will be populated with all identified conditional directives found within the subtree rooted at root.
Note
This function relies on the traversal capabilities of the IfDirectiveExtractor class to visit all relevant nodes in the AST.

Locate the 'if' directive context at a node.

Locates the surrounding if, ifdef, or ifndef directive context for a given node.

This function identifies the nesting structure of preprocessor conditional directives that encompass the specified target node. It performs a traversal of the global scope starting from the node's root to find all active conditional branches. The implementation utilizes an IfDirectiveContextFinder visitor to traverse the AST and extract the relevant top-level and bottom-level conditional cases.

Parameters
targetA pointer to the SgLocatedNode whose preprocessor context is being queried.
ifsA reference to a collection of Ifs_t used to store the discovered conditional contexts.
topA reference to a pointer that will be updated to point to the outermost (top) conditional case containing the target.
bottomA reference to a pointer that will be updated to point to the innermost (bottom) conditional case containing the target.
Precondition
The target node must be a valid pointer to an SgLocatedNode.
Postcondition
If the target node is found within a preprocessor conditional block, top and bottom will point to the respective boundaries of that context. If no global scope is found or the target is not within an if directive, top and bottom remain unchanged (or as previously set).
Note
This function uses const_cast to strip const-qualification from the target node to facilitate scope retrieval via TransformationSupport::getGlobalScope.
