Retrieves a constant reference to the predefined set of node type values.

Return all SDG::SDGNode::NodeType member values as a vector.

This function provides access to a static collection of 64-bit integer values representing various node types within the system. The values are stored in a static vector to ensure they are initialized only once and persist for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the sequence of node type identifiers: 0, 1, 2, 3, 4, 5, and 6.
Precondition
None.
Postcondition
The returned reference points to a valid, immutable vector of int64_t values.
Note
The implementation uses a static local variable to ensure thread-safe initialization (in C++11 and later) and to avoid repeated allocations.

const char * stringify::SDG::SDGNode::NodeType ( int64_t )

Converts a node type identifier into its corresponding string representation.

Convert SDG::SDGNode::NodeType enum constant to a string.

This function performs a mapping from a 64-bit integer identifier to a human-readable string constant representing the specific type of an SDG node. It uses a switch-case mechanism to evaluate the input integer and return the appropriate string literal.

Parameters
iThe 64-bit integer representing the unique identifier for the node type.
Returns
A pointer to a constant character string representing the node type name. Returns "Entry", "ASTNode", "FunctionCall", "ActualIn", "ActualOut", "FormalIn", or "FormalOut" based on the input value. Returns an empty string "" if the input does not match any predefined type.
Precondition
The input parameter i should correspond to one of the defined node type constants.
Postcondition
The returned pointer points to a static string literal and remains valid for the lifetime of the program.
Note
This function does not handle any custom or dynamically generated node types; it only recognizes the hardcoded set of identifiers.

Generates a string representation of a node type with an optional prefix removal.

Convert SDG::SDGNode::NodeType enum constant to a string.

This function retrieves the string representation of a node type associated with the provided integer ID. It first calls the overloaded NodeType(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(SDG::SDGNode::NodeType)" followed by the string representation of the ID using boost::lexical_cast. Additionally, if the resulting string starts with the specified 'strip' prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the node type.
stripA string representing a prefix to be removed from the start of the generated node type string if it exists.
Returns
A string containing the formatted node type name, potentially with the 'strip' prefix removed.
Precondition
The integer i must be a valid identifier for a node type.
Postcondition
The returned string will not start with the content of the 'strip' parameter if that content was present at the start of the original string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
