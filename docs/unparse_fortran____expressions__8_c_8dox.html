bool outputLogicalOperator ( SgExpression * expr)

Determines if a binary expression represents a logical operator based on its left-hand side type.

This function inspects a given SgExpression to check if it is a binary operator where the left-hand side (LHS) operand is of a boolean type. The function specifically validates that the expression is a binary operator and checks for type consistency between the LHS and RHS operands. If the LHS is boolean but the RHS is not, an error is printed and an assertion is triggered.

Parameters
exprA pointer to the SgExpression to be inspected. This expression is expected to be an instance of SgBinaryOp.
Returns
True if the expression is a binary operator and its left-hand side operand is of boolean type; false otherwise.
Warning
This function will trigger a ROSE_ABORT if the provided expression is not a binary operator. Additionally, it will trigger an assertion failure if the left-hand side is boolean but the right-hand side is not.
Precondition
expr must not be NULL and must be an instance of SgBinaryOp.
Postcondition
The return value indicates whether the expression's LHS is a boolean type within a binary operation context.
Note
The function relies on the helper functions isSgBinaryOp and isSgTypeBool to perform type and operator validation.
