Formats and strips a string representation of a specific mode.

Convert Rose::BinaryAnalysis::Disassembler::Aarch32::Mode enum constant to a string.

This function retrieves a string representation of a mode using the overloaded Mode(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a specific namespace identifier and the integer value. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer representing the mode to be formatted.
stripA string prefix that, if found at the start of the formatted mode string, will be removed.
Returns
A string representing the formatted mode, potentially with the specified prefix removed.
Precondition
The parameter i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the content of the strip parameter if it was originally present at the start of the formatted string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
