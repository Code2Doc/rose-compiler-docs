const char * stringify::Sawyer::Database::Statement::State ( int64_t )

Converts a numeric state identifier into its corresponding string representation.

Convert Sawyer::Database::Statement::State enum constant to a string.

This function maps specific 64-bit integer values to human-readable string literals representing the lifecycle states of a database statement. The mapping is implemented using a switch statement to provide efficient lookup for predefined state constants.

Parameters
iThe 64-bit integer representing the state to be stringified.
Returns
A pointer to a constant character string representing the state name. Returns "UNBOUND" for 0, "READY" for 1, "EXECUTING" for 2, "FINISHED" for 3, and "DEAD" for 4. Returns an empty string "" if the input does not match any of the predefined states.
Precondition
The input parameter i should ideally correspond to one of the defined state constants within the database statement lifecycle.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function does not handle error states other than returning an empty string.

Generates a formatted string representation of a state identifier with an optional prefix removal.

Convert Sawyer::Database::Statement::State enum constant to a string.

This function retrieves the string representation of a given 64-bit integer identifier using an overloaded State(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a specific namespace-prefixed label and the integer value. Additionally, the function checks if the resulting string starts with the provided strip string; if it does, the prefix matching strip is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the state.
stripA string representing the prefix to be removed from the start of the generated state string if a match is found.
Returns
A string containing the formatted state identifier, potentially with the specified prefix removed.
Precondition
The parameter i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the contents of strip if strip was a prefix of the original state string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
