Retrieves a constant reference to a predefined list of patch operation identifiers.

This function provides access to a static, immutable vector containing a sequence of 64-bit integer values representing specific patch operations. The values are hardcoded within the function scope and are stored in a static vector to ensure they persist for the lifetime of the program and are only initialized once.

Returns
A constant reference to a std::vector<int64_t> containing the sequence of patch operation values {0, 1, 2, 3, 4, 5, 6}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector that remains unchanged throughout the program execution.
Note
The implementation uses a static local variable to avoid repeated allocations and to ensure thread-safe initialization (as per C++11 standards for static local variables).

const char * stringify::nlohmann::basic__json::patch_operations ( int64_t i)

Converts a JSON patch operation integer code into its string representation.

This function maps specific 64-bit integer identifiers to their corresponding JSON Patch (RFC 6902) operation names. It uses a switch-case mechanism to perform a direct lookup of the operation type.

Parameters
iAn integer representing the patch operation code.
Returns
A pointer to a constant character string representing the operation name (e.g., "add", "remove", "replace", "move", "copy", "test", or "invalid"). Returns an empty string if the provided integer does not match any defined operation code.
Precondition
The input parameter i should ideally correspond to one of the defined RFC 6902 operation constants.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
The mapping is as follows: 0: add 1: remove 2: replace 3: move 4: copy 5: test 6: invalid

Generates a formatted string representing patch operations with an optional prefix removal.

This function retrieves a string representation of patch operations associated with a specific index using an underlying overload of patch_operations. If the retrieved string is empty, it constructs a fallback string containing a specific namespace identifier and the index. Finally, it checks if the resulting string starts with the provided strip string; if so, the prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer index used to identify the patch operations.
stripA string representing the prefix to be removed from the start of the generated operation string if it exists.
Returns
A string containing the formatted patch operations, potentially with a prefix removed or a fallback identifier appended.
Precondition
The index i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the content of the strip parameter if the original string contained that prefix.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
