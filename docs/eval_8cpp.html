Evaluates an AST expression while enabling tracing for a set of local variables.

This function performs an evaluation of the provided AST node res while temporarily modifying the symbol table entries of specific local variables to enable tracing. The function identifies local variables from either a single LocalVar node or a POETList containing LocalVar nodes. For each identified variable, it pushes a trace flag onto the symbol table entry and sets the entry type to LVAR_TRACE. After the evaluation via eval_AST is complete, the function restores the original state of the symbol table entries by popping the trace flag and restoring the previous code pointer.

Parameters
varsA POETCode pointer representing either a single LocalVar or a PONETList of LocalVar objects to be traced.
resA POETCode pointer representing the AST node to be evaluated.
Returns
A POETCode* pointer representing the result of the evaluation of res.
Precondition
vars must not be null and must point to an object of type SRC_LVAR or SRC_LIST containing only SRC_LVAR elements.
Postcondition
The symbol table entries for all variables identified in vars are restored to their original state (trace flag removed and original code pointer restored) regardless of the outcome of eval_AST.
Note
If vars contains elements that are not of type SRC_LVAR within a SRC_LIST, the function triggers an INCORRECT_TRACE_HANDLE error.
The function relies on eval_AST to perform the actual computation.
