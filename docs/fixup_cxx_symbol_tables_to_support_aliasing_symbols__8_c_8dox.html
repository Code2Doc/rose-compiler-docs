void fixupAstSymbolTablesToSupportAliasedSymbols ( SgNode * node)

Updates AST symbol tables to accommodate aliased symbols resulting from use declarations.

Fixup C++ symbol tables to use aliasing symbols for using declarations.

This function performs a traversal of the Abstract Syntax Tree (AST) starting from the provided node to update symbol tables. It specifically addresses the requirements for C++ symbol aliasing, such as those introduced by 'using' declarations or other directives. The function utilizes a preorder traversal strategy via the FixupAstSymbolTablesToSupportAliasedSymbols visitor. Additionally, it ensures that the global set of causal nodes for alias symbols maintained in SgSymbolTable is cleared after the traversal to prevent stale data from persisting.

Parameters
nodeThe root node of the AST subtree to be traversed and fixed up.
Precondition
The node parameter must not be null.
Postcondition
The symbol tables within the subtree of the provided node are updated to support aliased symbols.
The set returned by SgSymbolTable::get_aliasSymbolCausalNodeSet() is guaranteed to be empty.
Note
This function contains logic specifically tailored for C++ rules, although it may be invoked during Fortran processing.
The traversal behavior is subject to if 1 preprocessor blocks which currently enable the traversal logic.
If if ALIAS_SYMBOL_DEBUGGING is defined, the function performs additional logging regarding the state of the alias symbol causal node set.
