Converts a color component index into its corresponding string representation.

Convert QtColorLine::ColorComponent enum constant to a string.

This function maps a 64-bit integer index to a human-readable string representing a specific color component (e.g., Red, Green, Blue, etc.). The implementation uses a switch statement to perform a direct lookup based on the provided integer value.

Parameters
iThe integer index representing the color component.
Returns
A pointer to a constant character string containing the name of the color component. Returns an empty string "" if the provided index does not match any of the predefined component indices.
Precondition
The input parameter i should be a valid index within the range [0, 6] to retrieve a specific component name.
Postcondition
The returned pointer points to a static string literal that remains valid for the lifetime of the program.
Note
The supported indices are: 0: Red, 1: Green, 2: Blue, 3: Hue, 4: Saturation, 5: Value, 6: Alpha.

Retrieves a formatted color component string and optionally strips a prefix.

Convert QtColorLine::ColorComponent enum constant to a string.

This function first retrieves a string representation of the integer i using the overloaded ColorComponent(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(QtColorLine::ColorComponent)" followed by the string representation of i using boost::lexical_cast. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer representing the color component value.
stripA string representing the prefix to be removed from the start of the generated color component string if present.
Returns
A string containing the formatted color component, with the specified prefix removed if it was found at the start.
Precondition
The parameter strip should be a valid string.
Postcondition
The returned string will not start with the content of the strip parameter if that content was originally present at the start of the component string.
Note
This function relies on boost::lexical_cast and boost::starts_with.
