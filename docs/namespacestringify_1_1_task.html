Retrieves a constant reference to the predefined state vector.

Return all Task::State member values as a vector.

This function provides access to a static, immutable vector containing a fixed sequence of 64-bit integers. The vector is initialized once during the first call to the function and persists for the lifetime of the program. The values contained in the vector are 0, 1, 2, and 3.

Returns
A constant reference to a std::vector<int64_t> containing the predefined state values {0, 1, 2, 3}.
Precondition

Postcondition
The returned reference points to a valid, static vector that remains unchanged throughout the program execution.
Note

const char * stringify::Task::State ( int64_t )

Converts a numeric state identifier into its corresponding string representation.

Convert Task::State enum constant to a string.

This function maps specific 64-bit integer values to human-readable string literals representing the lifecycle states of a task. The mapping is implemented using a switch statement to provide efficient lookup for predefined state constants.

Parameters
iThe 64-bit integer representing the task state to be stringified.
Returns
A pointer to a constant character string representing the state name. Returns "BEFORE_START" for 0, "RUNNING" for 1, "FINISHED_SUCCESS" for 2, and "FINISHED_ERROR" for 3. Returns an empty string "" if the input does not match any of the predefined cases.
Precondition
The input parameter i should ideally correspond to one of the defined state constants to ensure a meaningful string is returned.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.

std::string stringify::Task::State ( int64_t ,

Generates a formatted state string and optionally removes a prefix.

Convert Task::State enum constant to a string.

This function retrieves a string representation of a state associated with the provided integer ID using the overloaded State(int64_t) function. If the resulting string is empty, it constructs a default string in the format "(Task::State)" followed by the integer ID. Finally, if the string starts with the specified 'strip' prefix, that prefix is removed from the string.

Parameters
iThe 64-bit integer identifier representing the state.
stripA string representing the prefix to be removed from the beginning of the generated state string if present.
Returns
A string containing the formatted state, with the specified prefix removed if it was found at the start of the string.
Precondition
The parameter 'strip' should be a valid string.
Postcondition
The returned string will not start with the content of 'strip' if 'strip' was originally a prefix of the generated state.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
