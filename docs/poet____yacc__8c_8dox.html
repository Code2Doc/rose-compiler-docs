Copies a string from a source to a destination and returns a pointer to the null terminator in the destination.

This function performs a string copy operation similar to the standard strcpy function, but with the distinct feature of returning a pointer to the end of the destination string (the position of the null terminator) rather than the beginning of the destination string. This allows for efficient sequential appending of strings by using the returned pointer as the starting point for subsequent copy operations. The implementation uses a simple loop that iterates through the source string, copying each character to the destination until the null terminator is encountered.

Parameters
yydestA pointer to the destination buffer where the string will be copied. The buffer must be large enough to hold the source string plus the null terminator.
yysrcA pointer to the source string to be copied.
Returns
A pointer to the null terminator of the newly copied string in the destination buffer.
Precondition
The destination buffer yydest must have sufficient space allocated to accommodate the entire content of yysrc including the terminating null character to prevent buffer overflow.
Postcondition
The string pointed to by yyssrc is copied to the buffer pointed to by yydest, and yydest now contains a null-terminated string identical to yyssrc.
Note
This function is useful for building strings incrementally in a single pass without repeatedly calling strlen.

Generates a detailed syntax error message for the parser.

This function constructs a human-readable error message describing a syntax error, including the unexpected token and a list of expected tokens. It calculates the necessary buffer size, manages memory allocation requirements for the error message, and formats the string using an internationalized format string. The function iterates through possible expected tokens by checking the parser's action table and state information, ensuring that the number of reported tokens does not exceed a predefined maximum.

Parameters
yymsg_allocA pointer to a variable of type YYSIZE_T that stores the currently allocated size of the error message buffer. The function may update this value if the buffer needs to be resized.
yymsgA pointer to a pointer to a character buffer where the formatted error message will be stored.
yysspA pointer to the parser stack, used to retrieve the current state to determine expected tokens.
yytokenThe integer value representing the token that was unexpectedly encountered.
Returns
An integer status code:
  • 0: Success. The error message was successfully formatted.
  • 1: The error message buffer was too small and needs to be reallocated to twice the required size.
  • 2: An error occurred during size calculation or the required size exceeds YYSTACK_ALLOC_MAXIMUM.
Precondition
The parser must be in an error state, and the pointers yymsg_alloc, yymsg, and yyssp must be valid and point to accessible memory.
Postcondition
The error message string is written to the buffer pointed to by *yymsg, and *yymsg_alloc is updated to reflect the new allocation size if a resize was triggered.
Note
The function avoids using sprintf to prevent namespace pollution. It manually parses the format string to handle s placeholders.
The number of expected tokens reported is capped by YYERROR_VERBOSE_ARGS_MAXIMUM to prevent excessively long error messages.

Processes and potentially strips quotes from a given string.

This function examines the input string yystr. The process handles escaped backslashes.
