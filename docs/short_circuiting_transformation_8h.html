bool IsSCGenerated ( const SgNode * n)

Checks if a given SgNode has the "SCGenerated" attribute.

This function inspects the provided SgNode to determine if it has been marked as being generated by the SC (SystemC) generation process. It does this by querying the node's internal attribute map for the existence of the "SCGenerated" key.

Parameters
nA pointer to the SgNode to be inspected.
Returns
True if the node contains the "SCGenerated" attribute, false otherwise.
Precondition
The pointer n must not be null.
Postcondition
The state of the SgNode remains unchanged.
Note
This function relies on the implementation of the attributeExists method within the SgNode class.

ROSE_DLL_API void shortCircuitingTransformation ( SgProject * prj)

Performs a transformation on the SgProject to implement short-circuiting logic.

This function applies an initial transformation to the provided SgProject and then, if the ifdef SCDBG macro is defined, enters a loop that iteratively applies short-circuiting optimizations. During each iteration of the loop, the function generates an AST JSON representation, runs all associated AST tests, and exports the unparsed C++ code to a file. The loop continues as long as the function reduceIfStmtsWithSCchild can further simplify or transform if-statements with short-circuiting children.

Parameters
prjA pointer to the SgProject object that will undergo the transformation.
Precondition
The prj parameter must not be null.
Postcondition
The SgProject prj is modified in-place with short-circuiting transformations applied. If SCDBG is defined, intermediate AST JSONs and C source files are generated.
Note
The behavior of this function is dependent on the ifdef SCDBG preprocessor directive. If SCDBG is not defined, only the initialTransformation is executed.
