int exprToInt ( SgExpression * exp)
static

Converts a SgExpression object to its integer representation.

This function attempts to extract an integer value from a given SgExpression pointer. It performs type checking to determine if the expression is an instance of SgUnsignedLongVal or SgIntVal. If the expression matches either of these types, the underlying integer value is retrieved and returned.

Parameters
expA pointer to the SgExpression to be evaluated.
Returns
The integer value contained within the expression if it is an SgUnsignedLongVal or SgIntVal; otherwise, returns -1 to indicate that the expression could not be converted.
Precondition
exp should be a valid pointer to an SgExpression object.
Postcondition
The return value is an integer representing the expression's value or -1.
Note
This function uses type-checking functions isSgUnsignedLongVal and isSgIntVal to perform the conversion.
