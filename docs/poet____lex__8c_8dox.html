Reads the next character from the input stream.

This function serves as the primary input mechanism for the scanner, retrieving characters from the current buffer. It manages buffer transitions, handles end-of-buffer conditions, and updates the line number tracking. When the end of the current buffer is reached, it attempts to refill the buffer using yy_get_next_buffer. It also handles the transition to end-of-file (EOF) by checking yywrap and potentially switching to a new file.

Precondition
The scanner buffers and pointers (such as yy_c_buf_p, yytext_ptr, and yy_hold_char) must be properly initialized.
Postcondition
The character pointer yy_c_buf_p is advanced, and the line number yylineno is incremented if the returned character is a newline.
Returns
The next character from the input stream as an integer, or EOF if the end of the input stream is reached and yywrap returns true.
Note
The function handles the distinction between a NUL character within the buffer and the actual end of the buffer. It also manages the logic for switching buffers when the EOB_ACT_LAST_MATCH or EOB_ACT_END_OF_FILE actions are triggered.

◆ yyensure_buffer_stack()

void yyensure_buffer_stack ( void )

Ensures that the buffer stack is properly allocated and has sufficient capacity.

This function manages the memory allocation for the global buffer stack used by the scanner. It performs two primary tasks:

  1. If the stack pointer is null, it performs an initial allocation for a small number of elements to minimize immediate reallocations.
  2. If the current stack capacity is nearly full (specifically, if the top index reaches the maximum capacity minus one), it expands the stack by a fixed growth size.

The implementation uses yyalloc for initial allocation and yyrealloc for expansion. After any allocation or expansion, the newly added slots are zero-initialized using memset to ensure a clean state.

Warning
If memory allocation fails during either the initial allocation or the reallocation process, the function triggers a fatal error via YY_FATAL_ERROR.
Precondition
The global pointer yy_buffer_stack and the allocator functions yyalloc and yyrealloc must be properly defined and accessible.
Postcondition
The yy_buffer_stack is guaranteed to be non-null and have a capacity sufficient to allow at least one more push operation. The yy_buffer_stack_max is updated to reflect the new capacity, and any new memory slots are zeroed.
Note
The initial allocation size is set to 1 element to conserve memory if the scanner does not require a stack, though the logic includes a comment suggesting a preference for 2 to avoid immediate realloc.

Destroys the current scanner state and cleans up allocated resources.

This function is designed to handle cleanup for both reentrant and non-reentrant scanners. It performs a deep cleanup of the scanner's internal state by iterating through the buffer stack, deleting each active buffer element using yy_delete_buffer, and popping the buffer states. After the stack is cleared, the memory allocated for the buffer stack itself is freed. Finally, the function resets global variables via yy_init_globals to ensure that subsequent calls to yylex() trigger a fresh initialization.

Note
