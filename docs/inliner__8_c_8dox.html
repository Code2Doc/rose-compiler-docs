Performs function inlining by replacing a function call with the function's body.

Performs inlining of a function call expression into its caller.

This function implements a complex AST transformation to inline the body of a called function into the caller's context. It handles various C++ constructs including member function calls (dot and arrow operators), virtual function checks, and lambda expressions. The implementation involves deep-copying the target function's body, renaming labels to prevent collisions, creating new local variables to shadow formal parameters with actual arguments, and transforming return statements into goto statements that jump to a newly created end-of-inline label.

Parameters
funccallA pointer to the SgFunctionCallExp representing the function call site to be inlined.
allowRecursionA boolean flag indicating whether direct recursion is permitted during inlining.
Returns
True if the inlining transformation was successfully performed; false if the function could not be inlined (e.g., due to virtual functions, header files, compiler-generated code, or incompatible recursion settings).
Precondition
funcall must not be NULL and must have a valid parent in the AST.
Postcondition
If successful, the funcall expression is replaced by a sequence of statements representing the inlined body, and the AST is updated to maintain consistency (e.g., updated lvalue flags).
Note
The function skips inlining for functions within system headers, compiler-generated code, and the std:: namespace.
For member functions, the function attempts to handle the this pointer by creating a local variable initialized with the caller's this pointer.
The function handles lambda captures by mapping closure variables to capture variables during the transformation process.
Preprocessor directives like include or define are not processed by this function, but the function respects logic related to header file suffixes.

Generates an assignment operation if a left-hand side expression is provided.

This function acts as a helper utility, primarily used within the inliner, to conditionally create an assignment operator. If the provided left-hand side (lhs) expression is not null, a new SgAssignOp is instantiated with the lhs and rhs, and its end-of-construct metadata is updated. If the lhs is null, the function simply returns the right-hand side (rhs) expression without performing any assignment operation.

Parameters
lhsA pointer to the left-hand side SgExpression. If this is NULL, no assignment is created.
rhsA pointer to the right-hand side SgExpression to be assigned.
Returns
A pointer to a new SgAssignOp if lhs is not NULL; otherwise, returns the original rhs pointer.
Precondition
lhs and rhs should be valid SgExpression pointers or NULL.
Postcondition
If lhs is not NULL, a new SgAssignOp object is allocated on the heap.
Note
This implementation uses SgNULL_FILE for the source location metadata in the constructed SgAssignOp.

void markAsTransformation ( SgNode * ast)

Marks nodes within an AST as being part of a transformation.

This function performs a deep traversal of the provided Abstract Syntax Tree (AST) using a preorder traversal strategy. It utilizes an internal visitor pattern (FixFileInfo) to identify all nodes that are instances of SgLocatedNode. For each located node found, the function updates the associated file information (Sg_File_Info) at the start of the construct, the end of the construct, and the operator position (if the node is an SgExpression). The update involves flagging these locations as having undergone a transformation and marking them as output for the code generation phase.

Parameters
astA pointer to the root SgNode of the AST to be traversed and modified.
Precondition
The ast parameter should be a valid, non-null pointer to an SgNode.
Postcondition
All SgLocatedNode instances within the AST, including their start/end construct positions and expression operator positions, will have their Sg_File_Info objects updated with transformation and code generation flags.
Note
The implementation uses a local struct inheriting from AstSimpleProcessing to implement the visitor pattern, ensuring that the traversal logic is encapsulated within the function scope.

Removes a redundant assignment initializer from a constructor initialization list.

This function optimizes the SgInitializedName node by stripping away an intermediate SgAssignInitializer layer. It identifies if the initializer is an assignment initializer and extracts the underlying SgConstructorInitializer, effectively promoting the constructor initializer directly to the initialized name.

Parameters
inThe SgInitializedName node to be processed.
Precondition
The parameter in must be a valid, non-null pointer to an SgInitializedName.
The initializer of in must be an instance of SgAssignInitializer.
The operand of the SgAssignInitializer must be an instance of SgInitializer.
The extracted SgInitializer must be an instance of SgConstructorInitializer.
Postcondition
The initializer of the in node is updated to point directly to the underlying SgConstructorInitializer.
The parent of the extracted SgConstructorInitializer is updated to be in.
