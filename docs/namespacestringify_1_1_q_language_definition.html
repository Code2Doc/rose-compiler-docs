Retrieves a static collection of predefined 64-bit integer flags.

Return all QLanguageDefinition::CollapseFlag member values as a vector.

This function provides access to a constant, immutable vector containing specific bitmask values used for flag collapsing operations. The values represent various bit boundaries (e.g., 0, 2^12-1, 2^24-1, etc.) and are stored in a static vector to ensure they are initialized only once during the program lifetime.

Returns
A constant reference to a std::vector<int64_t> containing the predefined flag values.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector of 64-bit integers that persists for the duration of the program.
Note
The vector contains exactly 6 elements: 0, 4095, 16773120, 268435456, 536870912, and 1073741824.

Generates a collapsed string representation of a flag, optionally stripping a prefix.

Convert QLanguageDefinition::CollapseFlag enum constant to a string.

This function first retrieves a collapsed string representation of the provided 64-bit integer using an overloaded version of CollapseFlag. If the resulting string is empty, it constructs a fallback string in the format "(QLanguageDefinition::CollapseFlag)" followed by the string representation of the integer. Finally, if the constructed string starts with the specified strip prefix, that prefix is removed from the string.

Parameters
iThe 64-bit integer identifier whose flag representation is being processed.
stripA string prefix that, if found at the beginning of the generated flag string, should be removed.
Returns
A string representing the collapsed flag, potentially with the strip prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was originally present.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
