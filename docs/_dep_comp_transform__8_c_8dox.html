Computes the configuration required for array copying operations during loop transformations.

This function analyzes the dependency and access patterns of array elements within a given unit of work. It determines whether an initialization copy is necessary (by checking if the initial assignment covers the required indices) and whether a save copy is required (by checking for potential modifications/writes within the unit). The function identifies the array being accessed, extracts the element type, and constructs a SelectArray object representing the index selection logic. It also determines the appropriate CopyArrayOpt flags based on the presence of initialization and write operations.

Parameters
stmtorderAn analysis object providing information about the modification and reference patterns of AST references.
unitA structure representing a unit of array elements to be processed, containing the set of references and the root node for the transformation.
initcutA pointer to a graph node representing the initial assignment or initialization point for the array elements.
Returns
A CopyArrayConfig object containing the calculated selection logic, optimization flags (e.g., INIT_COPY, SAVE_COPY), and the shift node.
Precondition
The unit.refs set must not be empty.
The initcut pointer must be valid and point to a node containing valid DepCompAstRef information.
The initcut->GetInfo().orig must represent a valid array access or expression.
Postcondition
Returns a fully initialized CopyArrayConfig that can be used to drive array replication or copying transformations.
Note
The function uses ROSE_ABORT() to terminate execution if the AST structure does not conform to expected array access patterns or variable references.
The function relies on LoopTransformInterface and AstInterface for AST traversal and type information extraction.

Identifies the boundary nodes within a set of references based on their statement order.

This function iterates through a collection of nodes contained within a CopyArrayUnit to find the extreme nodes (the "cut boundary") according to a specific ordering criteria provided by DepCompAstRefAnal. It determines the first and last nodes in the sequence by comparing each node's information using the CompareAstRef method.

Parameters

stmtorderAn analyzer object used to define the ordering logic for comparing AST references.
unitA collection unit containing a set of references to be processed.
cut1A reference to a pointer that will be updated to point to the node representing the "upper" boundary (the node that is "greater" according to the comparison).
cut2A reference to a pointer that will be updated to point to the node representing the "lower" boundary (the node that is "less" according to the comparison).
Precondition
The unit.refs container must not be empty, as the function contains an assertion that cut1 and cut2 must not be null after execution.
Postcondition
The pointers cut1 and cut2 will point to the nodes in unit.refs that are extremal according to the stmtorder.CompareAstRef logic.
Note
The function uses an iterative approach with a complexity of O(n), where n is the number of elements in unit.refs.

Identifies and collects all nodes reachable from a given set of loop tree statements via dependency edges.

This function traverses the dependency graph associated with a loop tree dependency computation. It iterates through a range of loop tree statements provided by an iterator and, for each statement not already present in the result set, performs a graph traversal (using GraphGetNodeReachable) to find all reachable dependency nodes in the specified direction. The discovered loop tree nodes are added to the provided result set.

Parameters

resultA wrapper for a set of pointers used to accumulate the discovered LoopTreeNodes.
Precondition
The comp object must contain a valid, initialized LoopTreeDepGraph.
Postcondition
The result set will contain all LoopTreeNodes reachable from the nodes in the stmts range following the specified edge direction.
Note

Identifies and marks nodes for removal based on their relationship to a root node and loop levels.

This function iterates through a set of nodes provided by an iterator and determines if they should be added to a set of "cuts". A node is added to the cuts set if it is the same as the output node's statement or if it shares a common loop with the output node's statement at a loop level greater than or equal to the specified copylever. The function tracks whether all nodes in the provided range were successfully processed/cut via the removeall flag.

Parameters
nodesAn iterator representing the range of nodes to be processed.
outnodeA pointer to the reference graph node that serves as the target/root for the comparison.
copylevelAn integer representing the threshold loop level used to determine if a common loop is deep enough to trigger a cut.
cutsA reference to a NodeSet that will be updated with nodes identified as meeting the removal criteria.
Returns
True if all nodes in the provided iterator range were identified as cuts (i.e., no nodes failed the criteria); false if at least one node was encountered that did not meet the removal criteria.
Precondition
The nodes iterator must be valid and not reach the end immediately if processing is expected.
The outnode pointer must not be null to safely access GetInfo().
Postcondition
The cuts set will contain all nodes from the iterator range that satisfy the loop level or statement equality condition.
Note
The function utilizes a LoopTreeInterface to perform loop-related queries such as GetCommonLoop and GetLoopLevel.
