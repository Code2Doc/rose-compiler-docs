const std::vector< T > & tgt )

Calculates the Damerau-Levenshtein distance between two sequences.

This function computes the minimum number of operations (insertions, deletions, substitutions, and transpositions of two adjacent characters) required to transform the source vector into the target vector. The implementation follows the algorithm used in the C# implementation found on Wikipedia, utilizing a 2D scoring matrix and a dictionary-like structure to track the last seen positions of elements to handle transpositions efficiently.

Parameters
srcThe source sequence of elements of type T.
tgtThe target sequence of elements of type T.
Returns
The Damerau-Levenshtein distance between the two input vectors.
Precondition
The elements of type T must be comparable using the equality operator (==) and must be compatible with the LevenshteinStack<T> structure.
Postcondition
The returned value is a non-negative integer representing the edit distance.
Note
The complexity of the algorithm is O(x * y), where x and y are the lengths of the input vectors.
This implementation uses a 2D vector for the scoring matrix, which requires O(x * y) additional space.

const std::vector< T > & tgt )

Computes the Levenshtein distance between two sequences.

This function calculates the minimum number of single-character edits (insertions, deletions, or substitutions) required to change the source vector into the target vector. The implementation utilizes a dynamic programming approach with a 2D scoring matrix to track the edit costs. The algorithm iterates through the elements of both vectors, computing the cost of operations based on whether the current elements match or differ.

Parameters
srcThe source vector of type T from which the distance is measured.
tgtThe target vector of type T to which the source is being compared.
Returns
The Levenshtein distance between the src and tgt vectors as a size_t.
Precondition
The type T must support the equality operator (==) for comparison.
Postcondition
The returned value represents the minimum edit distance between the two input sequences.
Note
The implementation uses a 2D vector score of size (x+2) by (y+2) to facilitate the dynamic programming calculation.
The complexity of the algorithm is O(x * y), where x and y are the lengths of the src and tgt vectors respectively.
