Detailed Description

template<class R, class T>
class RangeMapNumeric< R, T >

Scalar value type for a RangeMap. Values can be merged if they compare equal; splitting a value is done by copying it. The removing() and truncate() methods are no-ops. See the RangeMapVoid class for full documentation.
