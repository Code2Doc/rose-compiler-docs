Determines whether a given SgNode represents a container node.

This function checks if the provided node is a type of node that acts as a container for other statements or nodes. It specifically evaluates if the node is a scope statement, a case option statement, or a default option statement.

Parameters

Returns
True if the node is a container node (scope, case option, or default option), false otherwise.
Precondition

Postcondition

Compares two CFGNodePtr objects based on their underlying node addresses.

This operator provides a strict weak ordering for CFGNodePtr instances by comparing the raw pointers returned by the getNode() method of each node. This is primarily used for storing CFGNodePtr objects in sorted containers such as std::set or std::map.

Parameters
node1The first CFGNodePtr to be compared.
node2The second CFGNodePtr to be compared.
Returns
True if the underlying node of node1 is less than the underlying node of node2, false otherwise.
Precondition
Both node1 and node2 must be valid, non-null CFGNodePtr instances.
Postcondition
The relative order of the nodes is determined by their underlying memory addresses.
Note
This comparison relies on the implementation of the less-than operator for the type returned by getNode().
