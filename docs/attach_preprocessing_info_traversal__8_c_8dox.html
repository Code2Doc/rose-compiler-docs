Maps the token stream to the Abstract Syntax Tree (AST) nodes for a given source file.

Maps tokens from a token stream to their corresponding AST nodes.

This function establishes a relationship between a sequence of tokens and the corresponding nodes in the AST. It performs a traversal over the AST of the provided source file to identify which ranges of the token stream belong to which AST nodes. This mapping is essential for high-fidelity unparsing, allowing the system to use the original token stream (including whitespace and comments) for parts of the code that have not been transformed, while using AST-based unparsing for transformed nodes.

The implementation uses a TokenMappingTraversal to traverse the sourceFile using an InheritedAttribute that tracks the token range. It also populates the SgToken list within the SgSourceFile by converting stream_element objects into SgToken IR nodes. Additionally, it updates the representative whitespace statement map to ensure that transformations can maintain correct formatting.

Parameters
sourceFileA pointer to the SgSourceFile object representing the source file being processed. The function relies on this object having its preprocessor directives and comments list already initialized.
tokenVectorA reference to a vector of stream_element* pointers containing the flattened token stream of the source file.
Precondition
The sourceFile must have a non-null preprocessor directives and comments list, retrievable via get_preprocessorDirectivesAndCommentsList().
The sourceFile must have valid file information available via get_file_info().
Postcondition
The sourceFile will have its tokenSubsequenceMap updated with the mapping between SgNode and TokenStreamSequenceToNodeMapping.
The sourceFile's token list (get_token_list()) will be populated with newly created SgToken objects derived from the tokenVector.
The sourceFile's representative whitespace statement map will be updated with the mapping from the traversal.
Note
If tokenVector is empty, the function initializes an empty mapping for the sourceFile and returns early.
The function may print a warning to stdout if buildTokenStreamMapping() is called even though get_unparse_tokens() is false for the sourceFile.
This function uses TimingPerformance for internal performance tracking of the traversal and token list construction.

This function establishes a relationship between a sequence of tokens and the Abstract Syntax Tree (AST) nodes they represent. It performs a traversal over the provided source file to identify which ranges of the token stream correspond to specific SgNode instances. This mapping is crucial for unparsing the AST using the original token stream, thereby preserving formatting, comments, and preprocessor directives. The function also populates the SgSourceFile with SgToken IR nodes and updates representative whitespace information for subsequent transformations.

Parameters
sourceFileA pointer to the SgSourceFile object being processed. This object is used to retrieve preprocessor directives, check unparsing settings, and store the resulting token subsequence maps.
tokenVectorA reference to a vector of stream_element pointers representing the initial token stream of the source file.
Precondition
The sourceFile must have its preprocessor directives and comments list initialized (sourceFile->get_preprocessorDirectivesAndCommentsList() != NULL).
The sourceFile must have valid file information (sourceFile->get_file_info() != NULL).
Postcondition
The tokenVector is processed to create SgToken IR nodes which are added to the sourceFile's token list.
The sourceFile's token subsequence map is updated to point to the newly created tokenStreamSequenceMap.
The sourceFile's representative whitespace statement map is updated with the mapping discovered during traversal.
Note
This function uses a include-style approach to handle the mapping of tokens to nodes to ensure that unparsing can utilize the original token stream for high-fidelity source reconstruction.
If the tokenVector is empty, the function initializes an empty map for the sourceFile and returns early.
The function may print warnings to stdout if the function is called even when unparsing tokens is disabled for the specific source file.
