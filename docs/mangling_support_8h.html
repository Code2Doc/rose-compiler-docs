Traverses the scope hierarchy upwards to find the root function definition.

This function performs a recursive upward traversal through the scope hierarchy starting from the provided scope statement. It inspects the variant type of the current scope to determine if it represents a function definition (either a standard function or a template function). If the scope is a global scope, the traversal terminates. If the scope is of an unexpected type, the function attempts to move to the outer scope.

Parameters
scopeA pointer to the starting SgScopeStatement to begin the search.
Returns
A pointer to the SgFunctionDefinition if a function or template function definition is found at the root of the scope hierarchy; otherwise, returns nullptr if the traversal reaches a global scope or if the initial scope is nullptr.
Precondition
The scope pointer should ideally point to a valid SgScopeStatement.
Postcondition
The function returns either a valid pointer to an SgFunctionDefinition or nullptr.
Note
The function uses recursion to climb the scope tree.
If the scope variant is not a function definition or template definition, the function relies on scope->get_scope() to find the parent. It is assumed that the parent scope is not the same as the current scope to avoid infinite loops.
Warning
If the scope hierarchy is improperly structured (e.g., a scope points to itself), this function may result in infinite recursion.

Retrieves the number of local scopes preceding a specific target scope within a function definition.

Returns a unique positive integer ID to an SgScopeStatement within a function definition.

This routine computes a preorder numbering of the SgScopeStatements in the subtree rooted at 'func_def', and returns the number assigned to the 'target' scope statement, or 0 if the target could not be found in 'func_def'.

This function determines the scope index or count for a given scope statement within the context of a function definition. The implementation behavior depends on the ifdef SKIP_BLOCK_NUMBER_CACHING preprocessor directive.

If SKIP_BLOCK_NUMBER_CACHING is defined, the function performs a preorder traversal of the function's AST using a custom Traversal class (derived from AstSimpleProcessing). It counts the number of SgScopeStatement nodes encountered during the traversal until the target scope statement is reached.

If SKIP_BLOCK_NUMBER_CACHING is not defined, the function utilizes a more efficient caching mechanism by delegating the call to the func_def->get_scope_number(target) method, which avoids the quadratic complexity associated with repeated traversals.

Parameters

Precondition
func_def must be a valid, non-null pointer to an SgFunctionDefinition.
Postcondition
The state of the AST remains unchanged.
Note
The caching mechanism was implemented to prevent performance degradation in large source files where frequent traversals would otherwise lead to quadratic time complexity.
