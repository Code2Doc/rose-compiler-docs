void removeEmptyElses ( SgNode * top)

Removes empty else blocks from if-statements within a given subtree.

Removes empty else blocks from if-statements within a given node subtree.

This function traverses the subtree rooted at the provided node to identify all if-statements. For each identified if-statement, it checks if the false branch (the else block) is a basic block that contains no statements. If such an empty else block is found, it is replaced with a NULL pointer to clean up the intermediate representation.

Parameters
topA pointer to the root node of the subtree to be processed.
Precondition
top must not be NULL.
Postcondition
Any if-statements within the subtree of top that had an empty basic block as their false body will now have a NULL false body.
Note
This function uses NodeQuery::querySubTree to locate all instances of V_SgIfStmt within the provided hierarchy.
