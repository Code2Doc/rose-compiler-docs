void Outliner::Preprocess::checkAndPatchUpOptions ( )

Sanity check and patch up outliner options.

Validates and reconciles interdependent configuration options.

This function performs consistency checks on the preprocessing options to ensure that dependent flags are correctly set. Specifically, it enforces the logical dependency where the useStructureWrapper option requires the useParameterWrapper option to be enabled. If a discrepancy is detected (useStructureWrapper is true but useParameterWrapper is false), the function automatically updates useParameterWrapper to true and logs a warning to the standard output.

Precondition
The configuration options useStructureWrapper and useParameterWrapper must be initialized before calling this function.
Postcondition
The state of useParameterWrapper is guaranteed to be true if useStructureWrapper is true, ensuring a consistent configuration state.
Note
This function currently only handles the dependency between useStructureWrapper and useParameterWrapper. Future implementations may include additional validation logic for other interdependent options.

SgBasicBlock * Outliner::Preprocess::createBlock ( SgStatement * s)

Convert the "plain-old" statement into an SgBasicBlock. This normalization simplifies outlining of single statements.

Wraps a given statement in a new basic block if it is not already a basic block.

This function checks if the provided statement s is already an instance of SgBasicBlock. If it is not, the function creates a new SgBasicBlock using SageBuilder::buildBasicBlock. The new block is then integrated into the AST by replacing the original statement s with the new block b_new using SageInterface::replaceStatement. The original statement s is then appended to the new block, and the parent-child relationships are updated. Preprocessor information is moved from the original statement to the new block using ASTtools::moveUpPreprocInfo.

Parameters
sThe pointer to the SgStatement that needs to be checked and potentially wrapped in a new basic block.
Returns
A pointer to the SgBasicBlock containing the statement. If the original statement was already a basic block, the original statement is returned. The return value is validated to ensure it is a valid SgBasicBlock.
Precondition
The input parameter s must be a valid, non-null SgStatement pointer.
The parent of s must be a valid SgStatement if s is not a basic block.
Postcondition
If s was not a basic block, a new SgBasicBlock is created, and s is now a child of this new block.
The original position of s in the AST is replaced by the new basic block.
Note
The implementation uses if logic to decide between ASTtools::replaceStatement and SageInterface::replaceStatement, currently defaulting to the latter.
The function relies on ROSE_ASSERT to ensure the successful creation of the new block and the validity of the parent statement.

SgBasicBlock * Outliner::Preprocess::normalizeVarDecl ( SgVariableDeclaration * s)

Normalizes outline targets that are variable declarations, returning a new SgBasicBlock to outline.

Normalizes a variable declaration by splitting it into a declaration and a separate assignment block.

This routine converts a variable declaration of the form:

TYPE i, j = J0, k = K0, ...;

to:

TYPE i, j, k, ...; { // @RET j = J0; k = K0; ... }

and returns a pointer to the SgBasicBlock at "@RET".

In addition to creating a new SgBasicBlock, this routine modifies the original SgVariableDeclaration by removing all SgAssignInitializers.

This function processes a variable declaration statement to separate the declaration of variables from their initializations. It iterates through all variables within the provided SgVariableDeclaration, creates a new basic block, and moves the initialization logic into this new block via assignment statements. This is typically used during preprocessing to simplify the control flow graph by isolating assignments from declarations.

Parameters
sA pointer to the SgVariableDeclaration to be normalized.
Returns
A pointer to the newly created SgBasicBlock containing the assignment statements, or 0 (nullptr) if the input declaration is null.
Precondition
The input SgVariableDeclaration s must contain at least one variable.
The scope associated with the variable declaration s must be valid and non-null.
Postcondition
The original variable declaration s is modified such that its variables no longer retain their original initializers (they are set to 0), and a new basic block is inserted into the scope immediately after the declaration.
Note
There is a known potential memory leak when the initializer is set to 0.
The function uses ROSE_ASSERT to verify that the declaration is not empty and that the scope exists.

◆ preprocessOutlineTarget()

SgBasicBlock * Outliner::Preprocess::preprocessOutlineTarget ( SgStatement * s)

Preprocesses the outline target and returns an equivalent SgBasicBlock to outline.

Preprocesses a given statement to prepare it for outlining into a basic block.

The goal of this preprocessing is to simplify outlining by always providing the caller with an SgBasicBlock to outline.

This function performs several transformation steps on a target statement to ensure it is compatible with an outliner. The process involves ensuring the statement is wrapped in an SgBasicBlock, handling autotuning header insertions, and performing various AST transformations. The implementation follows these steps:

  1. Validates options via checkAndPatchUpOptions.
  2. If dlopen is enabled, it checks if a specific autotuning header needs to be inserted into the file.
  3. Normalizes the input statement into an SgBasicBlock. If the input is a variable declaration, it uses normalizeVarDecl; if it is already a basic block, it uses it as is; otherwise, it creates a new block via createBlock.
  4. Transforms preprocessing control structures (e.g., ifdef, ifndef) using transformPreprocIfs, provided OpenMP lowering is not active.
  5. Transforms 'this' expressions into local pointer references via transformThisExprs.
  6. Transforms non-local control flow via transformNonLocalControlFlow, provided OpenMP lowering is not active.
  7. Gathers non-local declarations via gatherNonLocalDecls.
  8. Propagates static const member variables (integers or enums) via propagateStaticConstMembers.
Parameters
sThe input SgStatement that is the target for the outlining process.
Returns
A pointer to the processed SgBasicBlock.
Precondition
s must not be a null pointer (verified by ROSE_ASSERT).
Postcondition
The returned SgBasicBlock is a transformed version of the input statement, potentially containing new blocks, transformed expressions, and updated headers.
Note
This function skips certain transformations (preprocessing control structures and non-local control flow) if the enclosing file node is currently undergoing OpenMP lowering to avoid bugs and illegal parallel region jumps.
The insertion of the autotuning header is suppressed if suppress_autotuning_header is true.

void Outliner::Preprocess::propagateStaticConstMembers ( SgBasicBlock * b)

Constant propagation for static member variables.

Replaces references to static constant members with their initializers.

This routine analyzes the basic block to-be-outlined, and determines if any variables need to be replaced with their constant values.

This is needed since the outlining step will use addressOf Operator to pass variables around, which may require explicit definition of static member variables of a class.

Original code do not need such definitions as long as they are integer or enumerate types of static constant variables with intialized values.

This function performs a transformation on a given basic block by traversing its Abstract Syntax Tree (AST). It identifies all variable references within the block and checks if they refer to static constant integers or enumerations that possess an explicit initializer. If such a reference is found, the reference is replaced by a deep copy of the underlying initializer expression. This is useful for constant folding or simplifying the IR by inlining known static constants.

Parameters
bA pointer to the SgBasicBlock to be processed.
Precondition
The pointer b must be a valid, non-null pointer to an SgBasicBlock.
Postcondition
All identified static constant member references within the block 'b' are replaced by their respective initializer expressions.
Note
The function utilizes RoseAst to iterate through the AST nodes and relies on helper functions like isSgVarRefExp and isStaticConstIntOrEnumWithInitializer to identify target nodes.

SgBasicBlock * Outliner::Preprocess::transformNonLocalControlFlow ( SgBasicBlock * b_orig)

Preprocess non-local control flow for outlining.

Transforms non-local control flow jumps within a basic block into local goto statements.

Let 'B' be an input code block (i.e., an SgBasicBlock node). We define a non-local jump to be any break, continue, return, or goto statement that cedes control to some point outside 'B'.

Given 'B', of the form,

// Start of input block, 'B' { ... // bunch of code JUMP_1; // First non-local "jump" statement ... JUMP_2; // Second non-local "jump" ... JUMP_k; // k-th non-local "jump" ... }

where each JUMP_i is a non-local jump statement, this routine transforms 'B' into

// Start of the transformed 'B' { int EXIT_TAKEN__ = 0; // A new block, 'G', transformed to use a local 'goto'. { ... { EXIT_TAKEN__ = 1; goto NON_LOCAL_EXIT__; } ... { EXIT_TAKEN__ = 2; goto NON_LOCAL_EXIT__; } ... { EXIT_TAKEN__ = k; goto NON_LOCAL_EXIT__; } ... NON_LOCAL_EXIT__: ; } if (EXIT_TAKEN__ == 1) JUMP_1; else if (EXIT_TAKEN__ == 2) JUMP_2; ... else if (EXIT_TAKEN__ == k) JUMP_k; }

and returns 'T'.

This function identifies non-local jumps (such as setjmp/longjmp or other non-local exits) and gotos within a given basic block. It restructures the control flow by creating a new "shell" block to encapsulate the transformed logic, renumbers existing jumps, and implements a jump table mechanism using a boolean flag (EXIT_TAKEN__) and conditional statements to simulate the non-local behavior using local gotos.

The implementation involves:

  1. Collecting all non-local jumps and gotos using ASTtools.
  2. Creating a new basic block (b_gotos) to act as a container for the transformed statements.
  3. Normalizing return statements to ensure visibility of variables.
  4. Injecting a tracking variable 'EXIT_TAKEN__' into the original block.
  5. Creating a target label 'NON_LOCAL_EXIT__' within the new block.
  6. Converting the identified non-local jumps into local gotos that target the new label.
  7. Constructing a jump table (if-statements) in the original block to handle the logic.
Parameters
b_origThe original basic block that contains the control flow statements to be transformed.
Returns
A pointer to the newly created SgBasicBlock that contains the transformed control flow logic, or the original block if no non-local jumps were detected.
Precondition
b_orig must be a valid, non-null pointer to an SgBasicBlock.
Postcondition
The original block b_orig is modified to include the 'EXIT_TAKENT__' variable and a jump table, while a new block is returned containing the restructured statements and the exit label.
Note
This transformation relies on the existence of ASTtools utilities for collecting jumps and transforming blocks.
The function uses ROSE_ASSERT to ensure the validity of newly created AST elements like the exit variable and labels.

Transform 'if' directive structure. It is possible that certain preprocessor directives may straddle the boundaries of a basic block. This routine attempts to detect and transform these instances so that the block may be safely outlined.

Transforms a basic block to handle preprocessor if-directive boundaries.

In particular, consider the following SgBasicBlock, which has 2 'if' directives straddling it (labeled 'B' and 'D') and one surrounding it ('A').

if [A1] S0;

if [B1] <==+

S1; |

elif [B2] <==+

S2; | { | S3; +— Straddles opening brace.

elif [B3] <==+

S4; |

endif [B] <==+

S5;

if [C] <==+

S6; +– Fully within the block

endif [C] <==+

S7;

if [D1] <==+

S8; |

elif [D2] <==+

S9; +-— Straddles ending brace. } | S10; |

elif [D3] <==+

S11; |

endif [D] <==+

S12; #endif [A]

This routine will transform this block into (new statements and directives marked with a '**'):

if [A1] S0;

if [B1]

S1;

elif [B2]

S2;

endif // [B] ** <==+ CLOSE ([B]);

#endif // [A] ** <==+ { { ** <==============+ if 1 // [A1] ** | OPEN ([B]);

if 1 // [B1, B2] ** <==+

S3;

elif [B3]

S4;

endif [B]

S5;

if [C]

S6;

endif [C]

S7;

if [D1]

S8;

elif [D2]

S9;

endif [D] ** <==+ CLOSE ([D]);

#endif [A] ** <==+ } ** if 1 //[A1] ** <=========+ OPEN ([D2]);

if 1 // [D1, D2] ** <==+

} S10;

elif [D3]

S11;

endif [D]

S12; #endif [A]

Note that the block to-be-outlined is now fully self-contained. Logically, the transformation consists of "closing" and "opening" the 'if' directive contexts at the boundaries to the outlined block as shown above.

This function identifies if the provided basic block is contained within the scope of C preprocessor if directives. If the block is bounded by such directives, the function wraps the block in a new shell block. This is achieved by creating a new block and re-arranging the preprocessor context boundaries (top and bottom) so that the preprocessor directives effectively wrap the newly created block structure.

Parameters
bThe source basic block to be processed.
Returns
A pointer to the new basic block (the shell block) if the block was wrapped due to preprocessor directives, or the original pointer to the block 'b' if no preprocessor directives were found.
Precondition
The input pointer 'b' must not be null and must have a valid parent.
Postcondition
If the block was wrapped, a new SgBasicBlock is returned that contains the original block as a child, with updated preprocessor context boundaries.
Note
This function relies on CPreproc::findIfDirectiveContext to determine the preprocessor state and uses ASTtools::transformToBlockShell to perform the structural transformation.

SgBasicBlock * Outliner::Preprocess::transformThisExprs ( SgBasicBlock * b)

Canonicalize references to 'this'.

Transforms 'this' expressions within a basic block by replacing them with a shadow variable declaration.

Given a basic block with 'this' expressions:

{ ... this ... }

creates a level of indirection to 'this' through an explicit local variable, so that the outliner includes it in the outlined function parameter list:

// 'this' shell { TYPEOF(this)* this__ptr__ = (TYPEOF(this) *)this; { ... this__ptr__ ... } }

This function identifies all instances of 'this' expressions within the provided basic block. If 'this' expressions are found, it creates a shadow variable declaration (named "this__ptr__") representing the class symbol associated with these expressions. The function then replaces all occurrences of the 'this' expression in the block with this new shadow variable. The implementation avoids creating a new inner-level basic block to ensure compatibility with various AST layouts, such as those produced by pragma rose_outline or pragma omp parallel/task, by inserting the declaration within the enclosing member function definition instead.

Parameters
bA pointer to the SgBasicBlock that needs to be processed for 'this' expression transformation.
Returns
A pointer to the SgBasicBlock after the transformation. The returned block is the same as the input block, potentially modified in-place with a new variable declaration and updated expressions.
Precondition
The input parameter b should be a valid, non-null pointer to an SgBasicBlock.
Postcondition
The 'this' expressions within the basic block b are replaced by a shadow variable declaration if any were present.
Note
The function uses ifdef linux to enable debug logging of the function entry and the state of the basic block.
The implementation relies on getClassSymAndVerify to retrieve the class symbol and createThisShadowDecl to generate the new variable declaration.
