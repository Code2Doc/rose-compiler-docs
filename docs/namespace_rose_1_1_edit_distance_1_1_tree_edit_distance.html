Detailed Description

Auto-generated documentation for the Rose::EditDistance::TreeEditDistance namespace.

Analysis to determine how to make one AST look like another.

Actually editing one tree have the same shape as another is, in many cases, nonsensical but the edit distance metric is nonetheless useful to determine the similarity of two trees. See Analysis::compute for details about how this analysis is implemented.

The way the analysis is used is like this:

using namespace Rose::EditDistance;
SgNode *ast1 = ...; // The first subtree
SgNode *ast2 = ...; // Second subtree
TreeEditDistance::Analysis ted; // Object for performing the analysis
ted.substitutionCost(0.0); // Adjust some parameters
ted.compute(ast1, ast2); // Run the analysis
double cost = ted.cost(); // Query some results

Or in one expression:

double cost = TreeEditDistance::Analysis() .substitutionCost(0.0) .compute(ast1, ast2) .cost();

The analysis object can be reused as many times as one likes by calling its compute method with different trees. The query methods always return the same results until the next call to compute.

Generates a flattened list of AST nodes based on a depth-constrained traversal.

This function performs a depth-first traversal of the provided Abstract Syntax Tree (AST) starting from the root node. It utilizes a SequenceGenerationTraversal object to navigate the tree structure, collecting nodes that fall within the specified depth boundaries. During the traversal, the depth of each visited node is recorded.

Parameters
astA pointer to the root SgNode of the AST to be traversed.
nodeDepthsAn output vector that will be cleared and then populated with the depth of each node found during the traversal, corresponding to the order of nodes in the returned vector.
containingFileA pointer to the SgFile containing the nodes, used for contextual information during traversal. Defaults to NULL.
minDepthThe minimum depth level (inclusive) from which nodes should be collected. Defaults to 0.
maxDepthThe maximum depth level (inclusive) up to which nodes should be collected. Defaults to the maximum possible value for size_t.
Returns
A vector of pointers to SgNode objects that were encountered during the traversal within the specified depth range.
Precondition
The ast pointer must not be NULL if a traversal is to be performed.
Postcondition
The nodeDepths vector is cleared and updated with the depths of the nodes returned in the resulting vector.
Note
The traversal follows the logic implemented in the SequenceGenerationTraversal class.
