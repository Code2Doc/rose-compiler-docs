Generates a loop statement to perform element-wise assignment between two arrays or pointers.

This function constructs a C++ loop structure that iterates through the elements of an array-like expression. It generates a unique loop index variable within the scope of the target statement, initializes it to zero, and sets the loop condition based on the size of the left-hand side (LHS) array. The loop body performs an assignment from the right-hand side (RHS) to the LHS. If the elements being accessed are themselves arrays, the function recursively calls itself to handle nested array packing.

Parameters
lhsThe left-hand side expression representing the destination array or pointer. Must be an array type.
rhsA reference to the right-hand side expression representing the source array or pointer.
targetThe target statement into which the loop index declaration will be inserted and which serves as the anchor for the generated loop.
Returns
A pointer to the newly constructed SgStatement representing the for-loop.
Precondition
The type of lhs must be an array type (verifiable via isSgArrayType).
The target statement must have a valid scope accessible via get_scope().
Postcondition
A new loop statement is created, and a variable declaration for the loop index is inserted before the target statement in the program structure.
Note
This function uses recursion to handle multi-dimensional array packing.
The function relies on SageInterface::generateUniqueVariableName to prevent variable name collisions in the target scope.

Identifies the set of variables that must be restored after function outlining.

This function iterates through a set of symbols to determine which variables require restoration at the end of an outlined function. A variable is added to the restoreVars set if it is modified (not present in the readOnlyVars set) and is considered live-out (present in the liveOutVars set). The determination of liveness depends on the Outliner::enable_liveness flag; if liveness analysis is disabled, all variables are conservatively treated as live-out.

Parameters
symsA set of symbols to be evaluated for potential restoration.
readOnlyVarsA set of SgInitializedName pointers representing variables that are only read and thus do not require restoration.
liveOutVarsA set of SgInitializedName pointers representing variables that are live at the exit of the block.
restoreVarsAn output set that will be populated with SgInitializedName pointers that must be restored.
Precondition
The elements within the syms container must not be NULL.
Postcondition
The restoreVars set will contain all variables that are written to and are live-out, as determined by the provided liveness and read-only sets.
Note
If Outliner::enable_liveness is false, the function assumes all variables in syms are live-out.
If Outliner::enable_debug is true, the function prints the execution status and the names of the identified variables to the standard output.

Identifies variables that require pass-by-address due to being mutable.

This function iterates through a set of variable symbols and determines which of them are not marked as read-only. If a variable is not present in the provided set of read-only variables, it is considered mutable (being written to) and its symbol is added to the output set of address-of variables. This is typically used during code outlining to decide which variables must be passed by pointer to ensure updates are reflected in the caller's scope.

Parameters
symsA set of variable symbols to be evaluated.
readOnlyVarsA set of initialized names that are considered read-only and do not require pass-by-address.
addressOfVarSymsAn output set that will be populated with the symbols of variables that are not read-only.
Precondition
The addressOfVarSyms set should be initialized before calling this function.
Postcondition
The addressOfVarSyms set will contain all symbols from syms whose declarations are not found in readOnlyVars.
Note
The function uses a reverse iterator to traverse the syms set.
