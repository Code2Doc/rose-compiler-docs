Consume tokens.

std::string Rosebud::Ast::File::trimmedContent ( size_t begin,
size_t end,
Token & outputToken )

Input string for file region.

Returns the content of the file from character position begin (inclusive) to end (exclusive). If the end is less than or equal to begin, then an empty string is returned. The text is modified by removing trailing white space from each line, replacing consecutive blank lines with a single blank line, and removing leading and trailing blank lines. If an exclude token is specified, then its text is not included in the returned string.
