bool isVariableReference ( SgExpression * expression)

Determines if a given expression consists entirely of variable references.

Returns true if the given expression refers to a variable. This could include using the dot and arrow operator to access member variables. A comma op counts as a variable references if all its members are variable references (not just the last expression in the list).

This function performs a recursive traversal of an expression tree to verify if every component of the expression is a variable reference. It checks for direct variable references, the this pointer, and recursively validates the operands of member access (dot and arrow operators), comma operators, and unary operators such as pointer dereferencing, casting, and address-of operations.

Parameters
expressionA pointer to the SgExpression to be evaluated.
Returns
True if the expression and all its constituent sub-expressions are variable references; false otherwise.
Precondition
expression should not be a null pointer.
Postcondition
The state of the expression tree remains unchanged.
Note
The function treats the comma operator as a variable reference only if both the left-hand side and right-hand side operands are also variable references.
