Constructs a new expression representing the result of a floating-point binary operation.

This function performs constant folding for binary operations involving floating-point types. It extracts the underlying values from the provided left-hand side and right-hand side expression nodes, performs the arithmetic operation using the calculate_float_t utility, and encapsulates the resulting value into a new expression node of type T1.

Parameters
binaryOperatorA pointer to the SgBinaryOp node representing the operation to be performed.
lhsValueA pointer to the left-hand side SgValueExp node. Must be castable to type T1.
rhsValueA pointer to the right-hand side SgValueExp node. Must be castable to type T1.
Returns
A pointer to a newly allocated SgValueExp of type T1 containing the folded result.
Precondition
The lhsValue and rhsValue must be non-null and must be valid pointers to objects of type T1 (or a class derived from T1) to satisfy the dynamic_cast and ROSE_ASSERT checks.
Postcondition
A new expression node is allocated on the heap. The source position of the newly created node is synchronized with the current transformation position via SageInterface::setOneSourcePositionForTransformation.
Note
This function relies on cf_get_value_t to extract the numeric value of type T2 from the expression nodes and calculate_float_t to execute the actual computation logic.

Constructs a new SgValueExp representing the result of a binary operation via constant folding.

This function performs constant folding for a binary operator by extracting the underlying values of the left-hand side (LHS) and right-hand side (RHS) operands, computing the result using the provided operator and types, and wrapping the result in a new expression object. The function utilizes dynamic casting to ensure the operands are of the expected type T1 and uses cf_get_value_t to retrieve the actual values of type T2.

Parameters
binaryOperatorA pointer to the SgBinaryOp representing the operation to be performed.
lhsValueA pointer to the left-hand side SgValueExp operand. Must be castable to T1.
rhsValueA pointer to the right-hand side SgValueExp operand. Must be castable to T1.
Returns
A pointer to a newly allocated SgValueExp of type T1 containing the folded result.
Precondition
lhsValue and rhsValue must be non-null and must be valid pointers to objects of type T1.
Postcondition
A new SgValueExp object is allocated on the heap. The source position of the newly created expression is set to match the current transformation context.
Note
This function relies on the existence of the template function cf_get_value_t and the calculation function calculate_t.
Warning
If the dynamic_cast to T1 fails for either lhsValue or rhsValue, a ROSE_ASSERT failure will occur.

Calculate the result of a binary operation on two constant float-kind values,.

Performs constant folding for a binary operator using provided operand values.

This function evaluates the result of a binary operation at compile-time or during transformation by dispatching the operation type to the appropriate C++ operator based on the variant type of the SgBinaryOp. It supports basic arithmetic, logical, and relational operations.

Parameters
binaryOperatorA pointer to the SgBinaryOp object representing the operation to be performed. The function uses binaryOperator->variantT() to determine the operation type.
lhsValueThe value of the left-hand side operand.
rhsValueThe value of the right-hand side operand.
Returns
The result of the evaluated binary operation as type T.
Warning
If the binaryOperator type is not recognized, a warning is printed to std::cerr and the function returns the initialized value of 0.
Division by zero is not explicitly handled and may result in undefined behavior depending on the type T.
Precondition
binaryOperator must not be a null pointer.
Postcondition
The returned value represents the computed result of the operation if the operator type is supported.
Note
The implementation uses a switch statement to map SgBinaryOp variants (such as V_SgAddOp, V_SgSubtractOp, etc.) to their corresponding C++ operators.

Performs constant folding for a given binary operator and two operands.

This function evaluates the result of a binary operation at compile-time (or during a constant folding pass) by inspecting the variant type of the provided SgBinaryOp. It supports a wide range of operations including arithmetic (addition, subtraction, multiplication, division), bitwise (AND, OR, XOR, shifts), logical (AND, OR), relational (equality, comparison), and exponentiation. The implementation uses a switch statement based on the operator's variant type to dispatch the appropriate C++ operator.

Parameters
binaryOperatorA pointer to the SgBinaryOp object representing the binary operation to be evaluated.
lhsValueThe value of the left-hand side operand.
rhsValueThe value of the right-hand side operand.
Returns
The computed result of the binary operation as type T.
Warning
Division by zero in V_SgDivideOp or V_SgIntegerDivideOp will result in undefined behavior or a runtime error.
For V_SgExponentiationOp, using large exponents may lead to overflow or precision loss when casting the result of pow() to type T.
If the binary operator type is not recognized, a warning is printed to stderr and the function returns a default-initialized value (0).
Precondition
binaryOperator must not be a null pointer.
Postcondition
The returned value represents the evaluated result of the operation if the operator type is supported.
Note
The function uses a default initialization of foldedValue to 0 to prevent uninitialized variable warnings during compilation.

This is the external interface of constant folding:

Performs constant folding optimization on a given AST node.

This function serves as the primary interface for the constant folding optimization pass. It utilizes a ConstantFoldingTraversal to traverse the provided SgNode and applies optimization logic to simplify constant expressions within the Abstract Syntax Tree (AST). The process uses ConstantFoldingInheritedAttribute to pass configuration, such as whether to perform internal testing against the frontend, and ConstantFoldingSynthesizedAttribute to capture the results of the traversal.

Parameters
nA pointer to the SgNode representing the root of the AST subtree to be optimized.
internalTestingAgainstFrontendA boolean flag indicating whether the optimization should perform error checking against constant expression trees stored in the AST.
Precondition
n must not be a null pointer.
Postcondition
The AST subtree rooted at n may be modified such that constant expressions are replaced with their computed values.
Note
The implementation contains conditional compilation blocks using if and else for debugging and assertion purposes.

ROSE_DLL_API void ConstantFolding::constantUnFoldingTest ( SgNode * n)

Performs tests for constant un-folding by generating complex constant expressions.

This function serves as the primary interface for testing constant un-folding capabilities. Because the existing constant folding mechanism only verifies results computed by EDG (where no transformations have occurred), this function implements a transformation strategy to create testable scenarios. It uses a ConstantUnFoldingTraversal to transform simple constants into long and complex constant expressions. This process creates synthetic constant expressions that the constant folding engine would otherwise not encounter, allowing for robust testing of the folding logic.

Parameters
nThe root node of the Abstract Syntax Tree (AST) to be traversed and transformed.
Precondition
n must be a valid, non-null pointer to an SgNode.
Postcondition
The AST rooted at n will have been traversed, and simple constants within the tree will have been replaced by complex, un-folded constant expressions.
Note
If the AST is saved beforehand using AST File IO, the resulting AST can be compared against the original to verify if the constant folding process successfully reduced the generated expressions back to their simplest forms.
The implementation currently relies on ConstantUnFoldingTraversal to perform the structural transformation of the nodes.

Performs constant folding on a given AST node to reduce it to a constant value expression.

This function serves as the primary interface for the constant folding optimization process. It utilizes a ConstantFoldingTraversal to traverse the provided SgNode and applies optimization rules to identify and replace constant sub-expressions with their computed results. The process uses ConstantFoldingInheritedAttribute to pass configuration settings, such as error checking flags, down the tree, and ConstantFoldingSynthesizedAttribute to collect the resulting folded expression back up the tree.

Parameters
nThe root node of the AST subtree to be processed for constant folding.
internalTestingAgainstFrontendA boolean flag that determines whether the traversal should perform internal error checking against constant expression trees stored in the AST.
Returns
A pointer to an SgValueExp representing the folded constant value. Returns NULL if no constant expression could be derived from the input node.
Precondition
The input node n must be a valid, non-null SgNode pointer.
Postcondition
The returned SgValueExp (if not NULL) represents a simplified version of the input subtree, where applicable constant operations have been pre-computed.
Note
The implementation uses if blocks for conditional compilation of debug print statements.
