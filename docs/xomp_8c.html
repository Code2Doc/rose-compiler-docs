Calculates the starting offset and size for a specific chunk in a statically partitioned range.

This function implements a work-distribution algorithm to divide a total range of size orig_size into chunk_count approximately equal parts. The algorithm handles the remainder of the division by distributing the extra elements across the first few chunks (specifically, the first remainder chunks).
