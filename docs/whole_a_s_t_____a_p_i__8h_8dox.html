Generates a DOT graph representing the inclusion relationships of header files.

Performs a traversal of the project files to identify and map the first and last statements within scopes to facilitate accurate source code reconstruction (unparsing).

This function constructs a directed graph in DOT format that visualizes the inclusion hierarchy of header files within a given SgProject. It iterates through the project structure and uses a recursive mechanism to trace how files include one another, effectively building a tree-like structure (though cycles or multiple inclusions may exist). The output is written to a file with a .dot extension.

Postcondition

This function iterates through all source files in a given project, traversing the Abstract Syntax Tree (AST) to populate a global mapping of the first and last statements for every scope encountered. It specifically handles the tracking of file boundaries, including header files and included dependencies, by associating statements with their respective source files and managing the mapping of include directives via the Rose AST traversal.

The function is designed to support high-fidelity unparsing by ensuring that the boundaries of code blocks (scopes) are correctly identified, even when dealing with complex include hierarchies and multiple translation units.

Parameters
projectA pointer to the project object containing the files and the AST nodes to be traversed.

The function utilizes a custom AST visitor (StatementVisitor) to traverse the nodes. For each node, it checks if the node represents a scope (e.g., a block, function, or class). It then updates the global mapping (Rose::firstAndLastStatementMap) with the first and last statements encountered within that scope. It also handles the logic for tracking statements across different files by checking the physical file associated with each AST node.

Note
The function relies on the correct identification of scope boundaries and the availability of file information for each AST node.
