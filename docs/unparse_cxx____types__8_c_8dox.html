string get_type_name ( SgType * t)

Converts an SgType object into its string representation.

This function performs a recursive traversal of an SgType object to generate a human-readable string that represents the type's name. It handles a wide variety of type variants including primitive types (int, char, float, etc.), complex types (pointers, references, arrays, tuples, matrices), and language-specific constructs (C99 _Bool, C++ templates, and OpenCL modifiers). The implementation uses a switch statement based on the type variant and recursively calls itself for nested or derived types such as pointers, function signatures, and member pointers.

Parameters

Returns

Precondition
The parameter t must not be null.
Postcondition
The function returns a valid string representing the type; the input SgType object remains unmodified.
Note
