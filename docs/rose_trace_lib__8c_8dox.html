void __ROSE_TraceEnd ( )

Closes the active ROSE trace file.

This function is designated as a destructor using the attribute((destructor)) compiler directive, meaning it is automatically invoked when the program terminates. It checks if a global trace file pointer is currently active. If a pointer exists, it attempts to close the file using fclose. The function provides feedback to stderr if the file fails to close or to stdout if the file is successfully closed and all traces are written.

Precondition
The global pointer __roseTraceFilePtr should be initialized to NULL if no tracing is intended.
Postcondition
The file pointed to by __roseTraceFilePtr is closed, and the __roseTraceFile string remains available for logging purposes.
Note
This function relies on the existence of global variables __roseTraceFilePtr and __roseTraceFile.
Warning
If fclose fails, an error message is printed to stderr.

void __ROSE_TraceStartup ( )

Initializes the ROSE tracing system and sets up the trace output file.

This function is an automated constructor that runs before the main program execution. It determines the destination path for the trace log by checking environment variables. First, it checks for the existence of the ROSE_TRACE_FILE_PATH_ENV variable. If present, that specific path is used. If not, it looks for ROSE_TRACE_DIR_ENV. If neither is set, it defaults to the current working directory. The filename is constructed using the system hostname and the current process ID (PID) to ensure uniqueness. Finally, it attempts to open the file for writing in binary mode.

Precondition
The environment variables ROSE_TRACE_FILE_PATH_ENV or ROSE_TRACE_DIR_ENV should ideally be set to control the output location.
Postcondition
A global file pointer __roseTraceFilePtr is initialized to a valid file stream pointing to the trace file, or the program terminates with an error.
Warning
If the hostname cannot be retrieved or the trace file cannot be opened, the function calls exit(-1), terminating the entire process.
Note
This function uses attribute__((constructor)) to ensure it executes during the program's initialization phase.

int ROSE_Tracing_Instrumentor ( uint64_t id)

Writes a unique identifier to the global trace file for instrumentation purposes.

This function performs a low-level write operation to a global file pointer __roseTraceFilePtr. It serializes a 64-bit unsigned integer representing a specific trace ID into the trace file. If the write operation fails, the function prints an error message to stderr, closes the trace file, nullifies the global pointer, and terminates the process.

Parameters
idThe 64-bit unsigned integer identifier to be recorded in the trace log.
Warning
This function is NOT thread-safe. Concurrent calls to this function from multiple threads may lead to race conditions, interleaved data, or file corruption.
Precondition
The global file pointer __roseTraceFilePtr must be valid and pointing to an open, writable file.
Postcondition
If the write is successful, the ID is appended to the trace file. If the write fails, the program exits with a status of -1 and __roseTraceFilePtr is set to NULL.
Note
The function relies on the global variables __roseTraceFilePtr and __roseTraceFile.
