Extracts a coefficient and updates a variable's bound based on a symbolic condition.

This function analyzes a symbolic condition relative to a pivot variable. It utilizes the UnwrapCond utility to determine the relationship between the condition and the pivot. Based on the resulting relation type (equality, less than, greater than, etc.), the function updates the provided pivotBound by intersecting it with a new symbolic bound derived from the condition's result.

Parameters
condThe symbolic condition to be unwrapped and evaluated against the pivot.
pivotThe symbolic variable acting as the pivot for the condition evaluation.
pivotBoundA reference to the symbolic bound of the pivot variable, which will be updated via intersection with the new constraints.
Returns
A SymbolicVal representing the coefficient extracted from the unwrapped condition. Returns 0 if the relation type is REL_NONE, or an empty SymbolicVal for unknown relation types.
Precondition
The pivotBound must be a valid, initialized SymbolicBound object.
Postcondition
The pivotBound is updated to the intersection of its previous state and the new constraint derived from the condition, provided the relation is not REL_NONE.
Note
The function relies on the behavior of UnwrapCond to produce a VarRestr object containing the relation type, the result, and the coefficient.
