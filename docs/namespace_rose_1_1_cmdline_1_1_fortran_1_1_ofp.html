ROSE_DLL_API std::string Rose::Cmdline::Fortran::Ofp::GetRoseClasspath ( )

Constructs the Java classpath string required for the Open Fortran Parser.

This function builds a formatted string representing the Java classpath, specifically configured for the Open Fortran Parser (OFP) environment. It identifies the locations of necessary JAR files, such as the ANTLR runtime and the OFP-specific JAR, by searching both the source tree and the build/lib directories. The resulting string is formatted with the "-Djava.class.path=" prefix and uses colons as path separators.

Returns
A string containing the complete Java classpath configuration, including the prefix and paths to all required library components.
Precondition
The ROSE_OFP_MAJOR_VERSION_NUMBER must be greater than or equal to 0, and ROSE_OFP_MINOR_VERSION_NUMBER must be greater than or equal to 8.
Postcondition
Returns a non-empty string starting with "-Djava.class.path=" and ending with a period representing the current directory.
Note
The function relies on findRoseSupportPathFromSource and findRoseSupportPathFromBuild to resolve relative paths to absolute or build-relative paths.
The implementation specifically includes antlr-3.5.2-complete.jar and the version-specific OpenFortranParser JAR.

std::vector< std::string > & argv )

Enables remote debugging for Fortran by configuring JVM options.

-rose:fortran:ofp:enable_remote_debugging Enable remote debugging of the Java Virtual Machine (JVM).

This function checks the command line arguments for the specific Fortran remote debugging option. If the option is detected, it attempts to append the necessary JDWP agent configuration to the global JVM options. The implementation relies on the CommandlineProcessing utility to identify the flag and modify the argv vector.

Parameters
projectA pointer to the SgProject instance being processed.
argvA vector of strings containing the command line arguments. This vector may be modified to remove the processed option.
Warning
If the option is present but the ifdef ROSE_BUILD_FORTRAN_LANGUAGE_SUPPORT macro is not defined, the function will print a fatal error and call ROSE_ABORT(), terminating the program.
Precondition
The argv vector should contain the command line arguments passed to the application.
Postcondition
If the remote debugging option is found and Fortran support is enabled, the JVM options vector will contain the JDWP socket transport configuration. The specific option string is removed from the argv vector.
Note
The function uses the prefix defined by Fortran::option_prefix to search for the "ofp:enable_remote_debugging" flag.

If the option is found, the associated parameter string is extracted, tokenized by spaces, and then applied to both the SgProject instance and the global Cmdline::Fortran::Ofp::jvm_options list. The option is removed from the argv vector during processing to prevent subsequent processing stages from encountering it.

Parameters

Precondition

ROSE_DLL_API void Rose::Cmdline::Fortran::Ofp::StripRoseOptions ( std::vector< std::string > & argv)

Removes ROSE-specific Fortran OFP command-line options from the argument vector.

This function scans the provided command-line argument vector for options prefixed with "-ofp:". It identifies these ROSE Fortran OFP options and removes them from the argv vector. The implementation utilizes CommandlineProcessing::generateOptionWithNameParameterList to identify and strip the relevant arguments. Additionally, the function iterates through the identified OFP options to log their removal if the global verbosity level is set higher than 1.

Parameters
argvA reference to a vector of strings representing the command-line arguments. This vector is modified in-place by removing the identified ROSE-specific options.
Precondition
The argv vector must be a valid, initialized vector of strings.
Postcondition
The argv vector will no longer contain any command-line arguments that were identified as ROSE Fortran OFP options (those starting with "-ofp:").
Note
If SgProject::get_verbose() is greater than 1, the function will print informational messages to standard output regarding the stripping process and the specific JVM options being removed.
