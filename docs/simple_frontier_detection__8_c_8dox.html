Performs frontier detection for mapping token streams to the AST.

This function identifies the "frontier" within an Abstract Syntax Tree (AST) to determine which parts of the code can be unparsed using a token stream versus which parts must be unparsed from the AST. It utilizes a traversal mechanism (SimpleFrontierDetectionForTokenStreamMapping) and an inherited attribute pattern to propagate information through the tree. The process is used before associating token subsequences to the AST.

Parameters
sourceFileA pointer to the SgSourceFile being processed. Must not be NULL.
traverseHeaderFilesA boolean flag indicating whether the traversal should extend to include header files. If true, the traversal covers the whole AST; if false, it is restricted to the contents of the source file.
Precondition
sourceFile must not be NULL.
Postcondition
The AST nodes within the scope of the traversal are updated with frontier detection information, potentially marking nodes as containing transformations.
Note
This function uses a TimingPerformance timer to track execution duration.
The implementation relies on include and define logic within the ROSE framework for attribute propagation.
