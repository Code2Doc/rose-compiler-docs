Determines if a specified dependency level is within the valid range of carry levels.

This function checks whether the provided level integer is less than or equal to the maximum carry level available in the given DepInfo object. It retrieves the count of carry levels by invoking the CarryLevels method on the DepInfo instance and compares the input level against the second value returned by that method.

Parameters
dA reference to a DepInfo object containing dependency information and carry level counts.
levelThe integer level to be validated against the available carry levels.
Returns
True if the specified level is less than or equal to the maximum carry level; false otherwise.
Precondition
The DepInfo object d must be a valid, initialized reference.
Postcondition
The state of the DepInfo object d remains unchanged.
Note
The function relies on the implementation of DepInfo::CarryLevels to populate the local variables num1 and num2.

Checks if a specific dependency type is present within the provided dependency information.

This function performs a bitwise AND operation between the dependency type retrieved from the DepInfo object and the provided selection mask. It determines if there is any overlap between the bits set in the info object's dependency type and the bits set in the selection criteria.

Parameters
infoA reference to a DepInfo object containing the dependency information to be checked.
selA reference to a DepType object representing the bitmask of dependency types to select for.
Returns
True if the intersection of the dependency type in info and the selection mask sel is non-zero; otherwise, false.
Precondition
The info and sel references must be valid and point to initialized objects.
Postcondition
The state of the input objects remains unchanged.
