bool debug_cfg ( )

Checks if the debug configuration option is enabled.

This function determines whether the "-debugcfg" command-line option is present within the global command options instance. It utilizes a static integer to cache the result of the check after the first invocation, ensuring that the expensive lookup in CmdOptions::GetInstance() is only performed once.

Returns
True if the "-debugcfg" option is detected in the command options; false otherwise.
Precondition
The CmdOptions singleton must be properly initialized before the first call to this function.
Postcondition
The internal state of the function (the static variable r) will be updated to reflect the result of the initial check.
Note
The function uses a static variable to implement a one-time initialization pattern for the debug flag status.
