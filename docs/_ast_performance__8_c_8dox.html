double time_stamp ( )

Retrieves the current system wall clock time as a double-precision floating-point value.

This function provides a portable method for computing the elapsed wall clock time. The implementation uses platform-specific APIs to ensure high precision:

  • On Windows (detected via ifdef _MSC_VER), it utilizes the QueryPerformanceCounter and QueryPerformanceFrequency functions to calculate time based on high-resolution performance ticks.
  • On POSIX-compliant systems, it utilizes the gettimeofday function to retrieve seconds and microseconds since the Epoch.
Returns
The current time represented as a double, where the value corresponds to seconds elapsed since the Unix epoch (on POSIX) or a high-resolution timer start (on Windows).
Precondition
None.
Postcondition
The returned value represents a monotonic-like snapshot of the current system time.
Note
The precision of the returned value depends on the underlying operating system's timer resolution.
