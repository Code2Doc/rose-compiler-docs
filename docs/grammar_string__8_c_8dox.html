Generates a C++ string representing the initialization of a list iterator.

This function constructs a formatted string that declares and initializes a constant iterator for a specific list type. The resulting string is formatted with leading indentation and a trailing newline, suitable for insertion into generated source code.

Parameters
typeNameThe name of the class or type containing the iterator (e.g., "std::list").
iteratorNameThe identifier to be used for the iterator variable.
listNameThe name of the list object being accessed.
accessOperatorThe operator used to access the beginning of the list (e.g., "->", ".", or "::").
Returns
A string containing the formatted C++ statement for iterator initialization.
Precondition
The input strings should not contain characters that would break C++ syntax in the resulting statement.
Postcondition
The returned string contains a single line of code starting with five spaces and ending with a newline character.
Note
The function specifically generates an initialization for a const_iterator.
