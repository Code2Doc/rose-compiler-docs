If the conversion succeeds, it uses std::find_if to locate the first unprintable wide character. In the event that a std::range_error occurs during conversion (e.g., due to invalid UTF-8 sequences), the function falls back to a byte-based approach using std::codecvt_utf8::length to determine the length of the valid portion of the input.

Postcondition

Note

Validates the structural integrity of quotes and escape sequences within a string.

This function checks whether a given string has balanced and properly escaped quotation marks. It specifically handles double quotes (") escaped by a backslash () and single quotes (') escaped by a duplicate single quote ('). The function iterates through the string, identifying the initial quote type and searching for its corresponding closing pair. During the process, it validates that any interior quotes are preceded or followed by the appropriate escape character.

Parameters
inputA reference to a string to be validated. Note that this function modifies the input string by erasing escape characters during the validation process.
Returns
True if the string is empty, does not contain quotes, or contains properly balanced and escaped quotes. False if quotes are unbalanced or if escape sequences are malformed.
Precondition
The input string should be a valid std::string object.
Postcondition
The input string may be modified; escape characters used for validation (such as the backslash for double quotes or the redundant single quote for single quotes) are removed from the string.
Note
The function treats the first character as the primary quote token if it is a double quote or a single quote. If the first character is neither, the string is considered valid by default.

There is an interior quote, which is OK as long as it is escaped properly:

  • " is escaped by \, e.g. "foo " bar";
  • ' is escaped by ', e.g. 'foo '' bar'.

Notice that the escape character for single quotes is also a single quote. As a result find_first_of will find the escape character for escaped single quotes.
