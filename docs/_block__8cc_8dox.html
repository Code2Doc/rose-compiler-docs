Appends a new assignment statement to a specified basic block.

This function attempts to create a new assignment expression statement using the provided initialized name and scope, and then appends this statement to the end of the target basic block. The process relies on the success of the underlying createAssignment function.

Parameters
nameA pointer to the SgInitializedName representing the left-hand side of the assignment.
scopeA pointer to the SgScopeStatement defining the scope in which the assignment occurs.
targetA pointer to the SgBasicBlock where the newly created assignment statement will be appended.
Returns
True if the assignment statement was successfully created and appended to the target block; false if the target block is null, the assignment creation failed, or no assignment was needed.
Precondition
target should be a valid, non-null pointer to an SgBasicBlock if an assignment is to be appended.
Postcondition
If the function returns true, the target basic block will contain one additional statement at its end, specifically an SgExprStatement representing the assignment.
Note
This function performs a null check on the target parameter before attempting any operations.

Creates an assignment expression statement from an initialized name and a scope.

This function constructs a new SgExprStatement representing an assignment operation. It extracts the initializer from the provided SgInitializedName to serve as the right-hand side (RHS) of the assignment and uses the provided scope to resolve the variable symbol for the left-hand side (LHS). The function performs several validation checks, including verifying the existence of an initializer, ensuring the target type is not a reference, and checking that the RHS type is compatible for a simple assignment (e.g., not a class type or a complex modifier type).

Parameters
nameA pointer to the SgInitializedName containing the variable definition and its initial value to be used as the RHS.
scopeA pointer to the SGGscopeStatement in which the variable symbol must be looked up to create the LHS variable reference.
Returns
A pointer to the newly created SgExprStatement representing the assignment. Returns 0 (nullptr) if the name is null, if there is no valid initializer, if the name's type is a reference, if the RHS type is a class type, or if the RHS type is a complex modifier type.
Precondition
name must not be null and must contain a valid SgAssignInitializer.
scope must not be null and must contain a variable symbol matching the name provided in the name parameter.
Postcondition
If a non-null SgExprStatement is returned, it contains a valid SgAssignOp with a deep-copied operand from the original initializer.
Note
The function uses ROSE_ASSERT to validate the internal state of the AST construction process, such as the successful lookup of the variable symbol and the successful creation of the assignment operator.
