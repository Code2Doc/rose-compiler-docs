SgExpression * GetFirstOperand ( SgExpression * expr)

Retrieves the primary or first operand from a given expression.

This function inspects the type of the provided expression and attempts to extract the most fundamental operand based on the expression's structure. The logic follows a hierarchical check:

  1. If the expression is a function call, it returns the function itself.
  2. If the expression is a unary operation, it returns the operand of that operation.
  3. If the expression is a binary operation, it returns the left-hand side (LHS) operand.
  4. If the expression does not match any of these types, it returns NULL.
Parameters
exprA pointer to the SgExpression to be analyzed.
Returns
A pointer to the first operand SgExpression, or NULL if the expression is not a function call, unary operation, or binary operation, or if no operand can be extracted.
Precondition
expr should be a valid pointer to an SgExpression object.
Postcondition
The returned pointer points to an existing SgExpression or is NULL.
Note
This function relies on type-checking functions such as isSgFunctionCallExp, isSgUnaryOp, and isSgBinaryOp to determine the expression type.

int GetOperatorVariant ( SgExpression * expr)

Identifies the underlying operator variant for a given expression.

This function analyzes an SgExpression to determine if it represents a specific operator call (such as assignment, arithmetic, or logical operators) or a standard function call. It specifically inspects function call expressions to see if the function being called is an overloaded operator (e.g., "operator+").

The implementation performs the following steps:

  1. Checks if the expression is a function call. If not, it returns the expression's intrinsic variant type.
  2. If it is a function call, it examines the function being called.
  3. For function references, dot expressions, or arrow expressions, it extracts the function name.
  4. It handles various reference types including SgMemberFunctionRefExp, SgTemplateMemberFunctionRefExp, and SgNonrealRefExp.
  5. It maps the extracted string name (e.g., "operator=") to the corresponding SgVariantType (e.g., V_SgAssignOp).
  6. If the name contains "operator" but does not match a specific known operator, it is treated as a cast expression.
Parameters
exprA pointer to the SgExpression to be analyzed.
Returns
An integer representing the variant type (V_SgVariantType) of the operator or expression. Returns -1 if an error occurs in the default case.
Precondition
expr must not be NULL.
Postcondition
The returned value corresponds to a valid SgVariantType representing the semantic nature of the expression.
Note
