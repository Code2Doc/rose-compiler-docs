Parses command-line arguments to configure application settings and extract the primary input argument.

Parses command-line arguments to configure the disassembler settings.

This function initializes and executes a command-line parser using the Sawyer::CommandLine framework. It defines two distinct switch groups: a "standard" group containing universal switches like help and version, and a "tool" group containing command-specific switches such as ISA specification, virtual address mapping, and instruction alignment. The function populates the provided Settings object based on the arguments passed via argc and argv.

Parameters
argcThe number of command-line arguments passed to the program.
argvAn array of C-style strings representing the command-line arguments.
settingsA reference to a Settings object that will be updated with the parsed values (e.g., ISA name, start virtual address, and alignment).
Returns
A ParserResult object containing the result of the parsing operation, which can be used to determine if the parsing was successful or if an action (like exiting for help) was triggered.
Precondition
The settings object must be properly initialized before being passed to this function.
Postcondition
The settings object is modified in-place with values parsed from the command line.
Note
The parser uses specific sub-parsers such as anyParser and nonNegativeIntegerParser to validate the types of arguments provided for the ISA and virtual address.

This function utilizes the Sawyer::CommandLine::Parser to process command-line arguments. It sets up a parser with a specific synopsis, includes generic switches, and defines a tool-specific switch group. The switch group includes a 'config' option to specify an alternative configuration file and a 'check-version' option to validate the ROSE library version. After parsing, the function validates the version requirement against the current build version (determined via define ROSE_PACKAGE_VERSION, define VERSION, or a fallback) and ensures that exactly one unreached argument (the primary input) is provided.
