LoopTreeNode * ApproachAncesLoop ( LoopTreeNode * start,
RoseSelectObject< LoopTreeNode * > & sel )

Traverses up the loop tree hierarchy to find an ancestor loop based on a selection criteria.

This function iterates upwards from a starting loop node through its ancestors. For each ancestor, it checks if the ancestor satisfies a selection predicate provided by the sel object. If the loop level increases during the traversal, the function attempts to restructure the loop tree by swapping node positions using LoopTreeSwapNodePos to maintain tree integrity relative to the starting node. The traversal continues as long as the ancestor exists and has exactly one child.

Parameters
startA pointer to the starting LoopTreeNode from which the upward traversal begins.
selA RoseSelectObject used to evaluate whether a specific ancestor loop meets the required selection criteria.
Returns
A pointer to the first ancestor LoopTreeNode that satisfies the selection predicate sel. Returns 0 (nullptr) if no such ancestor is found or if the traversal reaches the root.
Precondition
The start pointer must be a valid, non-null pointer to a LoopTreeNode.
Postcondition
If an ancestor is found and returned, the loop tree structure may have been modified via node swapping if IncreaseLoopLevel was triggered.
Note
The function relies on the Parent, ChildCount, IncreaseLoopLevel, and LoopTreeSwapNodePos methods of the LoopTreeNode class.

LoopTreeNode * FindSibling ( LoopTreeNode *& t,
int opt )

Navigates up the tree to find a sibling node based on the provided option.

This function traverses upwards through the parent nodes of the provided node t as long as each parent has exactly one child. This process effectively climbs up a chain of single-child nodes. Once the traversal reaches a node that either has no parent or has more than one child, the function selects a sibling of the current node t based on the opt parameter.

Parameters
tA reference to a pointer to a LoopTreeNode. This pointer is updated during the traversal to point to the last single-child parent encountered.
optAn integer flag used to determine the direction of the sibling search. If opt is less than 0, the function returns the previous sibling. Otherwise, it returns the next sibling.
Returns
A pointer to the identified sibling node (either the previous or next sibling of the node reached after traversal).
Precondition
The pointer t must not be null.
Postcondition
The pointer t is updated to the last node in the single-child chain encountered during the upward traversal.
Note
The function relies on the Parent(), ChildCount(), PrevSibling(), and NextSibling() methods of the LoopTreeNode class.
