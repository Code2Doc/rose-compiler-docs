template<class Iter>
unsigned CountIteratorSize ( Iter iter)

Calculates the number of elements reachable by an iterator.

This function iterates through a range starting from the provided iterator until the end of the range is reached, incrementing a counter for each step. It effectively computes the distance between the input iterator and the end of the sequence defined by the iterator's ReachEnd() method.

Parameters
iterAn iterator object used to traverse the collection. The iterator must implement a ReachEnd() method that returns a boolean value and must support the prefix increment operator.
Returns
The total number of elements traversed from the initial position to the end of the range.
Precondition
The iterator iter must be valid and its ReachEnd() method must correctly identify the boundary of the collection.
Postcondition
The returned value represents the count of elements from the original iterator position to the end.
Note
The complexity of this function is O(n), where n is the number of elements in the range.

Searches for the first element in an iterator range that satisfies a given predicate.

This function iterates through a collection using the provided iterator object, checking each element against a predicate function or functor. The iteration continues until the iterator reaches its end condition or an element satisfies the predicate. The algorithm uses a linear search approach, visiting each element exactly once.

Parameters
iterA reference to an iterator object. The iterator must implement the methods ReachEnd() to check for the end of the range, Current() to access the current element, and the prefix increment operator (++) to advance the position.
TA predicate (function, functor, or lambda) that accepts the type returned by iter.Current() and returns a boolean value.
Returns
True if an element is found that satisfies the predicate T; false otherwise.
Precondition
The iterator iter must be in a valid state and capable of being incremented and queried via ReachEnd() and Current().
Postcondition
If a match is found, iter will point to the element that satisfied the predicate. If no match is found, iter will be at the end of the range (where ReachEnd() returns true).
Note
The state of the input iterator iter is modified during the execution of this function.

Converts the elements of an iterator range into a single concatenated string.

This function iterates through a range defined by the provided iterator, starting from the initial position until the end of the range is reached. For each element pointed to by the iterator, it calls the toString() member function and appends the resulting string to a cumulative result string.

Parameters
iterAn iterator representing the starting point of the range to be converted. The iterator must support the increment operator, the dereference operator, and a ReachEnd() member function.
Returns
A std::string containing the concatenated string representations of all elements in the range.
Precondition
The iterator iter must be valid and the range must be traversable using the ReachEnd() method and the increment operator.
Postcondition
Returns a string containing the concatenated results of toString() calls for all elements in the range.
Note
The efficiency of this function depends on the complexity of the toString() implementation and the overhead of string concatenation within the loop.

Converts the elements of an iterator range into a single concatenated string.

This function iterates through a range of elements starting from the provided iterator until the end of the range is reached. For each element pointed to by the iterator, it calls the toString() method and appends the resulting string to a cumulative result string. The function assumes that the elements pointed to by the iterator are pointers or objects that support the ->toString() syntax.

Parameters
iterAn iterator representing the start of the range to be processed. The iterator must support incrementing, dereferencing, and a ReachEnd() method.
Returns
A string containing the concatenated string representations of all elements in the range.
Precondition
The iterator iter must be valid and the elements it points to must implement a toString() method that returns a std::string or a type convertible to std::string.
Postcondition
The returned string contains the full sequence of strings produced by the elements in the range, in the order they were traversed.
Note
The complexity of this function is proportional to the number of elements in the range and the length of the strings being concatenated.

template<class Iter, class Update>
void UpdateEach ( Iter iter,
Update T )

Iterates through a collection and applies an update function to each element.

This function traverses a range defined by an iterator-like object iter until the end of the range is reached. For every element encountered, it invokes the provided callable object T (the update function) passing the current element retrieved via iter.Current(). This is a generic utility for performing element-wise operations on custom iterator types.

Parameters
iterAn iterator-like object that supports ReachEnd() to check for the end of the range and operator++ for traversal, and Current() to access the current element.
TA callable object (function pointer, functor, or lambda) that accepts the type returned by iter.Current() as its argument.
Precondition
The iterator iter must be in a valid state and the range must be traversable using the provided increment operator.
Postcondition
All elements in the range defined by iter will have been processed by the update function T.
Note
The complexity of this function is O(n), where n is the number of elements in the range.
