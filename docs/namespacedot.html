T dot::conv ( const E & el)

Converts an element of type E to type T using stringstream.

This function performs a type conversion by first streaming the input element into a std::stringstream and then extracting the value into a variable of type T. This approach relies on the existence of overloaded operator<< for type E and operator>> for type T.

Parameters
elThe input element of type E to be converted.
Returns
The converted value of type T.
Precondition
The type E must support the stream insertion operator (<<) and the type T must support the stream extraction operator (>>).
Postcondition
The returned value represents the parsed representation of the input element as a string.
Note
This method is generally slower than direct casting or specialized conversion functions due to the overhead of stringstream buffering and parsing.

This function writes the initial line of a Graphviz DOT file to the provided output stream. It specifically formats the string to start a directed graph (digraph) using the provided identifier. This is typically the first step in generating a DOT representation of a program's control flow or structure.

Parameters

Formats and writes a directed edge definition to an output stream.

This function constructs a string representation of a directed edge in a graph-like syntax, specifically using the memory addresses of the source and target pointers as node identifiers. The output follows a pattern where nodes are prefixed with 'p' followed by their size_t representation. The edge includes a tail label and additional attributes.

Parameters
osThe output stream where the formatted edge string will be written.
srcA pointer to the source node; its memory address is used as the node ID.
tgtA pointer to the target node; its memory address is used as the node ID.
lblA string representing the label to be assigned to the edge's tail.
attrA string containing additional attributes to be appended to the edge definition.
Precondition
The output stream os must be in a valid, writable state.
Postcondition
The edge definition is appended to the stream os followed by a newline.
Note
The function casts the src and tgt pointers to size_t to generate unique identifiers based on their memory addresses.

bool dot::freshlyDiscovered ( std::set< const T * > & aset,
const T * elem )

Checks if an element has been previously encountered and marks it as discovered.

This function performs a membership test within a set of pointers. If the provided element is not present in the set, it is inserted into the set, effectively marking it as "discovered." This is typically used in graph traversal algorithms or during the processing of unique elements to prevent redundant operations.

Parameters
asetA reference to a std::set containing pointers to constant objects of type T. This set is updated in-place if the element is new.
elemA pointer to a constant object of type T to be checked and potentially inserted.
Returns
True if the element was not found in the set (and has now been inserted); false if the element was already present in the set.
Precondition
The set aset must be a valid, initialized std::set.
Postcondition
If the function returns true, elem is guaranteed to be present in aset. If the function returns false, the state of aset remains unchanged regarding elem.
Note
This function is useful for implementing a "visited" set in algorithms like Depth-First Search (DFS) or Breadleth-First Search (BFS).

std::string dot::short_name ( SgNode & n)

Extracts a shortened class name from an SgNode's type information.

This function retrieves the mangled type name of the provided SgNode using typeid and attempts to strip the "Sg" prefix. It searches for the first occurrence of the characters 'S' or 'g' in the type string and returns the substring starting after the "Sg" sequence.

Parameters
nThe SgNode object whose type name is to be processed.
Returns
A string containing the truncated type name, starting after the "Sg" prefix.
Precondition
The type information of the provided SgNode must contain the substring "Sg".
Postcondition
The returned string is a substring of the typeid(n).name() result.
Warning
This function relies on the presence of "Sg" in the type name. If the prefix is not found, the ROSE_ASSERT macro will trigger a failure. The behavior is dependent on the compiler's implementation of typeid(n).name().
