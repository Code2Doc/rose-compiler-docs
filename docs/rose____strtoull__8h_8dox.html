Converts a string to an unsigned 64-bit integer with extended support for binary literals.

This function provides an enhanced version of the standard strtoull. It specifically handles a special case when the base is set to 0: it checks for a Perl-style binary prefix "0b" (e.g., "0b101"). If this prefix is detected, the function parses the subsequent digits as a base-2 integer. It also handles optional leading whitespace and an optional sign ('+' or '-'). For all other bases, it delegates the conversion to the standard strtoull implementation.

Parameters
nptrA pointer to the null-terminated string to be converted.
endptrA pointer to a pointer to a char; if not NULL, this will point to the first character not converted.
baseThe numerical base to be used for the conversion. If 0, the function attempts to detect binary "0b" prefixes or falls back to standard base detection.
Returns
The converted unsigned 64-bit integer value. Returns 0 and sets errno to EINVAL if nptr is NULL.
Precondition
nptr should be a valid, null-terminated string if conversion is to be attempted.
Postcondition
If nptr is NULL, errno is set to EINVAL and endptr (if not NULL) is set to NULL.
Note
This function introduces a non-standard behavior for base 0 to allow parsing of "0b" prefixed strings, which is useful for compatibility with certain regular expression patterns.
Warning
If the input string represents a negative value in the "0b" format, the result is cast back to an unsigned 64-bit integer, which may result in a very large value due to two's complement representation.
