Attach metrics from a ProfIR tree to a Sage IR tree.

Attaches profiling metrics from an IR tree to a Sage AST project.

This function performs a multi-stage process to map performance metrics from a RoseHPCT IR tree onto the corresponding nodes in a Sage AST (SgProject). The implementation utilizes a MetricAttachTraversal to traverse the AST and identify matches between IR nodes and AST nodes. After the initial attachment, the function performs metric normalization to ensure that metrics shared across multiple AST nodes are distributed correctly. Finally, it uses a MetricFixupTraversal to finalize the metric attributes across the project.

Parameters
hpc_rootA pointer to the root of the RoseHPCT IR tree containing the profiling data to be attached.
sage_rootA pointer to the root of the Sage AST project where the metrics will be attached.
verboseA boolean flag that enables or disables detailed logging during the attachment and normalization processes.
Returns
void
Precondition
hpc_root must be a valid, non-null pointer to a populated IRTree_t.
sage_root must be a valid, non-null pointer to a traversable SgProject.
Postcondition
The AST nodes in sage_root will have updated metric attributes based on the data found in hpc_root.
If enable_debug is true, source code annotations will be added to the AST nodes.
Warning
The function modifies the state of the nodes within the sage_root AST by attaching and updating metric attributes.
Note
The normalization step is crucial for cases where a single profile IR node corresponds to multiple AST nodes, preventing the over-counting of metrics.

EquivPathMap_t RoseHPCT::getEquivPaths ( std::vector< std::string > & argvList)

Extract equivalent paths from a set of command-line options.

Parses command-line arguments to establish a mapping of equivalent paths.

This function extracts path equivalence definitions from a provided list of command-line arguments using the OPTION_HPCTEQPATH option. It iterates through the extracted raw strings and parses them based on an '=' delimiter. If a string contains an '=', the substring before the '=' is mapped to the substring after the '='. If no '=' is present, the entire string is mapped to a default period ('.') character. The resulting mappings are stored in an EquivPathMap_t (a map-like structure).

Parameters
argvListA reference to a vector of strings containing the command-line arguments to be parsed.
Returns
An EquivPathMap_t object containing the parsed key-value pairs representing the established path equivalences.
Precondition
The argvList must be properly initialized. The function assumes that the getRoseOptionValues function is available and correctly handles the OPTION_HPCTEQPATH flag.
Postcondition
Returns a populated map where each key represents a source path and each value represents its equivalent destination path.
Warning
The function prints parsing progress and mapping details directly to std::cerr.
Note
The parsing logic treats the absence of an '=' character as a mapping to the current directory ('.').

This routine extracts command-line flags of the form:

-rose:hpct:eqpath <source>=<dest>

and returns a map containing all (source, dest) key-value pairs.

See also
RoseHPCT::getProfileOptions, RoseHPCT::loadProfilingFiles

ProgramTreeList_t RoseHPCT::loadGprofVec ( const std::vector< gprof_info > & vec)

Constructs an Intermediate Representation (IR) tree from gprof profiling information.

This function iterates through a vector of gprof_info objects to build a hierarchical tree structure representing the program's execution profile. It parses the input data to create and organize nodes representing the Program, Files, Procedures, and Statements. The function maps the flat profiling data into a nested tree where metrics such as wall-clock time (self-seconds) and execution percentage are attached to the corresponding statement-level nodes.

Parameters
vecA constant reference to a vector of gprof_info objects containing profiling data, including file names, function names, line numbers, call counts, and timing metrics.
Returns
A ProgramTreeList_t containing a list of root nodes (typically a single Program node) that represent the reconstructed program hierarchy.
Warning
This function uses static variables (prog_root, file_node_map, and func_node_map) to persist the tree structure and mappings across multiple calls. This means subsequent calls to this function will append to or modify the existing global tree rather than starting from scratch.
Precondition
The input vector vec should contain valid gprof_info objects. The memory for the resulting IR nodes is managed by the tree structure and must be handled according to the lifetime rules of the IRTree_t.
Postcondition
A ProgramTreeList_t is returned containing the root of the constructed IR tree. The internal static maps and the program root are updated to include the new information from the provided vector.
Note
The function assumes that for statement-level information, the start and end line numbers are identical.
The function handles the conversion of gprof percentage values from integer-based percentages to decimal fractions (divided by 100.0).
The function uses ROSE_ASSERT to validate critical memory allocations and structural integrity.

This function is responsible for updating the IR tree nodes with profile-related metrics, such as execution counts or timing information, by mapping equivalence paths to the tree structure. It utilizes a PathTranslator to traverse the IR tree and apply transformations. If the profiling mode is not restricted to gprof-only, the function also calculates execution percentages (e.g., wallclock time percentage) for each node, provided that a non-zero total wallclock time has been accumulated.

Parameters
rootA pointer to the root of the IRTree_t structure that requires post-processing.
eqpathsA map containing the equivalence paths used to translate profile data into the IR tree structure.
Returns
True if the IR tree was modified during the translation or percentage calculation process; false otherwise.
Precondition
The root pointer must be a valid pointer to an IRTree_t structure (though the internal traversal handles null checks). The eqpaths map must be properly initialized.
Postcondition
The IR tree nodes may contain updated profile metrics and calculated percentages. The state of the tree is modified if changes were applicable.
Warning
If gprof_only is set to true, the percentage calculation phase is skipped, as gprof is assumed to provide the necessary information.
Note
The function relies on global or static state within PathTranslator (such as wallclk_sum) to perform percentage calculations.
Debug output for accumulated wallclock time is only printed if enable_debug is true.

reading gprof information into generic Container

Reads profiling information from a gprof file and populates a container.

This function reads a file line by line and populates the Container c with the gprof information found. Consider resizing the Container to an appropriate size, for performance reasons.

Parameters
gprof_filePath to gprof output file
cContainer to hold the data (must provide a push_back( const gprof_info& info ) member function )

This function opens a specified gprof output file and iterates through it line by line. For each line, it attempts to instantiate a temporary gprof_info object. If the construction of the gprof_info object is successful, the object is appended to the provided container. The function uses a try-catch block to silently ignore lines that fail to parse, ensuring that the process continues even if some lines in the file are malformed.

Parameters
gprof_fileA pointer to a null-terminated character string representing the path to the gprof file to be read.
cA reference to a container (e.g., std::vector, std::list) that supports the push_back method, where the parsed gprof_info objects will be stored.
Precondition
The gprof_file must point to a valid, readable file path.
Postcondition
The container c will contain all successfully parsed gprof_info objects from the file.
Note
The function suppresses all exceptions during the parsing of individual lines to ensure robustness against malformed input.

Convert an SgLocatedNode to a string (for debugging display).

Converts a located node into a string representation of its file location and class name.

This function extracts the source file information and the associated class name from a given SgLocatedNode. It retrieves the start and end file information to determine the filename and the line number range (from the start of the construct to the end of the construct). The resulting string combines the formatted file location (via the ::toFileLoc utility) with the class name enclosed in parentheses.

Parameters
nodeA pointer to the SgLocatedNode containing the source location and class metadata. Can be NULL.
Returns
A string containing the formatted file location and the class name, e.g., "filename:line_start-line_end (class_name)". Returns an empty string if the input node is NULL.
Precondition
node may be NULL.
Postcondition
Returns a non-empty string if node is valid, or an empty string if node is NULL.
Note
This function relies on the existence of helper functions getFilename, getLineNumber, and the global ::toFileLoc function.

Translates metric names within an IRTree based on a provided mapping.

This function performs a transformation on the provided IRTree by replacing existing metric names with their mapped counterparts as defined in the mets dictionary. It utilizes a MetricTranslator object to traverse the tree structure and apply the translation logic to each relevant node.

Parameters
rootA pointer to the root of the IRTree to be processed.
metsA map containing the original metric names as keys and the translated metric names as values.
Returns
True if any metric names were found and successfully translated; false otherwise.
Precondition
The root pointer must be valid and point to a properly initialized IRTree_t object.
Postcondition
The root tree may be modified in-place if matches were found in the mets map.
Note
The translation process is implemented via a visitor-style traversal pattern within the MetricTranslator class.
