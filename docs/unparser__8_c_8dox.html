Maps the first and last statements associated with each SgIncludeFile.

This function iterates through all source files within a given SgProject to identify and record the first and last statements belonging to each SgIncludeFile and the primary source files. This mapping is essential for supporting token-based unparsing, as it allows the unparser to determine when the end of an include file has been reached, ensuring that trailing whitespace tokens and scope-closing tokens are output correctly.

The implementation utilizes an internal class, IncludeFileStatementTraversal, which extends AstSimpleProcessing. The traversal visits nodes in the AST, checks for SgStatement nodes, and verifies if they correspond to a valid token subsequence in the source file's token map. It specifically handles the identification of statements within the same scope to ensure that the boundaries of include files are accurately captured. The function also handles the logic for both header files (via the EDG include file map) and the main input source files.

Parameters
projectA pointer to the SgProject containing the list of files to be processed.
Precondition
The project pointer must not be null and must contain a valid list of files.
Postcondition
The first and last statements for each SgIncludeFile and SgSourceFile in the project are updated within their respective objects, provided they correspond to valid token subsequences.
