Computes the differences between two sequences of SgNode pointers.

This function identifies the differences between two input vectors of SgNode pointers, A and B, by first computing the Longest Common Subsequence (LCS) length matrix and then backtracking through that matrix to extract the specific differences. The differences are stored as pairs of SgNode pointers in the provided result vector.

Parameters
AThe first input sequence of SgNode pointers.
BThe second input sequence of SgNode pointers.
resultA reference to a vector of pairs where the identified differences (mapping nodes from A to B) will be stored. This vector is cleared at the start of the function.
Precondition
The input vectors A and B should be valid and contain initialized SgNode pointers.
Postcondition
The result vector will contain the computed differences, and any previous contents of the result vector will be removed.
Note
This function relies on the LCSLength implementation to populate the scoring matrix C used for the backtracking step.

Checks if two SgNode objects represent the same instruction or function.

This function performs a structural equality check between two nodes in the SgNode hierarchy. It specifically attempts to identify if both nodes are x86 assembly instructions or both nodes are assembly functions. For instructions, equality is determined by comparing their unparsed string representations. For functions, equality is determined by comparing their names.

Parameters
AThe first SgNode to compare.
BThe second SgNode to compare.
Returns
True if both nodes are instructions with identical unparsed strings, or both nodes are functions with identical names. Returns false if either node is NULL, if the nodes are of mismatched types, or if their contents do not match.
Precondition
The pointers A and B should ideally point to valid SgNode objects, though the function handles NULL pointers gracefully.
Postcondition
The return value indicates the equality of the underlying assembly entities represented by the nodes.
Note
This function relies on the unparsing mechanism for instructions. The accuracy of the comparison depends on the consistency of unparseInstrFast output.

Computes and identifies the differences between two sequences of SgNode pointers.

This function serves as a high-level wrapper for the difference-printing logic. It first initializes a 2D structure to store the Longest Common Subsequence (LCS) length matrix by calling LCSLength. Once the matrix C is populated, it invokes an overloaded version of printDiff that performs the actual traversal of the matrix to identify which elements from sequence A are missing in B (minus instructions) and which elements from B are new in A (add instructions).

Parameters
AA vector of SgNode pointers representing the first sequence, indexed starting from one.
BA vector of SgNode pointers representing the second sequence, indexed starting from one.
addInstrA vector of integers used to store the indices of instructions added in sequence B relative to A.
minusInstA vector of integers used to store the indices of instructions removed from sequence A relative to B.
Precondition
The input vectors A and B must be valid and initialized.
Postcondition
The vectors addInstr and minusInst will be populated with the indices representing the differences between A and B.

◆ unparseInstrFast()

std::string LCS::unparseInstrFast ( SgAsmInstruction * iA)

Generates a simplified string representation of an assembly instruction.

This function provides a high-performance unparsing mechanism for assembly instructions. Instead of a full string reconstruction, it produces a condensed format consisting of the instruction mnemonic followed by abbreviated operand type identifiers. The implementation iterates through the instruction's operand list and appends a single character prefix to denote the type of each operand: 'R' for register references, 'M' for memory references, and 'V' for all other types (e.g., immediate values).

Parameters
iAA pointer to the SgAsmInstruction object to be unparsed.
Returns
A string containing the instruction mnemonic and the sequence of operand type identifiers.
Precondition
iA must not be a null pointer.
Postcondition
The returned string contains the mnemonic and a space-separated or concatenated sequence of operand type indicators.
Note
This function is optimized for speed and does not provide the full, human-readable assembly syntax, but rather a structural summary of the instruction.
