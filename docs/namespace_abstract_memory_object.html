Detailed Description

Auto-generated documentation for the AbstractMemoryObject namespace.

An interface to represent all memory locations as a set of abstract objects. Greg Bronevetsky drafted the original design document, with some help from me.

It is part of the work to support the Compiled MPI project

Goal: We only define interfaces and abstract implementation. Any particular instantiation should provide more details.

Liao 7/20/2011

ObjSet * AbstractMemoryObject::createAliasedObjSet ( SgType * t)

Creates or retrieves an ObjSet for type-based alias analysis.

This function implements a factory pattern to manage ObjSet instances based on the provided SgType. It utilizes a global or class-level map, aliased_objset_map, to ensure that only one ObjSet is created per unique SgType. The function determines the specific subclass of ObjSet to instantiate by inspecting the properties of the input type, such as whether it is a scalar, pointer, array, class, or function type.

Parameters
tA pointer to the SgType for which the ObjSet is being requested. This type determines the specific implementation of the ObjSet returned.
Returns
A pointer to an ObjSet instance associated with the provided type. Returns NULL if the type is not recognized or if the creation of the specific ObjSet subclass fails.
Precondition
t must not be NULL.
Postcondition
If a new ObjSet is created, it is stored in the aliased_objset_map associated with the input type t.
Note
The function handles several specific type categories:
  • Scalar types (via isScalarType): returns a ScalarAliasedObj.
  • Pointer types (via isSgPointerType): returns a PointerAliasedObj.
  • Array types (via isSgArrayType): returns an ArrayAliasedObj.
  • Class types (via isSgClassType): returns a LabeledAggregateAliasedObj.
  • Function types (via isSgFunctionType): returns a FunctionAliasedObj.
Warning
If an unhandled SgType is encountered, a warning is printed to stderr and the function may return NULL.

ObjSet * AbstractMemoryObject::createExpressionObjSet ( SgExpression * anchor_exp,
SgType * t )

Creates or retrieves an expression object set associated with a specific expression and type.

This function serves as a factory and cache manager for expression-based objects. It checks if an expression object already exists in the expr_objset_map for the given anchor_exp. If no mapping exists, it instantiates a new object of a specific subclass (e.g., ScalarExprObj, FunctionExprObj, PointerExprObj, LabeledAggregateExprObj, or ArrayExprObj) based on the properties of the provided SgType. The function ensures that the anchor_exp is not a variable reference (SgVarRefExp), as variable references are expected to be associated with named objects rather than expression objects.

Parameters
anchor_expThe base SgExpression that serves as the anchor for the new or existing object.
tThe SgType associated with the anchor expression.
Returns
A pointer to the newly created or existing ObjSet object. Returns NULL if the type is unhandled or if the creation fails.
Precondition
anchor_exp must not be NULL.
t must not be NULL.
The type of anchor_exp must be equal to t.
anchor_exp must not be an instance of SgVarRefExp.
Postcondition
If a new object is successfully created, it is stored in the expr_objset_map using anchor_exp as the key.
Warning
If anchor_exp is a SgVarRefExp, the function will print an error to cerr and call ROSE_ABORT().
If the provided type t does not fall into any of the handled categories (Scalar, Function, Pointer, Class, or Array), a warning is printed to cerr and the function may return NULL.
Note
The function uses SageInterface::isScalarType to identify scalar types, which includes char, short, int, long, void, Wchar, Float, double, long long, string, bool, complex, and imaginary.

ObjSet * AbstractMemoryObject::createNamedObjSet ( SgPntrArrRefExp * r)

Creates or retrieves an ObjSet representing a specific array or pointer reference.

This function is responsible for identifying the underlying memory object (ObjSet) associated with a pointer or array reference expression. It determines if the expression is a top-level reference or a nested subscript. If it is a top-level reference, the function attempts to resolve the array name to a variable symbol, constructs an index vector from the subscripts, and checks a global map (named_objset_map) to see if the ObjSet has already been created. If not, it invokes a creation mechanism to instantiate the ObjSet and caches it.

Parameters
rA pointer to an SgPntrArrRefExp representing the array or pointer reference expression to be processed.
Returns
A pointer to the created or existing ObjSet associated with the expression. Returns NULL if the array name cannot be resolved to a single variable or if the array is part of another aggregate object.
Precondition
r must not be NULL.
Postcondition
If a valid array reference is processed, the resulting ObjSet is stored in the named_objset_map for future retrieval.
Note
This function currently only handles canonical array references (e.g., a[1]) and does not support complex pointer arithmetic references (e.g., (p+10)[1]).
Warning
If the array name is not a single variable, a warning is printed to cerr. If the array is part of another aggregate object, a warning is also printed to cerr.

ObjSet * AbstractMemoryObject::createNamedObjSet ( SgSymbol * anchor_symbol,
SgType * t,
ObjSet * parent,
IndexVector * iv )

Creates or retrieves a named object set associated with a specific symbol and index vector.

This function manages the creation and caching of specialized ObjSet objects (such as ScalarNamedObj, FunctionNamedObj, PointerNamedObj, etc.) based on the type of the provided symbol. It uses a multi-level map named_objset_map to ensure that if an object set with the same parent, anchor symbol, and index vector already exists, it is reused rather than recreated. The function performs type-based dispatching to instantiate the appropriate subclass of ObjSet.

Parameters
anchor_symbolThe symbol that serves as the anchor for the object set. Must be either a variable symbol or a function symbol.
tThe SgType representing the type of the object set being created.
parentThe parent ObjSet in the hierarchy.
ivA pointer to an IndexVector representing the indices used to access the object set.
Returns
A pointer to the newly created or existing ObjSet. Returns NULL if the anchor_symbol is neither a variable nor a function symbol, or if the type 't' is not explicitly handled by the implementation.
Precondition
anchor_symbol must not be NULL.
If the anchor_symbol's type is neither an array type nor a pointer type, then the type of the anchor_symbol must be equal to the provided type 't'.
Postcondition
If a new ObjSet is created, it is stored in the named_objset_map for future retrieval.
Note
There is a known issue/TODO where the IndexVector is not yet uniquely generated, which may lead to incorrect object retrieval.
Warning
If the anchor_symbol is not a variable or function symbol, a warning is printed to stderr and the function returns NULL.
If the provided type 't' does not match any of the handled categories (Scalar, Function, Pointer, Class, or Array), a warning is printed to stderr.

ObjSet * AbstractMemoryObject::createNamedOrAliasedObjSet ( SgVarRefExp * r)

Creates a NamedObjSet or an aliased object from a variable reference.

This function traverses the expression tree of a variable reference to construct an appropriate ObjSet. If the variable reference refers to a member variable within a class definition, the function recursively resolves the parent expression (e.g., via dot or arrow operators) to build a chain of object references, eventually creating a memory object for the member. For non-member symbols, it creates a standalone NamedObjSet.

Parameters
rA pointer to the SgVarRefExp representing the variable reference to be processed.
Returns
A pointer to the constructed ObjSet, which may be a NamedObjSet representing a member or a standalone symbol, or an aliased object set.
Precondition
r must not be NULL.
The symbol associated with the variable reference r must not be NULL.
The type associated with the symbol must not be NULL.
If the symbol is a member variable declaration, the parent of r must be an SgDotExp or SgArrowExp.
Postcondition
Returns a valid ObjSet pointer representing the resolved memory structure or variable reference.
Note
The implementation uses recursion to handle nested member access (e.g., a.b.c).
There is a known TODO regarding whether the name should be clarified to create NamedObj only, as the function does not currently break the chain for pointer types.
The logic for handling pointer aliasing via if 0 blocks is currently disabled.

void AbstractMemoryObject::fillUpElements ( ObjSet * p,
std::vector< LabeledAggregateField * > & elements,
SgClassType * c_t )

Populates a vector with LabeledAggregateField elements based on a class definition.

This function iterates through the member declarations of a class definition provided via an SgClassType. For every variable declaration found within the class members, it creates a new ObjSet representing the field and wraps it into a LabeledAggregateField_Impl object, which is then appended to the provided elements vector. The process relies on dynamic casting the input ObjSet to a LabeledAggregate to establish the parent context.

Parameters
pA pointer to an ObjSet representing the parent aggregate. Must not be NULL and must be castable to a LabeledAggregate.
elementsA reference to a vector of LabeledAggregateField pointers that will be populated with the newly created field implementations.
c_tA pointer to an SgClassType representing the class whose members are to be processed. Must not be NULL.
Precondition
p must not be NULL and must be a valid LabeledAggregate pointer.
c_t must not be NULL.
The declaration associated with c_t must be a valid SgClassDeclaration.
The defining declaration of the class must be a valid SgClassDeclaration.
The definition of the class must be non-NULL if a defining declaration exists.
Postcondition
The elements vector will contain new LabeledAggregateField_Impl instances corresponding to each variable declaration found in the class definition.
Note
This function uses assertions to validate the integrity of the input pointers and the class hierarchy. It assumes that the members of the class are accessible and that the variable symbols can be retrieved via SageInterface::getFirstVarSym.

IndexVector * AbstractMemoryObject::generateIndexVector ( std::vector< SgExpression * > & subscripts)

Generates an IndexVector based on a collection of subscript expressions.

This function iterates through a vector of SgExpression pointers representing subscripts. For each expression, it determines whether the subscript represents a constant value or an unknown value. If the expression is identified as an SgValueExp, a ConstIndexSet instance is added to the resulting IndexVector. Otherwise, an UnknownIndexSet instance is added. The function constructs and returns a newly allocated IndexVector_Impl object containing these index sets.

Parameters
subscriptsA reference to a vector of SgExpression pointers representing the subscripts to be processed.
Returns
A pointer to a newly allocated IndexVector object containing the processed index sets.
Precondition
The subscripts vector must not be empty. An assertion is used to enforce this condition.
Postcondition
Returns a pointer to an IndexVector_Impl instance. The caller is responsible for managing the memory of the returned pointer.
Note
The implementation currently uses a new allocation for IndexVector_Impl without a specific strategy for avoiding duplicate creation.

bool AbstractMemoryObject::isAliased ( const SgType * t1,
const SgType * t2 )

Determines if two types are considered aliased based on type equality.

This function implements a basic alias analysis strategy where two types are considered aliased if they are identical. For function types, the function recursively checks if the return types are aliased and if the argument parameter lists are identical in size and composition (where each corresponding argument type is also aliased).

Parameters
t1The first type to compare.
t2The second type to compare.
Returns
True if the types are considered aliased; false otherwise.
Precondition
The pointers t1 and t2 should be valid, non-null pointers to SgType objects.
Postcondition
The function does not modify the input types.
Note
This is a simplified implementation. It currently does not account for subtype relationships (e.g., if t1 is a subtype of t2).

bool AbstractMemoryObject::isMemberVariableDeclarationSymbol ( SgSymbol * s)

Checks if a given symbol represents a member variable declaration within a class definition.

This function determines whether the provided symbol is a variable declaration that belongs to the scope of an SgClassDefinition. The implementation first verifies if the symbol is an instance of SgVariableSymbol. If so, it retrieves the underlying declaration and checks if the scope of that declaration is a class definition.

Parameters
sA pointer to the SgSymbol to be checked.
Returns
True if the symbol is a variable declaration whose scope is an SgClassDefinition; otherwise, false.
Precondition
The parameter s must not be NULL.
Postcondition
The function returns a boolean value indicating the membership status of the symbol.
Note
This function currently only supports checks for SgVariableSymbol types.
The function relies on an assertion that the declaration associated with the variable symbol is not NULL.
