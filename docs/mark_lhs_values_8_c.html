void markLhsValues ( SgNode * node)

Marks the left-hand side (LHS) values within an AST node.

This function performs a traversal of the provided SgNode to identify and mark nodes that represent left-hand side (LHS) values. It utilizes the MarkLhsValues traversal class to execute the marking logic. The traversal is performed using a preorder strategy to ensure that parent nodes are processed before their children, maintaining consistency with standard interface expectations.

Parameters
nodeA pointer to the SgNode that serves as the root of the sub-tree to be traversed and marked.
Precondition
node must not be a null pointer.
Postcondition
The nodes within the provided node's subtree that represent LHS values will be marked according to the logic defined in MarkLhsValues.
Note

This function performs a traversal of the provided SgNode to identify and mark nodes that represent left-hand side values (l-values). This process is essential for subsequent analysis or transformation phases that require knowledge of which nodes are assignable.
