Overloads the stream insertion operator to provide a string representation of a StructLayoutEntry.

This function formats the details of a StructLayoutEntry for output to an output stream. It identifies the nature of the entry by inspecting the underlying declaration. The output includes a label (such as a field name, "Anonymous union", or "Padding"), the byte offset, and the field size. If the entry represents a bit field, additional information regarding the bit offset and the container size is appended.

Parameters
oThe output stream where the formatted string will be written.
eThe StructLayoutEntry object to be serialized.
Returns
A reference to the modified output stream o.
Warning
If the declaration e.decl contains an unrecognized kind, the function prints an error to cerr and calls abort(), terminating the program.
Precondition
The e.decl pointer must either be null, point to an initialized name, or point to a class declaration.
Postcondition
The output stream o will contain a formatted string describing the layout entry, and the state of the stream remains unchanged unless an error occurs during insertion.
Note
The function relies on helper functions isSgInitializedName and isSgClassDeclaration to determine the type of the declaration.
