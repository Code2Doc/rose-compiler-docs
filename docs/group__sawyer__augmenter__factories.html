Detailed Description

Factories for creating instances of Sawyer::CommandLine::ValueAugmenter subclasses.

A factory function is a more terse and convenient way of calling the instance allocating constructors for the various subclasses of ValueAugmenter, and they sometimes alleviate the user from having to supply template arguments. They take the same arguments as the instance method(s) and have the same name as the class they return, except their initial letter is lower-case. These two calls are equivalent:

ValueAugmenter::Ptr a1 = Sum::instance<int>();
ValueAugmenter::Ptr a2 = sum<int>();

This function provides a global access point to the singleton instance of the Sum template class. It utilizes the internal implementation of Sum<T>::instance() to return a pointer to the managed instance. This is typically used to access accumulation logic or state associated with the Sum operation for type T.
Returns
A pointer of type typename Sum<T>::Ptr representing the singleton instance.
Precondition
The type T must be compatible with the Sum template implementation.
Postcondition
Returns a valid, non-null pointer to the Sum<T> instance, assuming the singleton has been properly initialized.
Note
This function relies on the singleton pattern implemented within the Sum<T> class.
