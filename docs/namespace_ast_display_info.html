QString AstDisplayInfo::getShortNodeNameDesc ( SgNode * )

Retrieves a brief, human-readable string representation of an SgNode's name or type.

Returns a short description of an Sg*Definition for named types (classes, functions etc) it returns the name if there is no adequate name for an SgNode it returns the getShortNodeTypeDesc if node is no definition it returns an empty string

This function attempts to extract a short descriptive name from various types of SgNode subclasses. It performs type checking using specialized predicates (e.g., isSgClassDefinition, isSgFile) to identify the specific nature of the node. The implementation uses a conditional branching logic to format the string based on the node type, such as prepending "namespace ", "typedef ", or "enum " where appropriate. For assembly functions, it utilizes StringUtility::demangledName. If the node type is not explicitly handled in the primary conditional block, the function falls back to getShortNodeTypeDesc.

Parameters
nodeA pointer to the SgNode to be described.
Returns
A QString containing the short description of the node. If the node type is not recognized by the specific type checks, the result of getShortNodeTypeDesc(node) is returned.
Precondition
node should not be a null pointer, although the function does not explicitly check for nullity before accessing node-specific predicates.
Postcondition
The returned QString contains a non-empty string representing the identity or type of the provided node.
Note
The function relies on several helper functions (e.g., isSgClassDefinition, isSgFile) and the StringUtility class for demangling names.

QString AstDisplayInfo::getShortNodeTypeDesc ( SgNode * )

Retrieves a short, human-readable description of a given SgNode type.

returns a description for SgNode-Type if SgNode is for example of type SgClassDefinition it returns "class"

This function performs type inspection on a provided SgNode pointer to determine its underlying semantic type (e.g., Class, Function, Namespace, etc.). It uses a series of type-checking helper functions to identify the specific subclass of SgNode and returns a localized string representation of that type.

Parameters
nodeA pointer to the SgNode to be inspected.
Returns
A QString containing the short description of the node type (e.g., "Class", "Function", "Namespace", "For-Loop", "While-Loop", or "AsD-Function"). Returns an empty QString if the node type is not recognized or if the node is null.
Precondition
The node pointer should be valid and not null, although the function handles unrecognized types gracefully by returning an empty string.
Postcondition
The function returns a localized string without modifying the input node.
Note
The returned strings are wrapped in QObject::tr() to allow for internationalization/translation.

NodeType AstDisplayInfo::getType ( SgNode * node)

Returns "type" of node (class,function,loop,namespace) at Sg*Definitions.

Identifies the underlying node type of a given SgNode.

This function performs type inspection on a provided SgNode pointer by attempting to cast or identify it as various specific SgNode subclasses, such as class definitions, function definitions, function declarations, namespace definitions, or assembler function declarations. It uses a series of type-checking helper functions to determine the specific category of the node.

Parameters
nodeA pointer to the SgNode to be inspected.
Returns
The identified NodeType (e.g., CLASS, FUNCTION, NAMESPACE, or UNKNOWN).
Precondition
The node pointer should be valid and not null, although the function will return UNKNOWN if the node does not match any known type.
Postcondition
The function returns a constant NodeType value representing the classification of the input node.
Note
The function treats both SgFunctionDefinition and SgFunctionDeclaration as the FUNCTION type. It also treats SgAsmFunction as the FUNCTION type.

QIcon AstDisplayInfo::nodeIcon ( SgNode * node)

icon for SgFunctionDeclaration, SgClassDeclaration...

Retrieves the appropriate icon for a given SgNode based on its type.

This function performs type inspection on the provided SgNode to determine its underlying semantic type (e.g., class definition, function, namespace, loop, etc.). It uses a series of type-checking predicates to identify the node's category and returns a QIcon pointing to a specific resource path within the application's Qt resource system.

Parameters
nodeA pointer to the SgNode to be inspected.
Note
The function relies on various helper functions such as isSgClassDefinition, isSgFunctionDefinition, and others to perform the type identification.
The icons are loaded from the internal Qt resource path prefix ":/util/NodeIcons/".
Precondition
The node pointer should be valid and not null, although the function will return an empty QIcon if the node type is not recognized.
Postcondition
Returns a QIcon representing the visual identity of the node type.
