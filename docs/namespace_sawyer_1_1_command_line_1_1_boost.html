Detailed Description

Auto-generated documentation for the Sawyer::CommandLine::Boost namespace.

Drop-in replacement to help boost users.

Some users use boost::program_options, but due to the complexity of the interface, they use only the most basic features. Essentially, they use boost to map switches like "--foo=bar" into a map containing the pair ("foo", "bar") both represented as std::string. Their source code then makes decisions and obtains switch values by querying them from this map and converting them to a non-string type that's stored in a C++ variable for later reference.

Sawyer::CommandLine can also operate in this "pull" mode although it's most often used in "push" mode, where the command-line parsing package is responsible for converting the string argument to a non-string type and storing it in a C++ variable somewhere.

Switch Sawyer::CommandLine::Boost::createSwitch ( const std::string & switchNames,
const std::string & doc )

Creates a Switch object from a comma-separated list of names and a documentation string.

This function parses a string containing comma-separated switch names to construct a Switch object. It distinguishes between long names and short names (single-character names) by iterating through the split list. The first valid long name or short name found is used to initialize the primary Switch identity, while any subsequent names in the list are added as additional aliases.

Parameters
switchNamesA comma-separated string of names representing the switches to be created. Names are categorized as long or short based on their length.
docA string containing the documentation/description associated with the created switch.
Returns
A Switch object configured with the parsed long names, short names, and documentation.
Precondition
The input switchNames must contain at least one valid long name or one valid short name.
Postcondition
A Switch object is returned where the first parsed name serves as the primary identifier, and all other parsed names are registered as additional long or short name aliases.
Note
The function relies on boost::split for parsing and assumes the existence of isShortName and isLongName predicate functions to categorize the names.
Warning
If the switchNames string contains no valid long or short names, an assertion failure will occur.

void Sawyer::CommandLine::Boost::notify ( variables_map & )

Notifies the system of changes in the variables map.

Transfer map to C++ variables.

This wrapper doesn't try to handle a "push" paradigm, but if you've gone around the wrapper to declare switches using Sawyer's interface and those switches were specified with storage locations, the data has already been moved before this function is called (it's part of command_line_parser::run).

This function serves as a notification mechanism to signal that the provided variables map has been modified. In its current implementation, the function body is empty and does not perform any specific logic or side effects.

Parameters
varsA reference to the variables_map that has undergone changes.
Precondition
The variables_map reference must be a valid, initialized object.
Postcondition
No changes are made to the state of the system or the provided map.
