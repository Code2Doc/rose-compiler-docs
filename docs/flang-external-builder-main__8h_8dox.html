Acts as the main entry point for the flang external builder process.

Acts as the main entry point for the Flang external builder process.

This function serves as a driver for the Fortran parsing and compilation process. It parses command-line arguments to configure a compiler driver, sets up Fortran parser options (including predefinitions and language features like CUDA support), and manages the compilation of Fortran and other language source files. It handles various flags for source form (fixed/free), preprocessor definitions, and compiler-specific behaviors.

The implementation iterates through the provided arguments, identifying Fortran source files, relocatable objects, and other language sources. It utilizes an external compiler (defined by the F18_FC environment variable, defaulting to gfortran) to perform the actual compilation and linking steps.

Parameters
argcThe number of command-line arguments.
argvAn array of command-line argument strings.

Returns
An integer representing the exit status of the builder process.
Precondition
The environment variable F18_FC should be set if a specific Fortran compiler other than gfortran is required.
Postcondition
The function ensures that CleanUpAtExit is registered to run upon program termination. Depending on the input, it may produce object files, link them, or perform syntax-only parsing.
Note
This function uses a hack to set the Rose source file globally, which is required until Rose is compatible with C++17.
The function handles various flags such as -Mfixed, -Mfree, -fopenmp, -D (definitions), and -I (include directories).
