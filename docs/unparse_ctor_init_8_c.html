bool trimCtorNameQual ( std::string & qualifier)
static

Fixes generated name-qualification for constructor calls Call to constructor Nspc::Abc() is internally qualified as Nspc::Abc::Abc() Which produces the name-qualifier Nspc::Abc:: Older compiler accept that qualification but not modern compilers which simply expect Nspc:: When needed, this code removes the trailing ::. In this case, it return false to signify that the constructor name does not need to be unparsed separately
