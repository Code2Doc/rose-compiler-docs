◆ to_string()

std::string nlohmann::to_string ( const NLOHMANN_BASIC_JSON_TPL & j)

user-defined to_string function for JSON values

Converts a JSON object to its string representation.

This function implements a user-defined to_string for JSON objects.

Parameters
[in]ja JSON object
Returns
a std::string object

This function provides a convenient way to serialize a JSON value into a std::string. It internally calls the dump() member function of the JSON object, which performs the serialization process. The resulting string contains the JSON data in a compact or formatted format depending on the underlying implementation of the dump() method.

Parameters
jThe JSON object to be converted to a string.
Returns
A std::string containing the serialized JSON representation of the input object.
Precondition
The input object j must be a valid, well-formed JSON value.
Postcondition
The returned string is a valid UTF-8 encoded string representing the JSON content.
Note
This function is a wrapper around the dump() method of the JSON class.
