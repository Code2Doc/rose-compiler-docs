Determines if a given SgNode is significant for the SgFilter slicing process.

This function evaluates the importance of an SgNode based on its type and its position within the Syntax Graph (SG). The logic varies depending on whether the ifdef SIMPLE_FILTER macro is defined. The primary goal is to filter out non-essential nodes (like certain expression statements or parameter lists) while retaining nodes that represent control flow, function calls, or critical assignments.

The implementation performs the following checks:

  • Always ignores SgExprStatement nodes to prevent duplicate nodes in the Dominance Tree.
  • Identifies function calls as important nodes.
  • Under ifdef SIMPLE_FILTER:
    • Includes all SgStatement nodes.
    • Includes expressions that are not sub-expressions of another expression (top-level expressions).
  • Under the default configuration:
    • Includes SgStatement nodes, excluding SgFunctionParameterList.
    • Includes initialized names if they are not part of a variable declaration.
    • Includes function calls if they are not contained within an SgExprStatement.
    • Includes binary or unary operations if they are part of a for-loop incremental expression (by traversing up the parent hierarchy until a non-expression node is reached).
