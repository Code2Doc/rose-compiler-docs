Wraps dependency edges into a new dependency graph structure.

This function iterates through a set of dependency edges provided by an iterator and constructs a new graph of AST references. For each dependency edge, the function identifies the source and sink nodes in the existing graph. If either the source or the sink AST node represents an array access, the function creates corresponding nodes in the result graph (mapping the AST nodes to their respective loop tree dependency nodes) and establishes a new edge between them using the dependency information.

Parameters
resA pointer to the DepCompAstRefGraphCreate object used to create the new nodes and edges in the resulting graph.
compA reference to the LoopTreeDepComp object, used to retrieve the associated tree nodes for the graph nodes.
gA pointer to the Graph object representing the existing dependency structure, used to look up the endpoints of the edges.
depsAn EdgeIterator used to traverse the collection of dependency edges.
Precondition
The pointer res must be valid and initialized.
The pointer g must be valid and contain the endpoints for the edges traversed by deps.
The deps iterator must be properly initialized and capable of traversing the dependency edges.
Postcondition
The res graph object will contain new nodes and edges representing the array access dependencies found in the deps iterator.
Note
The function skips edges where both the source and sink AST references are null.
The function specifically filters for edges where at least one endpoint is an array access, as determined by LoopTransformInterface::IsArrayAccess.

bool DebugRefGraph ( )

Checks if the debug reference graph option is enabled.

This function determines whether the "-debugrefgraph" command-line option is active. It utilizes a static integer to cache the result of the check after the first invocation, ensuring that the command-line option lookup via the CmdOptions singleton is only performed once during the program execution.

Returns
True if the "-debugrefgraph" option is present in the command-line arguments; false otherwise.
Precondition
The CmdOptions singleton must be properly initialized before the first call to this function.
Postcondition
The internal state of the function (the static variable r) is updated to reflect the result of the initial check.
Note
The function uses a static variable to persist the state of the debug flag across multiple calls.
