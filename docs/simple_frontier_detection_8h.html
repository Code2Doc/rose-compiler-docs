Detects the frontier of nodes for mapping token subsequences to the AST.

Performs frontier detection for mapping token streams to the AST.

This function performs a specialized traversal of the Abstract Syntax Tree (AST) associated with a given source file to identify the "frontier." The frontier represents the boundary where the unparsing process must decide between using the original token stream or the reconstructed AST. This detection is a critical precursor to the process of associating token subsequences to the AST in a separate mapping.

The implementation utilizes an inherited attribute traversal pattern. Depending on the 'traverseHeaderFiles' flag, the function either performs a traversal limited to the scope of the specific source file (using 'traverseWithinFile') or a broader traversal that includes associated header files (using 'traverse'). The process uses SimpleFrontierDetectionForTokenStreamMapping_InheritedAttribute to propagate information through the tree.

Parameters
sourceFileA pointer to the SgSourceFile object representing the source file to be processed. This file serves as the root for the frontier detection traversal.
traverseHeaderFilesA boolean flag indicating whether the traversal should extend into associated header files. If true, the entire AST scope is traversed; if false, the traversal is restricted to the current file's scope.
Returns
void
Warning
The function assumes that the 'sourceFile' pointer is not NULL. Passing a NULL pointer will trigger a ROSE_ASSERT failure.
Precondition
The 'sourceFile' parameter must be a valid, non-null pointer to an initialized SgSourceFile object.
Postcondition
The AST nodes within the scope of the 'sourceFile' (and potentially its headers) will have their frontier attributes updated, marking the boundaries for token-to-AST mapping.
Note
This function uses a TimingPerformance timer to track the execution duration of the frontier detection process.
The function's behavior regarding header files was updated in 2021 to ensure proper unparsing support when 'traverseHeaderFiles' is enabled.

This function identifies the "frontier" within an Abstract Syntax Tree (AST) to determine which parts of the code can be unparsed using a token stream versus which parts must be unparsed from the AST. It utilizes a traversal mechanism with inherited attributes to propagate information through the tree structure. The detection process occurs before associating token subsequences to the AST.

Precondition

Postcondition
