user-defined string literal for JSON values

A user-defined literal operator to parse JSON strings directly into nlohmann::json objects.

This operator implements a user-defined string literal for JSON objects. It can be used by adding "_json" to a string literal and returns a JSON object if no parse error occurred.

Parameters
[in]sa string representation of a JSON object
[in]nthe length of string s
Returns
a JSON object
Since
version 1.0.0

This operator allows for a convenient syntax to create JSON objects from string literals at compile-time or runtime using the _json suffix. It utilizes the nlohmann::json::parse method to interpret the provided character range as a JSON-formatted string.

Parameters
sA pointer to the start of the character array containing the JSON string.
nThe number of characters in the string, excluding the null terminator.
Returns
An nlohmann::json object parsed from the input character range.
Precondition
The input pointer s must not be null and must point to a valid memory range containing valid JSON text of length n.
Postcondition
Returns a valid JSON object representing the parsed content.
Warning
If the input string s does not contain valid JSON, the nlohmann::json::parse function will throw a nlohmann::json::parse_error exception.
Note
This operator is useful for embedding static JSON data directly within C++ source code for testing or configuration purposes.
