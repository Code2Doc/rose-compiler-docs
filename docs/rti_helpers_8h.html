Populates RTIMemberData with runtime type information and performs optional initialization checks.

Performs Runtime Type Information (RTI) processing for a specific class member.

This function is responsible for initializing an RTIMemberData object with metadata regarding a specific class member, including its type string, name, and contents. If the code is compiled with ROSE_USE_VALGRIND, the function performs an additional check using doUninitializedFieldCheck to verify the initialization status of the memory pointed to by fieldPtr.

Parameters
fieldPtrA pointer to the memory location of the field being documented.
fieldSizeThe size of the field in bytes.
thisPtrA pointer to the instance of the class containing the field.
classNameThe name of the class to which the field belongs.
typeStringA string representation of the data type of the field.
fieldNameThe name of the specific field within the class.
fieldContentsA string containing the actual data/contents of the field.
memberDataAn output reference to an RTIMemberData object that will be populated with the provided information.
Precondition
The fieldPtr must point to a valid, accessible memory region of at least fieldSize bytes.
Postcondition
The memberData object is updated to reflect the state of the provided typeString, fieldName, and fieldContents.
Note
The parameters fieldNameBase, fieldPtr, fieldSize, and thisPtr are used primarily for debugging and validation purposes when ROSE_USE_VALGRIND is defined.

This function is responsible for initializing an RTIMemberData object with metadata regarding a class field. It captures the type string, field name, and the actual contents of the field. If the code is compiled with ROSE_USE_VALGRIND, the function also performs an uninitialized field check to ensure memory safety during the RTI process.

Parameters
typeStringA string representing the type of the field being processed.
fieldNameThe name of the specific field within the class.
fieldContentsA string containing the serialized or string-based contents of the field.
memberDataAn output parameter of type RTIMemberData that will be populated with the provided type, name, and contents.
Precondition
The fieldPtr and fieldSize must represent a valid memory region if ROSE_USE_VALGRIND is defined.
Postcondition
The memberData object is updated to reflect the state of the provided field.
Note
This function uses ifdef logic to conditionally include Valgrind-based uninitialized memory checks.

std::string toStringForRTI ( const Sawyer::Container::BitVector & x)
inline

Converts a BitVector to its hexadecimal string representation prefixed with 0x.

This function takes a reference to a BitVector object and transforms its content into a human-readable hexadecimal string. It utilizes the internal toHex() method of the BitVector class and prepends the standard "0x" prefix to indicate the hexadecimal format.

Parameters
xThe BitVector instance to be converted to a hexadecimal string.
Returns
A string containing the hexadecimal representation of the BitVector, prefixed with "0x".
Precondition
The input BitVector x must be a valid, initialized instance.
Postcondition
Returns a non-empty string representing the bit pattern in hex format.
