Entry point for the experimental Fortran parsing process using the flang parser.

This function orchestrates the initialization of the global scope and invokes the flang external builder to parse the provided Fortran source file. It provides verbose logging if the global project verbosity level is set above zero, displaying command-line arguments and the final parsing status.

Parameters
argcThe number of command-line arguments passed to the program.
argvAn array of character pointers representing the command-line arguments.
srcFileA pointer to the SgSourceFile object representing the Fortran source file to be processed.
Returns
An integer status code representing the result of the parsing operation. Returns the status returned by flang_external_builder_main.
Precondition
srcFile must be a valid, non-null pointer to an SgSourceFile object.
Postcondition
The global scope is initialized, and the flang parser is executed.
Note
The function relies on SgProject::get_verbose() to determine if diagnostic information should be printed to the standard output.
The function uses ROSE_ASSERT to ensure that the global scope initialization was successful.

This function serves as a high-level wrapper to initialize the global scope for a given source file and subsequently invoke the flang external builder. It provides logging capabilities if the global project verbosity is set above zero, printing details regarding the parser invocation and the final execution status.

Parameters
argcThe number of command-line arguments passed to the program.
argvAn array of character pointers representing the command-line arguments.
srcFileA pointer to the SgSourceFile object representing the source file to be processed.
Returns
An integer status code representing the result of the parsing process. Returns the status returned by flang_external_builder_main, or -1 if the process fails to initialize.
Precondition
The srcFile pointer must be valid and not null.
Postcondition
The global scope is initialized via Rose::builder::initialize_global_scope, and the flang parser is executed.
Note
This function relies on the global state of SgProject for verbosity control. The function uses a ROSE_ASSERT to ensure that the global scope is successfully initialized before proceeding to the builder main.
