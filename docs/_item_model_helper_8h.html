used by drag and drop functions

This function performs a depth-first search (DFS) through the rows of a given model, starting from a specified parent index. It iterates through each row in the current level of the model for the specified column, retrieves the SgNode pointer stored in the SgNodeRole, and compares it to the target node. If a match is not found at the current level, the function recursively traverses the children of the current index.

Parameters
nodeThe pointer to the SgNode being searched for within the model.
modelThe QAbstractItemModel instance to be searched.
subTreeIndThe starting QModelIndex from which the search begins (the parent index).
columnThe specific column index within the model to inspect for the SgNodeRole.
Returns
A valid QModelIndex pointing to the location of the node in the model if found; otherwise, an invalid QModelIndex.
Precondition
The model must be a valid, initialized QAbstractItemModel.
Postcondition
The function returns a valid index if the node exists in the subtree of subTreeInd, or an invalid index otherwise.
Note
The search relies on the SgNodeRole being correctly populated with SgNode pointers within the model's data.
The complexity of the search is proportional to the number of nodes in the subtree of the provided subTreeInd.

Searches for a specific QVariant value within a hierarchical QAbstractItemModel.

This function performs a depth-first search (DFS) through the rows of a given model, starting from a specified parent index. It iterates through each row in the current level of the tree, checks if the data at the specified role and column matches the target value, and if not, recursively descends into the children of the current row.

Parameters
valueThe QVariant value to search for within the model.
modelThe QAbstractItemModel to be searched.
roleThe item data role to check when comparing values.
subTreeIndThe starting QModelIndex from which the search begins (the parent node).
columnThe specific column index within the model to inspect during the search.
Returns
A QModelIndex pointing to the first occurrence of the value found in the model. Returns an invalid QModelIndex if the value is not found.
Precondition
The model must be a valid, non-null instance of QAbstractItemModel.
Postcondition
The function returns either a valid QModelIndex or an invalid QModelIndex; the state of the model remains unchanged.
Note
The search is implemented using a recursive algorithm, which may lead to stack overflow if the model tree depth is extremely large.
