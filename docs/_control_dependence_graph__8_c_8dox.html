void dfsVisit ( SliceCFGNode p)

Performs a Depth-First Search (DFS) traversal to identify strongly connected components.

This function implements a variation of Tarjan's strongly connected components algorithm. It traverses the Control Flow Graph (CFG) starting from node p, maintaining discovery times (dfsnum) and low-link values (low) to identify nodes belonging to the same strongly connected component. The algorithm uses a stack (L) to keep track of the nodes in the current search path and a set (T) to track visited nodes. When a root of a strongly connected component is identified (where low[p] == dfsnum[p]), the function pops nodes from the stack until the root is reached.

Parameters
pThe current SliceCFGNode being visited in the depth-first traversal.
Precondition
The global or class-member variables L (stack), dfsnum (map/array), N (counter), low (map/array), and T (set) must be properly initialized.
Postcondition
The node p and its descendants in the DFS tree are processed, and if p is the root of a strongly connected component, the nodes belonging to that component are popped from the stack L.
Note
This implementation relies on external state (L, dfsnum, N, low, T) which must be managed by the caller or the containing class.

This function implements a variation of Tarjan's algorithm for finding strongly connected components (SCCs) within a Slice Control Flow Graph (CFG). It uses a stack-based approach to track nodes in the current search path and maintains discovery times (dfsnum) and low-link values (low) to identify the roots of SCCs. As the recursion unwinds, nodes belonging to the same SCC are popped from the stack.

Parameters
pThe current SliceCFGNode being visited during the depth-first traversal.
Precondition
The global or class-member structures L (stack), dfsnum (discovery time array/map), low (low-link value array/map), N (global counter), and T (set of visited nodes) must be properly initialized.
Postcondition
The node p and all its reachable descendants in the current SCC will have their dfsnum and low values updated. If p is the root of an SCC, the nodes belonging to that SCC will be popped from the stack L.
Note
This implementation relies on external state (e.g., L, dfsnum, low, N, T) which must be managed by the caller or the containing class.
