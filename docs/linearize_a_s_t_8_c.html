std::vector< SgNode * > linearize_subtree ( SgNode * node)

Performs a linearization of a given AST subtree into a flat vector of nodes.

This function executes a depth-first traversal of the subtree rooted at the provided node. It utilizes a specialized traversal class, LinearizeAST, and an associated LinearizeInheritedAttribute to manage the state and inherited attributes during the traversal process. The function effectively flattens the hierarchical structure of the subtree into a linear sequence of SgNode pointers based on the traversal order.

Parameters
nodeA pointer to the root SgNode of the subtree to be linearized.
Returns
A std::vector containing the sequence of SgNode pointers representing the linearized order of the subtree.
Precondition
The input node must not be a null pointer.
Postcondition
The returned vector contains the nodes of the subtree in the order determined by the LinearizeAST traversal algorithm.
Note
The implementation relies on the LinearizeAST class to perform the actual tree walking and the collection of nodes.
