Detailed Description

Implements an XML parser callback.

XMLHandler is a helper class for XMLParser that defines various call-back routines to construct a generic tree representation of the XML document.

This tree is an instantiation of the template type, Tree<T> in util/tree2.hh. The node values are of type XMLHandler::Elem.
