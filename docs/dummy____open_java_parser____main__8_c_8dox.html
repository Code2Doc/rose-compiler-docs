Attempts to execute the Java-based Open Java Parser.

Serves as the entry point for invoking the Java-based OpenJavaParser from C++.

This function serves as an entry point for the Java parser integration within ROSE. It checks for the availability of a Java runtime environment. If the ROSE build was not configured with the with-java flag during the configure stage, this function notifies the user via stderr that the feature is disabled and that the compilation of the input file will be ignored.

Parameters
argcThe number of command-line arguments passed to the program.
argvAn array of character pointers representing the command-line arguments.
Returns
An integer status code. Returns 1 to indicate that the Java parser could not be run due to missing configuration, even though the operating system may receive a 0 from the parent process.
Warning
This function will always fail and return 1 if ROSE was not configured with the –with-java option at compile time.
Precondition
The ROSE environment must be properly configured with Java support via the with-java flag to avoid the error message triggered by this function.
Postcondition
The function returns an error code of 1, and a warning message is printed to the standard error stream.

This function facilitates the execution of the Java Virtual Machine (JVM) and the OpenJavaParser (OFP) within a C++ environment. It manages the environment variables required to locate specific JNI libraries (such as libparser_java_FortranParserActionJNI.so) by temporarily modifying the library path variable (defined by ROSE_SHLIBPATH_VAR). The function dynamically determines the appropriate library path based on the build configuration (e.g., ifdef USE_CMAKE, ifdef _MSC_VER) to ensure that configuration-specific enum values in the IR nodes remain consistent.

The implementation follows these steps:

  1. Identifies the correct library path for the current build configuration.
  2. Backs up the existing value of the ROSE_SHLIBPATH_ARG variable.
  3. Updates the environment variable to include the new library path.
  4. If ifdef ENABLE_FORTRAN_ERROR_HANDLER is active, initializes the Fortran error handler.
  5. Executes the JVM via the runECJ function.
  6. Restores the original environment variable value.
Parameters
argcThe argument count from the command line.
argvThe argument vector from the command line.
Returns
An integer status code returned by the runECJ function, indicating the success or failure of the Java parser execution.
Precondition
The environment variable defined by ROSE_SHLIBPATH_VAR should be accessible.
Postcondition
The environment variable ROSE_SHLIBPATH_VAR is restored to its original state (if it was not null) after the function completes.
Note
This function relies on ifdef OVERWRITE_LD_LIBRARY_PATH to determine whether the environment variable should be modified.
The use of ifdef _MSC_VER allows for platform-specific handling of environment variable updates using _putenv_s on Windows.
