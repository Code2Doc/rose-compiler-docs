void copyNonLocalFuncDecls ( SgBasicBlock * b)

Copies function declarations from external basic blocks into the specified basic block.

This function traverses the subtree of the provided basic block b to identify all function references (SgFunctionRefExp). For every function reference found, the function retrieves the underlying function symbol and its corresponding declaration. If the declaration's parent is a basic block other than the current block b, a deep copy of the declaration (without the definition) is created and prepended to the start of block b. This ensures that the necessary function prototypes are available within the scope of the block.

Parameters
bThe SgBasicBlock where the non-local function declarations will be prepended.
Precondition
b must not be null.
Postcondition
The basic block b will contain new SgFunctionDeclaration statements at its beginning if non-local function references were found in its subtree.
Note
The implementation uses ASTtools::deepCopy to duplicate the declaration.
The function maintains symbol table integrity by setting the first non-defining declaration of the copy to the original declaration.
