const std::vector< int64_t > & stringify::nlohmann::detail::lexer__base::token_type ( )

Retrieves a constant reference to a vector containing predefined token type values.

This function provides access to a static, immutable collection of 64-bit integer values representing various token types. The values are stored in a static std::vector to ensure they are initialized only once during the first call and persist for the lifetime of the program. The vector contains 17 sequential values ranging from 0 to 16.

Returns
A constant reference to a std::vector<int64_t> containing the token type identifiers.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector of 17 elements.
Note
The implementation uses a static local variable to ensure thread-safe initialization (in C++11 and later) and to avoid the overhead of re-constructing the vector on every function call.

Converts a token type integer identifier into its corresponding string representation.

This function performs a mapping from a 64-bit integer representing a specific JSON token type to a human-readable C-style string. It uses a switch-case mechanism to evaluate the input integer and return the appropriate label. This is primarily used for debugging, logging, or error reporting within the lexer implementation.

Parameters
iThe integer identifier representing the token type to be converted.
Returns
A pointer to a constant character string representing the token type. Returns an empty string "" if the provided integer does not match any of the predefined token types.
Precondition
The input integer i should correspond to one of the defined token constants used within the lexer.
Postcondition
The returned string is a static literal and does not require manual memory management by the caller.
Note
The mapping covers standard JSON tokens such as literals (true, false, null), structural characters (begin_array, end_object, etc.), and parser-specific states (parse_error, end_of_input).

Formats a token type identifier into a human-readable string with an optional prefix removal.

This function retrieves the string representation of a token type using an overloaded token_type(int64_t) function. If the resulting string is empty, it constructs a fallback string containing the class name and the integer value. Additionally, if the string starts with the specified prefix provided in the strip parameter, that prefix is removed from the beginning of the string.

Parameters
iThe integer identifier representing the token type.
stripA string representing the prefix to be removed from the start of the formatted token type string, if present.
Returns
A string representing the formatted token type, potentially with the strip prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip substring if it was originally present at the start of the token type string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
