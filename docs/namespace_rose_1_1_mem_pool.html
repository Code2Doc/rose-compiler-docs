void Rose::MemPool::snapshot ( std::ostream & out)

Serializes the current state of the node pool to an output stream.

This function performs a snapshot of the existing node pool information by utilizing a visitor pattern. It instantiates a DumpPoolInfo object, which acts as a functor for the serialization process, and applies it to all nodes currently managed within the system. The resulting information is written directly to the provided output stream.

Parameters
outThe output stream where the serialized pool information will be written.
Precondition
The output stream out must be in a valid, writable state.
Postcondition
The state of the node pool is recorded in the out stream, and the stream's write pointer is advanced by the amount of data written.
Note
This function relies on the Nodes::apply mechanism to traverse the internal node structure.

void Rose::MemPool::snapshot ( std::string const & outfilename)

Saves a snapshot of the current state to a specified file.

This function provides a high-level interface to persist the current object's state into a file named by the provided string. It handles the creation and management of the file stream, delegating the actual serialization logic to an overloaded version of the snapshot function that accepts a std::ostream object.

Parameters
outfilenameThe path and name of the file where the snapshot will be saved.
Precondition
The directory containing the outfilename must exist and the process must have write permissions for that location.
Postcondition
If successful, a file is created or overwritten at the specified outfilename containing the serialized state.
Note
This function relies on the existence of an overload: void snapshot(std::ostream&).
