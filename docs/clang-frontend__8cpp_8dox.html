Orchestrates the translation of Clang AST to a Sage AST.

This function serves as the main entry point for the Clang-to-Sage translation process. It parses command-line arguments to identify include directories, preprocessor definitions, and the input source file. It then configures a Clang CompilerInstance with the appropriate language settings (C, C++, CUDA, or OpenCL), sets up the necessary include paths and system headers, and executes the translation using a ClangToSageTranslator. Finally, it attaches the resulting global scope to the provided SgSourceFile and performs a fixup phase on the generated AST.

Parameters
argcThe number of command-line arguments.
argvAn array of strings representing the command-line arguments. Expected flags include -I for include directories and -D for preprocessor definitions.
sageFileA reference to an SgSourceFile object where the resulting translated global scope will be stored.
Returns
An integer representing the number of diagnostic errors encountered during the translation process. A return value of 0 indicates success.
Precondition
The input file specified in argv must exist and be a valid source file compatible with the detected language (C, C++, CUDA, or OpenCL).
The sageFile object must be a valid, initialized instance of SgSourceFile.
Postcondition
If the function completes successfully, sageFile will contain a new global scope representing the translated AST.
If the function encounters errors during Clang parsing, the return value will be non-zero.
Note
The function uses ifdef and if logic to handle different build configurations, such as whether to exit after generating Dot files.
The function relies on the Clang compiler infrastructure, specifically clang::CompilerInstance and clang::ParseAST.
Warning
If the detected file extension does not match a supported language (C, C++, CUDA, OpenCL), the function will trigger a ROSE_ASSERT failure or ROSE_ABORT.
Objective-C support is explicitly not available and will cause the function to abort.

void finishSageAST ( ClangToSageTranslator & translator)

Finalizes the Sage Abstract Syntax Tree (AST) construction process.

This function performs the final cleanup and structural adjustments to the Sage AST after the translation from Clang is complete. It is responsible for iterating through the global scope to handle any remaining structural transformations, such as managing label statements or integrating preprocessor information into the AST.

Parameters
translatorA reference to the ClangToSageTranslator instance used to manage the translation state and access the global scope.
Precondition
The translator must have a valid global scope initialized and the translation from Clang must be complete.
Postcondition
The Sage AST is finalized and ready for subsequent analysis or code generation phases.
Note
Historically, this function included logic to move sub-statements following label statements, but this step is currently deprecated as sub-statements are now handled during the initial translation phase.
