void trim ( string & str)

Removes leading and trailing whitespace from a string.

This function modifies the input string in-place to remove all whitespace characters from both the beginning and the end of the string. The whitespace characters considered are spaces, tabs, newlines, and carriage returns (" \t\n\r").

The implementation works by first finding the last character that is not a whitespace character and erasing everything following it. Then, it finds the first character that is not a whitespace character and erases everything from the start of the string up to that position. If the string consists entirely of whitespace, the function clears the string.

Parameters
strA reference to the string to be trimmed.
Precondition
The input string str must be a valid, initialized std::string object.
Postcondition
The string str will no longer contain leading or trailing whitespace characters. If the string was only whitespace, it will be empty.
Note
This function performs in-place modification of the provided string.
