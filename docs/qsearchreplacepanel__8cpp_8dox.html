QString escapeCpp ( const QString & s,
bool rep )

Escapes or unescapes C++ style escape sequences within a string.

This function processes a given QString to handle C++ escape sequences. If the replacement flag is enabled, the function iterates through the string and interprets backslash-prefixed characters. Specifically, it handles the unescaping of sequences such as \, \t,
, \r, and \0. If the replacement flag is disabled, the string is returned unmodified.

Parameters
sThe input string containing potential C++ escape sequences.
repA boolean flag indicating whether to perform the unescaping process. If true, escape sequences are processed; if false, the original string is returned.
Returns
A QString containing the processed string with escape sequences resolved if rep is true, otherwise the original string.
Precondition
The input string s should be a valid QString instance.
Postcondition
The returned string will have specific escape sequences replaced by their literal character equivalents if rep is true.
Note
The function specifically handles the following mappings: \ to \ \t to tab
to newline \r to carriage return \0 to null character
