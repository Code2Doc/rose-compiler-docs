Retrieves the class object associated with a given Java object.

This function wraps the JNI function GetObjectClass to obtain the jclass representing the runtime class of the provided jobject. It includes error handling to ensure that the returned class pointer is not null. If the retrieval fails, the function prints an error message to stdout and triggers a ROSE_ABORT() to terminate the process.

Parameters
envA pointer to the JNI environment structure.
jobjThe Java object whose class is to be retrieved.
Returns
The jclass object corresponding to the class of the input jobj.
Warning
If GetObjectClass returns NULL, the function will abort the program execution via ROSE_ABORT().
Precondition
The env pointer must be a valid, non-null JNIEnv pointer.
The jobj must be a valid, non-null reference to a Java object.
Postcondition
Returns a valid jclass if the operation is successful.
If the operation fails, the program is aborted.
Note
This function uses printf and fflush to report errors to the standard output stream.
