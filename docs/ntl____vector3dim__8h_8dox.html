This function provides a way to output the contents of an ntlVector3Dim object to an output stream in a formatted string representation. The output follows the format [x, y, z], where x, y, and z are the individual components of the vector.

Parameters

Returns
A reference to the modified output stream (os) to allow for chained stream operations.
Precondition

Postcondition
The output stream os will contain the string representation of the vector i in the format '[value[0], value[1], value[2]]'.

Overloads the extraction operator to read a 3D vector from an input stream.

This function parses a formatted string from the provided input stream to populate the components of an ntlVector3Dim object. The expected input format consists of a starting character, followed by three scalar values separated by two-character delimiters, and ending with a closing character. The implementation uses a temporary buffer to skip the delimiter characters between the vector components.

Parameters
isThe input stream from which the data is being read.
iThe ntlVector3Dim object to be populated with the extracted scalar values.
Returns
A reference to the input stream is, allowing for chained extraction operations.
Precondition
The input stream is must be in a good state and contain data formatted as a single character, followed by three scalars separated by two-character delimiters, and a final character.
Postcondition
If the extraction is successful, the value array of the i object will contain the three extracted scalar values, and the stream position will be advanced past the final character.
Note
This function assumes a specific fixed-format input structure. If the stream encounters unexpected characters or formatting errors, the stream failbit will be set.
