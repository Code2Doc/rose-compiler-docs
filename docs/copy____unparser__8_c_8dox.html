bool DebugCopyUnparse ( )

Determines whether the debug unparsing mode is enabled based on command-line options.

This function checks the global command-line options to decide if the debug copy unparsing functionality should be active. It utilizes a static variable to cache the result of the option check after the first invocation, ensuring that the lookup in CmdOptions only occurs once during the program execution.

Returns
True if the "debugcpup" option is present in the command-line options, otherwise false.
Precondition
The CmdOptions singleton must be properly initialized before this function is called.
Postcondition
The internal state of the static variable doit is updated upon the first call.
Note
The function relies on the existence of CmdOptions::GetInstance() and the HasOption method.
