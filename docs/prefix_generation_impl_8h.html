std::string unparseDeclarationToString ( SgDeclarationStatement * declaration,
bool unparseAsDeclaration )

Generates a string representation of a declaration statement.

Unparse the declaration as a string for use in prototypes within the AST rewrite mechanism prefix mechanism.

Converts a declaration statement into its string representation.

This function converts an AST declaration statement into a string format suitable for intermediate files. This ensures that transformation code remains compilable by including necessary declarations. The function handles various types of declarations including enums, variables, templates, typedefs, classes, and functions. It specifically manages formatting options such as skipping comments, skipping CPP directives (using include, define, etc.), and handling function definitions versus declarations.

Parameters
declarationA pointer to the SgDeclarationStatement node to be unparsed. Must not be null.
unparseAsDeclarationA boolean flag indicating whether to unparse the statement as a full declaration (e.g., adding a semicolon for functions) or as a definition/parameter list component.
Returns
A string containing the unparsed representation of the declaration.
Precondition
declaration != nullptr
Postcondition
The returned string contains the unparsed declaration, potentially formatted based on the type of the declaration node.
Note
The function skips CPP directives because they have already been evaluated by the front-end.
For class declarations, the function can be configured to skip the class definition body if unparseAsDeclaration is false.
For function declarations, the function handles the addition of semicolons based on the unparseAsDeclaration flag.
For SgFunctionParameterList, the function manually iterates through arguments to build a semicolon-delimited string of type-name pairs.
Warning
If a SgVariableDefinition node is encountered, the function will trigger a ROSE_ABORT.
If an unknown declaration variant is encountered, the function will trigger a ROSE_ABORT.

Converts a scope statement to a string representation without its basic block.

This function performs a specialized unparsing of a given SgScopeStatement. It utilizes an SgUnparse_Info object configured to strip specific elements from the output, specifically excluding comments, the basic block (body), the trailing semicolon, and all C/C++ preprocessor directives (e.g., include, define). The function relies on globalUnparseToString to perform the actual string generation based on the specific variant of the scope statement.
