int clang_to_dot_main ( int argc,
char ** argv )

Generates a Graphviz DOT graph representing the Clang Abstract Syntax Tree (AST).

This function serves as a main entry point for a utility that parses C-family source files (C, C++, CUDA, OpenCL) using the Clang compiler frontend and translates the resulting AST into a DOT format file. The function parses command-line arguments to extract include directories (-I) and preprocessor definitions (-D), configures a Clang CompilerInstance with the appropriate language settings, and executes the AST parsing process. The resulting graph is written to a file named clangGraph.dot.

Parameters
argcThe number of command-line arguments provided.
argvAn array of strings representing the command-line arguments. Expected arguments include the input source file and flags such as -I for include directories and -D for macro definitions.
Returns
An integer status code. Returns 0 on successful generation of the DOT graph, or the number of diagnostic errors encountered during the Clang parsing process if an error occurs.
Precondition
The input file specified in argv must exist and be a valid C-family source file (e.g., .c, .cpp, .cu, .cl).
Postcondition
A file named clangGraph.dot is created or overwritten in the current working directory containing the AST representation in DOT format.
Warning
If the input file extension corresponds to Objective-C, the function will trigger a ROSE_ABORT().
The function relies on the existence of specific ROSE include paths and pre-defined C/C++ include strings.
Note
The function uses ifdef DEBUG_EDG_DOT_GRAPH_SUPPORT and if DEBUG_ARGS to enable additional logging for debugging purposes.
The implementation handles different language standards (C, C++, CUDA, OpenCL) by adjusting the clang::LangOptions.
