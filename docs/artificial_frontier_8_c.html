void buildArtificialFrontier ( SgSourceFile * sourceFile,
bool traverseHeaderFiles )

Identifies and builds the artificial frontier within an AST for token stream mapping.

This function performs frontier detection within a given source file's AST. This detection process occurs before token subsequences are associated with the AST in a separate map. The function utilizes an ArtificialFrontierTraversal and an inherited attribute (ArtificialFrontier_InheritedAttribute) to traverse the AST. Depending on the traverseHeaderFiles flag, the traversal either covers the entire AST (including headers) or is restricted to the scope within the specific file.

Parameters
sourceFileA pointer to the SgSourceFile object representing the source file to be processed. Must not be NULL.
traverseHeaderFilesA boolean flag indicating whether the traversal should extend to include header files. If true, the traversal is performed over the whole AST; otherwise, it is restricted to the file itself.
Precondition
sourceFile must not be NULL.
Postcondition
The AST nodes within the scope of the traversal are marked with frontier information, facilitating subsequent token stream mapping.
Note
This function uses ROSE performance tracking via TimingPerformance to monitor the duration of the AST build process.
The implementation relies on include and define logic via the ArtificialFrontierTraversal class.
