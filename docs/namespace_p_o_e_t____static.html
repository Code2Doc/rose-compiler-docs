Generates the code for a finite difference invocation.

This function constructs a sequence of operations within the POET intermediate representation to perform a finite difference calculation. It initializes a configuration block by assigning metadata such as the expression type, a name prefix, the trace variable, and scalar status. It also handles the assignment of private trace variables, permutation logic, and trace modification if provided. Finally, it aggregates the dimensions into a linked list and invokes the finite difference routine with the prepared configuration and arguments.

Precondition

Postcondition
Returns a valid POETCode sequence if dimVec is non-empty, otherwise returns 0.
Note
The function uses SEQ5 and SEQ macros to chain assignments and operations into a single executable block.
The dimensions in dimVec are processed in reverse order to build a linked list structure.
