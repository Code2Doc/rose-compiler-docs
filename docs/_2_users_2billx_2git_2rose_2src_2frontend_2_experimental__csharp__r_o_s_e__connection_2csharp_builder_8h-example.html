creates a using directive with unique C# identifier uid.

Parameters
uida unique key representing the C# declaration
levelsnumber of components of the name

pops of levels names from the name stack, assembles them to a single name and creates a new SgUsingDeclaration. The new IR node will get uid as its unique ID.

namestack->Text->System usingDirective(x, 2) => "System.Text"
