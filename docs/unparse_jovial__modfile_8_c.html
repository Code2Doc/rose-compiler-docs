void generateJovialCompoolFile ( SgFile * sfile)

Generates Jovial-specific module (*.rcmp) files from COMPOOL directives.

Generates a Jovial-specific module (*.rcmp) file from the provided source file.

This function iterates through the AST of a given source file to identify SgJovialCompoolStatement nodes. For each identified statement, it generates a corresponding .rcmp file in a designated output directory. The process involves cleaning the module name (removing single quotes and converting to lowercase), creating a file stream, and using an unparser to write the unparsed Jovial code into the new file. The generated file includes a specific header warning that it is automatically generated.

Parameters
sfileA pointer to the SgFile object representing the source file being processed. This file must contain the AST nodes to be parsed for Jovial COMPOOL statements.
Precondition
sfile must not be null.
sfile must be a valid SgSourceFile.
Postcondition
If the function executes, a new .rcmp file is created for each SgJovialCompoolStatement found in the AST, provided that the skip unparse and skip final compile steps flags are not set.
Note
The function uses the original module filename to assist in building unparsing information.
If the output file cannot be opened for writing, the function will trigger a ROSE_ABORT.
The function skips generation if the SgFile is flagged to skip unparsing or the final compilation step.

std::string get_rcompool_dir ( SgFile * sfile)

Retrieves the RCompool directory path from the original command line arguments of a file.

This function inspects the command line argument list associated with the provided SgFile object. It specifically searches for the "-outputdir" option. If the option is found and contains a parameter, the function returns the directory path followed by a trailing slash. If the option is not present or does not contain a parameter, an empty string is returned.

Parameters
sfileA pointer to the SgFile object whose command line arguments are to be inspected.
Returns
A string containing the directory path extracted from the "-outputdir" argument, including a trailing slash if found. Returns an empty string if the argument is not found.
Precondition
sfile must not be a null pointer.
Postcondition
The returned string will either be an empty string or a path ending with a forward slash.
Note
The function relies on CommandlineProcessing::isOptionWithParameter to parse the argument vector.
