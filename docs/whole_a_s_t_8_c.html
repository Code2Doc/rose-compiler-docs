void generateWholeGraphOfAST ( const char * filename)

Generates a complete Abstract Syntax Tree (AST) graph from a specified file.

Generate a whole AST graph with a specified filename, and the default filter sets, excluding frontend-specific nodes by default, char* for gdb.

This function serves as a convenience wrapper for the string-based overload of generateWholeGraphOfAST. It takes a C-style string representing a file path, converts it into a std::string, and initiates the process of parsing the specified file to construct and generate the entire AST graph structure.

Parameters
filenameA pointer to a null-terminated character array containing the path to the source file to be processed.
Precondition
The filename must point to a valid, readable file on the filesystem.
Postcondition
An AST graph representing the contents of the file is generated.
Note
This function internally calls the overload that accepts a std::string and a nullptr for the secondary parameter.

Generates a complete DOT graph representation of the entire Abstract Syntax Tree (AST).

Generate a whole AST graph with a specified filename, using filter_flags to turn on/off builtin node filters and using skippedNodeSet to exclude customized node set.

This function serves as a high-level wrapper to trigger the graph generation process for the full AST. It delegates the actual traversal and graph construction logic to the SimpleColorMemoryPoolTraversal::generateGraph implementation. The resulting graph is written to a file specified by the filename, applying filters and skipping nodes as defined by the provided parameters.

Parameters
filenameThe path to the output file where the DOT graph will be saved.
skippedNodeSetA set of SgNode pointers that should be excluded from the generated graph.
flagsA pointer to a structure containing filtering flags that determine which elements of the graph are included or how they are styled.
Precondition
The filename path must be valid and the process must have write permissions to the target directory.
Postcondition
A DOT file is created or overwritten at the specified filename containing the AST graph.
Note
This function relies on the implementation of SimpleColorMemoryPoolTraversal::generateGraph.
