void Rose::GraphUtility::deserialize ( std::istream & input,
Graph & graph )

Reconstructs a Graph object from a binary input stream.

This function reads a serialized graph representation from the provided input stream and populates the given Graph object. The deserialization process follows a specific binary format: it first validates a version number, then reads the number of vertices and edges, and finally iterates through the stream to reconstruct each vertex and edge. For each vertex and edge, the function relies on their respective internal value types to perform their own deserialization from the stream.

Parameters
inputThe input stream from which the graph data is being read.
graphThe Graph object that will be populated with the deserialized data.
Precondition
The input stream must be in a valid state and positioned at the start of a validly serialized graph buffer.
Postcondition
The graph object is cleared of any existing data and contains the structure and values exactly as they were in the serialized stream.
Warning
The function assumes a specific binary format and versioning. If the version number read from the stream is not 0, an assertion failure will occur.
The function relies on the internal deserialize methods of the vertex and edge value types; if those methods fail or encounter unexpected EOF, the graph state may be left partially constructed.
Note
The function uses boost::uint32_t for reading metadata, implying a dependency on the Boost library.
The function uses ASSERT_require2 for integrity checks during the reconstruction of vertices and edges.

void Rose::GraphUtility::serialize ( std::ostream & output,
Graph & graph )

Serializes the contents of a Graph object into an output stream.

This function performs a binary serialization of the provided Graph object. The serialization format follows a specific sequence: it first writes a placeholder zero, followed by the number of vertices, and then the number of edges. After the header information, the function iterates through all vertices and invokes their respective serialization methods. Finally, it iterates through all edges, writing the source vertex ID, the target vertex ID, and the edge's internal value serialization.

Parameters
outputThe output stream where the serialized graph data will be written.
graphThe Graph object to be serialized.
Precondition
The output stream must be in a writable state and capable of handling binary data. The graph object must be valid and its vertices and edges must be accessible via the provided iterators.
Postcondition
The output stream will contain the binary representation of the graph, including vertex and edge metadata and their associated values.
Note
The serialization relies on the serialize method being implemented for the value types contained within both vertices and edges.
The vertex and edge IDs are written as 32-bit unsigned integers (boost::uint32_t).
