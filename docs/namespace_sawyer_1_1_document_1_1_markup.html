Detailed Description

Auto-generated documentation for the Sawyer::Document::Markup namespace.

A system for embedding function calls in text.

This namespace has functions for marking up text with function calls. A function call looks like @foo{arg1}{arg2}... where foo is the name of the function and its arguments are each enclosed in curly braces. A function declaration for "foo" must be inserted into the grammar before "@@foo" can be recognized.

bool Sawyer::Document::Markup::isValidNameCharacter ( int c)

Checks if a given character is a valid character for a name.

This function determines whether a character is suitable for use in a name by checking if it is an alphanumeric character or one of the allowed special characters (underscore or hyphen). It utilizes the standard C library functions isalnum and strchr to perform the validation.

Parameters
cThe character to be validated, passed as an integer.
Returns
True if the character is alphanumeric, an underscore, or a hyphen; false otherwise.
Precondition
The input integer c should represent a valid character value representable by unsigned char or EOF.
Postcondition
The function returns a boolean value indicating the validity of the character.
Note
This function relies on the locale-dependent behavior of isalnum.
