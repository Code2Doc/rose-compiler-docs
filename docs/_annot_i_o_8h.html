Reads a sequence of items from an input stream separated by a specific character.

This function attempts to parse a list of items from the provided input stream. It first attempts to read an initial item using the provided generator object. Subsequently, it enters a loop that checks for a delimiter character. If the delimiter is non-zero and matches the next character in the stream, the delimiter is consumed and the next item is read. The process continues as long as the stream remains in a good state and the items can be successfully parsed.

Parameters
inThe input stream from which the items are to be read.
opAn object of type ItemGen that implements a read method used to parse individual items.
sepThe character used as a delimiter between items in the list. If this is set to 0, the function will attempt to read items continuously without looking for a separator.
Returns
True if the first item was successfully read; false if the initial read operation failed.
Precondition
The object op must implement a member function bool read(std::istream&) that handles the parsing logic for a single item.
Postcondition
If the function returns true, at least one item has been processed by op.read. The state of the input stream in may be modified (characters may be consumed).
Note
This function relies on the existence of peek_ch and read_ch functions to inspect and consume characters from the stream.
