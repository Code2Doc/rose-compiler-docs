Returns

Precondition

Postcondition
The returned reference points to a valid, static vector that remains unchanged throughout the program execution.
Note

This function maps specific 64-bit integer values to human-readable string constants. It uses a switch-case mechanism to evaluate the input integer and returns a pointer to a static string literal representing the flag.

Parameters
iThe 64-bit integer representing the flag to be stringified. Expected values are 0 for "FULL" and 1 for "ABBREVIATED".
Returns
A pointer to a constant character string. Returns "FULL" if i is 0, "ABBREVIATED" if i is 1, and an empty string "" for any other value.
Precondition
The input parameter i should be a valid integer representing a known flag state.
Postcondition
The returned pointer points to a null-terminated string literal that remains valid for the lifetime of the program.
Note
This function does not handle any values other than 0 and 1 explicitly; all other inputs result in an empty string.

Generates a formatted string representation of a flag identifier with an optional prefix removal.

Convert Rose::BinaryAnalysis::SymbolicExpression::TypeStyle::Flag enum constant to a string.

This function creates a string representation of a 64-bit integer flag. It first calls an overloaded version of Flag(i) to obtain the base string. If the resulting string is empty, it constructs a fallback string using a specific namespace-qualified type identifier followed by the integer value. Finally, if the resulting string starts with the provided strip prefix, that prefix is removed from the string.

Parameters
iThe 64-bit integer identifier to be converted into a string flag.
stripA string representing the prefix to be removed from the start of the generated flag string if it exists.
Returns
A string containing the formatted flag identifier, potentially with the specified prefix stripped away.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present at the beginning of the initial string generation.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
