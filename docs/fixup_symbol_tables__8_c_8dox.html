void fixupAstSymbolTables ( SgNode * node)

Repairs and updates the hierarchy and contents of AST symbol tables.

Fixup global and local symbol tables.

This function performs a comprehensive fixup of both global and local symbol tables within the Abstract Syntax Tree (AST). It ensures that the global function type table is rebuilt to account for potential name resets in templates during post-processing. Additionally, it validates the parent-child relationships for the global function type table and the global type table, ensuring they are correctly attached to a valid scope such as an SgProject or SgFile. Finally, it initiates a traversal using FixupAstSymbolTables to update local symbol tables throughout the provided node's subtree.

Parameters
nodeThe root node of the AST subtree from which the symbol table fixup traversal should begin.
Precondition
The global function type table must not be NULL, as verified by a ROSE_ASSERT.
Postcondition
The parent pointers for the global function type table and global type table are updated to the provided node if they were previously NULL and the node is an SgProject or SgFile. Local symbol tables within the subtree of the provided node are updated via a preorder traversal.
Note
The function utilizes TimingPerformance objects to track the execution time of the global and local symbol table fixup phases.

Updates and resolves the global function type symbol table.

Fixup the names used build the global function symbol table.

This function performs a fixup operation on the provided global function type symbol table. It utilizes a visitor pattern via the FixUpGlobalFunctionTypeTable class to traverse nodes stored in the memory pool for both SgFunctionType and SgMemberFunctionType. This ensures that both standard global functions and member function types are correctly processed and resolved within the symbol table, which is critical for resolving function pointers and member function pointers referenced from the global scope.

Parameters
globalFunctionTypeSymbolTableA pointer to the SgFunctionTypeTable that needs to be updated. This table must be the same as the one returned by SgNode::get_globalFunctionTypeTable().
Precondition
The parameter globalFunctionTypeSymbolTable must be the same instance as the one retrieved via SgNode::get_globalFunctionTypeTable().
Postcondition
The global function type symbol table is updated to include resolved types from the memory pool traversal.
Note
The implementation uses a TimingPerformance timer to track the execution duration of the fixup process.
The function also processes SgMemberFunctionType nodes to ensure that member function pointers are correctly handled.
