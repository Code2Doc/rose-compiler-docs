Executes the Python interpreter to process a given source file and update the SgGlobal state.

Initializes the Python interpreter to process a given source file.

This function serves as the main entry point for running the Python frontend. It initializes the Python interpreter environment, registers necessary Python types, and executes the Python frontend logic on the provided SgFile. After the Python execution, it updates the global scope and source position information within the SgGlobal object and links it to the corresponding SgSourceFile.

Parameters
filenameThe string representing the path or name of the Python file to be processed.
fileA pointer to the SgFile object representing the source file being processed.
Returns
An integer status code. This function currently returns -1 to indicate the completion of the process (often used in this context to signal a specific exit state or to prevent the host process from exiting immediately).
Precondition
The Python environment must be capable of being initialized via Py_Initialize().
The file pointer must be a valid, non-null pointer to an SgFile object.
Postcondition
The Python interpreter is finalized via Py_Finalize().
The SgGlobal object produced by the Python frontend is linked to the SgSourceFile.
The skip_commentsAndDirectives flag of the input file is set to true.
Note
This function relies on the successful execution of runPythonFrontend and initializePythonTypes.
The function modifies the internal state of the SgFile and SgGlobal objects.

This function orchestrates the execution of the Python frontend. After the interpreter execution, it finalizes the Python environment and updates the metadata of the SgSourceFile and SgFile objects, including setting the global scope and adjusting source position information.
