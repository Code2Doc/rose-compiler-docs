Reads graph structure and edge attributes from an input stream.

The function iterates through the stream, identifying source nodes, sink nodes, and edge labels. It relies on the Graph class interface to add nodes and edges.

Parameters

inThe input stream from which the graph data is read.
hintA string used as a delimiter or marker to identify the start of a new edge or a specific segment in the input stream.
Precondition
The Graph template parameter must provide a Node type and implement the following methods:
  • Node* add_node(const std::string& name)
  • void add_edge(Node* src, Node* snk, const std::string& label)
Postcondition
The graph object g will contain all nodes and edges parsed from the stream that match the provided hint criteria.
Note
The function assumes the input stream follows a specific sequence: a marker/identifier, a source node name, a sink node name, and an optional edge label. If the stream ends prematurely or the hint does not match, the parsing for that specific edge segment is aborted.

void write_graph ( const Graph & g,
OUTPUT & out,
const std::string & hint )

Serializes the structure and contents of a graph to an output stream.

This function iterates through all nodes in the provided graph and traverses their outgoing edges. For each node, it writes a formatted string to the output stream. If a node has no outgoing edges, only the node's identity is recorded. If edges exist, the function records the source node, the destination node, and the edge itself. The output format follows a pattern of hint:source->destination : edge.

Parameters
gThe graph object to be traversed and written. The graph must support NodeIterator, EdgeIterator, and GetNodeEdgeIterator.
outThe output stream or object where the graph data will be written. This object must support the insertion operator (<<).
hintA string prefix used to label the output entries, useful for distinguishing between different graph writes in a single stream.
Precondition
The graph g must be a valid, traversable graph object.
Postcondition
The output stream out will contain a serialized representation of all nodes and edges present in the graph g.
Note
The implementation relies on the GraphAccess::EdgeOut and GraphAccess::EdgeIn constants to determine traversal direction.

The output format includes a provided hint and the string representations of the node, the endpoint, and the edge itself.
