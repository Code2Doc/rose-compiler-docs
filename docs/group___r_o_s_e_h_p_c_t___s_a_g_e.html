Detailed Description

This submodule defines the metric attribute, RoseHPCT::MetricAttr, which is interpreted from the profile IR (ROSE-HPCT Profile IR) and is derived from AstAttribute so that it can be attached to Sage nodes.

In addition, this submodule provides a variety of support routines for traversing the Sage III IR and propagating metrics from low-level scopes to higher-level scopes (e.g., from statements to their surrounding loop and function scopes).
