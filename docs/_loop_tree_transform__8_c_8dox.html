The implementation uses the loop information from the second loop node to establish bounds for the restriction.

rThe dependency relationship object containing direction and alignment information.
Returns
A pointer to a newly allocated LoopTreeNode representing the dependency restriction. Returns a LoopTreeRelateLoopIvar if the dependency is an equality with identical min/max alignment. Returns a LoopTreeRestrLoopRange for other valid dependency types.
Precondition

Postcondition
The function returns a pointer to a heap-allocated LoopTreeNode.
