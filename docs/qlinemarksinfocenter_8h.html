QCE_EXPORT QDataStream & operator<< ( QDataStream & d,
const QLineMark & m )

Serializes a QLineMark object into a QDataStream.

This function implements the stream insertion operator for the QLineMark class, allowing for the binary serialization of line mark data. The serialization process extracts the line number, the file path, and resolves the mark type string via the QLineMarksInfoCenter singleton before writing them to the stream.

Parameters
dThe destination QDataStream where the data will be written.
mThe QLineMark object containing the line, file, and mark information to be serialized.
Returns
A reference to the modified QDataStream, allowing for chained stream operations.
Precondition
The QLineMarksInfoCenter singleton must be properly initialized to ensure markTypeId() can resolve the mark identifier.
Postcondition
The QDataStream contains the serialized integer line, QString file, and QString mark in a consistent binary format.
Note
The serialization order is: line (int), file (QString), and mark (QString). The mark string is retrieved by looking up the mark ID in the QLineMarksInfoCenter instance.

QCE_EXPORT QDataStream & operator>> ( QDataStream & d,
QLineMark & m )

Deserializes a QLineMark object from a QDataStream.

This operator overload reads the necessary components of a QLineMark from the provided QDataStream. It sequentially extracts an integer representing the line number, a QString representing the file path, and a QString representing the mark type. The extracted mark type string is then converted into its corresponding type ID using the QLineMarksInfoCenter singleton.

Parameters
dThe input QDataStream from which the data is being read.
mThe QLineMark object that will be populated with the deserialized data.
Returns
A reference to the input QDataStream to allow for chained extraction.
Precondition
The QDataStream must be in a valid state and contain the expected serialized data format (int, QString, QString).
Postcondition
The QLineMark object m is updated with the values read from the stream, and the stream position is advanced.
Note
The conversion of the mark string to a type ID relies on the QLineMarksInfoCenter::instance() being properly initialized.
