Convert Rosebud::Ast::CppStack::Type enum constant to a string.

This function retrieves the string representation of a type using the overloaded Type(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a specific type cast notation and the integer ID. Additionally, if the resulting string starts with the provided strip string, that prefix is removed from the final output.

Parameters
iThe 64-bit integer ID representing the type.
stripA string representing the prefix to be removed from the start of the type string if present.
Returns
A string representing the type, potentially modified by the stripping process.
Precondition
The integer i should correspond to a valid type ID recognized by the Type(int64_t) overload.
Postcondition
The returned string will not start with the strip substring if it was originally present.
Note
