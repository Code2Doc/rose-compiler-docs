Convert Jovial::State enum constant to a string.

Parameters
iThe 64-bit integer representing the state ID to be stringified.
Returns

Generates a formatted state string with an optional prefix removal.

Convert Jovial::State enum constant to a string.

This function retrieves a string representation of a state identified by the integer i. It first calls the overloaded State(int64_t) function. If the resulting string is empty, it constructs a default string in the format "(Jovial::State)" followed by the integer value. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the state.
stripA string representing the prefix to be removed from the start of the generated state string if it exists.
Returns
A string representing the state, potentially with the specified prefix removed.
Precondition
The parameter i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the content of the strip parameter if the original string did.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
