Detailed Description

Implements a pass over the AST that attaches metrics as attributes.

This pass simply attaches a metric to all matching statements. If HPCToolkit reports 100 cycles for a source line consisting of four distinct statements, e.g., a[0] = 0; a[1] = 1; a[2] = 2; a++; then this pass will assign 100 to all four statements.

To normalize the metrics correctly, see the normalizeMetrics routine.
