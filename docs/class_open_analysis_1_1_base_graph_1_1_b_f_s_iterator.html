Detailed Description

The BFSiterator calls the virtual function create_BFS_links the first time it is called, or if the graph has been changed since the last call.

BaseGraph::BFSIterator::BFSIterator ( BaseGraph & g)

DBFSIterator creates a node_iterator to enumerate nodes in the BFS order starting at the root. If this is the first time a BFS iterator has been demanded for this graph, or the graph has changed since the last BFS traversal, a BFS is actually carried out to fill in the BFS pointers. Otherwise, the nodes are simply traversed using the existing BFS pointers.
