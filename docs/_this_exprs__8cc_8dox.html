Creates a variable declaration that shadows the 'this' pointer within a member function.

This function generates a new variable declaration (a shadow variable) inside the body of a member function. The purpose is to create a local variable that holds the value of the 'this' pointer. The function checks if a variable with the provided name already exists in the function body; if it does, it retrieves the existing declaration. If not, it constructs a new declaration with a pointer type corresponding to the class symbol (handling const-correctness based on the function definition), initializes it with the 'this' expression, and prepends it to the function's basic block.

Parameters
nameThe string name to be assigned to the new shadow variable declaration.
symThe class symbol representing the class to which the 'this' pointer belongs.
func_defThe function definition within which the shadow declaration will be inserted.
Returns
A pointer to the created or existing SgVariableDeclaration.
Precondition
sym must not be NULL.
func_def must not be NULL.
func_def must be a member function definition.
The function body of func_def must be accessible and valid.
Postcondition
If a new declaration is created, it is prepended to the start of the function body.
The returned SgVariableDeclaration is associated with the function body's scope.
Note
The function uses ifdef linux to enable debug logging if enable_debug is true.
The function handles const-correctness by checking if the function definition is a const member function via ASTtools::isConstMemFunc.
If the unparse header files feature is enabled, the function updates the physical file specification for the new declaration to ensure correct unparsing in header files.

SgClassSymbol * getClassSymAndVerify ( const ASTtools::ThisExprSet_t & E)

Retrieves and verifies the class symbol from a set of 'this' expressions.

This function iterates through a collection of 'this' expressions to extract the underlying class symbol. It performs a consistency check to ensure that all 'this' expressions within the provided set refer to the same class symbol. If the set contains 'this' expressions pointing to different class symbols, an error is reported to stderr and the function returns null.

Parameters
EA set of 'this' expressions (ASTtools::ThisExprSet_t) to be verified.
Returns
A pointer to the SgClassSymbol associated with the 'this' expressions. Returns 0 (nullptr) if the set is empty, if an error is detected due to inconsistent symbols, or if the verification fails.
Precondition
The input set E should contain valid SgThisExp pointers.
Postcondition
If a valid symbol is found, it is returned; otherwise, 0 is returned.
Note
The function uses ROSE_ASSERT to ensure that each element in the set is a non-null pointer.

Replaces occurrences of 'this' expressions with a specific variable reference within an AST.

This function iterates through a set of 'this' expressions and replaces each one with a variable reference expression derived from the provided variable declaration. The implementation traverses the parent nodes of each 'this' expression to identify the context (such as binary operations, unary operations, expression lists, sizeof operators, or assignment initializers) and performs the necessary substitution in the AST.

Parameters
this_exprsA set of AST nodes representing 'this' expressions that need to be replaced.
declA pointer to the variable declaration from which the replacement variable symbol will be extracted.
Precondition
decl must not be null and must contain a valid SgVariableSymbol.
The elements within this_exprs must be valid SgThisExp nodes.
Postcondition
All 'this' expressions in this_exprs that are part of the handled AST node types (SgBinaryOp, SgUnaryOp, SgExprListExp, SgSizeOfOp, and SgAssignInitializer) are replaced by a new SgVarRefExp pointing to the symbol in decl.
Warning
The function uses ROSE_ASSERT to validate the structure of the AST. If a 'this' expression is found in a parent node type that is not explicitly handled by the implementation, the program will trigger an assertion failure.
Note
The replacement process involves creating a new SgVarRefExp and manually updating the parent pointer of the new expression to match the original parent of the 'this' expression.
