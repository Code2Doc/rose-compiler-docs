Retrieves all expressions that resolve to a specific function definition.

This function iterates through the memory pool to identify all instances of function calls and constructor initializers that target a specific function definition. It utilizes NodeQuery to find candidates of type V_SgFunctionCallExp and V_SgConstructorInitializer, then uses CallTargetSet::getDefinitionsForExpression to resolve the potential targets for each candidate. If a match with the provided targetDef is found, the expression is added to the output container.

Parameters
targetDefA pointer to the function definition whose call sites are being sought.
classHierarchyA pointer to the class hierarchy wrapper used for resolving function calls and determining call targets.
expsA reference to a container of SgExpression pointers where the identified call sites and initializers will be stored.
Precondition
targetDef must be a valid pointer to an SgFunctionDefinition.
Postcondition
The exps container will contain all SgFunctionCallExp and SgConstructorInitializer nodes that resolve to targetDef.
Note
The function performs a global search across the memory pool for specific node types, which may have performance implications in very large ASTs.

Retrieves the first virtual function definition found by traversing the class hierarchy upwards.

This function searches through the ancestor classes of a given class to find the first available definition of a virtual member function. It starts from a specified class (or the class scope of the member function) and performs a depth-first search using a worklist-based approach through the class hierarchy provided by the ClassHierarchyWrapper. The search identifies the first declaration that matches the signature of the provided member function declaration.

Parameters
crtClassA pointer to the SgClassType representing the starting point for the search. If this is NULL, the function uses the scope of the memberFunctionDeclaration.
memberFunctionDeclarationA pointer to the SgMemberFunctionDeclaration whose virtual definition is being sought.
classHierarchyA pointer to the ClassHierarchyWrapper used to traverse the ancestor classes of the current class definition.
Returns
A pointer to the SgFunctionDeclaration representing the first found virtual definition in the hierarchy, or NULL if no virtual definition is found or if the function is not virtual.
Precondition
memberFunctionDeclaration must not be NULL.
classHierarchy must not be NULL.
If crtClass is not NULL, its underlying declaration must be an SgClassDeclaration and its defining declaration must also be an SgClassDeclaration.
Postcondition
The function returns a valid SgFunctionDeclaration if a virtual override is found in the hierarchy, otherwise it returns NULL.
Note
The function uses an assertion-based approach to validate the integrity of the input pointers and the class hierarchy structure.
The search algorithm utilizes a worklist (vector) to implement a traversal of the class ancestor set.

Returns the list of all constructors that may get called via an initialization.

Identifies all constructor function declarations involved in a constructor initializer list.

This function performs a traversal of the class hierarchy to determine which constructor declarations are invoked during the initialization process of a given constructor initializer. It first checks the declaration of the constructor initializer itself to find the corresponding member function declaration. It then explores the inheritance tree of the class associated with the initializer. Using a worklist-based approach, the function iteratively examines base classes, identifying any default constructors called for superclasses. The algorithm handles cases where constructors might be compiler-generated and accounts for the possibility of primitive types within the initializer list.

Parameters
sgCtorInitA pointer to the SgConstructorInitializer object representing the constructor initializer list to be analyzed.
Returns
A vector of SgFunctionDeclaration pointers, where each element represents a constructor declaration that is part of the initialization sequence.
Precondition
sgCtorInit must not be a null pointer.
Postcondition
The returned vector contains the identified constructor declarations, and the state of the input sgCtorInit remains unchanged.
Note
The function uses an ASSERT_not_null macro, which implies that the underlying declarations must be valid and non-null for the assertion to pass.
The implementation handles the traversal of base classes via a worklist to manage the inheritance hierarchy.

This function determines all the constructors called in a constructor initializer. For example: Bar::Bar() : foo() {} In this case, we need to list foo() as having been called, and the constructors for all of foo's BaseClasses. (These are returned as SgFunctionDeclarations, in the props vector)

Resolves the set of potential target functions for a member function call.

This function determines the possible function declarations that can be invoked during a member function call. It distinguishes between standard (non-virtual) calls and polymorphic (virtual) calls. For virtual calls, it delegates the resolution logic to solveVirtualFunctionCall to account for the class hierarchy and potential overrides. For non-virtual calls, it identifies the in-class declaration of the function.

Parameters
crtClassA pointer to the SgClassType representing the class context of the call.
classHierarchyA pointer to the ClassHierarchyWrapper used to navigate the class inheritance structure.
memberFunctionDeclarationA pointer to the S0MemberFunctionDeclaration representing the function call being analyzed.
polymorphicA boolean flag indicating whether to treat the call as a polymorphic dispatch.
includePureVirtualFuncA boolean flag indicating whether pure virtual functions should be included in the resulting set.
Returns
A vector of SgFunctionDeclaration pointers representing the set of all possible target functions.
Precondition
memberFunctionDeclaration must not be null.
Postcondition
The returned vector contains the resolved function declarations; if the call is polymorphic and the function is virtual, the vector is populated via solveVirtualFunctionCall.
Note
The function internally identifies the in-class declaration (the declaration within the class scope) even if the provided memberFunctionDeclaration is an out-of-class definition.

std::vector< SgFunctionDeclaration * > CallTargetSet::solveMemberFunctionPointerCall ( SgExpression * functionExp,
ClassHierarchyWrapper * classHierarchy )

Resolves the set of possible target functions for a member function pointer call.

This function performs call graph analysis to identify all potential function declarations that could be invoked via a member function pointer expression. It analyzes the expression to determine the base class of the object and the signature of the member function being called. The algorithm iterates through the members of the identified class definition and, for virtual or pure virtual functions, traverses the class hierarchy using the provided class hierarchy wrapper to find all overriding implementations in subclasses.

Parameters
functionExpThe expression representing the member function call (e.g., an arrow or dot operator expression). The left-hand side must represent a class type, and the right-hand side must represent a member function type.
classHierarchyA wrapper providing access to the class hierarchy, used to retrieve subclasses for polymorphic resolution.
Returns
A vector of SgFunctionDeclaration pointers, where each pointer represents a potential target function declaration that matches the call signature and is not a pure virtual function.
Precondition
functionExp must be an expression that is either an arrow star operator or a dot star operator.
The left-hand side operand of functionExp must have a valid type that is not a template type or a non-real type.
The right-hand side operand of functionExp must have a type that can be resolved to a member function type.
classHierarchy must not be null and must contain valid subclass information.
Postcondition
The returned vector contains all non-pure-virtual function declarations matching the signature found in the class hierarchy.
Note
The implementation currently uses string unparsing to compare function types, which is noted as a FIXME in the source code.
The function ignores template types to avoid complex call graph analysis within class templates.
