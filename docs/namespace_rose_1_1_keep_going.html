void Rose::KeepGoing::AppendToFile ( const std::string & filename,
const std::string & msg )

Append msg to a file.

Appends a message string to a specified file using a file-locking mechanism.

AppendToFile a message.

This function implements a thread-safe and process-safe append operation by utilizing a sidecar lock file (filename + ".lock"). It ensures that multiple processes attempting to write to the same file are synchronized using boost::interprocess::file_lock. The function creates the target file and the lock file using a touch operation if they do not exist, acquires a scoped lock, appends the message, flushes the stream, and finally removes the lock file.

Parameters
filenameThe path to the file where the message should be appended. If the string is empty, the function returns immediately without action.
msgThe string message to be appended to the end of the file.
Warning
The function relies on the existence of a lock file for the flock() mechanism to succeed. If the lock file cannot be created or accessed, the locking mechanism may fail.
If the file cannot be opened for appending, an error message is printed to std::cerr.
Precondition
The process must have sufficient filesystem permissions to create, write to, and delete files in the directory containing the target filename.
Postcondition
The message is appended to the file if the operation was successful.
The lock file (filename + ".lock") is removed from the filesystem upon completion of the function.
Note
This implementation uses a scoped lock to ensure that the file lock is automatically released when the scope is exited, even if an exception occurs during the file writing process.

Configures a global signal handler for specific system signals.

This function sets up a custom signal handler for SIGSEGV and SIGABRT signals. On non-MSVC platforms, it initializes a sigaction structure, clears the signal mask using sigemptyset, and applies the provided handler to the specified signals. On Windows platforms (detected via ifdef _MSC_VER), the function triggers an assertion as the "KeepGoing" feature is not yet implemented.

Parameters

Returns true if the signal handler was successfully configured.
Precondition

void Rose::KeepGoing::touch ( const std::string & pathname)

Updates the access and modification timestamps of a specified file.

This function attempts to perform a "touch" operation on the file located at the provided pathname, similar to the Unix touch utility. On Linux systems, it opens the file with write-only, create, and non-blocking flags and then utilizes the utime function to set the access and modification times to the current time. If the file does not exist, it will be created with mode 0666.

The implementation is wrapped in an ifdef linux directive, meaning the operation is only performed on Linux environments.

Parameters
pathnameThe string representing the filesystem path to the file that should be touched.
Warning
This function relies on Linux-specific system calls (open, utime). On non-Linux platforms, the function performs no operation. If the file cannot be opened or the utime call fails, an error message is printed to std::cerr.
Precondition
The pathname must be a valid string representing a path accessible by the current process.
Postcondition
If the function executes on a Linux system and succeeds, the access and modification timestamps of the file at pathname are updated to the current system time.
Note
If the 'verbose' flag is set to true, a success message is logged to std::clog upon successful completion.
