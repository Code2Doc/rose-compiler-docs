Overloads the stream insertion operator for the Hasher class.

This function provides a way to output the internal state or representation of a Rose::Combinatorics::Hasher object directly to an output stream. It delegates the actual formatting and printing logic to the Hasher::print method.

Parameters

Precondition

Postcondition
