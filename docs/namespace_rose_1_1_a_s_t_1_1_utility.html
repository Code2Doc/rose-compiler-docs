Verifies the structural integrity of parent pointers within an SgNode tree.

Check that all parent pointers in the specified subtree are correct.

This function does a traversal of the tree starting at the specified root and checks that each child points to the correct parent. If not, then an error message is printed and the function returns false. If you do not want error messages, then pass a closed output stream.

Safety: This function is not thread safe.

This function performs a depth-first traversal of the tree starting from the provided root node. It maintains a stack-based path of the current traversal to ensure that each node's parent pointer correctly points to the node that was the immediate predecessor in the traversal order. If a discrepancy is found between a node's reported parent and the actual node in the traversal path, the failure is logged to the provided output stream.

Parameters
rootA pointer to the root SgNode from which the traversal begins.
outA reference to an output stream where error details are written if a parent pointer inconsistency is detected.
Returns
True if all nodes in the tree have consistent parent pointers relative to the traversal path; false otherwise.
Precondition
The root node must be a valid, non-null pointer to an SgNode.
Postcondition
The function ensures that the internal path stack is empty upon completion.
Note
This function relies on the Traversal::forward mechanism to visit nodes. It uses an assertion-based approach to validate the state of the traversal path.

void Rose::AST::Utility::repairParentPointers ( SgNode * root)

Repairs the parent pointers of all nodes within an SgNode tree.

Set parent pointers based on child pointers in a subtree.

Traverses a subtree, and makes sure that each child points to its parent. No diagnostics are emitted; if you want diagnostics then you should call checkParentPointers instead. I.e., checking and repairing are two separate operations.

Caveats:

  • If root is null, then this function is a no-op.
  • The parent pointer for the node pointed to by root is not adjusted.
  • Parent pointers in other subtrees that might be reachable from non-tree pointers that cross from this subtree to another are not adjusted.

Safety: This function is not thread safe.

This function performs a depth-first traversal of the tree starting from the provided root node. During the traversal, it maintains a stack-based path of the current lineage. As the traversal enters a node (PRE order), the function assigns the current top of the path as the parent of the new node and then pushes the new node onto the path. As the traversal exits a node (POST order), it pops the node from the path. This ensures that every node in the tree correctly points to its actual parent in the hierarchy.

Parameters
rootA pointer to the root SgNode from which the traversal begins.
Precondition
root must not be a null pointer.
Postcondition
All nodes reachable from the root will have their parent pointers correctly updated to reflect the tree structure established during the traversal. The internal path stack will be empty upon completion.
Note
The function relies on the Traversal::forward utility to perform the tree walk. It uses assertions to ensure the integrity of the path stack during the PRE and POST order phases of the traversal.

Logs a detailed report of child-parent consistency failures within an AST path to an output stream.

This function iterates through a provided path of SgNode pointers to identify and report discrepancies between the parent-child relationships defined by the tree structure (the path) and the internal parent pointers stored within each SgNode. It traverses the path in reverse order, starting from the leaf-most node, and prints the node's class name, its address, its reported parent, and the expected parent based on the path sequence.

Parameters
pathA vector of SgNode pointers representing a sequence of nodes in the AST, where each element is expected to be the child of the preceding element.
outThe output stream where the failure report will be written.
Precondition
All elements in the path vector must be non-null.
Postcondition
The out stream will contain a formatted error message detailing the nodes in the path and any detected parent-child mismatches.
Note
The function uses an ASSERT_not_null check on each node in the path.
The function relies on the class_name() and stream insertion operator of SgNode.
