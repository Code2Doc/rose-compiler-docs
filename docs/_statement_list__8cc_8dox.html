void dbgList ( std::vector< SgStatement * > & vec)

Iterates through a vector of statements and prints their memory addresses and type names to standard error.

This function is a debugging utility designed to inspect a collection of SgStatement pointers. For each statement in the provided vector, the function attempts to identify the underlying SgLocatedNode. If the statement is an instance of SgExprStatement, the function retrieves the associated expression node to ensure the most specific node type is logged. The output sent to std::cerr includes the raw pointer address and the result of the typeid operator's name() method.

Parameters
vecA reference to a vector of SgStatement pointers to be inspected and logged.
Precondition
The vector vec must be initialized and contain valid SgStatement pointers.
Postcondition
The contents of the vector remain unchanged, but information regarding the elements is printed to the standard error stream.
Note
This function uses std::flush after each piece of information to ensure logs are visible even if the program crashes shortly after.
The unparsing logic is currently commented out in the implementation.
