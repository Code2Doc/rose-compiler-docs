Converts an integer representation of an operator side effect into a human-readable string.

Convert AstUtilInterface::OperatorSideEffect enum constant to a string.

This function maps specific 64-bit integer constants to their corresponding string descriptions representing different types of side effects (e.g., Modify, Read, Kill). It uses a switch-case mechanism to perform the lookup.

Parameters
iAn 64-bit integer representing the side effect type code.
Returns
A pointer to a constant character string representing the side effect name. Returns an empty string "" if the provided integer does not match any predefined side effect code.
Precondition
The input integer i should correspond to one of the defined side effect constants (0 through 8) to retrieve a meaningful description.
Postcondition
The returned string is a static string literal and should not be modified.
Note
The mapping is as follows: 0: Modify 1: Read 2: Kill 3: Call 4: Decl 5: Allocate 6: Free 7: CallInput 8: CallOutput

Generates a formatted string representing the side effect of an operator.

Convert AstUtilInterface::OperatorSideEffect enum constant to a string.

This function retrieves a side effect string for a given operator ID and optionally removes a specified prefix from the beginning of the resulting string. It first calls an overloaded version of OperatorSideEffect(int64_t) to obtain the base string. If the base string is empty, it constructs a fallback string using the format "(AstUtilInterface::OperatorSideEffect)" followed by the string representation of the ID. Finally, if the string starts with the provided strip prefix, that prefix is removed.

Parameters
iThe unique identifier for the operator.
stripA string representing the prefix to be removed from the start of the generated side effect string, if present.
Returns
A string containing the formatted side effect information, potentially with the specified prefix stripped away.
Precondition
The input parameter i should be a valid operator identifier.
Postcondition
The returned string will not start with the contents of strip if strip was a prefix of the original side effect string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
