bool Rose::KeepGoing::Backend::UseOriginalInputFile ( SgFile * project)

Determines whether the original input file should be used based on the unparsed output status and error states.

This function evaluates the necessity of reverting to the original input file by checking two primary conditions. First, it checks if an unparsed output filename has failed to be generated. Second, it checks if there are any active errors in the frontend, midend, unparser, or backend compiler stages, provided that the "keep going" flag is enabled in the project settings. This logic is used to decide if the backend should attempt to proceed with the original source when the transformation/unparsing pipeline encounters issues.

Parameters
fileA pointer to the SgFile object representing the file being processed.
Returns
True if the original input file should be used (either because no unparsed output was generated or because errors occurred while the "keep going" option is active); false otherwise.
Precondition
file must not be NULL.
Postcondition
The state of the SgFile object remains unchanged.
Note
This function relies on the error state of the project and the specific file object. The logic is subject to the if configuration of the build.
