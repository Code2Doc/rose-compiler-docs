void resetTemplateNames ( SgNode * node)

Resets the template names within the provided AST node or project.

Sets names of template classes (calls custom traversal).

This function iterates through template instantiation declarations, function declarations, and member function declarations to reset their associated template names. The implementation utilizes a memory pool traversal strategy via ResetTemplateNamesOnMemoryPool to efficiently target relevant IR nodes. The traversal is specifically optimized to visit only the subset of nodes related to template instantiations, which improves performance by avoiding a full memory pool scan.

Parameters
nodeA pointer to the SgNode that serves as the starting point for the reset operation. The function checks if this node is part of a valid AST (by checking for a non-null parent) or if it is an SgProject node before proceeding with the traversal.
Precondition
The node parameter should ideally be part of a valid AST (i.e., have a non-null parent) or be an instance of SgProject.
Postcondition
If the node is valid, the template names within the relevant template instantiation nodes in the memory pool are reset.
Note
If the provided node is detected as an AST fragment not associated with a primary AST (no parent and not an SgProject), the function prints a warning to stdout and skips the template handling process.
The implementation uses if and else preprocessor directives to toggle between different traversal strategies, currently favoring a targeted memory pool traversal of specific template instantiation classes for better performance.
