Finds the first iterator in an AddressMap that satisfies the given constraints.

This function searches through the provided AddressMap to find the lower bound of nodes that satisfy the specified AddressMapConstraints. The search logic varies depending on whether an anchor is used for matching. If useAnchor is true and the constraints are anchored, the function validates that the constraint's interval is within the anchor's bounds and attempts to find a lower bound starting from the anchor's least address. If no anchor is used or the constraints are not anchored, the function evaluates the least address constraint to find the appropriate starting iterator.

Parameters
amapThe AddressMap to be searched.
cThe constraints applied to the search process.
useAnchorA boolean flag indicating whether to utilize the anchor information within the constraints for the search.
minAddrAn output parameter that stores the minimum address found that satisfies the search criteria.
Returns
An iterator pointing to the first node in the AddressMap that meets the constraints, or amap.nodes().end() if no such node exists or if the constraints are inherently unsatisfiable.
Precondition
The AddressMap amap must be initialized and valid.
Postcondition
The minAddr parameter will be updated with the least address of the found node or the least address of the constraint, depending on the search path taken.
Note
If the AddressMap is empty or the constraints never match, the function immediately returns the end iterator.

Performs a backward search through an AddressMap to find a range of nodes satisfying specific constraints.

This function implements a reverse-direction matching algorithm. It starts by establishing a search window using lower and upper bound constraints. It then iterates backwards from the upper bound, checking for constraint satisfaction, segment continuity, and size limits. The algorithm is designed to handle complex matching scenarios including anchored constraints, contiguous memory requirements, and non-address-based constraints.

Parameters

Returns

Performs a forward-direction matching of address map nodes against specified constraints.

This function attempts to find a range of nodes and an address interval within the provided AddressMap that satisfies the given AddressMapConstraints. The algorithm first establishes a search window by determining the lower and upper bounds of the addresses based on the constraints. It then refines the starting iterator by advancing it until all non-address constraints are satisfied. If the MATCH_CONTIGUOUS flag is set or non-address constraints are present, the function iterates forward through the nodes to extend the match, checking for segment boundaries, gaps, and the total element limit defined in the constraints.

Parameters

cThe constraints to be applied during the matching process, including address bounds, limits, and anchoring requirements.
flagsBitmask of MatchFlags that control the matching behavior, such as MATCH_CONTIGUOUS or MATCH_WHOLE.
Returns
A MatchedConstraints object containing the resulting iterator range of nodes and the calculated address interval. If no match is found, the returned range is empty.
Precondition
The amap parameter must be a valid, initialized AddressMap.
Postcondition
The returned MatchedConstraints object will contain a valid interval and iterator range that satisfies the provided constraints if a match exists.
Note
