Callback function triggered when an XML element ends.

This function serves as a wrapper or callback handler for XML parsing events. It extracts an XMLHandler pointer from the provided user data and invokes the endElement method of that handler, passing the name of the element that has just closed.

Parameters
user_dataA pointer to the user-defined context, which must be a valid pointer to an XMLHandler instance.
nameA pointer to a null-terminated string representing the name of the XML element being closed.
Precondition
user_data must be a non-null pointer to an object of type XMLHandler.
Postcondition
The endElement method of the retrieved XMLHandler is called with the provided name.

Callback function triggered when a start element is encountered during XML parsing.

This function serves as a wrapper or callback implementation designed to interface with an XML parser (such as libxml2). It extracts an XMLHandler pointer from the provided user_data and delegates the start element event to the handler's startElement method.

Parameters
user_dataA pointer to the user-defined context, which must be a valid pointer to an XMLHandler object.
nameThe name of the element being started, represented as a pointer to a null-terminated string of XML characters.
attrsAn array of pointers to null-terminated strings representing the attributes of the element.
Precondition
user_data must not be NULL and must point to a valid instance of XMLHandler.
Postcondition
The startElement method of the retrieved XMLHandler is invoked with the provided name and attributes.
Note
This function assumes that the casting of user_data to XMLHandler is safe and that the XMLHandler object is properly initialized.
