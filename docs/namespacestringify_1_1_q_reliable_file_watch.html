Converts a numeric state identifier into its corresponding string representation.

Convert QReliableFileWatch::State enum constant to a string.

This function maps specific 64-bit integer values to human-readable string literals representing the current state of a file watch operation. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the state code to be converted.
Returns
A pointer to a constant character string representing the state: "Clean" for 0, "Recent" for 1, "Duplicate" for 2, or an empty string "" for any other value.
Precondition
The input parameter i should be one of the defined state constants (0, 1, or 2) to receive a meaningful string.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function does not handle any values outside the defined range of 0 to 2 with specific labels, returning an empty string instead.

Generates a formatted state string for a given identifier, optionally stripping a prefix.

Convert QReliableFileWatch::State enum constant to a string.

This function retrieves a string representation of the state associated with the integer identifier i by calling an overloaded State(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(QReliableFileWatch::State)" followed by the string representation of i. Additionally, if the resulting string starts with the provided strip string, that prefix is removed from the beginning of the string.

Parameters

stripA string representing the prefix to be removed from the start of the generated state string if it exists.
Returns
A string representing the processed state.
Precondition

Postcondition
The returned string will not contain the strip prefix if the original string started with it.
Note
