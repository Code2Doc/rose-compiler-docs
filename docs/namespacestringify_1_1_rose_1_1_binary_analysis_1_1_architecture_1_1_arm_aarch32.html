Retrieves and optionally strips a prefix from the instruction set string representation.

Convert Rose::BinaryAnalysis::Architecture::ArmAarch32::InstructionSet enum constant to a string.

This function attempts to retrieve a string representation of an instruction set associated with a given identifier. It first calls the single-parameter version of InstructionSet(i). If the resulting string is empty, it constructs a fallback string containing a specific architecture namespace and the string representation of the identifier. Finally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the instruction set.
stripA string representing the prefix to be removed from the start of the retrieved instruction set string, if present.
Returns
A string containing the instruction set name, potentially modified by the removal of the strip prefix or the application of a fallback format.
Precondition
The identifier i should correspond to a valid instruction set mapping if a non-fallback string is desired.
Postcondition
The returned string will not start with the content of the strip parameter if that content was present at the start of the original string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
