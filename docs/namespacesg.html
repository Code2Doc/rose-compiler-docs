implements the ancestor search

Traverses up the syntax graph hierarchy to find the first ancestor of a specific type.

see comments for AncestorTypeFinder

This function performs an upward traversal of the syntax graph starting from the parent of the provided node n. It utilizes a dispatch mechanism via sg::dispatch and a specialized AncestorTypeFinder to iteratively check each ancestor in the hierarchy. The traversal continues until either an ancestor of type AncestorNode is found or the root of the graph (a null parent) is reached.

Parameters
nThe current syntax graph node from which the upward traversal begins.
Returns
A pointer to the first ancestor of type AncestorNode found in the hierarchy. Returns nullptr if no ancestor of the specified type is encountered before reaching the end of the graph.
Precondition
The node n must be a valid, non-null reference to a QualSgNode.
Postcondition
The function returns a pointer to an existing node in the graph or nullptr.
Note
The implementation relies on the sg::dispatch mechanism and the AncestorTypeFinder template class to handle type-specific logic during the traversal.
