std::tuple< bool, std::string, size_t > anonymous__namespace_02rose__attributes__list_8C_03::extractAdaComment ( const std::string & line)

Extracts an Ada-style comment and its position from a given string line.

This function scans a single line of text for the Ada comment delimiter "--". If the delimiter is found, the function identifies the start of the comment, captures the substring from the delimiter to the end of the line, and records the starting index. If no delimiter is found, it returns a tuple indicating no comment was found, with the substring being empty and the position set to the end of the string.

Parameters
lineThe input string representing a single line of text to be parsed.
Returns
A tuple containing three elements:
  • A boolean indicating whether a comment was found (true if "--" exists).
  • A string containing the extracted comment (including the "--" prefix) or an empty string if no comment was found.
  • A size_t representing the starting position of the comment in the original string, or the length of the string if no comment was found.
Precondition
The input string line should be a valid, initialized std::string.
Postcondition
The returned tuple contains the parsed components, and the string returned in the tuple is a valid substring of the input.
Note
The implementation uses std::string::find to locate the delimiter and includes a safety check to prevent std::string::substr from throwing an out_of_range exception when the delimiter is not present.

Recognizes and transforms "if" patterns within "end if" and "elsif" Ada-style constructs.

This function is designed to preprocess Ada-style conditional termination syntax to be compatible with C++-style identifier expectations. It specifically looks for the sequence "end if" (case-insensitive) following an "end" identifier. If the function detects that the current identifier is "end" and is followed by "if", it appends " if" to the identifier and updates the tracking position. This is primarily used during the translation or preparation of Ada code for C++ environments.

Parameters
lineThe current line of source code being processed.
cppIndentifierA reference to a string representing the current identifier being processed. This string is modified in-place if an "if" pattern is recognized.
lastCharA reference to an integer tracking the index of the last processed character in the line. This is updated if the transformation occurs.
Precondition
The function assumes that the input string line contains valid source text and that lastChar represents a valid index or the boundary of the previously processed segment.
Postcondition
If the "end if" pattern is detected, cppIndentifier will be updated to include " if" and lastChar will be updated to the position immediately following the "if" substring.
Note
The function only performs transformations if SageInterface::is_Ada_language() returns true. The identifier is converted to lowercase using boost::to_lower before the check is performed.
