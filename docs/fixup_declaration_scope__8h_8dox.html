void fixupAstDeclarationScope ( SgNode * node)

Ensures consistency in the scope assignment of declaration statements.

Enforces consistency in the scope assignments of AST declarations.

This function is designed to enforce consistency in how defining and non-defining declarations (such as friend declarations) have their scopes set within the AST. It traverses the memory pool to identify groups of related declarations and verifies that all associated declarations in a set share the same correct scope. It also serves as a mechanism to detect and warn about discrepancies in scope assignment that might arise from re-entrant namespace definitions or global scope issues across different files.

Parameters
nodeA pointer to the SgNode being processed during the traversal.
Precondition
The input node must not be NULL.
The first non-defining declaration in any identified set must not be NULL.
The first non-defining declaration must have a valid scope.
Postcondition
The scopes of the identified declaration sets are verified for consistency relative to the first non-defining declaration in each set.
Note
The function utilizes a FixupAstDeclarationScope traversal object that operates on the memory pool to ensure all hidden declarations (e.g., within SgClassType) are visited.
Warnings are printed to the console if a discrepancy is detected between the expected scope and the actual scope of an associated declaration.
The function uses ROSE_ASSERT to validate the integrity of the declaration pointers and their associated scopes.

This function is designed to address and rectify potential inconsistencies in how defining and non-defining declarations (specifically those associated with friend declarations) have their scopes set within the Abstract Syntax Tree (AST). It utilizes a specialized traversal, FixupAstDeclarationScope, to visit nodes within the memory pool, including those hidden within types like SgClassType.

The implementation iterates through a map of sets of declarations. For each group of declarations associated with a primary non-defining declaration, the function verifies that all associated declarations share the same correct scope. If a discrepancy is found between the scope of an associated declaration and the scope of the primary declaration, a warning is issued.

If an associated declaration's scope differs from the correct scope, a warning is logged via mprintf if SgProject::get_verbose() is greater than 0.
