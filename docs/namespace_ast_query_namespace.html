Merges the contents of one container into another.

This function appends all elements from the source container mergeTo to the end of the destination container mergeWith. The implementation utilizes the insert member function of the Rose_STL_Container class, specifically using a range-based insertion from the beginning to the end of the mergeTo container.

Parameters
mergeWithA reference to the destination container that will receive the elements from the source container.
mergeToThe source container containing the elements to be appended to mergeWith.
Precondition
The mergeWith container must be a valid, initialized instance of Rose_STL_Container<int>.
Postcondition
The mergeWith container will contain all its original elements followed by all elements that were present in mergeTo at the time of the call.
Note
The mergeTo container is passed by value, meaning a copy of the container is created during the function call.

Queries a subtree of the AST based on a functional predicate and specified depth.

This function performs a traversal of a subtree starting from a given node to identify nodes that satisfy a specific functional predicate. The scope of the search is determined by the defineQueryType, which can be configured to traverse all descendants or only the immediate children of the starting node. The implementation utilizes an AstQuery object to manage the traversal and application of the nodeFunc predicate. For the AllNodes case, a standard traversal is performed using the provided treeTraversalOrder. For the ChildrenOnly case, the function manually iterates through the successors contained within the node's traversal successor container.

Parameters
nodeA pointer to the starting SgNode from which the subtree query begins.
nodeFuncA functional object used as a predicate to determine if a node matches the query criteria.
defineQueryTypeSpecifies the depth of the query (e.g., AllNodes or ChildrenOnly). Defaults to AstQueryNamespace::AllNodes.
treeTraversalOrderThe order in which the tree is traversed (e.g., preorder). Defaults to preorder.
Returns
A collection of nodes (of type NodeFunctional::result_type) that satisfy the provided nodeFunc predicate within the specified subtree scope.
Warning
The function will call ROSE_ABORT() and terminate the program if defineQueryType is set to AstQueryNamespace::ExtractTypes or if an unrecognized query type is encountered.
Precondition
node must not be NULL.
Postcondition
The function returns a list of nodes matching the criteria without modifying the underlying AST structure.
Note
The implementation uses if 0 blocks for debugging, which are excluded from the compiled logic.
