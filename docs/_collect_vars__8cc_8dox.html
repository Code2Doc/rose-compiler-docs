void dump ( const ASTtools::VarSymSet_t & V,
const std::string & tag )

Prints the contents of a variable symbol set to the standard error stream with a provided tag.

This function serves as a debugging utility to output the string representation of an ASTtools::VarSymSet_t object. The output is formatted as tag{contents}. The function checks the global Outliner::enable_debug flag before performing any I/O operations to minimize performance overhead during normal execution.

Parameters
VThe variable symbol set to be dumped.
tagA string label used to identify the context of the dumped data in the output stream.
Precondition
The ASTtools::toString function must be able to process the provided V.
Postcondition
If Outliner::enable_debug is true, the formatted string is sent to std::cerr.
Note
This function relies on the ASTtools::toString utility for the serialization of the symbol set.
