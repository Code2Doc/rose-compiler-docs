Retrieves a constant reference to the predefined set of exception throw kinds.

Return all SgThrowOp::e_throw_kind member values as a vector.

This function provides access to a static collection of integer values representing the different types of throw kinds available in the system. The values are encapsulated within a static std::vector to ensure they are initialized only once and persist for the lifetime of the program.

Returns
A constant reference to a std::vector containing the int64_t values {0, 1, 2}.
Precondition
None.
Postcondition
The returned reference points to a valid, immutable vector of int64_t.
Note
The implementation uses a static local variable to ensure thread-safe initialization (in C++11 and later) and to avoid repeated allocations.

Converts a throw kind integer identifier into its corresponding string representation.

Convert SgThrowOp::e_throw_kind enum constant to a string.

This function maps specific 64-bit integer values to human-readable string literals representing different types of throw operations within the SgThrowOp context. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the throw kind identifier.
Returns
A pointer to a constant character string representing the throw kind. Returns "unknown_throw" for 0, "throw_expression" for 1, "rethrow" for 2, and an empty string "" for any other value.
Precondition
The input parameter i should be a valid identifier within the expected range of throw kinds.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.

Generates a formatted string representing the kind of an exception throw.

Convert SgThrowOp::e_throw_kind enum constant to a string.

This function retrieves a string representation of an exception kind using an overloaded version of e_throw_kind. If the retrieved string is empty, it constructs a fallback string in the format "(SgThrowOp::e_throw_kind)" followed by the integer value. Additionally, the function attempts to strip a specified prefix from the resulting string if the string starts with the provided strip parameter.

Parameters
iThe 64-bit integer identifier representing the exception kind.
stripA string containing the prefix to be removed from the start of the generated exception kind string.
Returns
A string representing the formatted exception kind, potentially with a prefix removed.
Precondition
The parameter i should correspond to a valid exception kind identifier.
Postcondition
The returned string will not contain the strip prefix if the original string started with it.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
