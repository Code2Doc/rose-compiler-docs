ROSE_DLL_API void Rose::AST::IO::clear ( )

Empties the memory pool of all nodes.

Clears all allocated nodes and memory pools.

This function performs a global cleanup of the ROSE environment by invoking the DeleteAllNode mechanism to traverse and delete all existing nodes in the system. Following the node deletion, it explicitly clears all memory pools managed by the AST_FILE_IO component to ensure no memory leaks persist.

Precondition
The system should be in a state where no further operations on existing AST nodes are required, as all nodes will be destroyed.
Postcondition
All nodes managed by DeleteAllNode are deleted, and all AST_FILE_IO memory pools are emptied.
Warning
Calling this function invalidates all existing pointers to nodes previously managed by the system. Use with extreme caution in multithreaded environments.

void Rose::AST::IO::merge ( SgProject * project)

Performs sharing of AST nodes followed by linking accross translation units.

Merges the AST nodes within a given SgProject by sharing, pruning, and linking.

Parameters
project

This function is mainly used after loading ASTs from files. It is used by the command line option: -rose:ast:read and -rose:ast:merge. It simply calls three functions in sequence: Rose::AST::share, Rose::AST::prune, and Rose::AST::link. It also provides statistics if Rose is in verbose > 0.

This function performs a structural optimization of the Abstract Syntax Tree (AST) contained within the provided SgProject. The process involves three primary stages:

  1. Sharing: Uses Rose::AST::IO::share to identify and unify redundant nodes.
  2. Pruning: Uses Rose::AST::IO::prune to remove unnecessary or unreachable nodes.
  3. Linking: Uses Rose::AST::IO::link to reconstruct the necessary connections between the remaining nodes.

The function tracks the number of nodes before and after the operation to calculate various performance metrics, including compression percentage, space savings, merge factor, and merge efficiency. If ifdef ENABLE_plot_links is active, DOT files are generated to visualize the AST state at each stage. If ifdef TAKE_MEMPOOL_SNAPSHOT is active, memory pool snapshots are recorded.

Parameters
projectA pointer to the SgProject instance to be merged and optimized.
Precondition
The project pointer must be valid and not null.
Postcondition
The SgProject is modified in-place; redundant nodes are removed, and the AST structure is updated to reflect the merged state.
Note
The efficiency calculation uses a multiplier based on the number of files in the project to account for the complexity of merging multiple files.
If ifdef DEBUG__ROSE_AST_MERGE is defined, the function prints debugging information regarding the project pointer address.

Deletes a collection of SgNode pointers in a top-down order to prevent double deletion.

This function performs a breadth-first traversal of a subgraph defined by a list of nodes to ensure that parent nodes are deleted before their descendants. This prevents the "double delete" problem that occurs when a child node is deleted via its own pointer before its parent node is processed. The algorithm first identifies the root nodes within the provided set (nodes whose parents are not present in the deletion list) and then iteratively processes each level of the hierarchy.

This function is mainly used when two or more translation units are merged together. Particularly, the ASTs of header files is duplicated when included from different translation-units.

This function implements a sharing mechanism within an SgProject by utilizing the NameBasedSharing class. It applies a transformation that identifies identical subgraphs or nodes based on their names and replaces duplicates with references to a single shared instance to reduce memory footprint and complexity.

Parameters
projectA pointer to the SgProject instance upon which the sharing operation will be performed.
Precondition
The provided SgProject pointer must not be null.
Postcondition
The SgProject is modified in-place such that nodes with identical names are shared via the NameBasedSharing algorithm.
