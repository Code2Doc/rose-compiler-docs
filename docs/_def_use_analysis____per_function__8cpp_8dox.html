Recursively populates a worklist and a debug path starting from a source node.

This function performs a depth-first traversal of the Control Flow Graph (CFG) starting from the provided source node. It checks if the source node is already present in the worklist to prevent infinite recursion in the presence of cycles. If the node is not present, it is added to both the worklist and the debug_path, and the function then recursively visits all successor nodes reachable via the outgoing edges of the current node.

Parameters
worklistA reference to a vector of FilteredCFGNode<IsDFAFilter> that acts as the primary collection of visited nodes.
debug_pathA reference to a vector of FilteredCFGNode<IsDFAFilter> used to track the sequence of nodes visited during traversal.
sourceThe starting node from which the traversal begins.
Precondition
The source node must be a valid FilteredCFGNode<IsDFAFilter> instance.
Postcondition
The worklist and debug_path will contain the source node and all reachable nodes from the source node that were not previously in the worklist.
Note
This function uses a recursive approach, which may lead to stack overflow for extremely deep CFGs.
