SgNode * popBuiltAST ( )

Removes and returns the top node from the built AST stack.

This function retrieves the most recently added node from the internal stack of built AST nodes maintained by the csharp_translator. It utilizes the pop template function from the csharp_translator namespace to extract an SgNode pointer from the nodes container.

Precondition
The csharp_translator::nodes container must not be empty.
Postcondition
The size of the csharp_translator::nodes container is decreased by one.
Returns
A pointer to the SgNode that was at the top of the stack.
