void Rose::KeepGoing::Frontend::SecondaryPass::SignalHandler ( int sig)

Handles incoming system signals during the secondary pass of frontend processing.

This function acts as a signal handler to intercept specific system signals. It logs a warning message to the standard output containing the signal number and its human-readable description (on non-MSVC platforms).

The implementation uses platform-specific logic: On non-MSVC platforms, it attempts to perform a long jump back to a predefined jump target (Frontend::SecondaryPass::jmp_target) using siglongjmp to abort the current execution flow. On MSVC platforms, it triggers a ROSE_ASSERT failure because the "KeepGoing" feature is not currently supported on Windows.

Parameters
sigThe integer signal number received from the operating system.
Warning
This function relies on a pre-established siglongjmp target on non-MSVC systems. If the target is not valid, the program may terminate unexpectedly.
Precondition
The signal handler must be registered via signal() or sigaction() before the signal is received. On non-MSVC platforms, Frontend::SecondaryPass::jmp_target must have been initialized via setjmp.
Postcondition
On non-MSVC platforms, the execution flow is redirected to the previously saved environment at Frontend::SecondaryPass::jmp_target. On MSVC platforms, the program will trigger an assertion failure.
