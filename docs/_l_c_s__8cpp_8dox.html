Recursively reconstructs the Longest Common Subsequence (LCS) path to identify differences between two sequences.

This function implements a backtracking algorithm on a pre-computed dynamic programming table (matrix C) to find the sequence of operations (matches, deletions, or insertions) that constitute the difference between two sequences of SgNode pointers, A and B. It traverses the matrix from the given indices (i, j) back to the origin (0, 0), identifying whether the current elements match or if a gap exists.

Parameters
CA 2D scoped array representing the dynamic programming table where C[i][j] stores the length of the LCS for prefixes A[1..i] and B[1..j].
AA vector-like structure containing SgNode pointers, indexed starting from one.
BA vector-like structure containing SgNode pointers, indexed starting from one.
iThe current row index in the DP table C, corresponding to the element in sequence A.
jThe current column index in the DP table C, corresponding to the element in sequence B.
resultA vector of pairs of SgNode pointers that will be populated with the reconstructed difference. A pair (A[i], B[j]) represents a match, (NULL, B[j]) represents an insertion from B, and (A[i], NULL) represents a deletion from A.
Precondition
The indices i and j must be within the bounds of the dimensions of matrix C and the respective sequences A and B.
Postcondition
The result vector will contain the sequence of SgNode pairs representing the alignment/difference between the sequences A and B, ordered from the start of the sequences to the current indices.
Note
This function uses recursion to traverse the DP table. For very large sequences, this may lead to stack overflow.
The function relies on an external function isEqual() to compare SgNode pointers.

Recursively computes and prints the differences between two sequences of SgNode pointers.

This function implements a recursive approach to traverse a dynamic programming table (matrix C) to reconstruct the edit path between two sequences A and B. It identifies insertions and deletions by comparing the values in the cost matrix C. During the traversal, it prints the instructions associated with the differences to standard output and records the indices of the added and removed instructions in the provided vectors.

Parameters
CA 2D scoped array representing the dynamic programming cost matrix used to store edit distances.
AA vector-like structure containing SgNode pointers, indexed starting from one, representing the first sequence.
BA vector-like structure containing SgNode pointers, indexed starting from one, representing the second sequence.
iThe current row index in the cost matrix C and the current position in sequence A.
jThe current column index in the cost matrix C and the current position in sequence B.
addInstrA vector of integers used to store the indices of instructions added from sequence B.
minusInstrA vector of integers used to store the indices of instructions removed from sequence or present in sequence A.
Precondition
The indices i and j must be within the bounds of the dimensions of matrix C and the sequences A and B.
The elements in A and B at indices i and j must be castable to SgAsmInstruction* for unparsing.
Postcondition
The function populates addInstr and minusInstr with the indices of the differences found.
The differences (additions and deletions) are printed to std::cout in a formatted manner.
Note
The function uses recursion to backtrack from the end of the sequences to the beginning.
The function relies on an external function isEqual to compare SgNode pointers.
The function relies on an external function unparseInstrFast to convert SgAsmInstruction to a string.
