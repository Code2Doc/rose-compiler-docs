This function takes a string and returns a new string with all whitespace characters (as defined by the isspace function) removed from both the beginning and the end of the input. The implementation first identifies trailing spaces by iterating backwards from the end of the string and erases them, then identifies leading spaces by iterating forwards from the start and erases them.

Parameters
sThe input string to be trimmed.
Returns
A new string containing the content of s with leading and trailing whitespace removed. If the input string is empty, the original empty string is returned.
Precondition
The input string s should be a valid std::string object.
Postcondition
The returned string contains no whitespace characters at its start or end, unless the string consists entirely of whitespace, in which case an empty string is returned.
Note
The function uses ROSE_ASSERT to validate internal state during the trailing space removal process.
