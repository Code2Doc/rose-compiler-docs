Performs a deep structural equality comparison between two expression trees.

Are two expressions equal (using a deep comparison)?

This function recursively traverses two SgExpression trees to determine if they are structurally identical. It compares the variant types of the nodes and then descends into the children of the nodes (such as operands in binary/unary operators, elements in expression lists, or arguments in function calls). For certain node types, such as variable references or function references, equality is determined by comparing the underlying declarations. For value expressions, it compares the literal values.

Parameters
aA pointer to the first SgExpression tree to compare.
bA pointer to the second SgExpression tree to compare.
Returns
True if the two expression trees are structurally equivalent and have matching values/declarations where applicable; false otherwise.
Precondition
The pointers a and b should ideally not be null, although the function contains logic for certain null-like expression types.
Postcondition
The structural integrity of the expression trees remains unchanged.
Note
The function uses a recursive approach, which may lead to stack overflow for extremely deep expression trees.
Certain expression types like SgDeleteExp and SgNewExp are explicitly not considered equal, and SgConstructorInitializer is currently marked with a FIXME.
The implementation uses a define macro named HANDLEVAL to reduce boilerplate when comparing various SgValueExp types.
