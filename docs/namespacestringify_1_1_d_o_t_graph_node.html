Returns

Precondition

Postcondition

Maps an integer ID to its corresponding DOT shape type string representation.

Convert DOTGraphNode::DOTShapeTypes enum constant to a string.

This function performs a lookup using a switch statement to convert a 64-bit integer identifier into a human-readable string representing a specific shape type used in DOT graph nodes. The mapping includes standard shapes like polygon and ellipse, as well as internal sentinel values.

Parameters
iThe 64-bit integer identifier representing the DOT shape type.
Returns
A pointer to a constant character string representing the shape type. Returns "UnknownListElementDOTShapeTypes" for 0, specific shape names for valid IDs, "END_OF_NODE_TYPE_LIST_DOTShapeTypes" for 5, and an empty string for any other value.
Precondition
The input parameter i should correspond to a valid identifier within the defined range of DOT shape types.
Postcondition
The returned string is a static constant and does not require manual memory management by the caller.
Note
This function is primarily used for serialization and debugging purposes when converting numeric IDs back to their string labels.

Generates a formatted string representing DOT shape types with an optional prefix removal.

Convert DOTGraphNode::DOTShapeTypes enum constant to a string.

This function retrieves a string representation of DOT shape types associated with a given identifier. It first calls the overloaded DOTShapeTypes(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(DOTGraphNode::DOTShapeTypes)i". Additionally, if the resulting string starts with the specified 'strip' prefix, that prefix is removed from the beginning of the string.

Parameters

Returns
A string containing the formatted DOT shape type information, potentially with the specified prefix stripped.
Precondition

Postcondition
