SgUsingDeclarationStatement * SageBuilderX::buildUsingDeclaration ( SgNamespaceDeclarationStatement * nsp)

Creates a new using declaration statement associated with a namespace declaration.

This function instantiates a new SgUsingDeclarationStatement object. The newly created statement is initialized with a pointer to the provided namespace declaration, effectively linking the using declaration to its target namespace.

Parameters
nspA pointer to the SgNamespaceDeclarationStatement that the using declaration will refer to.
Returns
A pointer to the newly allocated SgUsingDeclarationStatement object.
Precondition
nsp must not be NULL. The function uses ROSE_ASSERT to validate this.
Postcondition
A new SgUsingDeclarationStatement is allocated on the heap and linked to the provided nsp.
Note
The scope of the newly created statement is not explicitly set within this function, as the set_scope call is currently commented out.
