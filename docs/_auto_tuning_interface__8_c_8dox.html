Measures the elapsed wall-clock time since the first call to the function.

This function measures the time interval between the initial invocation of the function and the current moment. It utilizes the gettimeofday system call to capture high-resolution timestamps. On the very first call, the function initializes a static reference point using the current seconds and microseconds, and returns 0.0. On all subsequent calls, it calculates the difference between the current time and the stored start time, converting the microsecond component into a fractional second.

Returns
The elapsed time in seconds as a double-precision floating-point number.
Precondition
The system must support the gettimeofday function and the timeval structure.
Postcondition
The function maintains a static internal state representing the start time, which persists across multiple calls within the same execution lifetime.
Note
The precision of the returned value depends on the resolution of the underlying system clock provided by gettimeofday.
This function is not thread-safe due to the use of static variables for tracking the start time.
