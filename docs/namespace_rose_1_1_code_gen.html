bool Rose::CodeGen::ignore ( const std::string & name)

Determines whether a given string name should be ignored based on specific prefix criteria.

This function evaluates a string to decide if it meets the criteria for being ignored. A name is considered ignorable if it is an empty string, or if it starts with the prefix "__builtin", or if it starts with the prefix "__frontend_specific_variable_to_provide_header_file_path". This is typically used during symbol processing or name resolution to skip internal or compiler-specific identifiers.

Parameters
nameThe string identifier to be checked against the ignore criteria.
Returns
True if the name is empty or matches one of the specified ignore prefixes; false otherwise.
Precondition
The input parameter name should be a valid std::string object.
Postcondition
The function does not modify the input string.
Note
This function uses std::string::find to check for prefixes, which effectively checks if the substring starts at index 0.

bool Rose::CodeGen::ignore ( SgScopeStatement * scope)

Determines whether a given scope statement should be ignored based on its type.

This function checks if the provided scope statement represents a basic block. It serves as a predicate to identify if the scope is of a type that does not require further processing or traversal within the current context.

Parameters
scopeA pointer to the SgScopeStatement to be evaluated.
Returns
True if the scope is identified as a basic block via isSgBasicBlock, false otherwise.
Precondition
The scope pointer should be a valid pointer to an SgScopeStatement object.
Postcondition
The return value indicates the basic block status of the input scope.
