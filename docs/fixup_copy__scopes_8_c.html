void outputMap ( SgCopyHelp & help)

Prints the contents of the copied node map within an SgCopyHelp object to the standard output.

This function iterates through the map of copied nodes stored in the provided SgCopyHelp instance. For each entry in the map, it checks if the node has a valid start of construction and if that construction point is not frontend-specific. If these conditions are met, it prints the entry index, the memory addresses of the original and copied nodes, and the class name of the original node. The function also performs a runtime assertion to ensure that the variant types of the original and copied nodes are identical.

Parameters
helpA reference to an SgCopyHelp object containing the map of copied nodes to be printed.
Precondition
The help object must contain a valid, traversable map of copied nodes.
Postcondition
The contents of the map (filtered by specific criteria) are printed to stdout.
Note
The function uses printf for output.
The function uses ROSE_ASSERT to validate type consistency during iteration.

void resetVariableDefinitionSupport ( const SgInitializedName * originalInitializedName,
SgInitializedName * copyInitializedName,
SgDeclarationStatement * targetDeclaration )

Resets the variable definition support for a copied initialized name.

This function serves as a supporting utility for the SgInitializedName::fixupCopy_scopes() member function. It handles the reconfiguration of declaration pointers when an initialized name is being copied or updated, ensuring that the underlying declarations (such as variable definitions, enums, or function declarations) are correctly mapped to their new or target counterparts.

The implementation uses a switch statement to branch based on the variant type of the original declaration. For SgVariableDefinition, it constructs a new SgVariableDefinition, copies bitfield information, and replicates the start and end of construction file information. For other types like SgEnumDeclaration or various function declaration types, it updates the declaration pointer to the provided targetDeclaration if the pointers match.

Parameters
originalInitializedNameThe initialized name in the original scope whose declaration needs to be processed.
copyInitializedNameThe initialized name being created or copied that requires its declaration pointer updated.
targetDeclarationA pointer to the new declaration statement to be used if the original declaration is an existing type (like Enum or Function) that has already been copied.
Precondition
copyInitializedName must not be NULL.
copyInitializedName->get_declptr() must not be NULL.
If the original declaration is a SgVariableDefinition, targetDeclaration must be NULL.
If the original declaration is an SgEnumDeclaration, SgTemplateFunctionDeclaration, SgTemplateMemberFunctionDeclaration, SgFunctionDeclaration, SgMemberFunction FunctionDeclaration, SgTemplateInstantiationFunctionDecl, SgTemplateInstantiationMemberFunctionDecl, SgProcedureHeaderStatement, or SgProgramHeaderStatement, targetDeclaration must not be NULL.
Postcondition
If the original declaration is a SgVariableDefinition, a new SgVariableDefinition is created, and copyInitializedName's declptr is updated to point to this new definition.
If the original declaration is an existing type (Enum/Function) and the copy's declptr matches the original, the copy's declptr is updated to targetDeclaration.
Note
This function will call ROSE_ABORT() if the declaration variant is not recognized.
