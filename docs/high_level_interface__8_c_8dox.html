Constructs and allocates a new SgInitializedName object.

This function creates a new instance of SgInitializedName using the provided name, type, and scope. If no scope is explicitly provided, the function retrieves the current scope from the global scope stack. The function relies on ROSE_ASSERT to ensure the validity of the input parameters.

Parameters
nameThe SgName object representing the identifier for the initialized name.
typeA pointer to the SgType representing the type of the identifier.
scopeA pointer to the SgScopeStatment where the name is defined. If NULL, the top of the current scope stack is used.
Precondition
name must not be null.
type must not be NULL.
If scope is NULL, the current scope stack must not be empty.
Postcondition
A new SgInitializedName object is allocated on the heap.
Note
The caller is responsible for managing the memory of the newly allocated SgInitializedName object.

Sets the required metadata and location details for an expression node.

This function populates essential information for an SgExpression node, including its location relative to a parent node. If the expression is identified as an operator, the function also initializes its operator position using default file information generated for transformation nodes.

Parameters
exprA pointer to the SgExpression node that requires detail updates.
parentA pointer to the SgNode that serves as the parent of the expression.
Precondition
expr must not be a null pointer.
Postcondition
The location details of expr are updated relative to parent. If expr is an operator, its operator position is set to a default file info object.

void setLocatedNodeDetails ( SgLocatedNode * locatedNode,
SgNode * parent )

Sets the parent and construction metadata for a located IR node.

This function initializes the essential structural and positional details for an SgLocatedNode. It establishes the link to the parent node and assigns default file information to mark the node as part of a transformation. This is particularly useful when constructing new AST sub-trees via the High Level Interface, where the nodes do not correspond to an original source code position but are instead generated during a transformation process.

Parameters
locatedNodeA pointer to the SgLocatedNode instance that requires detail initialization.
parentA pointer to the SgNode that will serve as the parent of the locatedNode.
Precondition
locatedNode must not be a null pointer.
Postcondition
The locatedNode's parent is set to the provided parent node.
The locatedNode's start and end construction information are set to default transformation file information.
Note
The file information is generated using Sg_File_Info::generateDefaultFileInfoForTransformationNode(), which classifies the node as being part of a transformation to be output during code generation.

void setStatementDetails ( SgStatement * stmt,
SgNode * parent,
SgScopeStatement * scope )

Sets the essential metadata and structural details for an IR statement node.

This function populates the necessary internal details for an SgStatement node, specifically handling the assignment of its parent node, its location information, and its associated scope. If a scope is provided, it is explicitly assigned to the statement, which is particularly important for nodes like SgDeclarationStatement. The function also delegates the setting of location-based details to setLocatedNodeDetails.

Parameters
stmtA pointer to the SgStatement node whose details are being updated.
parentA pointer to the SgNode that serves as the parent of the statement.
scopeA pointer to an SgScopeStatement that defines the scope for the statement. If this is NULL, no scope is explicitly set.
Precondition
stmt must not be a NULL pointer.
Postcondition
The stmt node will have its parent and location details updated. If scope is not NULL, stmt will also have its scope set to the provided scope.
Note
This function is a utility for initializing or updating the structural integrity of the Intermediate Representation (IR) tree.
