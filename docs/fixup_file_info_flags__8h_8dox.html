size_t fixupFileInfoInconsistanties ( SgNode * ast)

Identifies and resolves inconsistencies in Sg_File_Info transformation flags within the AST.

This function traverses the provided Abstract Syntax Tree (AST) to ensure that the transformation flags in Sg_File_Info objects are consistent across the start and end of constructs in SgLocatedNode objects, as well as within SgExpression operator positions. It serves as a precursor to migrating the transformation API from Sg_File_Info to SgLocatedNode. When an inconsistency is detected, the function updates the end of the construct or the expression operator position to match the start of the construct and issues a warning to the console.

Parameters
astA pointer to the root SgNode of the AST to be traversed and fixed.
Returns
The total number of violations (inconsistencies) found and corrected during the traversal.
Precondition
The provided ast pointer must not be NULL.
Postcondition
The Sg_File_imfo transformation flags for the start and end of constructs in SgLocatedNodes and operator positions in SgExpressions within the AST will be synchronized to match the start of the construct.
Note
This function uses an internal helper class T1, inheriting from AstSimpleProcessing, to perform a preorder traversal of the AST.
The function specifically targets the isTransformation() flag. Other flags in Sg_File_Info (such as isCompilerGenerated or isShared) are noted as potential future candidates for consistency checks but are not handled in this implementation.

It specifically targets discrepancies where the transformation status of the start of a construct does not match the end of the construct.

The implementation uses an internal visitor pattern (AstSimpleProcessing) to perform a preorder traversal of the AST. When an SgLocatedNode is encountered, the function checks if the transformation flag of the start of the construct matches that of the end of the construct. If a mismatch is detected, the function updates the end of the construct to match the start and logs a warning. For SgExpression nodes, it also verifies consistency with the operator position.
