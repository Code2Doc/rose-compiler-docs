Converts an Abstract Syntax Tree (AST) node expression into a boolean integer value.

This function evaluates a given POETCode expression and reduces it to a boolean representation. The implementation first evaluates the expression using EvalTrace to handle any underlying computations or traces. If the resulting expression is a simple integer constant (SRC_ICONST), the function extracts and returns the raw integer value. Otherwise, the function treats the expression as a boolean by checking if its string representation is non-empty.

Parameters
rA pointer to the POETCode object representing the expression to be evaluated.
Returns
An integer representing the boolean result. Returns the integer value of the constant if the expression is an integer constant, or 1 if the string representation is non-empty, and 0 otherwise.
Precondition
The pointer r must be a valid, non-null pointer to a POETCode object.
Postcondition
The state of the POETCode object r may be modified due to the call to EvalTrace.
Note
This function relies on the behavior of EvalTrace and the string conversion method of the POETCode class.

POETCode * EvalTrace ( POETCode * var)

Follows a trace of local variable definitions to find the underlying code.

Follows a trace of local variable entries to find the underlying POETCode.

This function traverses a chain of trace-linked local variables. It iteratively checks if the current POETCode object represents a local variable (SRC_LVAR). If it does, the function retrieves the symbol table entry and checks if the entry type is specifically marked as a trace (LVAR_TRACE). If a trace is detected, the function attempts to jump to the associated code object. The process continues until it reaches a code object that is not a traced local variable, or it encounters a null pointer or a circular reference.

Parameters
varA pointer to the initial POETCode object to begin the trace evaluation. Must not be null.
Returns
A pointer to the terminal POETCode object at the end of the trace. Returns the original pointer if no trace is found, or the last valid code object in the chain.
Precondition
var != 0
Postcondition
The returned pointer points to a POETCode object that is either not a traced local variable or is the end of a valid trace chain.
Note
The function uses an assertion to ensure the input pointer is not null. It handles potential infinite loops by checking if the next code object in the trace is the same as the current one.

This function performs a traversal through a chain of trace-enabled local variables. It iteratively checks if the current POETCode represents a local variable (SRC_LVAR). If it does, the function retrieves the corresponding symbol table entry and checks if that entry is marked with the LVAR_TRACE type. If a trace exists and points to a different POETCode, the function continues the traversal with the new code. The process terminates when it reaches a code element that is not a traceable local variable, or when the trace leads back to the current node or a null pointer.

Parameters
varA pointer to the initial POETCode object to begin the trace evaluation. Must not be null.
Returns
A pointer to the final POETCode reached at the end of the trace. If no trace is found or the trace is invalid, the original or the last valid POETCode in the chain is returned.
Precondition
var must not be null (checked via assert).
Postcondition
The returned pointer points to a POETCode that is either the original input or a code element found through the LVAR_TRACE chain.
Note
This function relies on the LvarSymbolTable::Entry and LocalVar class structures to navigate the trace.

Converts a string representation of an integer into a POETIconst object.

This function parses a character buffer containing a numeric string and converts it into an integer constant within the POET program framework. The implementation iterates through the provided character array, handling an optional leading negative sign and accumulating the numeric value digit by digit using a base-10 accumulation algorithm.

Parameters
textA pointer to a null-terminated or length-specified character array representing the integer string.
lenThe number of characters in the string to be processed.
Returns
A pointer to a newly created POETIconst object representing the parsed integer. Returns 0 (nullptr) if the length is 0, if the string contains non-numeric characters (other than a leading minus sign), or if the string consists only of a minus sign.
Precondition
The text pointer must point to a valid memory location.
Postcondition
If a valid integer is parsed, a new POETIconst object is allocated via POETProgram::make_Iconst.
Note
The function does not explicitly check for integer overflow during the accumulation process.
Warning
If the input string contains characters outside the range '0'-'9' (excluding the initial sign), the function will return 0.

This function parses a character buffer containing a numeric string and converts it into an integer value, which is then wrapped in a POETIconst object using POETProgram::make_Iconst.
