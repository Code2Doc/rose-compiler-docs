void normalizeTypedefSequenceLists ( )

Normalizes typedef sequence lists across the AST to ensure consistency.

This function is designed to support the AST merge mechanism by ensuring that all SgTypedefSeq objects for the same type contain identical lists of typedefs. The process is implemented in two distinct phases:

Phase 1: The function builds a master set of lists of typedefs for each type present in the AST. This is achieved by traversing the memory pool nodes using the NormalizeTypedefSequenceLists traversal object.

Phase 2: The function copies the master lists from the global map back into the individual SgTypedefSeq objects for each type. This ensures that the sequences are consistent across the AST.

This consistency is critical for the AST merge mechanism, as it allows for the correct computation of unique names. If the same types have the same generated names, the merge can proceed properly. This process also ensures that a minimal representation of the type is maintained within the AST.

This function is typically invoked during AST post-processing or after reading multiple binary AST files as a preparation step for merging.

Precondition
The AST must be loaded and the memory pool containing the SgTypedefSeq nodes must be accessible.
Postcondition
All SgTypedefSeq objects associated with the same type in the AST will contain the same sequence of typedefs.
Note
The current implementation contains several if 0 blocks which effectively disable the core logic of the function, rendering the normalization process inactive in the provided source.
