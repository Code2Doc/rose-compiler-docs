Provides a fallback entry point for PHP-related operations when PHP support is unavailable.

This function serves as a placeholder or error handler for the PHP main interface. It is invoked when the system attempts to execute PHP-related logic but the underlying ROSE build lacks the necessary PHP support modules. The function outputs an error message to the standard error stream.

Parameters
SgFileA pointer to an SgFile object representing the file context.
Returns
An integer error code. Returns -1 to indicate that PHP support is not enabled in the current build.
Warning
This function indicates a configuration error in the ROSE build environment.
Precondition
The SgFile pointer should be valid, though the function does not explicitly dereference it.
Postcondition
The function terminates with a non-zero error status and prints a warning to stderr.
