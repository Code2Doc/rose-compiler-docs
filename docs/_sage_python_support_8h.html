Constructs an expression representing a reference to a symbol identified by id within a given scope.

Build a reference to the name in the given scope. If no such name exists, build an opaque VarRefExp.

This function attempts to resolve a symbol name (id) within the provided scope and its parent scopes. It performs a lookup using the SageInterface. If the symbol is found, the function identifies its type (function, variable, or class) and uses the appropriate SageBuilder method to create a specific reference expression (e.g., function reference, variable reference, or class name reference). If the symbol cannot be found in the scope hierarchy, it falls back to creating an opaque variable reference expression.

Parameters
idA C-style string representing the identifier name to be resolved.
scopeThe scope statement in which the symbol lookup should be initiated.
Returns
A pointer to the constructed SgExpression representing the reference. Returns an opaque variable reference if the symbol is not found.
Precondition
scope must not be NULL.
Postcondition
The returned SgExpression will be valid and linked to the provided scope.
Warning
If the symbol is found but its type does not correspond to a known symbol variant (SgFunctionSymbol, SgVariableSymbol, or SgClassSymbol), the function will print an error message to standard output and call ROSE_ABRT to terminate the program.
Note
This function relies on the SageInterface::lookupSymbolInParentScopes and SageBuilder utility classes.

Wraps a raw pointer into a Python capsule object.

This function utilizes the Python C API to create a new capsule object that encapsulates a pointer to an arbitrary C object. The capsule is useful for passing C pointers through the Python interpreter while maintaining type safety via a name string. This implementation uses NULL for the destructor, meaning no cleanup will be performed on the underlying pointer when the capsule is garbage collected.

Parameters
ptrA pointer to the C object that needs to be encapsulated.
nameA string representing the name of the capsule, used to identify the type of the encapsulated object.
Returns
A PyObject pointer to the newly created capsule, or NULL if the creation failed.
Precondition
The name parameter must be a valid, null-terminated string.
Postcondition
A new PyObject of type capsule is returned, which increases the reference count of the capsule object. The caller is responsible for managing the reference count of the returned PyObject.
Note
Since the destructor is set to NULL, the memory pointed to by ptr will not be automatically freed when the capsule is destroyed.

Appends a list of SgStatement objects to a target SgScopeStatement.

This function serves as a Python wrapper to interface with the ROSE C++ API. It extracts a target SgScopeStatement and a Python list of capsules containing SgStatement objects. The function iterates through the list, decapsulates each statement, and appends it to the target scope. The implementation handles different target variants: for SgFunctionDeclaration or SgLambdaRefExp, it redirects the insertion to the function body; for SgGlobal or SgClassDefinition, it normalizes the child statement to a declaration statement.

Parameters
selfA reference to the Python module or object calling this function.
argsA tuple containing the arguments: the first argument must be a valid SgScopeStatement (via SAGE_CONVERTER) and the second must be a Python list containing capsules that wrap SgStatement pointers.
Precondition
The args tuple must contain exactly two arguments.
The second argument must be a PyList containing PyCapsule objects.
Each capsule in the list must encapsulate a valid SgStatement pointer.
Postcondition
The statements from the input list are appended to the target scope or its body.
Warning
If the sg_target variant is not one of the handled types (SgBasicBlock, SgFunctionDeclaration, SgLambdaRefExp, SgGlobal, or SgClassDefinition), the function will print an error to stdout and trigger a ROSE_ABORT().
The function assumes that the capsules in the list are valid and contain the expected SgStatement type.
Note
This function relies on the SAGE_CONVERTER macro for argument parsing and PyDecapsulate for extracting C++ pointers from Python capsules.

Populates an SgNode with file information extracted from a Python object.

This function retrieves file metadata (line number, column offset, and filename) from a provided Python object and applies it to the Sg_File_Info associated with the given SgNode. If the SgNode does not already have an associated Sg_File_Info, the function attempts to create a new one and attach it, provided the node is an instance of SgLocatedNode. The function also resets transformation settings and enables output in code generation for the file info object.

Parameters
sg_nodeA pointer to the SgNode that will receive the file information. Must not be NULL.
py_file_infoA pointer to a Python object containing the attributes "lineno", "col_offset", and "filename".
Warning
If the sg_node is not an SgLocatedNode, it may be impossible to attach the newly created Sg_File_Info.
The function assumes that the Python object contains valid integer and string attributes as specified.
Precondition
sg_node must not be NULL.
Postcondition
The sg_node's file information is updated with the values from py_file_info. If no file info existed, a new Sg_File_Info is created and attached if the node supports location.
Note
The function uses ROSE_ASSERT to validate the sg_node pointer.
The function clears any existing transformation settings on the Sg_File_Info via unsetTransformation().
