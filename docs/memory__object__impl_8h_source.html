185 // Three kinds of memory objects in ROSE AST: each of them can be one of the four categories above.
186 // 1) SgExpression temporary variables: each SgExpression which is not named memory objects.
187 // They can be seen as compiler-generated discrete temp variables
188 // 2) named memory objects : one object for each named variable
189 // 3) aliased memory objects: one object for each type, used for a vague memory object
190 // representing a set of aliased objects. All aliased objects of the
