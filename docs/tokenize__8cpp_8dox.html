POETCode * make_inputlist ( POETCode * car,
POETCode * cdr )

Combines two POETCode objects into a single input list structure.

Creates or merges POETCode elements into a list structure.

This function takes two POETCode pointers and attempts to merge them into a list-like structure. If either pointer is null, the non-null pointer is returned. If both are valid, the function ensures both are treated as POETInputList objects. If a pointer does not already point to a POETInputList, a new POETInputList is instantiated wrapping that object. The second object (cdr) is then appended to the first object (car).

Parameters
carThe primary POETCode object which will serve as the base for the newly formed list.
cdrThe secondary POETCode object to be appended to the car list.
Returns
A pointer to a POETCode object representing the combined list. Returns the non-null input if one is null, or the updated carlist containing the cdrlist.
Precondition
The input pointers car and cdr should be valid POETCode pointers or null.
Postcondition
The returned POETCode pointer will point to a structure that encapsulates both car and cdr if both were non-null.
Note
This function uses dynamic_cast to determine if the input objects are already instances of POETInputList. It may perform heap allocations using the new operator.

This function facilitates the construction of a linked-list style structure using POETCode pointers. It checks for null pointers to handle base cases where one element is empty. If both elements are non-null, the function attempts to cast the cdr pointer to a POETInputList. If cdr is not already a POETInputList, a new POETInputList is instantiated containing cdr. Similarly, it checks if car is a POETInputList and wraps it if necessary. Finally, it appends the cdrlist to the carlist and returns the resulting list.

Parameters
carA pointer to a POETCode object representing the head or first element of the operation.
cdrA pointer to a POETCode object representing the tail or subsequent element of the operation.
Returns
A pointer to a POETCode object representing the newly formed or existing POETInputList. If car is null, returns cdr. If cdr is null, returns car.
Precondition
The pointers car and cdr should point to valid POETCode objects or be null.
Postcondition
The returned pointer points to a POETCode object that, if both inputs were non-null, is a POETInputList containing both the car and cdr elements.
Note
This function uses dynamic_cast to determine the type of the input pointers, which requires RTTI (Run-Time Type Information) to be enabled in the compilation environment. Memory for new POETInputList objects is allocated on the heap using new.
