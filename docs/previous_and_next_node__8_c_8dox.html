Computes a mapping of nodes to their respective previous and next node data.

This function iterates through a list of frontier nodes to establish a relationship between sequential nodes in a traversal. It builds a map where each key is an SgNode and the value is a pointer to PreviousAndNextNodeData, which contains information about the preceding and succeeding nodes in the sequence. The algorithm traverses the provided frontier nodes and maintains a sliding window of the current, previous, and previous-previous nodes to populate the data structures.

Parameters
globalScopeA pointer to the SgGlobal scope, used as the initial reference point for the traversal (acting as the starting previous node).
frontierNodesA vector of FrontierNode pointers representing the sequence of nodes to be processed.
Returns
A map where each SgNode* key points to a PreviousAndNextNodeData* object containing the context of the node's neighbors in the sequence.
Precondition
globalScope must not be NULL.
All elements within the frontierNodes vector must be non-NULL, and their internal node members must also be non-NULL.
Postcondition
The returned map contains entries for the nodes encountered during the traversal, linking them to their predecessor and successor context.
Note
This implementation provides an alternative method to compute the previous/next node map by directly using the token/AST unparsing frontier list.
The function allocates new PreviousAndNextNodeData objects on the heap; the caller is responsible for managing the memory of these objects.
