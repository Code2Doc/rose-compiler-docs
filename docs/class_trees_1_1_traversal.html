Detailed Description

template<class TreeType, bool isConst>
class Trees::Traversal< TreeType, isConst >

Defines a generic tree traversal which visits each node exactly once.

Use the policy parameter isConst to define whether or not the traversal is 'read-only' (i.e., whether the traversal modifies the tree values or structure).
