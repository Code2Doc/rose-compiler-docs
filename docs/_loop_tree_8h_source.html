17/* QY: The LoopTree data structure is a tree structure built as a wrapper
18of the real AST. The AST nodes are treated differently depending on whether
19the node represents a loop. There are two main different kinds of LoopTree
20nodes: LoopNode and StmtNode. All the non-loop ASTs are treated as atomic
21stmts (Stmt nodes) which are never modified. All the loops are reconstructed
22with internal symbolic information. The tree structure will be modified
23(loop optimizations). After transformation, calling CodeGen will re-construct
24the transformed AST. The goal is to support loop optimization more easily. */
