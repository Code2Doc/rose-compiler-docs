Converts a state integer code into its corresponding string representation.

Convert QDocumentLine::State enum constant to a string.

This function maps specific 64-bit integer flags to human-readable string literals. It uses a switch-case mechanism to identify predefined state constants used within the QDocumentLine context. The mapping covers states such as None, Hidden, CollapsedBlockStart, CollapsedBlockEnd, LayoutDirty, and FormatsApplied.

Parameters
iThe 64-bit integer representing the state or flag to be stringified.
Returns
A pointer to a constant character string representing the state name. Returns an empty string "" if the provided integer does not match any of the predefined state constants.
Precondition
The input parameter i should ideally correspond to one of the known defined state constants to receive a meaningful string.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function is useful for debugging and logging purposes where integer-based state flags need to be displayed as text.

Generates a formatted state string with an optional prefix removal.

Convert QDocumentLine::State enum constant to a string.

This function retrieves a string representation of a state associated with the provided integer ID. It first calls an overloaded State(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(QDocumentLine::State)" followed by the integer ID. Finally, if the string starts with the specified strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the state.
stripA string representing the prefix to be removed from the start of the generated state string if present.
Returns
A string representing the processed state, with the strip prefix removed if it was found at the start.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the content of strip if strip was a prefix of the original state string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix checking.
