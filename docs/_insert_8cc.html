SgClassDeclaration * findMatchingDefiningClassDeclaration ( SgSourceFile * targetFile,
SgClassDeclaration * target )

Empty function or ill-formed function detected. /.

Locates the class declaration that defines a specific target class within a given source file.

This function performs a traversal of the provided SgSourceFile to find a class declaration that matches the provided target SgClassDeclaration. It utilizes the FindMatchingDefiningClassDeclarationTraversal class to navigate the AST structure within the scope of the target file. This is particularly useful in scenarios where class declarations might be duplicated or present in both source and library-generated files (e.g., *.C and *_lib.C).

Parameters
targetFileA pointer to the SgSourceFile to be searched for the matching declaration.
targetA pointer to the SgClassDeclaration whose definition needs to be located.
Returns
A pointer to the SgClassDeclaration that matches the target, or nullptr if no matching declaration is found during the traversal.
Precondition
targetFile must not be null.
target must not be null.
Note
If enable_debug is active and the platform is ifdef linux, the function will print debug information to the standard output, including the PRETTY_FUNCTION and the file information of the target.
