void CopyVec ( DepRel * vec1,
DepRel * vec2,

inline

Copies elements from one array of DepRel pointers to another.

This function performs a shallow copy of elements from the source array (vec2) to the destination array (vec1) for a specified number of elements. It iterates through the arrays using a simple linear loop, assigning each element from the source index to the corresponding destination index.

Parameters
vec1Pointer to the destination array of DepRel pointers where elements will be copied.
vec2Pointer to the source array of DepRel pointers from which elements are being copied.
numThe number of elements to be copied from vec2 to vec1.
Precondition
vec1 and vec2 must point to valid, allocated memory buffers capable of holding at least num elements of type DepRel*.
The memory range [vec1, vec1 + num) and [vec2, vec2 + num) must be accessible.
Postcondition
The first num elements of vec1 will be identical to the first num elements of vec2.
Warning
This function performs a shallow copy. If the elements being copied are pointers, only the addresses are copied, not the underlying objects.
Ensure that num does not exceed the actual allocated size of either array to prevent buffer overflows.
