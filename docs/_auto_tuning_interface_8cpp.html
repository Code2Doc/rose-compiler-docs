◆ configure_optimization()

int configure_optimization ( )

Configures and returns a bitmask of optimization flags based on current loop transformation options.

This function evaluates the current optimization type settings retrieved from the LoopTransformOptions singleton instance. It maps specific loop transformation flags (such as loop nesting, multi-level, innermost, data, and parallel loop optimizations) to a corresponding set of OptSpec optimization levels. The function uses bitwise OR operations to accumulate the required optimization levels into a single integer bitmask.

Returns
An integer bitmask representing the set of optimization flags to be applied. The mask starts with OptSpec::OPT_NONE and is updated based on the active LoopTransformOptions.
Precondition
The LoopTransformOptions singleton must be properly initialized and accessible.
Postcondition
Returns a bitmask containing the aggregated OptSpec flags corresponding to the active transformation types.
Note
The mapping logic is as follows:
  • LOOP_NEST_OPT maps to OPT_CACHE_CLEANUP_LEVEL.
  • MULTI_LEVEL_OPT maps to OPT_CACHE_PROC_CLEANUP_LEVEL.
  • INNER_MOST_OPT maps to OPT_REG_LEVEL.
  • DATA_OPT maps to OPT_CACHE_REG_CLEANUP_LEVEL.
  • PAR_LOOP_OPT maps to both OPT_PAR_LEVEL and OPT_POST_PAR_LEVEL.

Inserts a parameter declaration into a POET program.

This function creates a new parameter declaration within the provided POET program object. It populates the declaration with a descriptive message, the type information derived from the parameter's entry restriction, and the default value from the parameter's entry code.

Parameters
poetA reference to the POETProgram instance where the declaration will be inserted.
parA pointer to the LocalVar object representing the parameter to be declared.
msgA string containing the message or description to be associated with the declaration.
lineNoThe line number in the source context where this declaration is being placed.
Precondition
par must not be a null pointer and must contain valid entry information (restriction and code).
Postcondition
A new ParameterDecl object is added to the poet object, and its properties are initialized.
Note
The function uses the STRING macro to process the msg parameter.

◆ print_list()

std::string print_list ( POETCode * r)

Recursively converts a POETList structure into a comma-separated string representation.

This function traverses a linked list structure of POETCode objects. It uses a recursive approach to visit each element in the list. If the provided pointer is a POETList, the function recursively processes the first element and the rest of the list, concatenating them with a comma delimiter. If the object is not a list or the list is empty, it falls back to the standard string representation of the current node.

Parameters
rA pointer to the POETCode object to be printed. This can be a single POETCode node or a POETList node.
Returns
A string containing the comma-separated elements of the list, or the string representation of the single node if it is not a list.
Precondition
r must not be a null pointer.
Postcondition
The returned string contains the elements of the list (if applicable) formatted as a comma-separated sequence.
Note
The function relies on dynamic_cast to identify if the POETCode pointer points to a POETList. The recursion depth is proportional to the length of the list.
