adaPathMismatch finds the first difference in two scope paths [locPos, locLim) and [remPos, remLim) and returns a pair of iterators indicating those positions.

Note
similar to std::mismatch, but pathMismatch takes into account that scope paths in Ada may have two consecutive entries for the the same scope (e.g., PackageSpec, PackageBody).
