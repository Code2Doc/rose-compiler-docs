Retrieves a static collection of predefined traversal type identifiers.

Return all DOTGeneration::traversalType member values as a vector.

This function provides access to a fixed set of 64-bit integer constants representing different traversal types. The values are stored in a static vector that is initialized once during the first call to the function and persists for the lifetime of the program. The predefined values are 0, 1, 2, 3, and 4.

Returns
A constant reference to a std::vector<int64_t> containing the predefined traversal type values.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing exactly five elements: {0, 1, 2, 3, 4}.
Note
The returned vector is static, meaning the underlying data is not re-allocated on subsequent calls.

Converts an integer identifier into its corresponding string representation of a traversal type.

Convert DOTGeneration::traversalType enum constant to a string.

This function maps specific 64-bit integer values to their human-readable string labels representing different tree or graph traversal strategies. The mapping is implemented using a switch statement that checks for predefined integer constants.

Parameters
iAn 64-bit integer representing the traversal type ID. 0L: PREORDER 1L: POSTORDER 2L: TOPDOWN 3L: BOTTOMUP 4L: TOPDOWNBOTTOMUP
Returns
A pointer to a constant character string representing the traversal type. Returns an empty string "" if the provided integer does not match any of the predefined traversal types.
Precondition
The input parameter i should ideally correspond to one of the defined integer constants (0 through 4) to retrieve a meaningful label.
Postcondition
The returned string is a static string literal and does not require memory deallocation.
Note
This function is useful for generating DOT files where traversal modes need to be explicitly labeled in the output text.

Retrieves a formatted traversal type string with an optional prefix removal.

Convert DOTGeneration::traversalType enum constant to a string.

This function retrieves a traversal type string associated with a given identifier. It first calls an overloaded version of traversalType(int64_t). If the resulting string is empty, it constructs a fallback string in the format "(DOTGeneration::traversalType)" followed by the string representation of the identifier i. Finally, if the resulting string starts with the provided strip string, that prefix is removed from the beginning of the string.

Parameters
