template<typename NodeT, typename PreFuncT, typename PostFuncT>
void Rose::Traits::traverse ( NodeT * node_,
PreFuncT & pre = traversal_details::nop_noargs_f,
PostFuncT & post = traversal_details::nop_noargs_f )

Performs a tree traversal on a given node using provided pre- and post-order functions.

This function initiates a traversal process starting from the specified node. It utilizes a dispatcher mechanism to apply a pre-order function before visiting children and a post-order function after visiting children. The implementation relies on traversal_details::Dispatcher to handle the dispatching logic based on the node type and the provided function objects.

Parameters
node_A pointer to the root node of the traversal.
preA reference to a function object to be executed before visiting the children of a node (pre-order). Defaults to a no-operation function.
postA reference to a function object to be executed after visiting the children of a node (post-order). Defaults to a no-operation function.
Precondition
node_ should be a valid, non-null pointer to a node of type NodeT.
Postcondition
The traversal is completed, and the pre- and post-order functions have been applied to the nodes in the hierarchy.
Note
The traversal behavior depends on the implementation of the Dispatcher and the structure of NodeT.
