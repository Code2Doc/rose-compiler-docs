const std::vector< int64_t > & stringify::ReachingDef::Type ( )

Retrieves a static vector containing the predefined type values.

Return all ReachingDef::Type member values as a vector.

This function provides access to a constant, static vector of 64-bit integers representing a fixed set of type identifiers. The values contained in the vector are 0, 1, and 2. The vector is initialized once and persists for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the values {0, 1, 2}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing the predefined values.
Note
The returned vector is static, meaning it is thread-safe for reading after initialization but should not be modified.

const char * stringify::ReachingDef::Type ( int64_t )

Converts a definition type integer ID into its corresponding string representation.

Convert ReachingDef::Type enum constant to a string.

This function maps specific 64-bit integer identifiers to human-readable string constants representing different types of definitions within the ReachingDef analysis. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the definition type. Expected values are 0L for "PHI_FUNCTION", 1L for "ORIGINAL_DEF", and 2L for "EXPANDED_DEF".
Returns
A pointer to a constant character string representing the type name. Returns an empty string "" if the provided integer does not match any of the predefined type IDs.
Precondition
The input parameter i should be one of the predefined integer constants representing a valid definition type.
Postcondition
The returned string is a null-terminated C-style string that remains valid for the lifetime of the program.

Generates a formatted type string for a given integer ID, optionally stripping a prefix.

Convert ReachingDef::Type enum constant to a string.

This function retrieves the string representation of an integer ID using an overloaded Type(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(ReachingDef::Type)" followed by the integer ID. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer ID to be converted into a type string.
stripA string representing the prefix to be removed from the start of the generated type string if it exists.
Returns
A string representing the processed type name.
Precondition
The input string strip should be a valid string object.
Postcondition
The returned string will not start with the strip prefix if the prefix was present in the original type string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
