void QCE::addDataPath ( const QString & path)

Adds a new directory path to the internal data path collection.

Add a path to the list of pathes used to fetch data.

This function checks if the provided path is already present in the internal data path container (__qce_data_path). If the path is not already contained within the collection, it is appended to the end of the list. This ensures that the collection maintains a set of unique paths.

Parameters
pathThe string representing the file system path to be added to the data path collection.
Precondition
The internal container __qce_data_path must be properly initialized.
Postcondition
The path is added to __qce_data_path if it was not already present.

Retrieves the list of all registered data paths.

This function provides access to the internal collection of data paths currently stored within the QCE module. It returns a copy of the global or class-level variable __qce_data_path.

QString QCE::fetchDataFile ( const QString & file)

Locates the absolute path of a data file by searching through predefined data paths.

Centralized access point to data fetching.

This function attempts to resolve a given filename into its absolute path. If the provided file path is already absolute, it is returned immediately. Otherwise, the function iterates through a global or predefined list of directories stored in __qce_data_path. For each directory in this list, the function checks if the file exists within that directory. If a match is found, the absolute path to the file is returned. If the file cannot be located in any of the searched paths, the original input string is returned.

Parameters
fileThe name or relative path of the file to be located.
Returns
The absolute path to the file if found in one of the search paths or if the input was already absolute. If the file is not found in any search path, the original input string is returned.
Precondition
The variable __qce_data_path must be initialized and contain valid directory paths to be searched.
Postcondition
The returned string represents either an absolute path to an existing file or the original input string.
Note
This function relies on the existence and accessibility of the paths defined in __qce_data_path.
