Sawyer::Attribute::Storage SgAsmNode::attributes

Attribute storage.

An attribute is extra user-defined data stored in an AST node.

Once ROSETTA is out of the picture, this interface will become cleaner because the typical way to add attribute storage to a type is to have the type be derived from Sawyer::Attribute::Storage. But as things stand now, ROSETTA doesn't support multiple inheritance and we must therefore use an awkward interface that reads like node->attributes().setAttribute(....) instead of the more streamlined node->setAttribute(....).
