const char * stringify::Rose::BinaryAnalysis::InstructionSemantics::BaseSemantics::InputOutputProperty ( int64_t )

Converts an integer representation of an I/O property into its string name.

Convert Rose::BinaryAnalysis::InstructionSemantics::BaseSemantics::InputOutputProperty enum constant to a string.

This function maps specific 64-bit integer constants to their corresponding human-readable string identifiers representing various input/output properties (e.g., READ, WRITE, INIT). It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the I/O property to be stringified.
Returns
A pointer to a constant character string containing the name of the property. Returns an empty string "" if the provided integer does not match any of the predefined property constants.
Precondition
The input parameter i should correspond to one of the defined property constants (0 through 5) for a valid property name to be returned.
Postcondition
The returned string is a static string literal and does not require manual memory management.
Note
The mapping is as follows: 0: IO_READ 1: IO_WRITE 2: IO_INIT 3: IO_READ_BEFORE_WRITE 4: IO_READ_AFTER_WRITE 5: IO_READ_UNINITIALIZED

Retrieves and optionally strips a prefix from an input/output property string.

Convert Rose::BinaryAnalysis::InstructionSemantics::BaseSemantics::InputOutputProperty enum constant to a string.

This function retrieves a property string associated with a given 64-bit integer ID by calling an overloaded version of InputOutputProperty. If the retrieved string is empty, a default formatted string is constructed containing a specific namespace path and the string representation of the ID. Additionally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier used to look up the property.
stripA string representing the prefix to be removed from the start of the property string if it exists.
Returns
A string representing the processed input/output property, with the specified prefix removed if applicable.
Precondition
The identifier i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the content of the strip parameter if the original string contained that prefix.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
