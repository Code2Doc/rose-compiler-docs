Retrieves a value from a constant edge ID property map using a specific key.

This function provides a wrapper to access the value associated with a given key within a Sawyer Boost constant edge ID property map. It utilizes the internal at() method of the property map to perform the lookup.

Parameters
pmapA reference to the Sawyer::Boost::ConstEdgeIdPropertyMap object containing the edge ID properties.
keyThe specific size_t key used to look up the value in the property map.
Returns
A constant reference to the size_t value associated with the provided key.
Precondition
The key must exist within the provided property map.
Postcondition
The state of the property map remains unchanged.
Warning
If the provided key is not present in the property map, the underlying at() method will throw an exception (typically std::out_of_range).
