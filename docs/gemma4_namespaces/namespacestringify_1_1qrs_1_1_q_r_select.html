const std::vector< int64_t > & stringify::qrs::QRSelect::Type ( )

Retrieves a constant reference to a predefined vector of type values.

Return all qrs::QRSelect::Type member values as a vector.

This function provides access to a static, immutable collection of 64-bit integers representing specific type identifiers. The vector is initialized once during the first call to the function and persists for the lifetime of the program. The values contained in the vector are 0, 1, and 2.

Returns
A constant reference to a std::vector<int64_t> containing the predefined type values {0, 1, 2}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing exactly three elements.
Note
The returned vector is stored in static memory, ensuring that the initialization overhead occurs only once.

Parameters

Generates a formatted type string for a given integer ID, optionally stripping a prefix.

Convert qrs::QRSelect::Type enum constant to a string.

This function retrieves a string representation of the integer i using an overloaded Type(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(qrs::QRSelect::Type)" followed by the string representation of the integer. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer ID used to determine the type string.
stripA string representing the prefix to be removed from the start of the generated type string.
Returns
A string representing the type, potentially modified by the stripping process.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present at the start of the original string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
