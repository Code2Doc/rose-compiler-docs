Retrieves a constant reference to a predefined list of template argument enumeration values.

Return all SgTemplateArgument::template_argument_enum member values as a vector.

This function provides access to a static, immutable collection of 64-bit integer values used for template argument enumeration. The values are hardcoded within the function scope and are stored in a static vector to ensure they persist for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the values {0, 1, 2, 3, 4}.
Precondition
None.
Postcondition
The returned reference points to a valid, non-empty vector containing exactly five elements.
Note
The implementation uses a static local variable, making the function thread-safe for initialization in C++11 and later.

const char * stringify::SgTemplateArgument::template_argument_enum ( int64_t )

Converts a template argument enum integer value into its string representation.

Convert SgTemplateArgument::template_argument_enum enum constant to a string.

This function maps specific 64-bit integer identifiers to their corresponding string labels representing different types of template arguments. It uses a switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the template argument enum value.
Returns
A pointer to a constant character string containing the name of the template argument type. Returns "argument_undefined" for 0, specific strings for values 1 through 4, and an empty string for any other unrecognized integer value.
Precondition
The input parameter i should ideally correspond to one of the defined integer constants for the template argument enum.
Postcondition
The returned string is a static string literal and does not require manual memory management.

Formats an enum value as a string and optionally removes a prefix.

Convert SgTemplateArgument::template_argument_enum enum constant to a string.

This function first attempts to retrieve a string representation of the integer value i using an overloaded version of template_argument_enum. If the resulting string is empty, it constructs a fallback string in the format "(SgTemplateArgument::template_argument_enum)" followed by the string representation of i using boost::lexical_cast. Finally, if the constructed string starts with the provided strip string, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer value representing the enum element to be formatted.
stripA string representing the prefix to be removed from the formatted result if it exists at the start of the string.
Returns
A string containing the formatted enum name, potentially with a prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if strip was present at the start of the initial formatted string.
Note
This function relies on boost::lexical_cast and boost::starts_with from the Boost library.
