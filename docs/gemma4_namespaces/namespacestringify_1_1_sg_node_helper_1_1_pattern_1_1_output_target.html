Formats an output type string based on an integer ID and an optional prefix to strip.

Convert SgNodeHelper::Pattern::OutputTarget::OType enum constant to a string.

This function retrieves a string representation of an output type using an overloaded version of OType. If the resulting string is empty, it constructs a fallback string containing a specific type identifier and the integer value. Additionally, if the resulting string starts with the provided strip string, that prefix is removed from the final output.

Parameters
iThe 64-bit integer identifier representing the output type.
stripA string representing the prefix to be removed from the start of the formatted type string if it exists.
Returns
A string representing the formatted output type, potentially with the strip prefix removed.
Precondition
The integer i should correspond to a valid type identifier recognized by the overloaded OType(int64_t) function.
Postcondition
The returned string will not start with the contents of strip if strip was a prefix of the original formatted string.
Note
