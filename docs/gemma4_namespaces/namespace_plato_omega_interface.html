Variables or functions that are specific to one of the libraries will have Plato or Omega in the name.

Retrieves the total user CPU time consumed by the current process.

This function utilizes the getrusage system call with the RUSAGE_SELF flag to access resource usage statistics for the calling process. It specifically extracts the user time component (utime), which includes both seconds and microseconds, and converts the total duration into a single double-precision floating-point value representing seconds.

Returns
The total user CPU time elapsed for the process in seconds.
Precondition

Note
The precision of the returned value depends on the resolution of the microsecond field in the struct rusage structure.

Converts a directory vector representation into a formatted string.

This function iterates through the bits of a directory vector (dv) to reconstruct a hierarchical string representation. It extracts 4-bit segments from the input value to index into a global or external array named StrDir, appending the corresponding directory names into a comma-separated list enclosed in parentheses. The function utilizes a static buffer to store results, cycling through five pre-allocated slots.

Parameters
dvThe directory vector containing encoded directory indices.
dvLevelThe number of levels/segments to extract and process from the vector.
Returns
A pointer to a character array containing the formatted string representation.
Warning
The returned pointer points to a static buffer. Subsequent calls to this function will overwrite the contents of the buffer. The buffer only holds 5 distinct strings, and each string is limited to 20 characters.
Precondition
The global or external array StrDir must be properly initialized and accessible to prevent undefined behavior during sprintf.
Postcondition
The function updates the internal static count variable, cycling through the available buffer slots using a modulo 5 operation.
Note
This function is not thread-safe due to the use of static variables str_dv and count.
