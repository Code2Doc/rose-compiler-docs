bool Jovial::name_char ( int c)

Determines if a given character is valid within a name.

This function checks whether the provided integer character c is a valid constituent of a name. A character is considered valid if it satisfies the criteria defined by start_name_char, or if it is a single quote ('), or if it is a numeric digit ('0'-'9').

Parameters
cThe integer representation of the character to be checked.
Returns
True if the character is a valid name character, false otherwise.
Precondition
The input c should represent a valid character code.
Postcondition
The function does not modify any global state or the input parameter.
Note
This function relies on the implementation of start_name_char to determine the validity of the initial character type.

std::ostream & out_stream,
std::ostream & token_stream )

Performs lexical preprocessing on an input stream to identify tokens and comments.

This function implements a finite state machine (FSM) to scan an input stream character by character. It identifies specific patterns such as "DEFINE" statements and various comment types (delimited by double quotes or percent signs). The function performs the following tasks:

  1. Copies the input stream content to an output stream.
  2. Detects and extracts comments, writing metadata (type, start/end line, start/end column) and the comment content to a separate token stream.
  3. Handles the splitting of excessively large comments (exceeding 96 lines) into multiple smaller comment segments to prevent buffer or processing issues.
  4. Identifies "DEFINE" directives preceded by whitespace.
Parameters
in_streamThe input stream containing the source text to be preprocessed.
out_streamThe output stream where the processed (and potentially modified) text is written.
token_streamThe output stream used to record metadata and content for identified tokens (comments).
Returns
An integer status code: 0 indicates successful preprocessing, -1 indicates an error encountered during processing (e.g., encountering an illegal character in an unexpected state).
Precondition
The in_stream, out_stream, and token_stream must be valid, open, and writable/readable streams.
Postcondition
The out_stream will contain the processed text, and the token_stream will contain comma-separated metadata and the content of identified comments.
Note
The function uses a State machine to track the current parsing context.
The function uses TRACE_CONSTRUCTION to log character-by-character transitions to std::cerr if the macro is defined.

bool Jovial::start_name_char ( int c)

Determines if a given character is a valid starting character for a name.

This function checks whether the provided integer representation of a character is allowed to initiate a name identifier. The implementation uses a series of conditional checks to verify if the character falls within the allowed ranges: the dollar sign '$', uppercase English letters 'A'-'Z', or lowercase English letters 'a'-'z'.

Parameters
cThe integer value representing the character to be checked.
Returns
True if the character is '$', an uppercase letter, or a lowercase letter; otherwise, false.
Precondition
The input integer c should represent a valid character encoding (e.g., ASCII).
Postcondition
The function returns a boolean value indicating the validity of the character.
Note
This function does not consider digits or underscores as valid starting characters, although they may be valid within the body of a name.
