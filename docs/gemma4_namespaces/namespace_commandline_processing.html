Splits a single command line string into a container of individual argument strings.

This function parses a provided command line string by identifying space characters as delimiters. It iterates through the input string, extracting substrings that represent individual arguments, and stores them in a Rose_STL_Container of strings. The implementation uses the string::find method to locate spaces and manages indices to traverse the entire length of the input string.

Parameters
commandlineThe raw command line string to be parsed into individual arguments.
Returns
A Rose_STL_Container containing the individual strings extracted from the input command line.
Precondition
The input string commandline should be a valid std::string.
Postcondition
The returned container contains all substrings separated by spaces found in the input string.
Note
The function relies on the space character (' ') as the sole delimiter. It does not handle quoted strings containing spaces (e.g., "program argument with space").
The implementation uses unsigned long int for index tracking to ensure compatibility with string::npos comparisons.

Initializes the list of valid executable file suffixes.

This function populates the validExecutableFileSuffixes container with a set of standard executable extensions. It uses a static flag to ensure that the initialization logic is executed only once during the lifetime of the program. The function accounts for system-specific case sensitivity using the if CASE_SENSITIVE_SYSTEM macro. On case-sensitive systems, it adds ".exe", whereas on case-insensitive systems, it adds ".EXE". An empty string is always added to represent files with no extension, which is valid for binaries on many platforms.

Precondition
The validExecutableFileSuffixes container must be accessible and writable within the CommandlineProcessing class.
Postcondition
The validExecutableFileSuffixes list will contain at least one empty string and one platform-appropriate ".exe" or ".EXE" suffix. The internal first_call flag will be set to false after execution.
Note
This function relies on the define CASE_SENSITIVE_SYSTEM preprocessor directive to determine the appropriate suffix casing.

bool CommandlineProcessing::isExecutableFilename ( string name)

Determines if a given filename refers to a valid executable file.

This function checks whether the provided filename ends with a known executable suffix and verifies the file's magic numbers to confirm it is a binary executable. The implementation first initializes the list of valid executable suffixes. It then iterates through the validExecutableFileSuffixes list, performing a suffix comparison. If a suffix match is found, the function calls isValidFileWithExecutableFileSuffix to ensure the file exists and is accessible. Finally, it attempts to open the file in binary read mode to inspect the first two bytes. It specifically looks for the ELF magic number (0x7F 0x45) or the PE magic number (0x4D 0x5A).

Parameters
nameThe string representing the filename or path to be checked.
Returns
True if the filename matches an executable suffix and contains a valid ELF or PE magic number; false otherwise.
Precondition
The validExecutableFileSuffixes list must be accessible and initExecutableFileSuffixList must be able to populate it.
Postcondition
The state of the file system is unchanged, though the file may be opened and closed during the check.
Note
This function relies on SgProject::get_verbose() to determine if logging should be printed to stdout.
Warning
This function performs file I/O operations. If the file is inaccessible due to permissions, the behavior depends on the isValidFileWithExecutableFileSuffix implementation.
The magic number check is a simple heuristic and may not detect all possible executable formats.
