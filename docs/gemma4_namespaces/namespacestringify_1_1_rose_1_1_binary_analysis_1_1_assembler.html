Return all Rose::BinaryAnalysis::Assembler::EncodingType member values as a vector.

This function provides access to a static collection of 64-bit integer values representing different encoding types. The values are hardcoded within the function scope and are encapsulated in a static std::vector to ensure they are initialized only once and persist for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the encoding type values {0, 1, 2}.
Precondition
None.
Postcondition
The returned reference points to a valid, immutable vector containing the predefined values.
Note

Convert Rose::BinaryAnalysis::Assembler::EncodingType enum constant to a string.

This function maps specific 64-bit integer values to their human-readable string labels representing different encoding types (Shortest, Longest, or Matches). It uses a simple switch-case mechanism to perform the lookup.

Parameters
iThe 64-bit integer representing the encoding type to be stringified.
Returns
A pointer to a constant character string representing the encoding type. Returns "ET_SHORTEST" for 0, "ET_LONGEST" for 1, "ET_MATCHES" for 2, and an empty string "" for any other value.
Precondition
The input parameter i should be a valid encoding type identifier (0, 1, or 2) to receive a non-empty string.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.

Retrieves the encoding type string for a given integer, optionally stripping a prefix.

Convert Rose::BinaryAnalysis::Assembler::EncodingType enum constant to a string.

This function first attempts to retrieve the encoding type representation of the integer i by calling the overloaded EncodingType(i) function. If the resulting string is empty, it constructs a fallback string containing a specific identifier and the string representation of the integer. Finally, if the resulting string starts with the provided strip prefix, that prefix is removed from the string.

Parameters
iThe 64-bit integer whose encoding type is to be determined.
stripA string representing the prefix to be removed from the start of the resulting encoding type string if it exists.
Returns
A string representing the encoding type, potentially with a prefix removed.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip substring if it was present at the beginning of the original encoding type string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
