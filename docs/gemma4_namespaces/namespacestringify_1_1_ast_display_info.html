Retrieves a static collection of predefined node type identifiers.

Return all AstDisplayInfo::NodeType member values as a vector.

This function provides access to a constant, globally shared vector containing a sequence of 64-bit integer values representing various node types. The implementation uses a static local variable to ensure that the vector is initialized only once during the first call to the function, providing efficient access to the underlying data without repeated allocations.

Returns
A constant reference to a std::vector<int64_t> containing the predefined node type values (0 through 8).
Precondition
None.
Postcondition
The returned reference points to a valid, immutable vector of int64_t values.
Note
The vector is stored in static memory and persists for the lifetime of the program.

Converts a node type identifier into its corresponding string representation.

Convert AstDisplayInfo::NodeType enum constant to a string.

This function maps a 64-bit integer identifier to a human-readable string representing the type of an Abstract Syntax Tree (AST) node. It uses a switch-case mechanism to perform the lookup based on the provided integer value.

Parameters
iThe 64-bit integer representing the unique identifier for the node type.
Returns
A pointer to a constant character string containing the name of the node type (e.g., "ROOT", "CLASS", "FUNCTION"). Returns an empty string "" if the provided identifier does not match any known type.
Precondition
The input parameter i should correspond to a valid, predefined node type constant within the system.
Postcondition
The returned string is a static string literal and does not require manual memory management.
Note
This function is useful for debugging and logging purposes when displaying AST structures.

Retrieves a string representation of a node type with an optional prefix removal.

Convert AstDisplayInfo::NodeType enum constant to a string.

This function retrieves the string representation of a node type based on the provided integer ID. It first calls the overloaded NodeType(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(AstDisplayInfo::NodeType)" followed by the string representation of the ID using boost::lexical_cast. Finally, if the string starts with the specified 'strip' prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier representing the node type.
stripA string representing a prefix to be removed from the start of the resulting node type string if it exists.
Returns
A string containing the formatted node type name, potentially with the specified prefix stripped away.
Precondition
The integer i must be a valid identifier for a node type.
Postcondition
The returned string will not start with the content of the 'strip' parameter.
Note
This function relies on boost::lexical_cast and boost::starts_with from the Boost libraries.
