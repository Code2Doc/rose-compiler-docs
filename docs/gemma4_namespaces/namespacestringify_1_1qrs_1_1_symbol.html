Retrieves a static vector containing the default type values.

Return all qrs::Symbol::Type member values as a vector.

This function provides access to a constant, statically allocated vector of 64-bit integers representing the fundamental type identifiers (0 and 1). The vector is initialized once during the first call to the function and persists for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the values {0, 1}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing exactly two elements.
Note
The implementation uses a static local variable to ensure thread-safe initialization (in C++11 and later) and to avoid repeated allocations.

Converts a 64-bit integer representation of a symbol type into a string.

Convert qrs::Symbol::Type enum constant to a string.

This function maps specific integer values to their corresponding string representations for symbol types. It uses a switch-case mechanism to evaluate the input integer. Specifically, it maps 0 to "Left" and 1 to "Right".

Parameters
iThe 64-bit integer representing the symbol type to be stringified.
Returns
A pointer to a constant character string ("Left", "Right", or an empty string if the input does not match the defined cases).
Precondition
The input parameter i should ideally be 0 or 1 to receive a meaningful label.
Postcondition
The returned pointer points to a static string literal.
Note
This function does not handle values other than 0 and 1 with specific labels; any other value results in an empty string.

Generates a formatted type string for a given integer ID, optionally stripping a prefix.

Convert qrs::Symbol::Type enum constant to a string.

This function retrieves the string representation of a type ID using an overloaded Type(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(qrs::Symbol::Type)" followed by the integer ID using boost::lexical_cast. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer representing the type identifier.
stripA string representing the prefix to be removed from the start of the generated type string if it exists.
Returns
A string representing the type, potentially with a prefix removed.
Precondition
The integer i should be a valid identifier compatible with the underlying Type(int64_t) implementation.
Postcondition
The returned string will not start with the strip substring if the original string contained it.
Note
This function relies on the boost library for lexical casting and string prefix checking.
