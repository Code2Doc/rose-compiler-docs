Retrieves a static list of predefined 64-bit integer options.

Return all QDocumentSearch::Option member values as a vector.

This function provides access to a constant, immutable collection of 64-bit integers representing specific configuration options or bit-mask values. The values are stored in a static vector that is initialized only once during the first call to the function, ensuring efficient access without repeated allocations.

Returns
A constant reference to a std::vector<int64_t> containing the predefined values: 1, 2, 4, 8, 16, 32, and 64.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing the predefined integer values.
Note
The returned vector is static and persists for the lifetime of the program.

const char * stringify::QDocumentSearch::Option ( int64_t )

Converts a bitmask flag integer into its corresponding string representation.

Convert QDocumentSearch::Option enum constant to a string.

This function maps specific integer values, representing individual bit flags, to their human-readable string names. It uses a switch-case mechanism to identify the flag associated with the provided 64-bit integer.

Parameters
iA 64-bit integer representing a specific option flag. Supported values include 1 (WholeWords), 2 (CaseSensitive), 4 (RegExp), 8 (Replace), 16 (Prompt), 32 (Silent), and 64 (HighlightAll).
Returns
A pointer to a constant character string representing the name of the provided option. Returns an empty string "" if the input value does not match any of the predefined flags.
Precondition
The input integer i should correspond to one of the defined bitwise constants used within the QDocumentSearch system.
Postcondition
The returned string is a static literal and does not require manual memory management.
Note
This function only handles single-bit flags. It does not support decomposing composite bitmasks containing multiple active flags.

Generates a formatted option string from an integer, with an optional prefix removal.

Convert QDocumentSearch::Option enum constant to a string.

This function retrieves a string representation of a given 64-bit integer using an overloaded Option(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(QDocumentSearch::Option)" followed by the integer value using boost::lexical_cast. Finally, if the string starts with the specified 'strip' prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer value to be converted into an option string.
stripA string representing the prefix to be removed from the start of the generated option string if it exists.
Returns
A string containing the formatted option, potentially with the leading 'strip' substring removed.
Precondition
The 'strip' parameter should be a valid string.
Postcondition
The returned string will not start with the 'strip' content if it was present in the original formatted string.
Note
This function relies on the existence of an overload for Option(int64_t) and the boost::lexical_cast utility.
