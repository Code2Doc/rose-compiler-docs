void Rose::KeepGoing::Backend::Compiler::SignalHandler ( int sig)

Handles incoming system signals during backend compiler processing.

This function acts as a signal handler to intercept and log system signals received during the execution of the backend compiler. It attempts to translate the signal number into a human-readable string using strsignal on non-MSVC platforms. Upon receiving a signal, the function logs a warning message to standard output.

The implementation uses conditional compilation via ifndef and else to handle platform-specific behavior between MSVC and other environments. On non-MSVC platforms, it uses siglongjmp to jump back to a predefined jump target (Backend::Compiler::jmp_target) to recover from the signal. On MSVC, it triggers an assertion because the "KeepGoing" feature is not yet supported on Windows.

Parameters
sigThe integer signal number received from the operating system.
Warning
This function performs a long jump using siglongjmp on non-MSVC platforms, which can disrupt the normal control flow of the application.
Precondition
The global jump target Backend::Compiler::jmp_target must be properly initialized via sigsetjmp before a signal is caught.
Postcondition
On non-MSVC platforms, the execution flow is redirected to the previously established jump target. On MSVC, an assertion failure is triggered.
