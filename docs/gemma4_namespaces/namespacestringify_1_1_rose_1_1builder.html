Retrieves a constant reference to the predefined set of Jovial enumeration values.

Return all Rose::builder::JovialEnum member values as a vector.

This function provides access to a static collection of 64-bit integer values that represent the Jovial enumeration constants. The values are stored in a static std::vector to ensure they are initialized only once and persist for the lifetime of the program. The implementation uses a static array to define the raw values and then constructs a static vector from that array.

Returns
A constant reference to a std::vector<int64_t> containing the values {0, 98, 99}.
Precondition
None.
Postcondition
The returned reference points to a valid, immutable vector containing the predefined enumeration values.
Note
The returned vector is static, meaning it is thread-safe for concurrent reads after its initial construction.

Convert Rose::builder::JovialEnum enum constant to a string.

This function attempts to retrieve a string representation of a given 64-bit integer using the overloaded JovialEnum(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a specific error/debug identifier and the integer value. Additionally, if the resulting string starts with the provided strip string, that prefix is removed from the final output.

Parameters
iThe 64-bit integer value to be converted to its enumeration string representation.
stripA string representing a prefix to be removed from the start of the resulting enumeration string if it exists.
Returns
A string containing the enumeration name, potentially modified by the stripping process or formatted as a fallback debug string.
Precondition

Postcondition
The returned string will not start with the strip content if it was present in the original string.
Note
