Creates a multiplication operation expression from two operands.

This function constructs a new multiplication expression by combining a left-hand side operand and a right-hand side operand. The implementation utilizes the SageBuilder namespace to build the operation. It performs a deep copy of the right-hand side expression to ensure that the newly created multiplication operation has its own independent copy of the rhs, preventing side effects from external modifications to the original rhs object.

Parameters
lhsA pointer to the left-hand side SgExpression. The caller is responsible for the ownership of this expression.
rhsA pointer to the constant right-hand side SgExpression. This expression is deep-copied during the creation process.
Returns
A pointer to the newly created SgExpression representing the multiplication of lhs and rhs.
Precondition
lhs must not be a null pointer.
Postcondition
A new SgExpression is returned which contains a deep copy of rhs.
Note
The function assumes that the SageBuilder and SageInterface namespaces are available in the scope.

Retrieves the dimensions of a C-style array as a vector of expressions.

This function processes an array type to determine its dimensions. It utilizes an underlying helper function to retrieve the base dimensions and then specifically handles cases where the first dimension is unspecified (open). For open first dimensions, such as those found in array initializers (e.g., int p[][2][3]), the function calculates the missing dimension by dividing the total size of the array variable by the product of the sizes of the subsequent dimensions and the size of the underlying element type.

Parameters
arrtypeThe array type structure containing the dimension information to be processed.
varrefBuilderA builder used to create a variable reference to the array, enabling the calculation of the total size via sizeof.
Returns
A vector of SgExpression pointers, where each element represents a dimension of the array. If the first dimension was open, the first element will contain the calculated expression for that dimension.
Precondition
The arrtype must be a valid SgArrayType.
Postcondition
The returned vector contains expressions representing all dimensions of the array, with the first dimension being explicitly calculated if it was originally null.
Note
The calculation for the implicit first dimension relies on the include of standard algorithms like std::accumulate and the use of SageBuilder operations like buildSizeOfOp and buildDivideOp.
