Convert qrs::Q3TextCursor::Operation enum constant to a string.

This function maps specific 64-bit integer identifiers to human-readable string literals representing cursor operations. It uses a switch-case mechanism to perform the lookup. The supported operations include EnterBegin, EnterEnd, Next, Prev, Up, and Down.

Parameters
iThe 64-bit integer representing the operation code to be stringified.
Returns
A pointer to a constant character string representing the operation name. Returns an empty string "" if the provided integer does not match any of the predefined operation codes.
Precondition
The input parameter i should be one of the predefined integer constants representing a valid cursor operation.
Postcondition
The returned pointer points to a static string literal that remains valid for the lifetime of the program.
Note
This function does not handle any integer values outside the range 0 to 5 with specific labels; any other value results in an empty string.

Formats and strips a prefix from an operation identifier string.

Convert qrs::Q3TextCursor::Operation enum constant to a string.

This function retrieves a string representation of an operation associated with the provided integer ID using an overloaded version of Operation(int64_t). If the resulting string is empty, it constructs a fallback string containing a specific class-based prefix and the string representation of the ID. Finally, if the string starts with the specified strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer identifier used to retrieve the base operation string.
stripA string representing the prefix to be removed from the start of the operation string if it exists.
Returns
A string containing the processed operation identifier, with the specified prefix removed if applicable.
Precondition
The parameter strip should be a valid string.
Postcondition
The returned string will not start with the contents of strip if strip was present at the start of the original operation string.
Note
