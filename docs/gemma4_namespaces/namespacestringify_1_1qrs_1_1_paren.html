Generates a formatted type string for a given integer, optionally stripping a prefix.

Convert qrs::Paren::Type enum constant to a string.

This function retrieves the string representation of an integer using an overloaded Type(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(qrs::Paren::Type)" followed by the integer value. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer whose type representation is being processed.
stripA string representing the prefix to be removed from the start of the generated type string if it exists.
Returns
A string representing the processed type name.
Precondition
The integer i must be a valid 64-bit signed integer.
Postcondition
The returned string will not contain the strip prefix at its start, even if the prefix was present in the original type string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
