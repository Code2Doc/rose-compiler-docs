Retrieves a constant reference to a vector containing predefined toolbar indices.

Return all qrs::QRSourceBox::ToolbarIdx member values as a vector.

This function provides access to a static, immutable collection of 64-bit integer values representing indices used for toolbar operations. The vector is initialized once during the first call to the function and persists for the lifetime of the program. The values contained in the vector are a contiguous sequence of integers from 0 to 8.

Precondition
None.
Postcondition
The function returns a reference to a static vector containing the elements {0, 1, 2, 3, 4, 5, 6, 7, 8}.
Note
The returned reference points to a static object, so the lifetime of the returned vector is the duration of the program execution.

const char * stringify::qrs::QRSourceBox::ToolbarIdx ( int64_t )

Retrieves the string identifier associated with a specific toolbar index.

Convert qrs::QRSourceBox::ToolbarIdx enum constant to a string.

This function maps a 64-bit integer index to a corresponding string constant representing a toolbar action or element name. It uses a switch-case implementation to perform a direct lookup based on the provided integer value.

Parameters
iThe 64-bit integer index representing the toolbar element.
Returns
A pointer to a constant character string containing the toolbar identifier. Returns an empty string "" if the provided index does not match any predefined toolbar elements.
Precondition
The input parameter i should be a valid index within the range 0 to 8 to retrieve a specific identifier.
Postcondition
The returned pointer points to a static string literal that remains valid for the lifetime of the program.
Note
The mapping is as follows: 0: tbTargetMode 1: tbCacheView 2: tbCollectMode 3: tbClearCache 4: tbBroadcastCache 5: tbGoto 6: tbLookup 7: tbZoomIn 8: tbZoomOut

Generates a formatted toolbar index string with an optional prefix removal.

Convert qrs::QRSourceBox::ToolbarIdx enum constant to a string.

This function retrieves a base index string using an overloaded version of ToolbarIdx(int64_t). If the resulting string is empty, it constructs a fallback string containing a specific class-based identifier and the integer value. Additionally, if the resulting string starts with the provided strip string, that prefix is removed from the final output.

Parameters
iThe 64-bit integer index used to generate the base toolbar identifier.
stripA string representing the prefix to be removed from the start of the generated index string if a match is found.
Returns
A string representing the processed toolbar index.
Precondition
The parameter strip should be a valid string.
Postcondition
The returned string will not start with the contents of strip if strip was a prefix of the generated identifier.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix checking.
