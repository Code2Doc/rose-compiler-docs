void Rose::KeepGoing::Midend::SignalHandler ( int sig)

Handles incoming system signals during midend processing.

This function acts as a signal handler to intercept and log system signals encountered during the execution of the midend. It attempts to provide a human-readable description of the signal using strsignal on non-MSVC platforms. Upon receiving a signal, the function attempts to perform a long jump back to a predefined recovery point (Midend::jmp_target) on non-MSVC platforms. On MSVC platforms, it triggers an assertion failure because the "KeepGoing" feature is not yet implemented for Windows.

Parameters
sigThe integer signal number received from the operating system.
Warning
On MSVC platforms, this function will trigger a fatal assertion failure because the recovery mechanism is not supported.
Precondition
The signal handler must be properly registered with the operating system using a mechanism like signal or sigaction before this function is invoked.
Postcondition
On non-MSVC platforms, the execution flow is redirected to Midend::jmp_target using siglongjmp. On MSVC platforms, the program will terminate due to a failed assertion.
Note
The implementation uses ifndef and else preprocessor directives to handle platform-specific differences between MSVC and other compilers, specifically regarding signal string translation and error recovery capabilities.
