void Rose::KeepGoing::Frontend::Commandline::SignalHandler ( int sig)

Handles incoming system signals during commandline processing.

This function serves as a signal handler callback. When a signal is intercepted, it logs a warning message to the standard output containing the signal number and its descriptive string (on platforms where strsignal is available).

The implementation uses conditional compilation to handle platform differences. On non-MSVC platforms, it attempts to perform a non-local jump back to a predefined jump target using siglongjmp to recover from the signal. On MSVC platforms, it triggers a runtime assertion because the "KeepGoing" feature is not yet implemented for Windows.

Parameters
sigThe integer value of the signal that was intercepted.
Warning
On Windows (MSVC), this function will trigger a fatal assertion rather than attempting to recover via longjmp.
Precondition
The signal handler must be properly registered with the operating system using a mechanism like signal or sigaction before this function is invoked.
Postcondition
On non-MSVC platforms, the execution flow is redirected to Frontend::Commandline::jmp_target via siglongjmp. On MSVC, the program will likely terminate due to a failed ROSE_ASSERT.
