SgIfStmt * getElseIfStatement ( SgIfStmt * parentIfStatement)

Retrieves the else-if statement associated with a given if statement.

This function traverses the structure of a provided SgIfStmt to identify if it contains an embedded else-if branch. The implementation checks the false branch of the parent if statement. It specifically looks for a SgBasicBlock containing a single statement that is itself an SgIfStmt marked as an else-if statement. Additionally, it accounts for legacy or experimental AST designs where the false branch might directly be an SgIfStmt without an intermediate basic block.

Parameters
parentIfStatementA pointer to the SgIfStmt object to be inspected for an else-if child.
Returns
A pointer to the SgIfStmt representing the else-if statement if one is found; otherwise, returns nullptr.
Precondition
parentIfStatement should be a valid pointer to an SgIfStmt object.
Postcondition
The returned pointer, if not null, points to a valid SgIfStmt that is part of the structure of the parentIfStatement.
Note
The logic includes specific handling for different AST designs (e.g., experimental Fortran parser) where the structure of the false branch may vary between a SgBasicBlock containing an SgIfStmt and a direct SgIfStmt.

bool hasCStyleElseIfConstruction ( SgIfStmt * parentIfStatement)

Checks if an if-statement contains a C-style else-if construction.

This function determines whether the provided if-statement is part of an extended else-if chain. In a C-style AST representation, an else-if construction is identified when the false branch of the current SgIfStmt is itself another SgIfStmt. Unlike other block-based constructions, this specific pattern does not have an SgBasicBlock immediately preceding the SgIfStmt representing the else-if clause.

Parameters
parentIfStatementA pointer to the SgIfStmt being inspected for an else-if child.
Returns
True if the false branch of the parentIfStatement is an SgIfStmt, indicating an else-if construction; false otherwise.
Precondition
parentIfStatement should not be a null pointer.
Postcondition
The state of the parentIfStatement is not modified.
Note
This implementation relies on the isSgIfStmt helper function to perform the type check on the false body.

bool unparseDimensionStatement ( SgStatement * stmt)

Unparses a dimension statement into its string representation.

This function processes an SgStatement that is expected to be an attribute specification statement of type dimension statement. It iterates through the parameter list of the statement to identify array references. For each array reference found, it attempts to unparse the dimension information. The function determines if the dimension information needs to be explicitly outputted based on whether the array variable has an existing explicit declaration.

Parameters
stmtA pointer to the SgStatement to be unparsed. This statement must be an instance of SgAttributeSpecificationStatement representing a dimension statement.
Returns
True if at least one dimension statement was successfully unparsed for an array variable; false otherwise.
Precondition
The input stmt must be a valid pointer and must be identifiable as an SgAttributeSpecificationStatement with an attribute kind of SgAttributeSpecificationStatement::e_dimensionStatement.
The attribute specification statement must have a non-null parameter list.
Postcondition
The function returns a boolean indicating whether any dimensioning information was processed and flagged for unparsing.
Note
This function relies on the internal state of the SgAttributeSpecificationStatement to determine if the dimensioning is redundant or necessary based on existing variable declarations.

bool unparseDimensionStatementForArrayVariable ( SgPntrArrRefExp * arrayReference)

Determines whether a dimension statement needs to be unparsed for an array variable.

This function checks if an array variable already has an explicit dimensioning information provided within its variable declaration. If the variable is declared with explicit dimensions in its declaration (e.g., within a SgVariableDeclaration), the function determines that no additional dimension statement is required. Otherwise, it indicates that a dimension statement must be output.

The implementation performs a search through the scope of the variable. If a direct SgVariableDeclaration is found via the variable's parent, it verifies the existence of the declaration within the current basic block. If no direct declaration is found, the function iterates through all SgVariableDeclaration nodes within the function's body to see if the SgInitializedName is present in any variable list.

Parameters
arrayReferenceA pointer to the SgPntrArrRefExp representing the array reference to be checked.
Returns
True if no explicit variable declaration was found (meaning a dimension statement must be output), false if an explicit declaration was found (meaning the dimension is already handled).
Precondition
arrayReference must not be null.
The left-hand side operand of arrayReference must be a valid SgVarRefExp.
The symbol associated with the variableReference must not be null.
The declaration associated with the variableSymbol must not be null.
Postcondition
The function returns a boolean value indicating the necessity of unparsing a dimension statement.
Note
This function relies on ASSERT_not_null checks for the integrity of the IR tree structure.
The search algorithm may involve an expensive traversal of the function's basic block statements if a direct declaration is not immediately accessible.
