Embeds the non-reserved branches of a source QNFA into a destination QNFA.

Embeds the branches of a source QNFA into a destination QNFA.

This function iterates through the branches of the output branch of the source QNFA. For each branch that does not have the Reserved flag set in its type, the function inserts that branch into the destination QNFA's output branch at the specified index. The index is incremented for each successful insertion. Finally, the tree structure of the source is copied to the destination.

Parameters
srcA pointer to the source QNFA from which branches will be extracted.
destA pointer to the destination QNFA where branches will be embedded.
idxThe starting index in the destination's output branch where insertion begins.
Precondition
The pointers src and dest must be valid and non-null.
Postcondition
The branches of src that are not of type Reserved are inserted into dest starting at idx. The src->tree is copied to dest->tree.
Note
The function uses an incremental approach to the idx parameter, meaning the value of idx passed by the caller will be effectively shifted by the number of non-reserved branches found.

uint qHash ( const QPointer< QDocument > & p)

Generates a hash value for a QPointer pointing to a QDocument.

This function provides a hashing mechanism for QPointer instances that wrap a QDocument. It performs a type cast of the QPointer to a raw QDocument pointer and then invokes the standard qHash overload for raw pointers. This allows QPointer objects to be used effectively in hashed containers like QHash.

Parameters
pA QPointer to a QDocument object.
Precondition
The QPointer p must be a valid QPointer type compatible with QDocument.
Postcondition
Returns a uint representing the hash value of the underlying pointer address.
Note
The hash value is derived from the memory address of the QDocument object. If the QPointer is null, the hash will be based on a null pointer address.
