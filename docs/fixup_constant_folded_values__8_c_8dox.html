void deleteExpressionAndOriginalExpressionTree ( SgNode * node)

Recursively deletes an AST node, its associated original expression tree, and all successor nodes.

This function performs a deep deletion of a given SgNode and its entire subtree within the AST. The implementation uses a depth-first traversal approach. It first checks if the node is a valid pointer. If the node is identified as an SgExpression and possesses an associated original expression tree, the function recursively calls itself to delete that tree first. Subsequently, the function iterates through all traversal successors of the current node, recursively invoking the deletion process on each non-null successor. Finally, the memory for the current node is deallocated.

Parameters
nodeA pointer to the SgNode to be deleted.
Precondition
The node pointer should be a valid pointer to an existing SgNode, or NULL.
Postcondition
The node and all its reachable successors in the traversal tree are deleted from memory.
Note
This function relies on the validity of the pointer check via if (node->get_freepointer() != AST_FileIO::IS_VALID_POINTER()).
Warning
Calling this function on a node that is already part of a different deletion process might lead to double-free errors if the traversal logic does not account for shared nodes.

Retrieves the parent expression if the current expression has been folded into it.

This function checks the parent of the provided expression to determine if the parent is an SgExpression and if the current expression is the original expression tree that was replaced or folded into that parent. It essentially verifies if the expression is part of a folding operation where it serves as the source of the fold.

Parameters

Returns
A pointer to the parent SgExpression if it is a valid expression and the input expression is the original tree for that parent; otherwise, NULL.
Precondition
expr must not be NULL.
Postcondition
The returned pointer is either a valid SgExpression or NULL.
Note
This function relies on the validity of the parent pointer returned by expr->get_parent().

Removes nodes from the AST that have been replaced by constant folding.

This function identifies and cleans up SgExpression nodes in an SgProject that are part of a constant folding chain. It utilizes a CollectExpressionTrees utility to traverse the memory pool and identify orphaned, disconnected, or substituted expressions. The function traverses substitution chains, identifies the original nodes that should be replaced by their folded counterparts, and manages the deletion of intermediate nodes and nodes that are no longer part of the valid AST structure. It also handles edge cases such as enum values and lambda expressions to prevent invalid AST states or type errors.

Parameters
projectA pointer to the SgProject containing the AST to be processed.
Precondition
The SgProject and its associated AST must be fully constructed and the memory pool must be traversable by CollectExpressionTrees.
Postcondition
The AST is modified such that all constant-folded intermediate nodes are removed, and their parents are updated to point to the new representative nodes. Nodes identified as orphans or disconnected are deleted.
Note
If ROSE_GRAPHVIZ_EXPRESSION_TREES is defined, the function will generate a Graphviz DOT file named "expr_trees.dot".
If ROSE_WARN_ORPHAN_EXASPRESSIONS or ROSE_WARN_DISCONNECTED_EXPRESSIONS are defined, warnings regarding disconnected or orphaned nodes will be printed to std::cerr.
The function uses edgePointerReplacement to update the AST structure based on the identified replacement map.
