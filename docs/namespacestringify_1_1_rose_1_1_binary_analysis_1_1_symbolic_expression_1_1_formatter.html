Formats and optionally strips a prefix from a comment string associated with an integer ID.

Convert Rose::BinaryAnalysis::SymbolicExpression::Formatter::ShowComments enum constant to a string.

This function retrieves a formatted comment string for a given 64-bit integer ID by calling an overloaded version of ShowComments. If the resulting string is empty, it generates a default fallback string containing a specific class path and the integer ID. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer ID used to look up or generate the comment string.
stripA string representing the prefix to be removed from the start of the formatted comment if it exists.
Returns
A string containing the formatted comment, potentially stripped of the specified prefix.
Precondition
The input string strip should be a valid, well-formed string.
Postcondition
The returned string will not start with the strip prefix if the prefix was present in the original formatted string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
