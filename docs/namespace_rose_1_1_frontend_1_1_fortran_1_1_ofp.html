void Rose::Frontend::Fortran::Ofp::jserver_start ( JvmT * je)

Initializes and starts the Java Virtual Machine (JVM) within the Jserver context.

This function configures the necessary arguments for JVM initialization, including setting the JNI version to 1.8 and handling unrecognized options. It retrieves JVM options from the Rose::Cmdline::Fortran::Ofp namespace, appends the Rose classpath and a specific stack size option (-Xss2m) to ensure stability on certain systems, and then invokes JNI_CreateJavaVM to instantiate the VM. The function populates the JavaVM and JNIEnv pointers within the provided JvmT structure.

Parameters
jeA pointer to a JvmT structure which will hold the initialized JavaVM and JNIEnv pointers upon successful execution.
Precondition
The pointer je must be a valid, non-null pointer to an allocated JvmT object.
The Rose::Cmdline::Fortran::Ofp::jvm_options list must be accessible.
Postcondition
If successful, je->jvm and je->env will contain valid pointers to the initialized Java Virtual Machine and its environment.
If the JVM creation fails or the resulting pointers are null, the function will terminate the process via exit(1).
Warning
If JNI_CreateJavaVM returns an error, a failure message is printed to stdout, and the program will exit.
The function uses strdup to allocate memory for option strings; the caller or the lifecycle of the JvmT object must account for the management of these allocated strings if they are not cleaned up.
Note
The function explicitly sets the JNI version to JNI_VERSION_1_8 to avoid dependencies on legacy JDK versions.
A stack size of 2MB (-Xss2m) is hardcoded to prevent crashes on specific RHEL7 environments.
