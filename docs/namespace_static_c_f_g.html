Creates and adds a Control Flow Graph (CFG) edge between two nodes if valid.

This function attempts to establish a directed edge between two CFG nodes. It performs several semantic checks to ensure that the edge represents a valid control flow transition. Specifically, it evaluates the types of statements at the source node (e.g., goto, break, continue, return, or process control statements) and the relationship between the source and destination nodes to prevent the creation of invalid or discontinuous edges.

Parameters
fromThe source CFG node from which the edge originates.
toThe destination CFG node to which the edge points.
resultA reference to a vector of CFGEdge objects where the newly created edge will be appended if all validation checks pass.
Precondition
The result vector must be a valid, initialized std::vector<CFGEdge>.
Postcondition
If the validation logic permits, a new CFGEdge connecting from to to is added to the result vector. If any control flow discontinuity is detected, the result vector remains unchanged.
Note
The function implements specific logic for handling:
  • Jump statements (goto, break, continue) that terminate flow.
  • Return statements and their relationship to parent nodes.
  • Process control statements (e.g., e_stop) and their impact on flow.
  • Switch statement body transitions.

Retrieves the index associated with a specific graph node.

This function attempts to extract a CFGNodeAttribute object from the provided SgGraphNode by looking up the "info" attribute. If the attribute is found and is of the correct type, the function returns the index stored within that attribute.

Parameters
nodeA pointer to the SgGraphNode from which the index is to be retrieved.
Returns
The integer index stored within the CFGNodeAttribute associated with the node.
Precondition
The node parameter must not be null and must contain an attribute named "info" that can be successfully cast to a CFGNodeAttribute.
Postcondition
The state of the node and its attributes remains unchanged.
Warning
This function uses ROSE_ASSERT to verify the existence and type of the "info" attribute. If the attribute is missing or cannot be cast to CFGNodeAttribute, the program will trigger an assertion failure.
Note
This function relies on the presence of a specific attribute key "info" within the SgGraphNode's attribute map.

void StaticCFG::writeCFGNode ( std::ostream & out,
const CFGNode & cfgNode )

This function helps to write the DOT file for vertices.

Writes the DOT format representation of a Control Flow Graph (CFG) node to an output stream.

This function generates a DOT-compatible attribute string for a specific CFG node. It determines the visual properties of the node, such as color and line style, based on the underlying SgNode type and the node's properties. The function handles the formatting of labels, including escaping special characters like quotes and newlines, and provides specific labels for function entry and exit points.

Parameters
outThe output stream where the DOT formatted string will be written.
cfgNodeThe CFG node object containing the SgNode and metadata such as index and interest status.
Precondition
The pointer returned by cfgNode.getNode() must not be null, as a ROSE_ASSERT is performed.
Postcondition
The specified output stream out will contain a formatted DOT attribute string representing the node.
Note
The color of the node is determined by the type of the underlying SgNode:
  • Blue for SgStatement.
  • Green for SgExpression.
  • Red for SgInitializedName.
  • Black for all other types.
The line style is set to "solid" if the node is marked as interesting via cfgNode.isInteresting(), otherwise it is set to "dotted".
For SgFunctionDefinition nodes, special "Entry" or "Exit" labels are prepended if the node index corresponds to the start (0) or end (3) of the function.
String escaping is performed on the unparsed node content to ensure compatibility with DOT syntax, specifically replacing double quotes and newline characters.
