int Rose::Backend::Java::CompileBatch ( SgProject * project,
std::vector< std::string > argv )

Executes a batch compilation process for Java source files within a project.

This function orchestrates the compilation of Java source files by constructing a command-line invocation for the Java compiler. It processes the provided arguments, filters out existing source filenames to prevent duplicates, appends the actual source file paths from the SgProject, and ensures the destination directory for .class files is created. The command is then executed via a system call.

Parameters
projectA pointer to the SgProject containing the source files to be compiled. The project must be valid and specifically configured for Java.
argvA vector of strings representing the command-line arguments to be passed to the Java compiler, excluding the initial ROSE translator executable path.
Returns
An integer representing the error code returned by the system execution. A value of 0 typically indicates success.
Precondition
The project pointer must not be null.
The project must be a Java-only project (project->get_Java_only() must return true).
Postcondition
The destination directory for compiled .class files is created via CreateDestdir.
The project's Java, ECJ, and frontend error codes are reset to 0.
Note
The function modifies the command line by removing the first element of argv (the ROSE translator) and inserting the BACKEND_JAVA_COMPILER_NAME_WITH_PATH.
The implementation currently contains a TODO to improve error handling and a hardcoded override that sets errorCode to 0.

std::string Rose::Backend::Java::CreateDestdir ( SgProject * project)

Creates the destination directory for Java output as specified by the project.

This function retrieves the Java destination directory path from the provided SgProject object and attempts to create the directory on the file system using the boost::filesystem library. If the directory creation fails and the directory does not exist after the attempt, the function prints a fatal error message and aborts the program execution.

Parameters
projectA pointer to the SgProject instance containing the Java destination directory configuration.
Returns
A string containing the path to the created Java destination directory.
Precondition
The project parameter must not be null and must have a valid Java destination directory path configured via get_Java_destdir().
Postcondition
The directory specified by project->get_Java_destdir() will exist on the file system. If the directory could not be created, the program will have terminated via ROSE_ABORT().
Warning
If the directory creation fails, the function triggers a fatal error and calls ROSE_ABORT(), which terminates the entire process.
Note
This function relies on the boost::filesystem library for filesystem operations.
