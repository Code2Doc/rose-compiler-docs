Converts a syntax graph root into a string representation via an output stream.

This function performs the unparsing process by traversing a syntax graph structure (root) and writing its textual representation to the provided llvm::raw_ostream. It utilizes an internal UnparseSageVisitor to perform a depth-first traversal of the graph. The visitor handles the logic for formatting, encoding, and keyword capitalization based on the provided configuration parameters.

Parameters
outThe output stream where the unparsed text will be written.
rootThe root node of the syntax graph to be unparsed.
encodingThe character encoding to be used during the unparsing process.
capitalizeKeywordsA boolean flag indicating whether keywords should be rendered in uppercase.
backslashEscapesA boolean flag indicating whether backslash escape sequences should be applied to special characters.
cookedA pointer to the collection of all cooked sources used for contextual information during unparsing.
preStatementA pointer to a preStatementType object used to manage state or formatting before statements are emitted.
Precondition
The root object must be a valid, traversable syntax graph structure.
Postcondition
The output stream 'out' will contain the string representation of the provided graph, and the visitor state will be finalized via the Done() call.
Note
This function relies on the Walk function to traverse the graph structure.
