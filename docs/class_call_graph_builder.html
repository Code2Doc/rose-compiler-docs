SgGraphNode * CallGraphBuilder::hasGraphNodeFor ( SgFunctionDeclaration * fdecl) const

Retrieve the node matching a function declaration using firstNondefiningDeclaration (does not work across translation units).

Checks the graphNodes map for a graph node match fdecl.

CallGraphBuilder::hasGraphNodeFor

This does a lookup on the CallGraph map to see if a given function is in it. This is used in constructing the CallGraph. If multiple files are input on the command line firstNondefiningDeclartion may not be unique, so not finding a graphNode for fdecl does not guarantee that the target function does not exist in the graph, only that it is not in the lookup map. Use getGraphNodeFor to be sure. Again, this is mainly used in constructing the call graph.

[in]fdeclThe declaration of the function to look for in the graph
