bool partOfArrowOperatorChain ( SgExpression * expr)

Determines if a given expression is part of a chain of arrow operators.

This function recursively traverses the parent nodes of a binary operator expression to detect if it is part of an arrow operator chain. It specifically looks for instances where an overloaded "operator->" is being used within an SgArrowExp context. The implementation checks if the binary operator's parent is a function call that references "operator->", and then climbs up the expression tree, skipping over SgCastExp nodes, to see if the chain eventually terminates in an SgArrowExp.

Parameters
exprThe expression node to be checked for membership in an arrow operator chain.
Returns
True if the expression is identified as part of an arrow operator chain; otherwise, false.
Precondition
expr should be a valid SgExpression pointer.
Postcondition
The function returns a boolean indicating the presence of the operator chain without modifying the input expression tree.
Note
The function uses recursion to traverse the parent hierarchy.
The implementation includes logic to skip over SgCastExp IR nodes during the upward traversal.
Debugging information can be toggled using the define DEBUG_ARROW_OPERATOR_CHAIN directive.

Removes all occurrences of a specified substring from a given string.

This function iterates through the input string s and searches for every occurrence of the pattern p. Whenever an occurrence is found, it is erased from the string. The implementation uses the find method of basic_string to locate the pattern and the erase method to remove it.

Parameters
sThe source string that will be modified in-place by removing the substrings.
pThe pattern string to be searched for and removed from s.
Precondition
The string s and the pattern p must be compatible with the same basic_string character type T.
Postcondition
The string s will no longer contain any instances of the substring p.
Note
The function modifies the input string s directly.
The complexity depends on the number of occurrences of p in s and the efficiency of the underlying find and erase operations.

string unparse_operand_constraint ( SgAsmOp::asm_operand_constraint_enum constraint)

Converts an assembly operand constraint enumeration value into its string representation.

This function maps each element of the SgAsmOp::asm_operand_constraint_enum to a single-character string used in assembly language syntax (e.g., 'r' for register, 'm' for memory). It utilizes a static lookup table containing the character mapping for each constraint type.

Parameters
constraintThe enumeration value representing the specific assembly operand constraint to be converted to a string.
Returns
A string containing the single character corresponding to the provided constraint.
Precondition
The constraint value must be a valid member of the SgAsmOp::asm_operand_constraint_enum and must be within the bounds of the internal lookup table (less than SgAsmOp::e_last).
Postcondition
The function returns a valid std::string containing the character representation.
Note
The implementation uses a static array of characters for efficient lookup.
Historical notes in the implementation indicate adjustments for compatibility with GNU and Intel assemblers, such as changing the character for aoc_imm_number.
