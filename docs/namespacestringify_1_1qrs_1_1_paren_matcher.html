Retrieves a constant reference to a predefined vector of selection values.

Return all qrs::ParenMatcher::Selection member values as a vector.

This function provides access to a static, immutable vector containing a fixed set of 64-bit integer values. The implementation uses a static local variable to ensure that the vector is initialized only once during the first call to the function and persists for the lifetime of the program.

Returns
A constant reference to a std::vector<int64_t> containing the values {1, 2}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing the predefined elements.
Note
The returned vector is static and its lifetime is tied to the program execution. Since it returns a const reference, the contents of the vector cannot be modified through this function.

const char * stringify::qrs::ParenMatcher::Selection ( int64_t )

Converts a status integer into its corresponding string representation.

Convert qrs::ParenMatcher::Selection enum constant to a string.

This function maps specific 64-bit integer values to human-readable string literals representing the state of a parenthesis match. It uses a simple switch-case mechanism to evaluate the input.

Parameters
iThe 64-bit integer representing the selection state. Expected values are 1 for "Match" and 2 for "Mismatch".
Returns
A pointer to a constant character string. Returns "Match" if i is 1, "Mismatch" if i is 2, and an empty string "" for any other value.
Precondition
The input parameter i should be a valid integer representing a known state.
Postcondition
The returned pointer points to a static string literal that remains valid for the lifetime of the program.
Note
This function does not handle values outside of the 1 and 2 cases with specific error messages, returning an empty string instead.

Generates a formatted selection string based on an index and an optional prefix strip.

Convert qrs::ParenMatcher::Selection enum constant to a string.

This function retrieves a selection string using the single-parameter Selection(int64_t) overload. If the resulting string is empty, it constructs a fallback string containing a specific class identifier and the provided index. Finally, if the string starts with the specified strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer index used to retrieve the base selection string.
stripA string representing the prefix to be removed from the start of the generated selection string if it matches.
Returns
A string representing the processed selection. This may be the original string from Selection(i), a formatted fallback string, or a substring of the original/fallback string with the prefix removed.
Precondition
The parameter strip should be a valid string.
Postcondition
The returned string will not start with the contents of strip if strip was present at the start of the initial selection string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix checking.
