Converts a base 62 (All letters and numbers) number to a 64 bit int.
This is the most compressed format that can be used for a C++ identifier.

Converts a base-62 (All letters and numbers) number to a 64 bit int.

Base-62 is used to store hashes in the most efficient was that can also be a C++ identifier. Converting back to a uint64 is not generally required, but here's a function to do so.

This function iterates through each character of the provided Base62 string and accumulates the value by multiplying the current result by 62 and adding the numerical value of the current character. The character mapping used is '0'-'9' (0-9), 'A'-'Z' (10-35), and 'a'-'z' (36-61).

Parameters
base62A string containing the Base62 encoded characters to be converted.
Returns
The decoded 64-bit unsigned integer value.
Warning
If the input string represents a value that exceeds the maximum capacity of a 64-bit unsigned integer (UINT64_MAX), the resulting value will overflow and wrap around.
The function throws a std::invalid_argument exception if the input string contains any character not present in the Base62 alphabet.
Precondition
The input string base62 should contain only alphanumeric characters (0-9, A-Z, a-z).
Postcondition
The function returns a valid uint64_t representing the decoded value, provided no exception was thrown.
Note
The character set used for encoding is defined internally as "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz".

The permutation index pn must be strictly less than the factorial of sz.
Postcondition

Note

Permute a vector according to the specified permutation number. The permutation number should be between zero (inclusive) and the factorial of the values size (exclusive). A permutation number of zero is a no-op; higher permutation numbers shuffle the values in repeatable ways. Using swap rather that erase/insert is much faster than the standard Lehmer codes, but doesn't return permutations in lexicographic order. This function can perform approx 9.6 million permutations per second on a vector of 12 64-bit integers on Robb's machine (computing all 12! permutations in about 50 seconds).

Reorders the elements of a vector based on a provided mapping of indices.

Reorder the values of one vector according to another.

The second vector says how the first vector is rearranged. The argument values are the values to be reordered, and the argument remap says how to reorder them. Both arguments must be the same length, n. The remap argument contains all the integer indices from 0 (inclusive) to n (exclusive). If the values in their original order are named "old" and the values in their new desired order are named "new", then new[i] = old[remap[i]].

This function is useful when sorting parallel arrays. Say we have three parallel arrays named a, b, and c and we want to sort them all so array a is in ascending order according to its natural less-than operator. We could do that as follows:

std::vector<ValueA> a = { ... };
std::vector<ValueB> b = { ... };
std::vector<ValueC> c = { ... };
std::vector<size_t> remap(a.size());
std::iota(remap.begin(), remap.end(), 0);
std::sort(remap.begin(), remap.end(), [&a](const size_t i, const size_t j) {
return a[i] < a[j];
});
reorder(a, remap);
reorder(b, remap);
reorder(c, remap);

This function rearranges the elements within the values vector such that each element at index i in the resulting vector is the element that was originally at index remap[i]. The implementation uses an O(n) approach by creating a temporary copy of the original vector to ensure that the remapping process does not overwrite elements before they are moved to their new positions.

Parameters
valuesA reference to a vector of type T that will be modified in-place to reflect the new order.
remapA constant reference to a vector of size_t containing the new indices. Each element remap[i] specifies the source index from the original values vector.
Precondition
The size of the values vector must be equal to the size of the remap vector.
Postcondition
The values vector is updated such that values[i] contains the original value of values[remap[i]].
Note
The time complexity of this function is O(n), where n is the number of elements in the vectors, due to the allocation and copying of the temporary vector. The space complexity is also O(n) because of the temporary vector old.
Warning
This function assumes that all indices provided in the remap vector are within the valid bounds of the original values vector. Out-of-bounds indices in remap will lead to undefined behavior.

Shuffles a subset of elements within a vector using a random index swap algorithm.

Shuffle the values of a vector.

This algorithm randomly shuffles the items in the vector by swapping values at indexes zero through limit with values at randomly selected indexes zero through nitems. The defaults for nitems and limit are the size of the input vector.

This function performs a partial shuffle on the provided vector. It iterates up to a specified limit, selecting a random index within the range of the first nitems elements and swapping the element at the current iteration index with the element at the randomly selected index. This is a variation of the Fisher-Yates shuffle algorithm, constrained by the nitems and limit parameters.

Parameters
vectorThe vector of elements to be shuffled in-place.
nitemsThe range of indices (from 0 to nitems-1) from which a random index is selected. Defaults to UNLIMITED, which effectively uses the full size of the vector.
limitThe number of iterations to perform, determining how many elements are swapped. Defaults to UNLCDED, which effectively shuffles up to nitems.
Precondition
The vector must be a valid std::vector instance.
Postcondition
The elements within the range [0, limit-1] of the vector will have been swapped with elements within the range [0, nitems-1].
Note
The function uses Sawyer::fastRandomIndex to generate the random indices.
The effective value of nitems is clamped to the vector size, and the effective value of limit is clamped to the effective nitems.
