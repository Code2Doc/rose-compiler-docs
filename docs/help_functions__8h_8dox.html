Searches for the class declaration node associated with a specific SgType within a vector of nodes.

This function attempts to locate an SgNode representing a class declaration by matching the name of the provided sageType against nodes within the provided nodeVector. The search strategy depends on whether the sageType is a typedef. If the type is a typedef, the function uses a specific query (queryNodeClassDeclarationFromTypedefName) to find the underlying class declaration. If it is not a typedef, it performs a standard search for a class declaration matching the type name. The function iterates through the nodeVector, treating each element as a scope statement, and performs a subtree query.

Parameters
nodeVectorA vector of SgNode pointers representing the scope or tree segments to be searched.
sageTypeA pointer to the SgType whose class declaration is being sought.
Returns
A pointer to the SgNode representing the found class declaration, or NULL if no matching declaration is found.
Precondition
sageType must not be NULL, and the name derived from sageType via TransformationSupport::getTypeName must have a length greater than 0.
All elements in nodeVector must be valid SgNode pointers and must satisfy isSgScopeStatement.
Postcondition
The function returns a pointer to an existing SgNode within the searched subtree or NULL.
Note
The function uses NodeQuery::querySubTree to perform the search.
If the type is a typedef, the search specifically looks for the class declaration linked to that typedef name.
The function may print error messages to cerr if the search results are empty or unexpected.

SgNodePtrVector findScopes ( SgNode * astNode)

Retrieves a list of all relevant scopes associated with a given AST node.

Empty function or ill-formed function detected. /.

This function traverses the scope hierarchy upwards from the provided AST node, collecting all parent scopes until the global scope of the current file is reached. Once the global scope of the current file is identified, the function further expands the list to include the global scopes of all other files present within the same project. This ensures that the returned vector contains a complete set of scopes necessary for cross-file symbol resolution and visibility analysis.

Parameters
astNodeA pointer to the starting SgNode in the Abstract Syntax Tree. The node is expected to be an SgStatement.
Returns
A SgNodePtrVector containing the sequence of scopes, starting from the scope of the input node and ending with the global scopes of all files in the project.
Precondition
The input astNode must be a valid SgStatement (verified via ROSE_ASSERT).
The astNode must belong to a valid SgFile which in turn belongs to a valid SgProject.
Postcondition
The returned vector contains at least the scope of the input node and the global scopes of all files in the project.
Warning
This function relies heavily on ROSE_ASSERT statements; if the input node is not an SgStatement or if the hierarchy is broken, the program will abort.
Note
The implementation uses a loop to climb the scope tree using get_scope() and get_parent() methods.
