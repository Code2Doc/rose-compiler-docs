Rose_STL_Container< SgNode * > NodeQuery::generateListOfTypes ( SgNode * astNode)

Generates a list of all SgType nodes associated with a given AST node.

This function retrieves a collection of IR nodes that are variants of SgType. The implementation employs an optimization strategy based on the scope of the provided astNode. If the astNode belongs to an SgProject that contains only a single file, the function utilizes a high-performance memory pool query via queryMemoryPool. If the node is not part of a single-file project, the function falls back to a subtree traversal using querySubTree.

Parameters
astNodeA pointer to the SgNode representing the root of the subtree or the context from which types should be queried.
Returns
A Rose_STL_Container containing pointers to all SgNode objects that are variants of SgType found within the specified context.
Precondition
astNode should be a valid pointer to an SgNode.
Postcondition
Returns a container populated with SgType nodes; the container may be empty if no types are found.
Note
The fallback mechanism using querySubTree is noted as being expensive and potentially less accurate (e.g., missing vacuious destructors).
The use of memory pool querying is preferred for performance when the project scope is limited to a single file.
