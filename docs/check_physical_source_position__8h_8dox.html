size_t checkPhysicalSourcePosition ( SgNode * ast)

Validates the consistency of physical source position information within an AST.

This function performs a traversal of the provided Abstract Syntax Tree (AST) to ensure that all nodes implementing the SgLocatedNode interface possess consistent physical file information. It specifically checks that if a file ID is valid (non-negative), the corresponding physical file ID must also be valid (non-negative). The function utilizes an internal visitor pattern (AstSimpleProcessing) to inspect each node.

If an inconsistency is detected—specifically where a file ID is non-negative but the physical file ID is negative—the function prints an error message containing the file info and the parent node's details, and then triggers a ROSE_ABORT().

Parameters
astA pointer to the root node of the AST to be inspected.
Returns
The number of physical source position violations detected during the traversal.
Precondition
The input ast must be a valid pointer to an SgNode.
Postcondition
The function leaves the AST in its original state, but may terminate the program via ROSE_ABERT() if an inconsistency is found.
Warning
This function will abort the program execution if it encounters a node where the file ID is valid but the physical file ID is invalid.
Note
The implementation uses a local struct T1 inheriting from AstSimpleProcessing to encapsulate the traversal logic and violation counting.
