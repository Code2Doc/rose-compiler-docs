void commandLineProcessing ( std::vector< std::string > & argvList)

Parses command line arguments to configure RoseHPCT execution modes and options.

This function iterates through the provided argument list to detect specific RoseHPCT configuration flags. It specifically checks for flags related to enabling debug mode via the -rose:hpct:enable_debug option and configuring gprof-based line-by-line performance analysis via the -rose:gprof:linebyline option. If the --help or -help flags are detected, the function prints a usage summary to the standard output. The function modifies global or static state variables such as enable_debug and gprof_only based on the presence of these arguments.

Parameters
argvListA reference to a vector of strings containing the command line arguments to be processed.
Precondition
The argvList must be properly initialized and contain the command line arguments passed to the application.
Postcondition
The global/static variables enable_debug and gprof_only are updated based on the contents of argvList. The state of the gprof_file_name variable may be modified if the gprof option is present.
Note
This function relies on the CommandlineProcessing utility class for parsing logic.
The --help option is intentionally left in the argument list processing flow to allow other modules to respond to the help request.

Extracts all values associated with a specific option name from a list of arguments.

This function searches through a vector of strings representing command-line arguments to find occurrences of a specified option name. It utilizes the sla_str utility function to identify matches based on a predefined option prefix and value separator. If matches are found, the function extracts the associated values and appends them to the provided values vector.

Parameters
argvListA reference to a vector of strings containing the argument list to be searched.
opt_nameA C-style string representing the name of the option to search for.
valuesA reference to a vector of strings where the discovered option values will be stored.
Returns
The number of matches found for the specified option name.
Precondition
The argvList and values vectors should be in a valid state.
Postcondition
The values vector will contain all newly discovered values appended to its existing contents if matches were found.
Note
This function performs dynamic memory allocation for an array of strings (raw_values) internally to hold the matches before pushing them into the values vector.
Warning
This function does not explicitly call delete[] on the raw_values array, which may lead to a memory leak if the underlying sla_str implementation does not manage the lifecycle of the allocated raw_values array.
