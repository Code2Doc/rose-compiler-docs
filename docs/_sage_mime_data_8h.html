QMimeData * createSageMimeData ( SgNode * node)

Creates a QMimeData object containing serialized SgNode information.

creates MIME Data out of a SgNode depending on the node, the base type (source or binary) gets set by finding the appropriate SgFile the other file gets set if the appropriate Link Attribute is set

This function encapsulates an SgNode pointer and its associated hierarchical metadata into a QMimeData object suitable for drag-and-drop operations. The function serializes the raw pointer of the node into a QByteArray associated with the SG_NODE_MIMETYPE.

The implementation performs a tree traversal upwards from the provided node to find the nearest SgFile ancestor. Depending on whether the ancestor is an SgSourceFile or an SgBinaryComposite, the function further serializes attribute mechanism links (using writeLinks) into the QMimeData object under the SG_NODE_SOURCE_MIMETYPE and SG_NODE_BINARY_MIMETYPE keys.

Parameters
nodeA pointer to the SgNode to be encapsulated in the QMimeData.
Returns
A pointer to a newly allocated QMimeData object containing the serialized node and its hierarchical metadata.
Precondition
node must not be a null pointer for the serialization of the node pointer to be meaningful, although the function logic handles traversal based on the node's existence.
Postcondition
The returned QMimeData object contains at least the SG_NODE_MIMETYPE data. If the node's ancestor is an SgSourceFile or SgBinaryComposite, additional MIME types may be present.
Note
The serialization of the node pointer relies on the memory address remaining valid during the lifetime of the QMimeData usage.
The function uses QDataStream with Unbuffered mode for raw data writing.

Extracts a vector of SgNode pointers from QMimeData based on a specific MIME type.

This function retrieves raw binary data from a QMimeData object associated with the provided MIME type. It uses a QDataStream to deserialize the byte array, iterating through the stream to reconstruct a sequence of SgNode pointers. Each pointer is read directly from the raw data stream.

Parameters
dataA pointer to the QMimeData object containing the encoded node information. If this pointer is null, an empty vector is returned.
typeA QString representing the MIME type format to look for within the data.
Returns
An SgNodeVector containing the deserialized SgNode pointers. If the data is null, the type is not found, or the stream is empty, an empty vector is returned.
Precondition
The QMimeData object data should contain valid, serialized SgNode pointers encoded in a format compatible with QDataStream.
Postcondition
Returns a vector containing all successfully read SgNode pointers.
Note
The function relies on the assumption that the size of a pointer (SgNode*) is consistent with the architecture used during serialization.
Warning
If the data stream is corrupted or does not contain complete pointer addresses, the behavior of the pointer reconstruction may be undefined.
