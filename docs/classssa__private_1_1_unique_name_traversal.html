◆ propagateNamesThroughComma

const bool ssa_private::UniqueNameTraversal::propagateNamesThroughComma
private

If true, expressions such as (a, b).x will be named as b.x. This allows detecting more defs, but if the left-hand side of a comma has modifying side effects it may reduce the safety of an analysis.
