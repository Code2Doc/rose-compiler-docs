◆ setProgressFunc()

void qrs::QRQueryOperator::setProgressFunc ( QRQueryProgressFunc func,
void * arg )

Sets progress event-handler.

The event handler(func) supplied is of type QRQueryProgressFunc, which contains three arguments: isInit (boolean), count(unsigned) and a user-supplied argument (arg). This event-handler is called first with isInit set to 'true' and count with the total number of domain elements. Afterwards, the event-handler is called for every node queried with isInit set to 'false' and count set to the number of nodes queried at that point.
