bool Rose::Cmdline::Gnu::OptionRequiresArgument ( const std::string & option)

Determines if a given command-line option requires an associated argument.

Returns
true if the GNU option requires a user-specified argument.

This function checks the provided command-line option string against a predefined list of options that necessitate an argument (e.g., key-value pairs). Currently, it specifically checks if the option is "--param", which expects a "variable=value" format.

Parameters
optionA string representing the command-line option to be checked.
Returns
True if the specified option requires an argument, false otherwise.
Precondition
The option string should be a valid command-line flag.
Postcondition
The return value indicates the requirement status of the input option.
Note
This function is part of the Rose::Cmdline::Gnu namespace logic for parsing GNU-style command-line arguments.

Processes GNU command-line options for a given project.

This function parses and applies command-line arguments provided in the argv vector to the specified SgProject instance. It utilizes the ProcessParam helper function to handle the underlying parameter parsing logic. If the project's verbosity level is set higher than 1, an informational message is printed to the standard output indicating the start of the processing phase.

Parameters
projectA pointer to the SgProject instance that will receive the processed command-line configurations.
argvA reference to a vector of strings containing the command-line arguments to be parsed.
Precondition
project must not be a null pointer.
Postcondition
The project state is updated based on the contents of argv, and any applicable command-line parameters are applied to the project.
Note
This function relies on the verbosity setting of the SgProject to determine whether to log progress to the console.

void Rose::Cmdline::Gnu::ProcessParam ( SgProject * project,
std::vector< std::string > & argv )

Processes a specific command-line parameter from the provided argument vector.

This function scans the provided argument vector argv for a specific parameter pattern defined by the "--" prefix and a "(param)" suffix. If such a parameter is found, the function extracts the associated value into a local string. If the SgProject verbose level is set higher than 1, an informational message is printed to the standard output indicating the detected parameter.

Parameters
projectA pointer to the SgProject instance used to check the current verbosity level via get_verbose().
argvA reference to a vector of strings representing the command-line arguments to be parsed.
Precondition
The project pointer must be valid and not null to safely call SgProject::get_verbose().
Postcondition
If a parameter matching the specified pattern is found, it is processed internally, and a message may be logged to std::cout.
Note
This function relies on CommandlineProcessing::isOptionWithParameter to perform the actual parsing logic.
