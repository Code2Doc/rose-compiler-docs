Applies a rewrite rule to a syntax graph node and its descendants recursively.

This function performs a deep rewrite operation on a given syntax graph node. It utilizes a DoRewriteRuleDeepVisitor to traverse the syntax graph starting from the provided node using a preorder traversal strategy. During the traversal, the visitor applies the specified rewrite rule to the nodes. After the traversal is complete, the original node reference is updated to point to the new node produced by the visitor.

Parameters
ruleA pointer to the RewriteRule object containing the logic for the transformation.
nA reference to a pointer of an SgNode. This node is the root of the subtree to be processed. The pointer will be updated to the new node resulting from the rewrite operation.
Returns
True if the rewrite rule was successfully applied and the process is complete; false otherwise.
Precondition
The rule pointer must be valid and not null. The node n must point to a valid SgNode or be null.
Postcondition
The node n is updated to the new node returned by the visitor. The state of the syntax graph subtree rooted at n is modified according to the rule.
Note
The traversal follows a preorder pattern, meaning the parent nodes are visited before their children.
