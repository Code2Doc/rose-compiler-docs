12// The support for unparsing from the token stream is a feature in
13// ROSE to provide a new level of portability for the generated code.
14
15// This support for frontier detection on the AST distinguishes
16// the subtrees that must be unparsed from the AST vs. those that
17// may be unparsed from the token stream. The solution is not to
18// simply unparse the whole file from the token stream starting
19// at the SgSourceFile, since this would not reflect transformations
20// and might not reflect parts of the AST for which there is some
21// lack of precise enough information in the mapping of the token
22// stream to the AST (to support this feature of unparsing from
23// the token stream).
24
25// This SIMPLE version is an attempt to build a more precise unparsing
26// which is simpler and which will divide the unparsing from the
27// token stream into pieces that surround the subtree that must be
28// unparsed from the AST (because it was transformed).
