Traverses a directed graph to collect all reachable nodes and edges starting from a specific node.

This function performs a graph traversal (resembling a breadth-first search approach) to identify all nodes and edges that are reachable from a given starting node within an incidence directed graph. The implementation uses sets and vectors to track visited edges and nodes to prevent infinite loops in the presence of cycles. It iteratively expands the frontier of discovered edges and nodes by querying the outgoing edge set of newly discovered nodes using the computeEdgeSetOut method.

Parameters
gA pointer to the SgIncidenceDirectedGraph instance to be traversed.
startA pointer to the SgGraphNode from which the traversal begins.
Returns
A pair of vectors, where the first element is a vector of pointers to all reachable SgGraphNode objects, and the second element is a vector of pointers to all reachable SgDirectedGraphEdge objects.
Precondition
g must not be a null pointer.
start must not be a null pointer and must be a valid node within the graph g.
Postcondition
The returned vectors contain all nodes and edges reachable from the start node via directed paths.
Note
The complexity of the traversal depends on the number of reachable edges and nodes in the graph.
The function relies on the computeEdgeSetOut method of the SgIncidenceDirectedGraph class to discover adjacent edges.

Creates and populates a new myGraph instance based on an incidence directed graph and a CFG.

This function performs a transformation from a structural representation (SgIncidenceDirectedGraph) to a custom graph representation (myGraph). It traverses the edges of the provided incidence directed graph starting from the entry node of the CFG. For each edge encountered, the function maps the source and target SgGraphNodes to new vertices in the myGraph instance. It maintains a mapping between the original nodes and the new vertex IDs to ensure that each unique node is represented by exactly one vertex in the resulting graph. The function also reconstructs the edges between these vertices, ensuring that duplicate edges are not added to the new graph.

Parameters
gA reference to a pointer of an SgIncidenceDirectedGraph. This graph serves as the source of the structural information used to build the new graph.
cfgA reference to a StaticCFG::CFG object used to provide the control flow graph context and to map SgGraphNodes to CFG nodes.
Returns
A pointer to the newly allocated myGraph object containing the mapped vertices and edges.
Precondition
The input graph g must be a valid, non-null pointer to an SgIncodeDirectedGraph.
The cfg object must be properly initialized and capable of mapping SgGraphNodes via toCFGNode.
Postcondition
A new myGraph object is allocated on the heap. The caller is responsible for managing the memory of the returned pointer.
Note
The implementation relies on an internal mapping mechanism (VSlink) to track previously encountered nodes to prevent redundant vertex creation.
The function uses Boost Graph Library (BGL) components such as boost::add_vertex and boost::add_edge for graph construction.

Constructs and initializes a custom graph structure from an incidence directed graph and a control flow graph.

This function performs a transformation from a ROSE-based SgIncidenceDirectedGraph and an InterproceduralCFG into a specialized myGraph object. The implementation traverses the edges of the provided incidence graph starting from the entry node of the CFG. For each edge encountered, the function maps the source and destination SgGraphNodes to unique VertexIDs within the new graph. It utilizes a mapping mechanism (VSlink) to ensure that each SgGraphNode is represented by exactly one vertex in the resulting graph and uses a set of vertex pairs to prevent the creation of duplicate edges in the new graph structure.

Parameters
gA reference to a pointer of an SgIncidenceDirectedGraph, representing the source incidence graph.
cfgThe InterproceduralCFG object used to retrieve the entry node and map SgGraphNodes to CFG nodes.
pstartA pointer to an SgNode representing the starting point for the graph instantiation.
Returns
A pointer to the newly allocated myGraph object containing the mapped vertices and edges.
Precondition
The input SgIncidenceDirectedGraph pointer g must be valid.
The cfg object must be properly initialized and contain a valid entry node.
The pstart node must be a valid SgNode.
Postcondition
A new myGraph object is allocated on the heap.
The returned graph contains vertices corresponding to the SgGraphNodes reachable via edges in g.
Note
The function relies on the existence of a global or externally defined VSlink map, getGraphNode map, and the getAllNodesAndEdges helper function.
