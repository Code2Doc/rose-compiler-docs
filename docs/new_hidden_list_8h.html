Generates hidden type and declaration lists for name qualification support.

This function serves as the top-level API for Name Qualification support within the ROSE framework. It is primarily invoked during the unparsing process (e.g., via Unparser::unparseFile) to compute and store name qualification information into static data member maps within SgNode. The process involves traversing the provided AST node to populate maps that support the qualification of both named IR nodes and types. The function utilizes a HiddenListTraversal to perform the actual computation, passing references to global maps and the provided referenced name set.

Parameters
nodeA pointer to the SgNode representing the root of the AST fragment to be processed.
referencedNameSetA set of SgNode pointers used to track and store the set of referenced names encountered during the traversal.
Precondition
The node parameter should not be null, and the referencedNameSet should be a valid, initialized std::set.
Postcondition
The global qualified name maps for names and types, as well as the global type name map in SgNode, are updated based on the traversal of the provided node. The referencedNameSet is populated with the nodes discovered during the traversal.
Note
This function is designed to be the single entry point for ROSE to access name qualification functionality. It relies on the HiddenListTraversal class to execute the underlying tree traversal and attribute inheritance.

Parameters
nodeA pointer to the SgNode representing the root of the AST fragment to be processed.
referencedNameSetA reference to a set of SgNode pointers that will be populated with the set of referenced names discovered during the traversal.
Precondition
The node parameter should not be NULL and should represent a valid part of the AST or a SgProject.
Postcondition
The referencedNameSet is updated to include all discovered referenced nodes. The global qualified name maps and type maps in SgNode are updated via the traversal process.
Note
This function is a key entry point for the unparser to ensure that nested types and qualified names are correctly resolved during code generation.
The implementation uses a TimingPerformance timer to track the execution duration of the generation process.
