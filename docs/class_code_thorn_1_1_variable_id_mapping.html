virtual

create the mapping between symbols in the AST and associated variable-ids. Each variable in the project is assigned one variable-id (including global variables, local variables, class/struct/union data members)

param[in] project: The Rose AST we're going to act on param[in] maxWarningsCount: A limit for the number of warnings to print. 0 = no warnings -1 = all warnings
