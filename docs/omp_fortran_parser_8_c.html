◆ omp_fortran_parse()

OmpSupport::OmpAttribute * omp_fortran_parse ( SgNode * locNode,
const char * str )

Parses OpenMP directive strings associated with a specific node.

This function implements a parser for OpenMP directives formatted as Fortran-style comments (e.g., !$omp). It scans the provided string for recognized OpenMP sentinels and keywords such as atomic, barrier, critical, do, parallel, etc. The function identifies the type of OpenMP directive, handles associated clauses (like private or firstprivate), and constructs an OmpAttribute object to represent the parsed directive. It also handles complex directives like "end parallel do" or "end critical" by checking for subsequent keywords.

Parameters
locNodeThe SgNode representing the location in the AST where the directive is associated.
strThe input string containing the OpenMP directive text to be parsed.
Returns
A pointer to a newly constructed OmpAttribute object if a valid OpenMP directive is found; otherwise, returns NULL if no OpenMP sentinels are detected.
Precondition
locNode must not be NULL.
Postcondition
If a valid directive is found, a non-null OmpAttribute is returned and global parsing state (like c_char and c_sgnode) is updated.
Warning
The function calls ROSE_ABORT() if an invalid OpenMP directive is encountered after a valid sentinel is detected.
Note
The parser uses a lowercase copy of the input string for case-insensitive matching. It relies on helper functions like ofs_match_substr, ofs_match_omp_clauses, and buildOmpAttribute to perform the actual tokenization and object construction.

Parses OpenMP directives within Fortran source files.

This function iterates through all located nodes in a given Sage source file to identify and parse OpenMP directives formatted as Fortran-style comments (e.g., !$omp). It specifically handles the complexities of Fortran line continuations using the '&' character, which may appear at the end of a line or as a marker for a second line. The implementation merges lines that are part of a continuous directive, removes unnecessary characters, and uses the omp_fortran_parse utility to extract OpenMP attributes.

Parameters
sageFilePtrA pointer to the SgSourceFile representing the source file to be parsed.
Precondition
sageFilePtr must be a valid, non-null pointer to an SgSourceFile object.
Postcondition
OpenMP attributes found in the source file are parsed and added to the global omp_comment_list, and associated metadata is attached to the corresponding SgLocatedNode.
Note
The function relies on the existence of SgLocatedNode objects within the provided source file and assumes that preprocessing information is attached to these nodes.
The parsing logic accounts for various line continuation scenarios, including cases where source comments might follow a continuation character.

This function iterates through all located nodes in a given Sage source file to identify and parse Fortran-style OpenMP directives (e.g., !$omp). It specifically handles the complexities of Fortran line continuations using the '&' character, where a directive might span multiple lines. The algorithm identifies preprocessing information attached to nodes, checks for OpenMP sentinels, merges lines that are part of a continuation sequence, and removes extraneous comments. Once a complete, non-continued directive is reconstructed, it invokes the OpenMP parser to create attribute objects.

Parameters
sageFilePtrA pointer to the SgSourceFile representing the source code to be parsed.
Precondition
sageFilePtr must be a valid, non-null pointer to an SgSourceFile object.
Postcondition
The function populates the global omp_comment_list with parsed OmpAttribute objects and updates the preprocessing information within the SgNodes where applicable.
Note
The function relies on the existence of NodeQuery::querySubTree to locate nodes and omp_fortran_parse to perform the actual directive parsing.
The handling of line continuations is designed to manage cases where the '&' character is used both for standard line continuation and as a marker for the start of a second line.
