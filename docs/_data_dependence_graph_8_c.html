void outputNodeInfo ( std::ostream & os,
SgNode * defSgNode )

Outputs a formatted string containing information about an SG node to an output stream.

This function writes a descriptive string to the provided output stream representing the identity of the given SgNode. The output format includes the node's name and its class name. If the node has an initialized name (retrieved via isSgInitializedName), the function uses the qualified name of that initialized name. Otherwise, it falls back to the string representation obtained from the unparseToString method of the node.

Parameters
osThe output stream where the node information will be written.
defSgNodeA pointer to the SgNode whose information is to be output.
Precondition
defSgNode should not be a null pointer to avoid undefined behavior when accessing class_name() or unparseToString().
Postcondition
The content of the stream os is appended with a string in the format: "name" of class className.
Note
The function relies on the implementation of isSgInitializedName, get_qualified_name, unparseToString, and class_name to construct the output string.
