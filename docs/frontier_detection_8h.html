void frontierDetectionForTokenStreamMapping ( SgSourceFile * sourceFile,
bool traverseHeaderFiles )

Detects the frontier of nodes for mapping token subsequences to the AST.

This function performs a traversal of the AST (either within a single file or including header files) to identify "frontier" nodes. These nodes represent the boundaries where unparsing may switch between using the original token stream and the reconstructed AST. The function identifies these nodes, associates them with specific attributes (such as color-coded DOT attributes for visualization), and builds a mapping of statements to their respective frontier nodes. It also computes adjacency information (previous and next nodes) to establish a linked structure for the unparsing process.

Parameters
sourceFileA pointer to the SgSourceFile to be processed. Must not be NULL.
traverseHeaderFilesA boolean flag indicating whether the traversal should extend into included header files or remain restricted to the current source file.
Precondition
sourceFile must not be NULL.
The SgSourceFile must be part of a valid SgProject.
Postcondition
The frontier nodes identified during traversal are stored in the FrontierDetectionForTokenStreamMapping traversal object.
SgStatement nodes within the frontier are decorated with FrontierDetectionForTokenStreamMappingAttribute for visualization.
The source file (or its associated include file) is updated with a mapping of SgStatement pointers to FrontierNode pointers.
Note
The function uses include and define logic via the ROSE framework to manage AST attributes.
Visualizations in DOT format may be generated if the SgProject verbose level is sufficiently high.
