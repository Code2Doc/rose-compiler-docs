Return all TaintLattice::Vertex member values as a vector.

This function provides access to a static, immutable vector containing a hardcoded sequence of 64-bit integer values. The values are stored in a static array and then encapsulated within a static std::vector to ensure the data persists for the lifetime of the program and is only initialized once.

Returns

Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing the predefined elements.
Note

const char * stringify::TaintLattice::Vertex ( int64_t )

Converts a lattice element integer ID to its corresponding string representation.

Convert TaintLattice::Vertex enum constant to a string.

This function maps specific 64-bit integer identifiers to their human-readable string labels within the TaintLattice domain. It uses a switch-case mechanism to perform a direct lookup of the vertex name based on the provided ID.

Parameters
iThe 64-bit integer representing the lattice vertex ID.
Returns
A pointer to a constant character string representing the vertex name. Returns "VERTEX_BOTTOM" for 0, "VERTEX_UNTAINTED" for 1, "VERTEX_TAINTED" for 2, and an empty string "" for any other value.
Precondition
The input parameter i should correspond to a valid defined vertex ID in the lattice.
Postcondition
The returned pointer points to a static string literal and does not require manual memory management.
Note
This function does not handle error states for undefined IDs other than returning an empty string.

Generates a string representation of a vertex, optionally stripping a prefix.

Convert TaintLattice::Vertex enum constant to a string.

This function retrieves the string representation of a vertex ID using the overloaded Vertex(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(TaintLattice::Vertex)" followed by the integer ID. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe unique identifier for the vertex.
stripA string prefix to be removed from the start of the generated vertex string if it exists.
Returns
A string representing the vertex, potentially with a prefix removed.
Precondition
The parameter i should be a valid identifier within the TaintLattice context.
Postcondition
The returned string will not start with the strip content if it was originally present at the start of the vertex string.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
