Accumulates properties of neighbors of specified edges using a binary operation.

This function iterates through a collection of edges and, for each edge, identifies a corresponding neighbor using a provided member function pointer. It then retrieves the property associated with that neighbor from a property map and accumulates these values into an initial value using a binary operation. If the input edge list is empty, the function returns a specified fallback value.

Parameters
cfgThe control flow graph containing the underlying graph structure.
propA map containing properties associated with graph nodes.
edgesA vector of integers representing the edges to be processed.
edge_to_neighborA pointer to a member function of PRE::simpleGraph that maps an edge index to a neighbor node index.
combineA binary operation object used to accumulate the properties.
initThe initial value for the accumulation process.
ifnoneThe value to be returned if the edges vector is empty.
Returns
The accumulated result of the binary operation applied to the properties of the neighbors, or the value of ifnone if no edges are provided.
Precondition
The edge_to_neighbor function must return a valid node index that exists within the prop map.
Postcondition
The returned value represents the result of the combine operation applied sequentially to the properties of all neighbors found.
Note
The second parameter of the function is an unnamed integer and is not documented.

bool legacy::anyOfListPotentiallyModifiedIn ( const vector< SgVariableSymbol * > & syms,
SgNode * n )

Checks if any variable in a given list is potentially modified within a specific node.

Are any variables in syms modified anywhere within n, or is n a declaration of one of them?

This function iterates through a list of variable symbols and determines if any of them undergo potential modifications within the scope of the provided SgNode. The implementation checks for modifications by creating temporary variable reference expressions and evaluating them using isPotentiallyModified. Additionally, it checks if the node itself is a variable declaration that includes any of the symbols from the input list, which would also constitute a modification/initialization.

Parameters
symsA vector of pointers to SgVariableSymbol representing the list of variables to check.
nThe SgNode within which the potential modifications are being investigated.
Returns
True if at least one variable in syms is found to be potentially modified in n, false otherwise.
Precondition
The pointer n must be a valid SgNode. The elements within the syms vector should be valid SgVariableSymbol pointers.
Postcondition
The function does not modify the input syms vector or the SgNode n. Temporary SgVarRefExp objects created during the process are properly deleted.
Note
This function currently contains a FIXME note suggesting it should be moved to the inliner.
The function uses manual memory management for the temporary SgVarRefExp object.

SageNode * legacy::cloneNode ( const SageNode * n)

Creates a deep copy of a given SageNode.

This function provides a high-level interface for duplicating a node within the Sage graph structure. It utilizes the SageInterface::deepCopy mechanism to ensure that the entire subtree rooted at the provided node is replicated, maintaining the structural integrity of the cloned node.

Parameters
nA pointer to the constant SageNode to be cloned.
Precondition
The input pointer n should ideally point to a valid, initialized SageNode.
Postcondition
Returns a pointer to a new SageNode that is a deep copy of the original, or a null pointer if the input n was null.
Note
If n is nullptr, the function returns nullptr without attempting any copy operations.

Counts the number of times a specific expression is computed within a given node's subtree.

Count how many computations of expr are within root. Same caveats as expressionComputedIn.

This function utilizes the ExpressionComputedInVisitor pattern to traverse the provided syntax graph node hierarchy. It performs a postorder traversal starting from the root node to identify and count all occurrences where the target expression is computed within the scope of the root node.

Parameters
exprA pointer to the SgExpression whose computation occurrences are being tracked.
rootA pointer to the SgNode that serves as the starting point for the traversal.
Returns
The total count of computations of the specified expression found within the subtree of the root node.
Precondition
expr and root must not be null.
Postcondition
The returned integer represents the frequency of the expression's computation in the traversal.
Note
The traversal follows a postorder strategy, ensuring that child nodes are processed before their parents.

Determines if a specific expression is computed within a given node tree.

Is the expression expr computed within root? This test is simple, and does not account for changes to the variables in expr.

This function checks whether the provided expression is computed at least once within the scope of the specified root node. It relies on counting the occurrences of computations associated with the expression.

Parameters
exprA pointer to the SgExpression whose computation status is being checked.
rootA pointer to the SgNode representing the root of the tree/scope to search within.
Returns
True if the number of computations of the expression found in the root is non-zero; false otherwise.
Note
This function does not account for changes to the variables within the expression.
Precondition
expr and root should be valid, non-null pointers to their respective types.
Postcondition
The state of the expression or the root node remains unchanged.
