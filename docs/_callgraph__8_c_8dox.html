Assigns a file location string to a graph vertex attribute based on an SgNode.

This function extracts source code location information (filename and line numbers) from an SgNode, provided it is an instance of SgLocatedNode. It constructs a URI-style string in the format file://filename:startline:0[:endline:0] and stores this string in the GraphType's vertex attribute map under the specified label for the given vertex.

Parameters
nodeA pointer to the SgNode being inspected for location information.
labelThe attribute key (string) used to store the location string in the graph.
vdescA reference to the specific vertex in the graph to which the attribute is assigned.
GThe GraphType object containing the vertex attribute maps.
Precondition
node must not be null if it is to be processed, though the function handles non-located nodes gracefully.
Postcondition
If the node is an SgLocatedNode and has valid start information, the graph G is updated with a new attribute value for vertex vdesc at the provided label.
Note
The function uses boost::get to access the vertex attribute map.
If the node is not an SgLocatedNode or lacks start file information, no changes are made to the graph.

Searches for class declarations within the AST that match a specific type.

This function inspects a given AST node to determine if it represents a class declaration that matches the provided type. It performs a type check by casting the input type node to an SgType and comparing it against the type associated with the class declaration. If a match is found, the node is added to a list of results.

Parameters
astNodeThe AST node to be inspected for a class declaration.
typeThe type node used for comparison against the class declaration's type.
Returns
A NodeQuerySynthesizedAttributeType containing a list of matching SgNode pointers. If no match is found, an empty list is returned.
Precondition
astNode must not be null.
Postcondition
The returned list contains the astNode if it is an SgClassDeclaration and its type matches the type provided in the parameters.
Note
This function utilizes ROSE assertion checks to ensure the validity of the input astNode. It also prints debug information to the standard error stream (cerr) during the search process.

Identifies if a given AST node matches a specific function declaration by name.

This function performs a query to determine if the provided astNode represents the same function as the functionDecl. It retrieves the mangled name of the functionDecl and compares it against the mangled name of the astNode, provided that the astNode is identified as an SgMemberFunctionDeclaration within a class definition.

Parameters
astNodeThe AST node to be queried for a matching function declaration.
functionDeclThe function declaration node used as the reference for the name comparison.
Returns
A NodeQuerySynthesizedAttributeType containing a list of matching nodes. If the astNode matches the functionDecl, the list contains the astNode; otherwise, the list is empty.
Precondition
astNode must not be NULL.
Postcondition
The returned list will either contain the astNode or be empty, depending on the name match.
Note
This function relies on the mangled name of the nodes for comparison.
The function uses ROSE_ASSERT to validate the input astNode.

Queries whether a given AST node is a member function definition matching a specific function definition node.

This function attempts to identify if the provided astNode represents a member function declaration that points to the same definition as the provided functionDefinition. It performs checks to verify if the node is a member function declaration, if it belongs to a class definition, and if its underlying definition node matches the functionDefinition parameter.

Parameters
astNodeThe AST node to be queried. Must not be NULL.
functionDefinitionThe function definition node to compare against the definition of the astNode.
Returns
A NodeQuerySynthesizedAttributeType containing a list of nodes. If the astNode is a member function declaration whose definition matches functionDefinition, the list will contain astNode. Otherwise, the list will be empty.
Precondition
astNode must not be NULL.
Postcondition
The returned list will either contain the astNode or be empty, depending on the structural relationship between astNode and functionDefinition.
Note
This function contains debug print statements that output to cerr regarding node locations and class definition findings.
