Constructs a code reference variable based on two POETCode objects.

This function attempts to create a CodeVar reference by casting the first input to a CodeVar. It performs a validation check to ensure that if the first object has defined parameters, those parameters match the second object using the MATCH_PAR_NOMOD criteria. If the first object is not a valid CodeVar or if parameter mismatch is detected, an error is triggered via CODE_UNDEFINED or CVAR_MISATMATCH macros. Finally, it delegates the actual construction to the ASTFactory singleton.

POETCode * RemoveSpaceFromList ( POETCode * r)

Recursively removes nodes containing only whitespace from a POETCode structure.

This function traverses a POETCode tree structure (which may be a list or a string) and prunes nodes that consist solely of whitespace characters. For POETList structures, the function recursively processes the first and rest elements, rebuilding the list while omitting any elements that evaluate to EMPTY. For string nodes (SRC_STRING), if the content consists entirely of whitespace as determined by the IS_SPACE macro, the node is replaced with EMPTY.

Parameters
rA pointer to the POETCode node to be processed. This can be a POETList, a POETString, or any other type of POETCode node.
Returns
A pointer to a new or existing POETCode structure with all whitespace-only nodes removed. Returns EMPTY if the input node is a string containing only whitespace or if the resulting list becomes empty.
Precondition
The input pointer r should be a valid pointer to a POETCode object or NULL.
Postcondition
The returned POETCode structure contains no nodes that represent purely whitespace strings. The original structure may be partially reconstructed via ASTFactory.
Note
The function uses dynamic_cast to identify POETList nodes and static_cast for SRC_STRING nodes. It relies on the existence of the ASTFactory singleton and the EMPTY constant.
