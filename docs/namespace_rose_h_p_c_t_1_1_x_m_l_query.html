map< string, string > RoseHPCT::XMLQuery::getMetricTable ( const XMLNode_t * doc)

Returns a lookup table of short-to-long metric names.

Extracts a mapping of metric identifiers to their corresponding values from an XML document.

This function traverses the provided XML document tree to find all elements with the tag name "Metric". For each "Metric" element found, it retrieves the attribute "i" to serve as the map key and the attribute "n" to serve as the map value. The function uses an XMLElemFinder utility to iterate through the relevant nodes. Only elements where the "i" attribute is not empty are added to the resulting map.

Parameters
docA pointer to the root or subtree XMLNode_t from which to begin the search for metric elements.
Returns
A map where each key is a string representing the "i" attribute of a "Metric" element, and each value is a string representing the "n" attribute of that same element.
Precondition
The pointer doc should be a valid, non-null pointer to an XMLNode_t structure.
Postcondition
Returns a populated map containing all valid metric pairs found in the provided XML subtree.
Note
The function ignores "Metric" elements that have an empty "i" attribute.

Return all statement elements in the XML tree.

Retrieves all elements with the tag name "S" from the provided XML document.

This function traverses the provided XML document tree to find all occurrences of elements specifically tagged as "S". It utilizes an XMLElemFinder utility to iterate through the document nodes and collects every matching element into a vector of XMLElem objects.

Parameters
docA pointer to the root or parent XMLNode_t from which the search for "S" elements begins.
Returns
A vector containing all XMLElem objects found with the tag name "S". If no such elements are found, an empty vector is returned.
Precondition
The doc pointer must not be null.
Postcondition
The returned vector contains all identified "S" elements, and the original XML document remains unmodified.
Note
The search is performed using the XMLElemFinder class, which implements an iterator-based traversal of the XML tree.

Returns the version of the XML file.

Retrieves the version attribute from the HPCToolkitExperiment element in an XML document.

This function searches the provided XML document for an element named "HPCToolkitExperiment". If exactly one such element is found, it extracts and returns the value of the "version" attribute. The implementation utilizes the XMLElemFinder utility to locate the specific node within the provided XML tree structure.

Parameters
docA pointer to the root or parent XML node (XMLNode_t) to be searched.
Returns
A string containing the value of the "version" attribute if a single "HPCToolkitExperiment" element is found; otherwise, returns an empty string.
Precondition
The doc pointer must be a valid, non-null pointer to an XMLNode_t object.
Postcondition
The function does not modify the input XML document.
Note
If multiple elements named "HPCToolkitExperiment" are found, the function returns an empty string to avoid ambiguity.
