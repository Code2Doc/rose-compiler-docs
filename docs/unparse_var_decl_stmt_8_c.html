std::string build_decl_item_asm_register ( SgInitializedName * decl_item)

Constructs an inline assembly register string for a given initialized name.

This function generates a formatted string suitable for C++ inline assembly syntax, specifically targeting the register operand part of an assembly block. It checks if the provided SgInitializedName object contains register-specific metadata, such as a register code or a register name string. The function handles the construction of the string by prepending the appropriate compiler-specific prefix (e.g., asm for Intel Compiler or asm for others) and appending the register identifier within parentheses.

Parameters
decl_itemA pointer to the SgInitializedName object containing the declaration information, including potential register assignments and names.
Returns
A string containing the formatted inline assembly register instruction (e.g., " asm (\"eax\")") if register information is present, or an empty string if no register information is associated with the decl_item.
Precondition
The decl_item pointer must not be null.
If a register code or register name is present, the decl_item name must not be empty.
Postcondition
The returned string, if not empty, will follow valid inline assembly syntax for the target compiler.
Note
The function uses ifdef and else logic to determine whether to use the __asm__ or asm keyword based on the presence of the BACKEND_CXX_IS_INTEL_COMPILER macro.
The function utilizes ROSE_ASSERT to ensure that a declaration does not simultaneously contain both a register code and a register name, and that the declaration name is valid if assembly registration is required.
Debugging information may be printed to stdout if the DEBUG__build_decl_item_asm_register macro is defined.

std::string build_decl_item_name ( SgInitializedName * decl_item)

Constructs a string representation of a declaration item's name.

This function extracts the name of a given SgInitializedName object and formats it into a human-readable string. The implementation checks if the name is anonymous (either empty or starting with the "__anonymous_0x" prefix). If the name is not anonymous and the language is identified as C++, the function prepends the qualified name prefix to the base name.

Parameters
decl_itemA pointer to the SgInitializedName object whose name is to be constructed.
Returns
A string containing the unparsed name of the declaration item. If the item is anonymous, an empty string is returned. Otherwise, it returns the qualified prefix concatenated with the name.
Precondition
decl_item must not be a null pointer.
Postcondition
The returned string is a valid, non-null std::string.
Note
The function utilizes if DEBUG__build_decl_item_name to perform logging of the input parameters and intermediate processing steps during debug builds.
The function checks for C++ specific behavior using SageInterface::is_Cxx_language().

Unparse_ExprStmt & unparser,

Generates the string representation for the C11 _Alignas keyword.

This function handles the unparsing logic for declarations that utilize the C11 _Alignas keyword. It checks if the provided declaration item contains the _Alignas keyword and, if so, constructs the syntax _Alignas(operand). The operand can be either a type or a constant expression. The function uses the provided unparser object to print the necessary syntax and recursively unparse the operand.

Parameters
decl_itemA pointer to the SgInitializedName representing the declaration to be unparsed.
unparserA reference to the Unparse_ExprStmt object used to manage the unparsing stream and printing operations.
infoA reference to the SgUnparse_Info object containing context information for the unparsing process.
Precondition
decl_item must not be null and must be a valid SgInitializedName object.
Postcondition
The unparser stream will contain the formatted _Alignas string if the declaration item uses the C11 _Alignas keyword.
Note
If the operand for the _Alignas keyword is neither a valid SgType nor a valid SgExpression, the function will print an error message and trigger a ROSE_ABORT().
This function may use if DEBUG__unparse_alignas for diagnostic printing.
