void Rose::KeepGoing::Frontend::SignalHandler ( int sig)

Handles incoming system signals during frontend processing.

This function acts as a signal handler to intercept and log system signals that occur during the execution of the frontend. It attempts to provide a human-readable description of the signal using strsignal on non-MSVC platforms. Upon receiving a signal, the function attempts to perform a long jump back to a predefined jump target to recover the execution flow, provided the platform supports it.

Parameters
sigThe integer signal number received from the operating system.
Warning
On Windows (where ifdef _MSC_VER is true), the function does not support the "KeepGoing" feature and will trigger a ROSE_ASSERT failure if a signal is caught.
Precondition
The global or accessible jump target Frontend::jmp_target must be properly initialized via sigsetjmp before a signal is caught if recovery is intended.
Postcondition
On non-MSVC platforms, the execution flow is redirected to Frontend::jmp_target using siglongjmp. On MSVC platforms, the program will likely terminate due to an assertion failure.
Note
The implementation uses ifndef _MSC_VER to differentiate between POSIX-compliant signal handling (using strsignal and siglongjmp) and Windows-specific behavior.
