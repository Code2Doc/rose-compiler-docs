Validates that template instantiations are not declared within a template definition scope.

This function performs semantic checks to ensure that template instantiations are not incorrectly placed within the scope of a template definition. For member functions, the function ensures the parent of the function is set to the provided scope and validates the scope's integrity. For non-member template functions, it verifies that if a template instantiation is detected, the associated scope is a valid template class definition.

Parameters
funcA pointer to the SgDeclarationStatement representing the function or declaration being checked.
scopeA pointer to the SgScopeStatement representing the scope in which the declaration resides.
Precondition
scope must not be NULL if the function is identified as a member function declaration.
Postcondition
If func is a member function declaration, its parent is set to the provided scope.
Note
The implementation may include debug-specific behavior via ifdef ROSE_DEBUG_NEW_EDG_ROSE_CONNECTION.
The behavior regarding enforcement of template function declarations in template class instantiations is controlled by the if !ENFORCE_NO_FUNCTION_TEMPLATE_DECLARATIONS_IN_TEMPLATE_CLASS_INSTANTIATIONS macro.

◆ generate_type_list()

string generate_type_list ( SgType * type)

Generates a comma-separated string representing the hierarchy of types in a type structure.

This function traverses the underlying type structure of a given SgType object, stripping away various type modifiers, references, pointers, arrays, and typedefs level by level. It concatenates the class name of each encountered type level into a single string, separated by a comma and a space. The traversal logic is governed by a bitmask (bit_array) that determines which specific type decorators are to be stripped during the iteration.

Parameters
typeA pointer to the SgType object from which the type list is to be generated.
Returns
A string containing the concatenated names of the types found at each level of the type hierarchy, separated by " , ".
Precondition
The input pointer type should ideally point to a valid SgType object.
Postcondition
The returned string contains the names of all types encountered during the traversal of the type hierarchy, up until a type is reached that cannot be further stripped according to the defined bitmask.
Note
The function uses a bitmask containing SgType::STRIP_MODIFIER_TYPE, SgType::STRIP_REFERENCE_TYPE, SgType::STRIP_RVALUE_REFERENCE_TYPE, SgType::STRIP_POINTER_TYPE, SgType::STRIP_ARRAY_TYPE, and SgType::STRIP_TYPEDEF_TYPE to decide which layers to peel away.
