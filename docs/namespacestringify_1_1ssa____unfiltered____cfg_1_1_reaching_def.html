Retrieves a constant reference to a predefined vector of type values.

This function provides access to a static, immutable collection of 64-bit integers representing specific type identifiers. The vector is initialized once during the first call to the function and persists for the lifetime of the program. The values contained in the vector are 0, 1, 2, and 3.

Returns
A constant reference to a std::vector<int64_t> containing the predefined type values {0, 1, 2, 3}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing exactly four elements.
Note
The returned vector is stored in static memory, ensuring that the initialization overhead occurs only once.

const char * stringify::ssa__unfiltered__cfg::ReachingDef::Type ( int64_t i)

Converts a definition type integer ID into its corresponding string representation.

This function maps specific 64-bit integer identifiers to human-readable string constants representing different types of definitions within the SSA unfiltered configuration context. The mapping is implemented using a switch-case mechanism.

Parameters
iThe 64-bit integer representing the definition type ID.
Returns
A pointer to a constant character string representing the type name. Returns "PHI_FUNCTION" for 0, "ORIGINAL_DEF" for 1, "EXPANDED_DEF" for 2, and "EXTERNAL_DEF" for 3. Returns an empty string "" if the input does not match any of the predefined cases.
Precondition
The input parameter i should ideally correspond to one of the defined integer constants used within the ReachingDef analysis.
Postcondition
The returned string is a static literal and does not require memory deallocation.

Generates a formatted type string for a given integer ID, optionally stripping a prefix.

This function retrieves a string representation of the provided 64-bit integer ID using an overloaded Type(int64_t) function. If the resulting string is empty, it constructs a fallback string in the format "(ssa_unfiltered_cfg::ReachingDef::Type)" followed by the integer ID. Finally, if the string starts with the specified strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer ID to be converted into a type string.
stripA string representing the prefix to be removed from the start of the generated type string if it exists.
Returns
A string representing the processed type name.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the strip content if it was present in the original string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
