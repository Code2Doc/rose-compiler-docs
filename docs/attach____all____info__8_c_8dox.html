const string & opt_name,
std::vector< std::string > & values )

Extracts values associated with a specific option name from command-line arguments.

This function searches through a vector of command-line arguments for occurrences of a specified option name, identified by a predefined prefix and separator. It utilizes the sla_str utility to first count the number of matches and then perform a second pass to retrieve the actual string values associated with that option. The retrieved values are then appended to the provided values vector.

Parameters
argvA reference to a vector of strings representing the command-line arguments.
opt_nameThe name of the option to search for within the argument vector.
valuesA reference to a vector of strings where the found option values will be appended.
Returns
The number of matches found for the specified option name.
Precondition
The argv vector must contain valid command-line argument strings.
Postcondition
The values vector will contain all newly found values appended to its existing contents if matches were found.
Note
This function relies on the existence of OPTION_PREFIX_ROSE and OPTION_VALUE_SEPARATOR macros or constants.

std::vector< std::string > readWordsInFile ( std::string filename)

Reads a sequence of words from a specified file and returns them as a vector of strings.

This function attempts to open a file specified by the provided filename and extract individual words separated by whitespace. Currently, the implementation is controlled by a preprocessor directive if. When if is enabled, the function delegates the operation to the StringUtility::readWordsInFile method. In the alternative implementation path, the function manually opens an fstream, checks for file accessibility, and iterates through the file content using the extraction operator to populate a vector.

Parameters
filenameThe path to the file from which words are to be read.
Returns
A vector of strings containing all the words found in the file.
Warning
If the file cannot be opened (e.g., file does not exist), the alternative implementation path will print an error message to standard output and terminate the program using exit(1).
Precondition
The filename must point to a valid, readable file on the filesystem.
Postcondition
The returned vector contains all whitespace-separated tokens found in the file.
Note
The current implementation relies on if 1, meaning the logic is presently redirected to the StringUtility namespace.
