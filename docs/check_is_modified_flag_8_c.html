bool checkIsModifiedFlag ( SgNode * node)

Checks if any node in a subtree is marked as modified and resets their flags.

This function performs a preorder traversal of the AST subtree rooted at the provided node. It identifies any nodes within the subtree that have their isModified flag set to true. If such a node is found, the function records that a modification was detected and subsequently resets the isModified flag of that node to false. This implementation is a memory-efficient reimplementation designed to avoid the high space complexity associated with previous versions when processing large programs.

Parameters
nodeA pointer to the root SgNode of the subtree to be inspected and processed.
Returns
True if at least one node in the subtree was found with the isModified flag set; otherwise, false.
Precondition
node must not be a null pointer.
Postcondition
All nodes within the subtree of the provided node that had isModified set to true will have their isModified flag reset to false.
Note
The set_isModified() function is the only setter-style access function that does not trigger the modification flag, which is a relevant detail for the consistency of the flag state during traversal.

ROSE_DLL_API void unsetNodesMarkedAsModified ( SgNode * node)

Resets the modified flag on all nodes within a given AST subtree.

This function performs a deep traversal of the Abstract Syntax Tree (AST) starting from the provided node. It utilizes an internal visitor class, NodesMarkedAsModified, which inherits from AstSimpleProcessing. During a preorder traversal, the function checks each node to see if its isModified flag is set to true; if so, it invokes set_isModified(false) to clear the flag.

Parameters
nodeA pointer to the root SgNode from which the traversal begins.
Precondition
The node pointer must not be null.
Postcondition
All nodes reachable from the input node that previously had their isModified flag set to true will now have their isModified flag set to false.
Note
The set_isModified() function is specifically noted as the only setter access function that does not trigger a recursive modification flag update.
