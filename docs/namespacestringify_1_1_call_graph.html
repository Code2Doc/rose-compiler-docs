Retrieves a constant reference to the default edge type values.

Return all CallGraph::EdgeType member values as a vector.

This function provides access to a static collection of 64-bit integer values representing the edge types. The implementation uses a static local vector initialized with a single element (0L) to ensure the data persists for the lifetime of the program and to avoid unnecessary reallocations.

Returns
A constant reference to a std::vector<int64_t> containing the predefined edge type values.
Precondition
None.
Postcondition
The returned reference points to a valid, non-empty vector containing the value 0.
Note
The returned vector is static and thread-safe for reading after initialization.

std::string stringify::CallGraph::EdgeType ( int64_t ,

Generates a formatted string representing an edge type, optionally stripping a prefix.

Convert CallGraph::EdgeType enum constant to a string.

This function retrieves the string representation of an edge type associated with the provided ID. If the underlying EdgeType(i) call returns an empty string, a default format "(CallGraph::EdgeType)" followed by the string representation of the ID is used. Additionally, if the resulting string starts with the specified strip string, that prefix is removed from the final output.

Parameters
iThe 64-bit integer identifier representing the edge type.
stripA string prefix that, if found at the start of the generated edge type string, should be removed.
Returns
A string containing the formatted edge type, potentially with the specified prefix removed.
Precondition
The identifier i should correspond to a valid edge type definition within the system to avoid default fallback formatting.
Postcondition
The returned string will not start with the contents of strip if strip was a prefix of the original edge type string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
