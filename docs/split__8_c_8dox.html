vector< string > split ( const string & s)

Splits a string into a vector of substrings based on whitespace delimiters.

This function iterates through the input string s to identify contiguous sequences of non-whitespace characters. It uses a two-pointer approach (indices i and j) to skip leading whitespace and identify the boundaries of each word. The implementation is a string-based adaptation of a character-pointer-based algorithm.

Parameters
sThe input string to be parsed and split.
Returns
A vector of strings, where each element is a substring of s containing non-whitespace characters.
Precondition
The input string s should be a valid std::string object.
Postcondition
The returned vector contains all non-empty substrings separated by whitespace found in the original string.
Note
This implementation relies on isspace to determine word boundaries.
The algorithm effectively ignores all whitespace characters (spaces, tabs, newlines, etc.) acting as delimiters.
