Detailed Description

Implementation of a parser/visitor for Ada language constructs.

This module provides a large-scale switch-based dispatcher that processes various Ada language elements (AST nodes) extracted from a parser. It handles the semantic construction of the Abstract Syntax Tree (AST) by traversing nodes such as:

  • Package/Subprogram Declarations: Handles ada_package, ada_subprogram, and ada_procedure nodes, managing scope and visibility.
  • Type Declarations: Processes ada_type, ada_record, and ada_access definitions, including private types and discriminants.
  • Variable/Constant Declarations: Manages ada_variable and ada_constant instantiations, including visibility within blocks.
  • Task/Concurrency Constructs: Handles ada_task and task body definitions.
  • Complex Type Definitions: Processes ada_array, ada_enumerated, and ada_derived types.

The implementation utilizes a visitor pattern to traverse the AST, performing semantic analysis, symbol table population, and construction of the final decorated AST.

Note
The implementation relies heavily on a context object to maintain state (symbol tables, scope levels, and current node pointers).
