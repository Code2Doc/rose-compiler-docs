Parameters

Generates a formatted string representing a template instantiation enumeration.

Convert SgProject::template_instantiation_enum enum constant to a string.

This function retrieves a string representation of a template instantiation index and optionally removes a specified prefix. It first calls an overloaded version of template_instantiation_enum(int64_t) to obtain the base string. If the resulting string is empty, it constructs a fallback string in the format (SgProject::template_instantiation_enum) followed by the integer value. Finally, if the string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer representing the template instantiation index.
stripA string representing the prefix to be removed from the start of the generated string if it exists.
Returns
A string containing the formatted template instantiation identifier, potentially with the specified prefix stripped away.
Precondition
The parameter i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the content of the strip parameter if the original string contained that prefix.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
