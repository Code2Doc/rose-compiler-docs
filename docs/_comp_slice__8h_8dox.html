const CompSlice * slice )

Identifies an unused loop induction variable within a given code slice.

This function iterates through the loop hierarchy present in the provided code slice. It collects all loop induction variable names defined within the slice and tracks which of these variables are referenced within the bodies of other loops in the same slice. The function identifies the first induction variable that is not referenced by any other loop in the slice.

The implementation uses a nested iteration approach:

  1. It traverses the loop tree using a ConstLoopIterator.
  2. For each loop, it extracts the induction variable name.
  3. It then iterates through the statements within that loop to find enclosing loops that might reference the current loop's induction variable.
  4. It uses a std::set to maintain a collection of all slice variables and a separate set for variables that are explicitly used.
  5. Finally, it performs a set difference to find an unused variable.
Parameters
faThe AST interface used for creating new variables if no unused loop induction variable is found.
sliceA pointer to the CompSlice object representing the code segment to be analyzed.
Returns
A SymbolicVar representing the first found unused loop induction variable. If all loop induction variables are used, it returns a newly created SymbolicVar of type "int" via the fa interface.
Precondition
The slice pointer must not be null.
Postcondition
The returned SymbolicVar will either be an existing loop variable from the slice or a newly allocated integer variable.
Note
The function relies on GetEnclosingLoop and LoopTreeInterface to traverse the loop hierarchy.

The function compares the set of all loop variables against the set of used variables to find the first variable that does not appear in the usage set.

Computes the symbolic bounds for a loop range within a given slice.

This function iterates through the constant statements within a provided slice to determine the union of symbolic bounds. It retrieves the variable bounds from the parent of the provided loop tree node and adjusts the bounds of each loop found in the slice by subtracting the alignment offset. The final result is a union of all these adjusted bounds, merged with the existing bounds of the parent node.

Parameters
sliceA pointer to a CompSlice object containing the statements to be analyzed.
rootA pointer to the LoopTreeNode representing the root of the loop structure being analyzed.
Returns
A SymbolicBound object representing the union of the adjusted bounds calculated from the slice statements and the parent's bounds.
Precondition
The slice pointer and root pointer must not be null.
Postcondition
The returned SymbolicBound contains the aggregated bounds of all loops processed in the slice, adjusted by their respective alignment.
Note
The function relies on the loop tree structure and the ability to retrieve variable bounds via LoopTreeGetVarBound and LoopTreeGetVarConstBound.

Determines the common loop step and reversibility for all loops within a slice.

This function iterates through all loops contained within the provided CompSlice to identify a consistent step value and determine if the entire sequence of loops can be considered reversible. It examines the step size and the reversibility property of each loop in the slice. If a discrepancy in step size is found, the function validates that the steps are additive inverses and checks compatibility with the reversibility flag.

This function iterates through all loops contained within the provided CompSlice. It attempts to find a consistent step value and a global reversibility flag. The algorithm starts with the step and reversibility of the first loop and updates them as it traverses the slice. If a loop's step differs from the current step, it checks if the steps are additive inverses and if at least one of the loops is reversible. If a loop is not reversible, the global reversibility flag is set to false.

Note
