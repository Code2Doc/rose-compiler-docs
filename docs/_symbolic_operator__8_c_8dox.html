Performs symbolic division of two symbolic values.

This operator implements division by transforming the operation into a multiplication by the reciprocal. Specifically, it calculates the power of the second operand (v2) to the power of -1 and then multiplies the first operand (v1) by this result. This approach allows the symbolic engine to handle division using existing multiplication and exponentiation logic.

Parameters
v1The dividend in the division operation.
v2The divisor in the division operation.
Returns
A SymbolicVal representing the result of the division v1 / v2.
Precondition
v2 should not represent a symbolic value that evaluates to zero to avoid division by zero errors in subsequent evaluations.
Postcondition
The returned SymbolicVal represents the mathematical equivalent of v1 * (v2^-1).
Note

For directional relations, the function swaps less-than with greater-than and less-than-or-equal with greater-than-or-equal.

Postcondition

Note
