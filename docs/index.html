\c libRoseQtWidgets provides Qt-Widgets which can display internal datastructures of ROSE. \n
   These Qt-Widgets make it easy to build a GUI for your own ROSE project.\n

Location in ROSE distribution

The project is split up into several directories:

  • Library with all widgets is located at src/roseExtensions/qtWidgets
  • Plugin library for Qt-Designer at projects/QtDesignerPlugins
  • RoseQt is a application which uses all these widgets, it is located at projects/RoseQt
RoseQt GUI

Projects that already use RoseQtWidgets

There are several projects which already use the ROSE QtWidgets. You can look at them to learn how to integrate the Qt-Widgets in your own project.

  • RoseQt Gui projects/RoseQt
  • Compass projects/compass/tools/compass/gui2
  • RTED Debugger projects/RTED/CppRuntimeSystem/DebuggerQt
