jobject sourcePosition )

Converts a Java source position object into a native JavaSourceCodePosition structure.

This function interfaces with the Java Native Interface (JNI) to extract source code positioning metadata from a Java object. It retrieves the class of the provided sourcePosition object and uses reflection-style method calls to fetch the start and end indices for both lines and columns. Once the integer values are retrieved, a new instance of JavaSourceCodePosition is allocated on the heap.

Parameters
envA pointer to the JNI environment used to interact with the Java Virtual Machine.
sourcePositionA reference to the Java object representing the source code position, which must implement methods for getting line and column boundaries.
Returns
A pointer to a newly allocated JavaSourceCodePosition object containing the extracted line and column information. The caller is responsible for managing the memory of the returned pointer.
Precondition
The env parameter must not be NULL.
The sourcePosition object must be a valid JNI reference and must possess the methods: getLineStart, getLineEnd, getColumnStart, and getColumnEnd with the signature ()I.
Postcondition
A new JavaSourceCodePosition object is allocated on the heap.
Note
This function performs heap allocation using the 'new' operator.

Converts a Java string to a C++ std::string with path normalization.

This function facilitates the conversion of a JNI jstring object into a standard C++ string. It retrieves the UTF-8 encoded characters from the Java string using the JNI environment. If the code is being compiled with the MSVC compiler (detected via ifdef _MSC_VER), the function performs an additional step of replacing Windows-style backslash path separators with POSIX-style forward slashes. Finally, the resulting string is passed through a normalization function before being returned.

Parameters
envA pointer to the JNI environment structure used to interact with the Java Virtual Machine.
java_stringThe input Java string object to be converted.
Returns
A std::string containing the converted and normalized content of the input Java string.
Precondition
The JNIEnv pointer env must be valid and currently attached to the calling thread.
Postcondition
The JNI resources allocated by GetStringUTFChars are released using ReleaseStringUTFChars to prevent memory leaks.
Note
The function relies on the existence of a normalize function to process the final string.
Note that env cannot be passed into this function as const.
