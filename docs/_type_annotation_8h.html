bool DebugAnnot ( )

Checks if debug annotation mode is enabled based on command line options.

Checks if debug annotation is enabled based on command line options.

This function determines whether the debug annotation feature should be active. It utilizes a static integer variable to cache the result of the check after the first invocation, ensuring that the command line options are only inspected once. The function queries the singleton instance of CmdOptions to look for the specific flag "-debugannot".

Returns
True if the "-debugannot" option is present in the command line arguments, false otherwise.
Precondition
The CmdOptions singleton must be properly initialized before this function is called.
Postcondition
The internal static state of the function is updated to reflect the result of the first check, preventing repeated lookups.
Note
The function uses a static variable to maintain state across multiple calls, making the check efficient after the initial execution.
