void fixupFunctionDefaultArguments ( SgNode * node)

Determines the best function declaration to associate default arguments.

This function identifies the most appropriate function declaration within the AST to hold default arguments, ensuring that redundant default argument entries across multiple declarations are eliminated. It handles both SgProject nodes (by recursively processing all files in the project) and SgFile nodes.

The implementation uses a traversal mechanism (FixupFunctionDefaultArguments) to collect function declarations and their associated default arguments. It then iterates through the collected sets to find a primary declaration. For all other declarations in the same set, the function removes the redundant default arguments by clearing their initializers.

Parameters
nodeA pointer to the SgNode to be processed. This can be an SgProject, an SgFile, or any other SgNode.
Precondition
node must not be NULL.
Postcondition
If the node is an SgProject, all associated files are processed. If the node is an SgFile, redundant default arguments in function declarations within that file are removed, and the associated AST nodes for those arguments are deleted (unless they contain lambda expressions).

This function identifies the most appropriate function declaration within an AST (Abstract Syntax Tree) to hold default arguments, ensuring that redundant default argument entries are eliminated across multiple declarations of the same function.

The implementation performs the following steps:

  1. If the provided node is an SgProject, it recursively calls this function for every file in the project.
  2. If the node is part of an existing AST, it retrieves the associated SgFile.
  3. It utilizes a FixupFunctionDefaultArguments traversal to collect all function declarations and group them by their shared identity.
  4. It identifies a "best" declaration (the primary one) to retain the default arguments.
  5. For all other redundant declarations in the set, it iterates through the arguments and removes the initializers (the default values).
  6. It includes specific logic to handle lambda expressions, ensuring that the AST nodes for default arguments are not deleted if they contain lambdas, to prevent memory corruption or dangling pointers.
Parameters
nodeA pointer to the SgNode to be processed. This can be an SgProject, an SgFile, or any node within an AST hierarchy.
Precondition
node must not be NULL.
Postcondition
Redundant default arguments in secondary function declarations are removed, and the AST is updated such that only the primary declaration retains the default values.
Note

The function uses SageInterface::deleteAST to clean up removed default argument expressions, provided they do not contain lambda expressions.
