Identifies and aggregates subtrees within a search tree that correspond to a specific macro call.

This function performs a structural analysis of a given SgNode tree to find nodes that match the patterns defined by a macro call. It utilizes a traversal mechanism via FindSmallestStatements to identify initial matching nodes and then iteratively climbs the AST hierarchy. The algorithm attempts to group multiple matching nodes under a common parent if that parent contains multiple identified subtrees, effectively merging fragmented matches into larger, contiguous subtrees bounded by statement boundaries. The implementation uses set operations (intersection and difference) to manage the collection of matching nodes during the upward traversal.

Parameters
searchTreeA pointer to the root SgNode from which the search for macro-matching subtrees begins.
macroCallA pointer to the PreprocessingInfo object containing the details of the macro call to be matched against the tree.
matchingSubtreeA reference to a vector of SgNode pointers that will be populated with the identified matching subtrees. This vector is modified in-place.
Returns
True if the macro successfully matches the subtrees; otherwise, false. Note that the current implementation primarily returns true unless specific logic is added.
Precondition
searchTree must not be a null pointer.
Postcondition
matchingSubtree will contain the identified SgNode pointers that represent the maximal subtrees matching the macro call.
Note
This function contains logic wrapped in an ifndef CXX_IS_ROSE_CODE_GENERATION preprocessor directive.
The function uses a goto statement (did_removal) to restart the traversal logic after a parent node has been merged into the matching set.
Warning
The function performs heavy tree traversals and set operations, which may impact performance on very large ASTs.

void UnparseMacro::unparseMacroCalls ( SgNode * searchTree)

Replaces expanded macro calls in the AST with their original macro call text.

This function traverses the provided Abstract Syntax Tree (AST) to identify nodes associated with preprocessor information. It attempts to revert the unparsing of expanded macro calls by matching the preprocessor information to specific subtrees within the AST. For each match found, it replaces the expanded content with the original macro string. The function handles logic for appending semicolons in specific configurations where the macro call is not an expression, specifically when ifndef USE_ROSE and ifndef ROSE_SKIP_COMPILATION_OF_WAVE are defined.

Parameters
searchTreeA pointer to the root SgNode of the AST to be searched and modified.
Precondition
searchTree must not be NULL.
Postcondition
The nodes within the searchTree that represent expanded macro calls are updated with new PreprocessingInfo containing the original macro call string.
Note
The function relies on the existence of a findPreprocInfo class to traverse the tree and a matchMacroToSubtrees function to identify replacement targets.
The implementation uses ROSE_ASSERT to ensure that identified nodes are valid SgStatement and SgLocatedNode instances.
