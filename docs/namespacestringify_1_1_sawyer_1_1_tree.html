Return all Sawyer::Tree::TraversalEvent member values as a vector.

This function provides access to a static, immutable vector containing the fundamental values used to represent traversal events. Convert Sawyer::Tree::TraversalEvent enum constant to a string.

Parameters
iThe integer identifier representing a traversal event. 0L corresponds to "ENTER" and 1L corresponds to "LEAVE".
Returns
A pointer to a constant character string ("ENTER", "LEAVE", or an empty string if the input does not match).
Precondition
The input parameter i should be a valid event code (0 or 1) to receive a meaningful string.
Postcondition
The returned pointer points to a static string literal that remains valid for the lifetime of the program.
Note
Any integer value other than 0 or 1 will result in an empty string return.

Formats and strips a traversal event string based on a provided prefix.

Convert Sawyer::Tree::TraversalEvent enum constant to a string.

This function generates a string representation of a traversal event associated with a specific ID. It first attempts to retrieve a formatted string using an overloaded version of TraversalEvent. If the resulting string is empty, it constructs a default identifier string in the format "(Sawyer::Tree::TraversalEvent)" followed by the string representation of the ID. Finally, if the generated string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe unique identifier for the traversal event.
stripA string prefix that, if found at the start of the generated event string, should be removed.
Returns
A string representing the processed traversal event, with the specified prefix removed if applicable.
Precondition
The strip parameter should be a valid string.
Postcondition
The returned string will not start with the contents of strip if strip was present at the start of the original event string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix checking.
