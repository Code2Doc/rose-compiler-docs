Retrieves a constant reference to the predefined set of element types.

Return all Sawyer::Yaml::ConstIterator::eType member values as a vector.

This function provides access to a static, immutable collection of 64-bit integer values representing specific element types. The collection is initialized once during the first call to the function and persists for the lifetime of the program. The values contained in the vector are 0, 1, and 2.

Returns
A constant reference to a std::vector<int64_t> containing the predefined type values {0, 1, 2}.
Precondition
None.
Postcondition
The returned reference points to a valid, static vector containing the predefined values.
Note
The returned vector is stored in static memory, ensuring that the overhead of construction is incurred only once.

Parameters
iThe 64-bit integer representing the type identifier to be converted.
Returns
A pointer to a constant character string representing the type name. Returns "None" for 0, "SequenceType" for 1, "MapType" for 2, and an empty string "" for any other value.
Precondition

The returned string is a static literal and does not require manual memory management.

Formats an enumeration type value as a string with an optional prefix removal.

Convert Sawyer::Yaml::ConstIterator::eType enum constant to a string.

This function retrieves the string representation of an integer value using an overloaded eType function. If the resulting string is empty, it constructs a fallback string containing a specific class identifier and the integer value. Additionally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer value representing the enumeration type to be formatted.
stripA string representing the prefix to be removed from the start of the formatted string if it exists.
Returns
A string representing the formatted enumeration type, potentially with the strip prefix removed.
Precondition
The integer i should be a valid value for which an eType representation exists.
Postcondition
The returned string will not start with the strip substring if it was present at the start of the original formatted string.
Note
This function relies on boost::lexical_cast for integer-to-string conversion and boost::starts_with for prefix detection.
