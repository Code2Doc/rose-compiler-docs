Adds a preprocessor macro directive as attached information to a given statement.

This function creates a new PreprocessingInfo object representing a macro directive based on the provided macro string and directive type. It then attaches this information to the specified SgStatement node. The implementation uses hardcoded metadata (filename, line number, and column number) for the purpose of macro-call fixups in specific test cases.

Parameters
associatedStatementThe SgStatement node to which the macro information will be attached.
macroStringThe string content representing the macro directive.
directiveTypeThe type of the preprocessor directive (e.g., define, undef).
Precondition
associatedStatement must not be a null pointer.
Postcondition
The associatedStatement will contain a new PreprocessingInfo object in its attached preprocessing information collection.
Note
This function allocates a new PreprocessingInfo object on the heap using the new operator. The caller or the owner of associatedStatement is responsible for managing the lifecycle of the attached information to prevent memory leaks.

void fixupSelfReferentialMacrosInAST ( SgNode * node)

Fixes self-referential macros within an Abstract Syntax Tree (AST) node.

This function performs a traversal of the provided AST node to identify and resolve macros that refer to themselves. It utilizes a specialized traversal class, FixupSelfReferentialMacrosInAST, to navigate the tree structure. The traversal is performed using a preorder strategy to ensure that parent nodes are processed before their children, maintaining consistency with other ROSE interface traversals. The function also includes performance tracking to monitor the execution time of the macro fixup process.

Parameters
nodeA pointer to the root SgNode from which the traversal begins.
Precondition
The node parameter must not be a null pointer.
Postcondition
The AST subtree rooted at the provided node will have self-referential macros corrected.
Note
The traversal uses a preorder approach to ensure uniform interface behavior.
