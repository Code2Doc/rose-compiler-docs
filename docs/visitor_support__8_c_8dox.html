Generates C++ code to delegate a visitor method to a strategy object.

This function writes a specific C++ code snippet to the provided output stream. The generated code defines a virtual override for a visitor pattern, which intercepts a call for a specific node type and forwards the execution to an internal strategy object's visit method. This is typically used during code generation phases to implement boilerplate delegation logic.

Parameters
headerThe output stream where the generated C++ code will be written.
nodeTypeA string representing the class name of the node type to be used in the function signature of the generated visit method.
Precondition
The header stream must be in a valid, writable state.
Postcondition
The header stream will contain a new line followed by a formatted virtual function definition that calls _strategy->visit(x).
Note
The generated code assumes that a member variable named _strategy is accessible within the scope where the generated code is placed.

Generates C++ code for visitor pattern support in header and implementation files.

This function automates the generation of boilerplate code required for a visitor pattern implementation. It handles the creation of function declarations in a header stream and function definitions in an implementation stream. If the node type is "SgNode", it delegates the task to emitLocalOutputVisitorSupport. For other node types, it generates a function declaration in the header and a function definition in the implementation that performs a static cast to the base node type before calling the base visit method.

Parameters
headerAn output stream representing the header file where the function declaration will be written.
implAn output stream representing the implementation file where the function definition will be written.
visitorTypeA string representing the name of the visitor class.
nodeTypeA string representing the name of the specific node type being processed.
Precondition
The header and impl streams must be valid and open for writing.
Postcondition
The header stream will contain a new function declaration if nodeType is not "SgNode". The impl stream will contain a new function definition if nodeType is not "SgNode".
Note
This function relies on the existence of a base node type within the nodeType class to perform the static_cast.

Generates C++ code for visitor pattern method declarations and implementations.

This function automates the generation of boilerplate code required for a visitor pattern. It writes a virtual function declaration to the provided header stream and a corresponding function definition to the implementation stream. The implementation is designed to call a default visit method, allowing derived classes to provide specific overrides.

Parameters
headerAn output stream where the virtual function declaration will be written.
implAn output stream where the function implementation will be written.
visitorTypeA string representing the name of the visitor class.
nodeTypeA string representing the type of the node being visited.
Precondition
The header and impl streams must be open and in a writable state.
Postcondition
The header stream will contain a new virtual function signature, and the impl stream will contain the function body calling visitDefault.
Note
This function is used during code generation processes to ensure consistency between header and implementation files when adding new node types to a visitor.
