Copies the end file information from a source node to a destination node.

This function synchronizes the end-of-construct file information (filename, line, and column) from a source node to a destination node. If the destination node is identified as an OpenMP body statement, the function redirects the source to the body's end file info. The function performs a deep copy of the file information if the source and destination locations differ, ensuring that the destination's end-of-construct metadata matches the source.

Parameters
srcThe source node from which the end file information is to be retrieved.
destThe destination node that will receive the updated end file information.
oaA pointer to the OmpAttribute associated with the operation, used for potential preprocessing information retrieval.
Returns
Returns true if the end file information is already identical or if no copy was necessary; otherwise, returns the value of the result variable (which is initialized to false in this implementation).
Precondition
src and dest must not be null.
src and dest must be instances of SgLocatedNode or be able to be cast to SgLocatedNode to access file information.
Postcondition
The destination node's end-of-construct file information will match the source node's end-of-construct file information if a copy was performed.
If a new Sg_File_Info is created, the previous end-of-construct file information in the destination node is deleted to prevent memory leaks.
Note
This function contains specific logic for handling OpenMP body statements.
There is a known limitation regarding Fortran language support for accurate comment line number adjustment, which is currently marked for future implementation.

Copies file location information from a source node to a destination node.

This function synchronizes the file information (filename, line number, and column) from a source SgNode to a destination SgNode. It is specifically designed to preserve the original metadata of SgPragma or Fortran comments during transformations. The function performs a deep copy of the start-of-construct information. If the destination node already contains file information, that information is deleted to prevent memory leaks before the new information is assigned. For Fortran language processing, the function utilizes the preprocessing information from the provided OmpAttribute to adjust the line number to ensure accuracy.

Parameters
srcThe source SgNode from which the file information will be copied. Must be a valid, non-null node and must be an instance of SgLocatedNode.
destThe destination SgNode that will receive the updated file information. Must be a valid, non-null node and must be an instance of SgLocatedNode.
oaA pointer to an OmpAttribute object used to retrieve preprocessing information when processing Fortran code.
Returns
Returns true if the file information is already identical between src and dest, or if src and dest are the same pointer. Returns false if a copy operation was performed (though the internal result variable is initialized to false).
Precondition
src and dest must not be NULL.
src and dest must be instances of SgLocatedNode.
If the language is Fortran, oa and oa->getPreprocessingInfo() must not be NULL.
Postcondition
The destination node's start-of-construct information will match the source node's start-of-construct information.
The previous file information in the destination node is deleted.
Note
This function uses ROSE_ASSERT to validate the integrity of the nodes and the validity of the file information pointers.

Parses OpenMP directives within Fortran source files.

This function iterates through all located nodes in a given Sage source file to identify and parse OpenMP directives formatted as Fortran-style comments (e.g., !$omp). It specifically handles the complexities of Fortran line continuations using the '&' character, which may appear at the end of a line or as a marker for a second line. The implementation merges lines that are part of a continuous directive, removes unnecessary characters, and uses the omp_fortran_parse utility to extract OpenMP attributes.

Parameters
sageFilePtrA pointer to the SgSourceFile representing the source file to be parsed.
Precondition
sageFilePtr must be a valid, non-null pointer to an SgSourceFile object.
Postcondition
OpenMP attributes found in the source file are parsed and added to the global omp_comment_list, and associated metadata is attached to the corresponding SgLocatedNode.
Note
The function relies on the existence of SgLocatedNode objects within the provided source file and assumes that preprocessing information is attached to these nodes.
The parsing logic accounts for various line continuation scenarios, including cases where source comments might follow a continuation character.

This function iterates through all located nodes in a given Sage source file to identify and parse Fortran-style OpenMP directives (e.g., !$omp). It specifically handles the complexities of Fortran line continuations using the '&' character, where a directive might span multiple lines. The algorithm identifies preprocessing information attached to nodes, checks for OpenMP sentinels, merges lines that are part of a continuation sequence, and removes extraneous comments. Once a complete, non-continued directive is reconstructed, it invokes the OpenMP parser to create attribute objects.

Parameters
sageFilePtrA pointer to the SgSourceFile representing the source code to be parsed.
Precondition
sageFilePtr must be a valid, non-null pointer to an SgSourceFile object.
Postcondition
The function populates the global omp_comment_list with parsed OmpAttribute objects and updates the preprocessing information within the SgNodes where applicable.
Note
The function relies on the existence of NodeQuery::querySubTree to locate nodes and omp_fortran_parse to perform the actual directive parsing.
The handling of line continuations is designed to manage cases where the '&' character is used both for standard line continuation and as a marker for the start of a second line.
