void IncludeFileGraph::graph_include_files ( SgIncludeFile * includeFile)

Recursively generates a DOT graph representation of include file dependencies.

This function traverses the hierarchy of include files starting from a given SgIncludeFile node. It constructs a directed graph in DOT format, representing relationships between include directives, their associated source files, parent include files, and nested include files. The function uses a depth-first traversal approach and maintains a set of visited nodes (graphNodeSet) to prevent infinite loops in the case of circular dependencies.

For each unique include file encountered, the function generates a DOT node with a label containing metadata such as the filename, the name used in the include directive, directory prefixes, and whether the file is a system include. It also applies specific colors to nodes based on properties like whether the file is an application file, a system include, or requires unparsing. Edges are created to represent the "file" relationship (to SgSourceFile), the "parent" relationship, and the "include" relationship (to nested SgIncludeFile objects).

Parameters
includeFileA pointer to the SgIncludeFile node from which the graph traversal begins.
Precondition
includeFile must not be NULL.
Postcondition
The function writes DOT format edge and node definitions to the associated file stream and updates the internal graphNodeSet with newly discovered include files.
Note
The function relies on the existence of a file stream (implicitly available in the class scope) to output the graph data.
The function uses if define ifdef ifndef endif elif pragma directives for conditional compilation of debug prints and specific graph features.

void IncludeFileGraph::graph_include_files ( SgProject * project)

Recursively traverses a project and its associated files to generate a DOT graph of include relationships.

This function performs a depth-first traversal of the file hierarchy starting from a given SgProject. It identifies all files associated with the project via the SgFileList and creates graph nodes and edges in a DOT format. The function tracks visited nodes using graphNodeSet to prevent infinite loops in the case of circular dependencies. For each file encountered, it generates a directed edge from the parent project/file to the child source file and then recursively calls itself to process the included files.

Parameters
projectA pointer to the SgProject object representing the root of the traversal.
Precondition
The project pointer must not be null.
Postcondition
The function updates the internal file stream with DOT-formatted graph definitions and populates the graphNodeSet with the visited project/file nodes.
Note
The function relies on the define DEBUG_HEADER_GRAPH_SUPPPORT macro for debug logging.
The implementation uses StringUtility::numberToString to convert pointers to string representations for unique node identification in the graph.

void IncludeFileGraph::graph_include_files ( SgSourceFile * sourceFile)

Recursively traverses and generates DOT graph notation for file include dependencies.

This function performs a depth-first traversal of the include hierarchy starting from a given source file. It identifies unique source files, creates graph nodes in a DOT format, and establishes directed edges representing the association between a source file and its associated include file. The function uses a set of previously visited nodes to prevent infinite recursion in the presence of circular dependencies.

Parameters
sourceFileA pointer to the SgSourceFile object representing the starting point of the include traversal.
Precondition
sourceFile must not be NULL.
Postcondition
If the sourceFile has not been visited, a new node is added to the graph output and an edge is created to its associated include file (if one exists). The function may recursively call itself for associated include files.
Note
The function relies on include DEBUG_HEADER_GRAPH_SUPPPORT for debug logging.
The output is written to an internal file stream (member variable file).
The function uses StringUtility::numberToString to generate unique identifiers for nodes based on the memory address of the SgSourceFile objects.
