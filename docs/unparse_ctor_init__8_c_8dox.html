Determines if a constructor initializer is associated with a C++11 initialization list.

This function determines whether a given constructor initializer object refers to a member function declaration named "initializer_list". It inspects the declaration associated with the provided SgConstructorInitializer and compares its name against the specific string "initializer_list". The implementation utilizes if DEBUG__isAssociatedWithCxx11_initializationList for trace logging during execution.

Parameters
con_initA pointer to the SgConstructorInitializer to be inspected.
Returns
True if the initializer is associated with a member function named "initializer_list", false otherwise.
Precondition
con_init may be NULL; the function handles NULL pointers gracefully.
Postcondition
The return value indicates the presence of a C++11-style initializer list association without modifying the input con_init.
Note
The function relies on the name of the member function declaration retrieved via con_init->get_declaration().

bool trimCtorNameQual ( std::string & qualifier)

Removes the trailing double colon from a constructor name qualifier string.

This function checks if a given string representing a type qualifier ends with the :: delimiter. If the string ends with ::, the function removes these two characters and returns false, indicating that the constructor name does not require separate unparsing. If the string does not end with :: (or if specific compiler-based logic dictates no trimming is necessary), the function returns true.

The implementation includes conditional logic based on preprocessor directives such as ifdef USE_CMAKE, ifdef CMAKE_COMPILER_IS_GNUCXX, and ifdef CMAKE_COMPILER_IS_CLANG to handle compiler-specific edge cases regarding how scope resolution is parsed.

Parameters
qualifierA reference to a std::string containing the qualifier to be trimmed. The string is modified in-place.
Returns
Returns false if the trailing :: was successfully removed from the string. Returns true if no trimming was performed (either because the string was empty, the compiler logic bypassed the trim, or the string did not end with ::).
Precondition
The string qualifier should have a size of at least 2 if it is expected to contain a trailing :: to be removed, as the function uses ROSE_ASSERT(size >= 2).
Postcondition
If the function returns false, the qualifier string will be shorter by exactly two characters. If the function returns true, the qualifier string remains unchanged (unless it was empty).
