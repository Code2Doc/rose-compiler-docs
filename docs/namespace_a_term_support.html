SgFunctionCallExp * ATermSupport::buildIntrinsicFunctionCallExp_nfi ( const std::string & name,
SgExprListExp * params,
SgScopeStatement * scope )

Constructs an expression representing a call to a predefined intrinsic function.

This function creates a function call expression for specific intrinsic functions recognized by the system. It determines the appropriate return type based on the provided function name. For a predefined set of intrinsics (such as BYTEPOS, MAXINT, MININT, etc.), it assigns an integer type. For others like FLOATRELPRECISION or FLOATUNDERFLOW, it assigns a double type. If the name does not match any known intrinsic, it defaults to a void type. The function also handles the initialization of parameters and scope if they are provided as null.

Parameters
nameThe string identifier of the intrinsic function to be called.
paramsA pointer to an expression list representing the arguments passed to the function. If null, a new empty expression list is created.
scopeA pointer to the scope statement in which the function call expression will reside. If null, the top of the current scope stack is used.
Returns
A pointer to the newly created SgFunctionCallExp representing the intrinsic call, or nullptr if the return type could not be determined or the call expression creation failed.
Precondition
params and scope should ideally be non-null, though the function provides defaults.
Postcondition
The returned expression, if not null, will have its source position set via SI::setSourcePosition.
Note
This function relies on the SB (SageBuilder) and SI (SageInterface) namespaces for building expressions and setting source positions.

SgVarRefExp * ATermSupport::buildIntrinsicVarRefExp_nfi ( const std::string & name,
SgScopeStatement * scope )

Creates a variable reference expression for an intrinsic variable.

This function constructs a variable reference expression representing an intrinsic variable within a specified scope. It utilizes the SageBuilder to create the expression based on the provided name and scope.

Parameters
nameThe string identifier of the intrinsic variable to be referenced.
scopeThe scope statement in which the variable reference expression is to be created.
Returns
A pointer to the newly created SgVarRefExp object. Note that the type of the expression is currently set to SgUnknownType.
Precondition
The scope pointer must be a valid, non-null pointer to an SgScopeStatement.
Postcondition
A new SgVarRefExp instance is returned, associated with the provided name and scope.
Note
The type for the expression is currently SgUnknownType; a more specific type implementation is planned for future updates.
