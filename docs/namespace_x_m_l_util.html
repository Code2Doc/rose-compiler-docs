ostream & XMLUtil::operator<< ( ostream & o,
const XMLCh *const s )

Overloads the stream insertion operator for XMLCh strings.

This function provides a convenient way to stream XMLCh (XML character) sequences directly into an output stream. It achieves this by first converting the XMLCh sequence into a standard string representation using the toString function and then inserting that string into the provided output stream.

Parameters
oThe output stream where the string representation will be inserted.
sA constant pointer to a constant XMLCh character sequence to be streamed.
Returns
A reference to the modified output stream o, allowing for chained stream operations.
Precondition
The output stream o must be in a valid state and ready for writing.
Postcondition
The output stream o will contain the string representation of s.
Note
This operator relies on the existence of a toString function capable of converting XMLCh* to a streamable string type.

ostream & XMLUtil::operator<< ( ostream & o,
const XMLElem & e )

Overloads the stream insertion operator to provide a string representation of an XMLElem.

This function facilitates the logging or printing of an XML element's metadata to an output stream. It iterates through the attributes associated with the provided XMLElem and formats them into a readable string containing the element name and a comma-separated list of its attributes, including their names, values, and types.

Parameters
oThe output stream where the formatted string will be written.
eThe XMLElem object to be serialized into the stream.
Returns
A reference to the modified output stream o to allow for chained stream operations.
Precondition
The XMLElem object e must be a valid, initialized instance.
Postcondition
The output stream o will contain a formatted string representing the element and its attributes.
Note
The output format follows the pattern: [element] 'name' := (attr1 = 'val1' : type1, attr2 = 'val2' : type2).

Overloads the stream insertion operator to print an XML node tree.

This function provides a convenient way to serialize an XML node structure to an output stream. It utilizes an internal XMLTreePrint object to perform a depth-first traversal of the provided XML node tree, formatting the output as a human-readable XML string.

Parameters
oThe output stream where the XML content will be written.
rootA pointer to the root node of the XML tree to be printed.
Returns
A reference to the same output stream o to allow for chained stream operations.
Precondition
The root pointer must be valid. If root is null, the behavior depends on the implementation of the traverse method within XMLTreePrint.
Postcondition
The output stream o will contain the string representation of the XML tree starting from root.
Note
This operator relies on the XMLTreePrint class to handle the actual traversal and formatting logic.

string XMLUtil::toString ( const XMLCh *const s)

Convert an XMLCh string to a C++ string.

Converts an XMLCh pointer to a standard C++ string.

This function performs a type cast of the input XMLCh pointer to a const char pointer and constructs a std::string object from the resulting character sequence. It is intended to facilitate the conversion of XML-specific character types to standard string representations for easier manipulation in C++.

Parameters
nameA pointer to a constant XMLCh character array to be converted.
Returns
A std::string containing the character sequence represented by the input name.
Precondition
The input pointer name must point to a null-terminated character array compatible with a C-style string cast.
Postcondition
Returns a new string object that is a copy of the characters pointed to by name.
Note
This function assumes that the memory pointed to by name can be safely cast to const char* and that the sequence is null-terminated.
