Converts a token type integer ID into its corresponding string representation.

Convert Sawyer::Language::Clexer::TokenType enum constant to a string.

This function performs a mapping from a 64-bit integer identifier to a human-readable string constant representing a specific token type within the Clexer lexer. It uses a switch-case mechanism to evaluate the input ID and return the appropriate string literal.

Parameters
iThe 64-bit integer representing the token type ID to be converted.
Returns
A pointer to a constant character string representing the token name. Returns "TOK_EOF" for 0, "TOK_LEFT" for 1, "TOK_RIGHT" for 2, "TOK_CHAR" for 3, "TOK_STRING" for 4, "TOK_NUMBER" for 5, "TOK_WORD" for 6, "TOK_CPP" for 7, "TOK_COMMENT" for 8, and "TOK_OTHER" for 9. Returns an empty string "" if the provided ID does not match any known token type.
Precondition
The input parameter i should ideally correspond to a valid token ID defined within the lexer's logic.
Postcondition
The returned pointer points to a static string literal that remains valid for the lifetime of the program.
Note
This function does not perform bounds checking on the input; it simply defaults to an empty string for unrecognized values.

Converts an integer token ID into a human-readable string representation, optionally stripping a prefix.

Convert Sawyer::Language::Clexer::TokenType enum constant to a string.

This function retrieves the string representation of a token type using the overloaded TokenType(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a descriptive type name and the integer value cast to a string via boost::lexical_cast. Additionally, if the resulting string starts with the provided strip prefix, that prefix is removed from the beginning of the string.

Parameters
iThe 64-bit integer representing the token type ID.
stripA string prefix that, if found at the start of the token type string, should be removed.
Returns
A string representing the token type, potentially modified by the stripping process.
Precondition
The parameter i must be a valid token identifier.
Postcondition
The returned string will not contain the 'strip' prefix if the original string started with it.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
