template<class Node>
void OpenAnalysis::BuildCFG ( AstInterface & fa,
const AstNodePtr & head,
BuildCFGConfig< Node > & ng )

Constructs a Control Flow Graph (CFG) from an AST node.

This function facilitates the translation of an Abstract Syntax Tree (AST) node into a ROSE-compatible Control Flow Graph representation. It utilizes a wrapper mechanism to encapsulate the AST node and invokes a translation utility to populate the provided configuration object with the resulting CFG structure.

Parameters
faA reference to the AstInterface used for AST traversal and analysis.
headA pointer to the root AstNode from which the CFG construction begins.
ngA reference to a BuildCFGConfig object that will be populated with the constructed CFG information.
Precondition
The head pointer must not be null and must point to a valid AstNode.
Postcondition
The ng object will contain the translated CFG information derived from the head node.
Note
This function relies on the ROSE_CFG_Wrap utility and the OA2ROSE_CFG_Translate translation logic.

template<class Node>
void OpenAnalysis::OA2ROSE_CFG_Translate ( ROSE_CFG_Wrap & wrap,
BuildCFGConfig< Node > & ng )

Translates a Control Flow Graph (CFG) from OpenAnalysis format to a ROSE-based representation.

This function performs a structural translation of a CFG. It iterates through the nodes of the source graph using a Dominator Frontier Search (DFS) iterator. For each node in the original graph, it creates a corresponding node in the target graph and migrates all associated statements by converting them from a StmtHandle to an AstNodePtr via the SageIRInterface.

After the node and statement translation phase, the function performs a second pass to reconstruct the control flow edges. It iterates through the outgoing edges of each source node, determines the edge type (TRUE_EDGE, FALSE_EDGE, or ALWAYS), and creates the corresponding edge in the target graph between the mapped source and sink nodes.

Parameters
wrapA reference to a ROSE_CFG_Wrap object containing the source OpenAnalysis CFG.
ngA reference to a BuildCFGConfig object used to manage the creation of the target graph nodes, statements, and edges.
Precondition
The wrap object must contain a valid, non-null CFG.
The ng object must be properly initialized to handle node and edge creation.
Postcondition
The target graph represented by ng will contain a structural replica of the CFG found in wrap, with mapped nodes and edges.
Warning
This function assumes that all edges in the source graph are either of type CFG::TRUE_EDGE or CFG::FALSE_EDGE, or defaults to CFG::ALWAYS. If an unexpected edge type is encountered, a ROSE_ASSERT failure will occur.
Note
The translation process relies on the mapping between CFG::Node and the template type Node, which is maintained internally via a PtrMapWrap.
