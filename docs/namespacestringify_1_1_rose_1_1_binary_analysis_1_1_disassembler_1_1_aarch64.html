Formats and strips a prefix from a string representation of a mode.

Convert Rose::BinaryAnalysis::Disassembler::Aarch64::Mode enum constant to a string.

This function retrieves a string representation of a mode for a given integer ID using an overloaded Mode(int64_t) function. If the resulting string is empty, it constructs a fallback string containing a specific class-path-like identifier and the integer value. Finally, it checks if the string starts with the provided strip prefix and removes it if a match is found.

Parameters
iThe 64-bit integer identifier representing the mode to be formatted.
stripA string representing the prefix to be removed from the beginning of the formatted mode string.
Returns
A string containing the formatted mode, with the specified prefix removed if it was present at the start of the string.
Precondition
The parameter i must be a valid 64-bit integer.
Postcondition
The returned string will not start with the content of the strip parameter if the original string started with that prefix.
Note
This function relies on boost::lexical_cast for string conversion and boost::starts_with for prefix detection.
