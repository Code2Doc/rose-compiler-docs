void generateFullTree ( DisplayTreeNode * node,
int height )

Recursively generates a tree structure of a specified height with predefined node labels.

This function populates a tree structure starting from a given root node. It uses a recursive depth-first approach to create a tree where each node at a given level spawns a fixed set of four children: two nodes labeled "Short Entry", one node labeled "LongLongLongLongLong Entry", and one node labeled "a". The recursion continues until the specified height reaches zero.

Parameters
nodeA pointer to the DisplayTreeNode that serves as the parent for the newly generated children.
heightThe remaining depth to which the tree should be expanded. A height of 0 stops the recursion.
Precondition
node must not be a null pointer.
Postcondition
The tree structure under the provided node is expanded to the specified height, with each node containing exactly four children (unless height is 0).
Note
The function uses a hardcoded set of strings for node names.
The commented-out section in the implementation suggests an alternative loop-based approach for generating a variable number of children was previously considered.

DisplayTreeNode * generateLeftBTree ( int length,
QGraphicsScene * scene )

Generates a left-skewed B-Tree structure within a graphics scene.

This function constructs a tree-like hierarchy of DisplayTreeNode objects. The algorithm iterates for a specified number of levels (length), creating a chain of nodes where each node contains a "left" child, two "longEntry" children, and a "right" child. The traversal follows the "left" path to extend the depth of the tree, effectively creating a left-heavy structure. Each node is instantiated and associated with the provided QGraphicsScene.

Parameters
lengthThe number of levels/iterations to perform in the tree construction.
sceneA pointer to the QGraphicsScene where the tree nodes will be visually or logically hosted.
Returns
A pointer to the root DisplayTreeNode of the newly created tree.
Precondition
The scene pointer must be valid and not null to ensure proper initialization of the root node.
Postcondition
A tree structure of depth 'length' is created in the scene, and the caller is responsible for the memory management of the returned root and its descendants.
Note
The function uses dynamic memory allocation with 'new'. Ensure appropriate cleanup to prevent memory leaks.

DisplayTreeNode * generateSmallInterleaving ( QGraphicsScene * scene)

Generates a small, predefined tree structure of DisplayTreeNodes.

This function constructs a hardcoded hierarchical tree of DisplayTreeNode objects. The structure starts with a root node associated with the provided QGraphicsScene, which then branches into 'left' and 'right' child nodes. The 'left' node further contains a 'leftleft' child, and the 'right' node contains a 'rightright' child. Each node is created using the addChild method of its parent.

Parameters
sceneA pointer to the QGraphicsScene that will be associated with the root node.
Returns
A pointer to the root DisplayTreeNode of the newly created tree structure.
Precondition
The scene pointer must be valid and not null to ensure the root node is correctly initialized.
Postcondition
A new tree of DisplayTreeNode objects is allocated on the heap. The caller is responsible for managing the memory of the returned root node and its descendants.
Note
The nodes are created using the 'new' keyword, so manual memory management or a smart pointer strategy is required to prevent memory leaks.
