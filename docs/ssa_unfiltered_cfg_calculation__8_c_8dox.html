Retrieves a set of all variable names that are either defined or used within the CFG.

This function aggregates all variable names involved in the SSA Unfiltered Control Flow Graph (CFG). It performs two primary passes:

  1. It iterates through the reaching definitions table to collect all variables that are considered defined at specific CFG nodes.
  2. It iterates through the AST node variable references to collect all used variables. For every variable reference found, the function also includes all its prefixes (e.g., for a variable 'p.x.y', it inserts 'p', 'p.x', and 'p.x.y' into the set) to ensure hierarchical dependencies are captured.
Parameters
defsA map associating CFG nodes with the names of variables defined within them.
usesA map associating AST nodes with the references to variables used within them.
localDefTableA mapping from CFG nodes to their respective reaching definition tables, used to identify all variables reaching specific points in the program.
Returns
A set of SSA_UnfilteredCfg::VarName containing all identified used and defined variable names.
Precondition
The input maps and tables must be valid and contain consistent CFG node references.
Postcondition
Returns a set containing the union of all variables found in the reaching definitions and all prefixes of variables found in the AST usage map.
Note
The function uses ROSE_ASSERT to ensure that any variable name extracted from an SgVarRefExp is not an empty name.
