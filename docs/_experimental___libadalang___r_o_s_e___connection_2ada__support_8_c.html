SgSourceFile * file )

Orchestrates the translation of Ada source files to ROSE Sg format using Libadalang.

This function serves as the main entry point for the Libadalang-to-ROSE translation process. It initializes the ROSE environment, parses command-line arguments to configure GNAT and ASIS compiler flags, and locates necessary Ada source files and system include directories. The function sets up an Ada analysis context, identifies all relevant compilation units (including dependencies and specification files), and invokes the translation engine. It handles the complexities of GNAT environment variables, such as include% GNAT_HOME, and manages the discovery of Ada library files.

Parameters
argsA vector of strings containing command-line arguments, used to extract include paths (via -I) and GNAT-specific compiler options.
fileA pointer to the SgSourceFile object representing the primary Ada source file to be processed.
Returns
An integer status code where 0 indicates successful translation and 1 indicates a failure (e.g., missing GNAT_HOME, translation error, or unhandled exception).
Precondition
The environment variable GNAT_HOME must be set and point to a valid GNAT installation.
Postcondition
The input Ada source file (and its dependencies) is translated into the ROSE Sg representation, provided no fatal errors occurred. The global ROSE assertion behavior is restored to its original state.
Warning
If GNAT_HOME is not found in the environment, the function will log a fatal error and return 1.
Note
The function performs recursive discovery of Ada files in the source directory and system include paths. It also handles the conversion of file path naming conventions (e.g., replacing '-' with '.') when locating corresponding Ada specification (.ads) files for body (.adb) files.
