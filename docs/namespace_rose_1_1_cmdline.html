void Rose::Cmdline::NormalizeIncludePathOptions ( std::vector< std::string > & argv)

Convert -I <path> to -I<path>.

Normalizes command-line arguments by formatting include path options.

This function iterates through a vector of command-line arguments to identify and standardize include path flags (e.g., -I). It handles cases where the path is provided as a separate argument (e.g., "-I", "path") or attached to the flag (e.g., "-Ipath"). On Windows platforms (defined by ifdef _MSC_VER), the function ensures that the paths are enclosed in double quotes to handle spaces correctly. It also performs a sanity check to verify if the provided path exists as a directory, issuing a warning if the path is invalid.

Parameters
argvA reference to a vector of strings representing the command-line arguments to be processed and normalized.
Warning
If an '-I' flag is found without a subsequent path argument, the function prints a fatal error message and terminates the program using exit(1).
Precondition
The input vector argv should contain valid command-line arguments.
Postcondition
The function returns a new vector of strings containing the normalized arguments, where include paths are properly formatted and potentially quoted for Windows compatibility.
Note
The function uses boost::filesystem to validate directory existence.
The function uses Rose::ir_node_mlog for conditional debug logging.

Processes the "-rose:keep_going" command line option to set the global keep-going flag.

This function inspects the provided command line arguments for the presence of the "-rose:keep_going" option. If the option is detected, the function updates the internal state of the SgProject object and sets the global Rose::KeepGoing::g_keep_going flag to true. If the project's verbosity level is 1 or higher, an informational message is printed to the standard output.

Parameters
projectA pointer to the SgProject instance that will be updated with the keep-going status.
argvA vector of strings containing the command line arguments to be parsed.
Precondition
project must not be a null pointer.
Postcondition
If the "-rose:keep_going" option is found in argv, project->set_keep_going(true) is called and Rose::KeepGoing::g_keep_going is set to true.
Note
This function relies on CommandlineProcessing::isOption to parse the argument vector.

◆ StripRoseOptions()

void Rose::Cmdline::StripRoseOptions ( std::vector< std::string > & argv)

Removes Rose-specific command-line options from the provided argument vector.

Removes "-rose:" options, or transforms them into their associated compiler options.

For example, 

-rose:java:classpath "/some/class/path"

becomes

-classpath "/some/class/path"

Whereas, this ROSE-only option is completely removed: 

-rose:verose 3

This function iterates through the command-line arguments stored in the argv vector and strips out options that are specific to the Rose framework. It achieves this by delegating the stripping process to specialized unparsers for different language-specific contexts, including Unparser, Fortran, Java, and Ada.

Parameters
argvA reference to a vector of strings representing the command-line arguments to be processed and modified in-place.
Precondition
The argv vector must be properly initialized and contain valid command-line arguments.
Postcondition
The argv vector will no longer contain any Rose-specific options that were identified by the underlying language-specific unparsers.
Note
This function relies on the implementation of StripRoseOptions within the Cmdline::Unparser, Cmdline::Fortran, Cmdline::Java, and Cmdline::Ada namespaces.
